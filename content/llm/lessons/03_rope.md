# 位置编码：RoPE 在转什么

自注意力本身不认“第几个字”。同一组内容向量打乱次序，分数可以不变。要让模型知道前后，必须把位置写进表示里。

早期做法是另加一段位置向量。RoPE（旋转位置编码）换了一种写法：按位置把成对的坐标旋转一个角度。相对位置于是出现在两次旋转的差里。两个位置离得远，高频分量转得更多，点积往往更小。这就是“近处更相关”的一种实现，不是注意力自己长出来的。

`base`（常见 10000）和头维数决定每对坐标转多快。改 base，远程依赖的衰减曲线会变。这和“上下文窗口突然变长”时要不要重调哪一类超参是同一件事。

## 学

能画出一件事就够：同一对坐标，位置 0 和位置 8，旋转角差在哪；距离从 1 走到 8，相对点积往哪边掉。讲不清“转”和“加”的差别，后面看 Llama 类模型的配置会撞墙。

## 玩

默认 `dim=8`、`max_distance=4`。先跑，看 `decay` 里距离和点积。把 `base` 从 10000 改到 500，再跑一次。比的是衰减变陡还是变缓，不是绝对值漂不漂亮。
