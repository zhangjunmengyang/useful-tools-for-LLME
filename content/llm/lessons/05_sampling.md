# 下一个 token 怎么抽

模型先给出每个词表项的 logit。这还不是概率。后面通常有三步：除以温度、按 top-k 或 top-p 丢掉一部分、再做 softmax 抽样。

温度大于 1，分布变平，冷门 token 更容易出现。温度靠近 0，分布变尖，几乎总抽最大的那个。top-k 只留分数最高的 k 个。top-p 从高到低累加概率，切到覆盖 p 为止。两套截断可以一起用，顺序以实现为准，课里用工具里的那套。

“更有创意”如果只是把温度拧大，也会把胡话的概率一起拧大。要约束胡话，截断候选往往比继续加热更直接。

## 学

给三个 logit：2、1、0。手算温度 1 和温度 0.5 的概率，再对工具。对上了，再把 top-k 设成 2，看最小的那个是否被丢掉。

## 玩

默认样本就是 A / B / C。先跑温度 1。再改温度 0.2 和 1.8 各跑一次。最后把 top_p 设成 0.7。每次只看概率表，不要同时拧三个旋钮。
