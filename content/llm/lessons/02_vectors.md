# 向量空间里的远近

嵌入（embedding）把一段文本或一个 token 写成一组数字。后面的注意力、检索、分类，多数是在比这些数字的远近。

常用两种比法。点积看“投影有多大”。余弦把长度抹掉，只看方向。同一组向量，换度量，最近邻可能换人。所以写“这两个很像”之前，先写用的是哪一种。

教学里常拿三个向量举例：查询、一个近的、一个远的。近不是因为标签写成 near，而是因为夹角小。标签可以骗人，数字不会。

这课不训练嵌入模型。只把已经算好的坐标丢进同一个函数，看矩阵怎么排。真正的模型输出也可以事后丢进来比，接口一样。

## 学

拿一张纸写下三个二维或三维向量，手算它们两两的余弦。再对一下工具给出的矩阵。对不上，先查是不是把点积当成了余弦。

## 玩

默认样本是三条三维向量，标签是 query / near / far。先跑一遍看矩阵。再改 `near`，让它和 `far` 一样，看最近邻是否换人。数字改完再跑，不要只改标签。
