# 第 24 课：用 14 个模拟工作日给 Agent 办一场缩小版上岗

> 类型：毕业设计（14 日模拟为机制实验；记忆与技能库为实战；每日权重更新为加分）<br>
> 建议周期：4-7 天（不要和第 23 课压进同一周）<br>
> 硬件：主线 CPU + 本地小模型或 API；权重更新需要单卡，标加分<br>
> 锚定仓库：[letta-ai/letta](https://github.com/letta-ai/letta)（记忆，现文档见 [docs.letta.com/quickstart](https://docs.letta.com/quickstart/)）；技能库复用 [第 21 课](21_voyager_skill_library.md) 机制；可选 on-policy 更新对照 [SakanaAI/rl-razor-mnist](https://github.com/SakanaAI/rl-razor-mnist) 与 [第 20 课](20_seal_rl_razor.md)<br>
> 产物：毕业报告（协议、对照、遗忘数字、失败案例、离梁文峰说的那种持续学习还差什么）

## 1. 这一课做什么

这是第六幕最后一课，也是整门课的终点。不是再开一篇展望。第 23 课刚证明：自我生成数据若没有验证筛选，错误会强化自己；「自己出下一版」仍在猜想栏。这一课把已经造过的零件装进一份会变的工作：记忆写入、技能入库、可选的小步权重更新，看一个 Agent 在连续多天里能不能越用越熟，并且周一学的周五还在。

梁文峰转写里的员工类比是本课的主类比，第 04、16 课已经用过，这里不再抒情，只把它收成可测的题。原话要点：招一个员工要花两个月熟悉公司和同事；你说「把小王叫过来」，他知道小王是谁；现在的 AI 没有那两个月，你得把全部上下文每次重说一遍。转写未获 DeepSeek 官方确认。课内把「两个月」缩成 14 个模拟工作日，把「公司」缩成一份课内环境：日历、员工名录、会变的座位、会新增的内部工具。真等两个月、开放世界、真实同事，本课都没有。

上一课留下的零件：自编辑必须经过筛选，否则越训越错。本课允许的学习通道只有三条，而且第三条是加分：

1. 记忆写入（外挂日记和名录，第 13 课）。
2. 技能入库（成功的流程写成可再调用的脚本，第 21 课）。
3. 每日结束时，用当天成功轨迹做一次小步权重更新（第 20 课 on-policy 方向；资源不够就关掉）。

对照是冻结 Agent：同一套提示词和工具，14 天里不写记忆、不入库、不改权重。冻结组用来回答「越用越熟」到底有没有发生。没有冻结组，分数涨了也可能只是后几天的题变简单了。

贯穿主干在这一课不再换零件，而是把整条循环跑满 14 天：新经验进来，先决定写到记忆、技能库还是（可选）权重，再决定覆盖还是追加，写完立刻测新任务和旧任务，第 14 日再测还能不能继续学。做完你手里应有一份毕业报告，必须含第 03 课协议下的数字、至少两个失败案例，以及最后一节：整门课学完你有什么，离梁文峰说的那种持续学习还差什么。缺失败案例或把 14 日模拟写成「已经解决持续学习」，报告不算通过。

术语速查（前面课讲过的只标课次）：

| 术语 | 一句解释 |
|---|---|
| 冻结 Agent | 14 天内不写记忆、不入库、不改权重的对照体 |
| 记忆块 | Letta 式外挂档案：名录、座位、偏好；权重可以不动（第 13 课） |
| 技能库 | 验证过的流程脚本抽屉，下次检索再跑（第 21 课） |
| 小步权重更新 | 用当天成功轨迹做一次靠近原模型的更新；本课标加分 |
| 座位冲突 | 同一人新旧座位并存或覆盖失败，叫人就会找错地方 |
| 新工具上手步数 | 内部工具第一次出现后，做到正确调用所需的尝试次数 |
| 旧任务回放 | 把前几天已测过的题在后面某天重测，看周一的是否还在 |
| 预衡评估（prequential） | 先对今天的题作答再允许学习，避免「先看答案再考试」（第 03 课） |
| 毕业报告 | 本课唯一交付物：协议、对照、遗忘、失败、「还差什么」 |
| 开放世界 | 未写进状态表的新同事、新工具、未写明惯例；本课 14 日模拟没有 |

## 2. 问题

一个会用工具的语言模型，在连续工作日里看起来越来越顺手，常常只是上下文里堆了更多今天的日志。把日志撤掉，它还记不记得小王坐哪、发票脚本怎么跑、上周那条座位变更是覆盖还是并存？这是第 04 课「叫小王」在多日、多通道上的版本。

本课要分开测的是四类在岗能力有没有真的留下，聊天是否流畅不算数：

- 事实：谁在哪、谁今天请假、谁是新同事。
- 冲突事实：座位表改了之后，旧座位还在不在记忆里抢答。
- 流程技能：内部工具的惯用法，能不能写成可再调用的脚本，而不是每天从零试。
- 新工具：日历中途出现的命令，上手步数有没有随「会学习」下降；冻结组应几乎不下降。

第 16 课的分流结论在这里直接变成通道开关。那张 4×4 必须再看一眼：

```text
            RAG   记忆   编辑   权重
事实         1     1      1      0
文档         1     1      0      0
流程         0     0      0      1
规则         0     0      0      1
```

14 日主线打开的是「事实 → 记忆」和「流程 → 技能库」。技能库是 [第 21 课](21_voyager_skill_library.md) 的可执行外存：矩阵里「流程 / 权重 = 1」说的是只存文本不够；OPEN_PROBLEMS 第 2 条补了一句，可执行形态下权重仍可以不变。规则那一行（计分、优先级、岗位直觉）主线没有写进去。权重列仍是加分。加分通道打开时，必须同时测旧任务，因为第 15 课和第 23 课已经表明：乱更新会忘，也会把错的写进去。成功轨迹才允许进权重，这是第 23 课筛选在在岗场景里的对应物。

环境必须非平稳，否则 GDumb 式「把样本存下来重训」会显得一切都很容易。本课故意做三件不干净的事：座位在 Day 5 和 Day 11 改；Day 8 来新同事；Day 6 和 Day 10 上新内部工具。没有任务边界公告。Agent 要自己发现世界变了。

14 日不是 60 日。转写里的两个月包含同事默契、未写进文档的流程、跨项目偏好。本课覆盖不了那些。报告里必须把这个差距写出来，不能用「14 日过关」代替「两个月上岗」。

## 3. 准备

- 读过 [第 03 课](03_cl_evaluation.md) 的准确率矩阵、遗忘、BWT、预衡评估。毕业报告用那套协议，不另发明平均分。
- 读过 [第 04 课](04_not_just_rag.md) 的「上下文 / 检索 / 权重」和 [第 16 课](16_when_weights_must_move.md) 的四类经验分流。
- 记忆通道按 [第 13 课](13_external_memory.md) 和当前 Letta 文档；技能通道按 [第 21 课](21_voyager_skill_library.md)；数据从环境来按 [第 22 课](22_era_of_experience.md)；自更新筛选按 [第 23 课](23_self_iteration.md)。
- Python 3.10+，能跑 `experiments/run.py`。机制实验不下载模型。
- 实战主线：本地小模型（课程沿用的 SmolLM2-135M 级）或任意对话 API。Letta 当前快速开始是 Node 22.19+ 上的 CLI，不是几年前的 `pip install letta` 单行；以 [Quickstart](https://docs.letta.com/quickstart/) 为准。
- 加分：单卡做每日小步更新。没有卡就把权重通道保持关闭，报告里写「未做」，不要用冻结权重冒充更新过。
- 毕业报告用纯文本或 Markdown 即可，放在你的笔记目录，不提交进课程仓库。文件名建议 `lesson24-hire-report.md`，方便和第 03 课协议模板对照。

## 4. 学习目标

1. 默写北港文具环境的可变零件：名录、两次座位变更、两名新工具上线日、一名新同事入职日。
2. 画出四条对照曲线：冻结 / 只记忆 / 记忆+技能 / 再加权重（最后一条可标未做）。
3. 用第 03 课公式计算平均准确率、遗忘、BWT，并另报新工具上手步数与冲突事实覆盖率。
4. 写出至少两个失败案例：一个来自座位冲突，一个来自新工具或冻结对照。
5. 在报告末页用自己的实验回答：手里有什么，还差什么。差的部分落到 OPEN_PROBLEMS 的七个格子，不许空喊。
6. 填一张「本模拟有 / 真实上岗没有」对照，至少写明：无未写明惯例、无跨月、无开放世界。

## 5. 原理

六个机制。前三个把环境和工作协议钉死，后三个把学习通道钉死。

### 5.1 缩小版公司：日历、名录、座位、工具都是状态

直觉：新员工是在一间会挪桌子、会发新脚本、会来新人的办公室里干活，不是对着一张静态 FAQ 考试。状态不写进环境，Agent 就没法「熟悉公司」。

机制：环境状态 $s_d$（第 $d$ 日， $d=1,\dots,14$）至少含四张表。

- 日历 $C_d$：工作日序号、星期、当天公告（请假、入职、工具上线）。
- 名录 $E_d$：工号、姓名、角色。Day 8 增加周岚 E05。
- 座位 $P_d:\text{工号}\to\text{座位}$。王小旺：Day 1-4 为 A3，Day 5-10 为 B1，Day 11-14 为 C2。陈秋：Day 1-7 为 B2，Day 8-14 为 A1。李响 D4、赵衡 E5 固定；赵衡 Day 9 请假，当天叫他应失败。
- 工具 $U_d$：Day 1-5 只有 `seat_lookup`、`ship_status`；Day 6 起增加 `invoice_draft`；Day 10 起增加 `shift_swap`。工具有固定调用约定（参数名、成功返回码），不在任务文本里把说明书全文塞进每一题。

课内把这家公司叫做北港文具内部运营。姓名沿用第 04 课的「小王」：报告里写王小旺，任务口令可以是「把小王叫过来」。这是教学环境，不是某个真实仓库的官方模拟器。

三层日历不要混报。书面北港协议是毕业报告可以照着出题的那张表。`lesson_24.py` 没有实现这张完整表：它用缩小状态机，第 7 日把小王座位从 A3 覆盖成 B7，第 8 日上线 `nightly_sync`，Day 14 回放 4 道旧探针。浏览器看板是第三套 14 日标签（叫小王、座位变更、新内部工具、新计分规则），「保持」从 1 往下乘。CPU 数字只许引用 `result.json`；按北港书面协议跑的实战日志另记，不得写进课包结果文件。

验证：不看 Agent，先打印 CPU 世界的 $s_1,s_7,s_8$。第 7 日座位必须是 B7，第 8 日工具列表必须含 `nightly_sync`。书面北港表若你自己出题，六天 $s_1,s_5,s_6,s_8,s_{10},s_{11}$ 必须和 5.1 上表一致。环境若写死 14 天座位不变，后面所有「越用越熟」都没有非平稳可学。

类比失效处：真公司还有未写进表的默契、走廊对话、权限系统。本课状态是全可观测的结构化表，只对 Agent 藏起来，对评测器公开。

### 5.2 每天 10 题，先考后学

直觉：如果允许先看今天的标准答案再「学习」再答题，14 日曲线会好看，那是泄漏。新员工是先干活，下班后才整理笔记。

机制：第 $d$ 日有任务序列 $T_d=(q_{d,1},\dots,q_{d,10})$。每题属于四类之一：叫人、查项目事实、调已有工具、调新工具（仅工具上线日及之后出现）。预衡评估：对第 $k$ 题，Agent 只能用 $s_d$ 在环境中的交互结果，以及 $d$ 日开始前已经写入的记忆、技能、权重。答完第 $k$ 题之后，才允许把这一题的轨迹写入当日缓存。当日结束，才允许把缓存刷进记忆、技能库、（可选）权重。

题面不得包含完整名录。允许的观察是：工具返回、环境报错、日历上的一条公告（例如「座位调整已生效」但不给新表全文）。这逼 Agent 用工具或记忆，而不是读题抄答案。

记 $R_{d,j}$ 为第 $d$ 日结束时、在第 $j$ 日任务重放上的正确率（$j\le d$）。第 03 课的终点平均准确率

$$
\mathrm{ACC}=\frac{1}{14}\sum_{j=1}^{14} R_{14,j}
$$

遗忘（第 $j$ 日任务在后来最好成绩与终点的差）

$$
F_j=\max_{d\in\{j,\dots,13\}} R_{d,j}-R_{14,j},\quad
\bar F=\frac{1}{13}\sum_{j=1}^{13} F_j
$$

后向迁移

$$
\mathrm{BWT}=\frac{1}{13}\sum_{j=1}^{13}(R_{14,j}-R_{j,j})
$$

$R_{j,j}$ 是第 $j$ 日当天预衡正确率，不是「允许先学再考」的正确率。BWT 为负表示后来的学习伤了前面的天。前向迁移 FWT 需要「尚未学习的未来日」基线，本课用冻结 Agent 在第 $j$ 日的成绩当 $\bar b_j$，则

$$
\mathrm{FWT}=\frac{1}{13}\sum_{j=2}^{14}(R_{j-1,j}-\bar b_j)
$$

学习中的 Agent 若真能把技能带到新一天，FWT 应为正。

验证：日志里每一题带时间戳「答题时刻的记忆条数、技能条数、是否已做当日权重更新」。若权重更新发生在答题之前，预衡作废。

### 5.3 冻结对照：没有它，曲线没有因果

直觉：后几天任务可能更容易，或者你作为出题人无意识地降低了难度。冻结体用同一题序，把「题变了」从「学会了」里减掉。

机制：冻结策略 $\pi_0$ 与学习策略 $\pi$ 共享初始提示词和工具接口，14 天内禁止三条写入。对每个 $d$，比较 $\mathrm{ACC}_d(\pi)$ 与 $\mathrm{ACC}_d(\pi_0)$，以及旧任务回放（把 Day 1 的 10 题在 Day 5、Day 10、Day 14 重测）。

断言方向（机制实验必须钉死）：Day 14 上，冻结体对早期任务的保持差于至少一个学习体（只记忆或记忆+技能）。若学习体也没更好，先查记忆是不是其实没写进去，或重放题是否仍把名录放进了提示词。

代码落点：`lesson_24.py` 跑同一 `seed` 下的冻结与学习两条轨迹。浏览器「14 日看板」用开关切换四条曲线。

验证：两条轨迹的任务序列必须逐题相同。乱序就不是对照。四条曲线画在同一张图上时，横轴是日，纵轴不要混用单位：准确率一张图，记忆条数和技能数一张图，上手步数一张图。混在一个纵轴上会看起来「都在涨」，其实在比三种量纲。

### 5.4 记忆通道：名录和冲突怎么写

直觉：叫小王靠的是「小王现在坐哪」这一条可变事实。写错位置，比不写更糟。

机制：记忆是外挂键值或 Letta 记忆块，不改 $\theta$。写入规则必须显式规定冲突：同一 `employee_id` 的座位，新值覆盖旧值，并留下一条带日期的变更记录。并存而不覆盖，叫人任务应判失败。这和第 13 课「冲突写入」同一条纪律。

Letta 当前产品入口（写课前打开 Quickstart）：CLI 为 `npm install -g @letta-ai/letta-code`，交互里 `/memory` 查看块，`/remember` 把纠正写耐久，`/init` 做一次深初始化。Python 另有 `letta-client`。本课不要求你复刻 Letta 的全部分层；要求你的模拟记忆至少有「名录块」和「日记块」。名录块给当前座位，日记块给变更历史。检索时先查名录块。

覆盖率：Day 11 之后问「小王坐哪」，正确答案是 C2。答 A3 或 B1 记为冲突失败。赵衡 Day 9 被叫到，应回答请假不可用，而不是报 E5 当作人在。

验证：故意写入错误座位，再写正确座位，读出来必须是后者。只追加不覆盖，算通道没实现。

类比失效处：Letta 的记忆模型在演进，CLI 与多年前的 MemGPT 服务器不是同一个安装命令。报告里写你实际用的文档日期和命令，不要抄过期的 `letta server` 当唯一官方入口。

### 5.5 技能库通道：流程写成下次还能跑的脚本

直觉：发票怎么开，不该每天重新发明。Voyager 把成功程序放进抽屉，检索再跑，权重可以不变。

机制：一次工具调用成功且校验器通过，则把「意图、参数模板、校验条件」写成技能卡片，键是意图嵌入或关键词。第 $d$ 日遇到同类意图，先检索再执行。失败则重写卡片，不保留失败脚本（第 21 课：失败后重写）。

新工具上手步数：设工具 $u$ 在 $d_u$ 日上线，定义 $S(u)$ 为从 $d_u$ 起到第一次成功调用的尝试次数。学习体的 $S(\texttt{invoice\_draft})$、$S(\texttt{shift\_swap})$ 应低于冻结体。技能库若从不检索，步数不会降，那和第 21 课「不入库就从零试」是同一个对照。

验证：Day 7 的发票题，学习体应能命中 Day 6 入库的卡片。命中次数记进日志。技能数只涨不用，曲线好看但任务不涨，报告里要写出来。

这对应第 16 课矩阵里「流程技能 / 记忆或技能库」格，还不是「推理模式写入权重」。

### 5.6 加分：每日小步更新，且必须筛选

直觉：有些东西日记写不清，例如「这个仓库脚本的报错要先看第二行」。那是使用习惯，可能需要动权重。动了就会忘，所以本课把它标成加分，并且套上第 23 课的筛选。

机制：当日预衡全部结束之后，把成功轨迹（环境校验通过的那几题）收成 $\tilde D_d$。失败轨迹不进。更新

$$
\theta_{d+1}=\mathrm{Update}(\theta_d,\tilde D_d)
$$

主线若做，优先 on-policy 小步（第 20 课 RL's Razor：在能解决新任务的策略里，on-policy 更靠近原模型，旧任务往往更稳）。资源不够用 SFT 也可以，但必须把「用了 SFT」写进报告，并预期旧任务掉得更多。学习率应小到当日更新后，Day 1 回放不得掉到随机。

禁止：把当天全部生成（含叫错人、幻觉参数）送去微调。那就是第 23 课关掉筛选的在岗版。

验证：加分组与「记忆+技能、权重冻结」同题序对照。若 ACC 升而 $\bar F$ 明显变差，报告记为失败案例，不是加分成功。未做加分不扣毕业分。

### 5.7 主线开了记忆加技能，权重仍是加分

CPU 学习体只做两件事：把座位和项目写进字典（记忆），把校验通过的工具名写进 `skills`（技能）。权重向量不存在。所以本机 `learning_retention = 1.00` 来自记忆覆盖加技能入库，不能拿去充当「改了慢权重」。浏览器的「再加权重」通道会在推理日把保持乘 0.93，用来显示打开第 16 课权重列的代价；那条曲线是示意，不进 `result.json`。

对照 [第 16 课](16_when_weights_must_move.md) 矩阵读本课三条通道：

| 通道 | 打开的格子 | 本课 CPU 有没有跑 |
|---|---|---|
| 只记忆 | 事实 / 记忆 | 浏览器有；CPU 学习体记忆和技能绑在同一个 `learn=True` 开关上，没有单独的只记忆轨迹 |
| 记忆+技能 | 事实 / 记忆，流程 / 可执行外存 | 有。本机记忆条数停在 5，技能 1→2 |
| 再加权重 | 规则 / 权重 | 没有。加分项，报告写「未做」 |

把 CPU 的 1.00 写成「权重持续学习已经通了」，算没读矩阵。

### Step 1: 浏览器实验「14 日看板」

打开本课网页实验（`lab-24-fourteen-days`）。每天揭晓任务。你能看到三条曲线：记忆条数、技能数、旧任务保持。切换「冻结 / 只记忆 / 记忆+技能 / 再加权重」。

先预测再运行。两个预测题与页面一致，也是 LAYER_MAP 里「浏览器先猜什么」那一句：14 日后保持最高的是哪条通道。

1. 14 日后旧任务保持最高的是哪个通道？选项含冻结、只记忆、再加权重。
2. 技能数谁更高？选项：「冻结 / 只记忆」对「记忆+技能 与 再加权重」。

## 11. 前沿与改造

前沿怎么做：Zheng et al. 2025 的路线图（arXiv:2501.07278）把 LLM Agent 的终身学习拆成感知、记忆、行动三块，并承认现有系统多为静态。Letta 把记忆当一等公民，产品在往「会改自己记忆块」走，但公开文档仍是外挂状态加工具，不是稳定的权重持续学习配方。Voyager 证明技能外存能在开放环境里涨能力，权重不动。SEAL 与 DGM 证明自修改需要外在评价。上岗这一周对照五篇：空间/时间何时必须改权重（[arXiv:2607.07847](https://arxiv.org/abs/2607.07847)）、稀疏记忆槽微调、Razor 的 on-policy、SEAL 的自编辑、AWM 的工作流外存。没有一家把这三件事在真实两个月岗位上跑通并公开可复现。

我们差在哪：14 日、缩小名录、2 个新工具、状态全可观测。没有开放世界，没有跨月，没有未写明惯例，权重更新常常关着。冻结对照能证明「写了比不写好」（本机保持 1.00 vs 0.00），不能证明「已经像新员工那样上岗」。差在哪，用第 12 节的 OPEN_PROBLEMS 格子填，不要另写口号。

动手改造：

1. 把预衡改成在线逐步公开名录。位置：出题器。预算：CPU。预期：冻结体变强，学习体与冻结体的差距缩小但仍在冲突事实上领先。失败：差距消失且冲突覆盖也不领先。
2. 技能卡片加过期。位置：技能库检索，座位相关技能在座位变更日失效。预算：CPU。预期：Day 5 不会检索到「小王在 A3」的流程卡。失败：过期规则误杀发票技能。
3. 权重更新加回放缓冲。位置：加分通道，混入 Day 1 成功轨迹。预算：单卡。预期：$\bar F$ 小于无回放的 SFT。失败：新工具上手步数升回冻结体水平。
4. 换真实日历。位置：把北港表换成你自己项目一周的 issue。预算：API。预期：报告多一节「真实一周」，数字不与 14 日模拟混报。失败：没有冻结对照。

顺手复现映射：第 20 课复现 5 仍在原课。本课不新增复现编号。Hope 完整语言模型、SEAL 全量 RL、Voyager Minecraft 官方分数，能跑标实战，不能跑标只讲，禁止山寨分数。

手里有什么，还差什么，写在下一节之后的收束，作为报告最后一页的参考答案结构。你必须用自己的数字（至少填上 1.00 / 0.00 / B7）替换其中的空白，不能整段粘贴充数。差的部分只许填 OPEN_PROBLEMS 已有的格子。

## 12. 论文与延伸

1. Harrington, Saxena, Murphy, Borovykh, Yun, Kamath, Kyi, Darrell, Malik, Bai, 2026, *When Does Continual Learning Require Learning*，[arXiv:2607.07847](https://arxiv.org/abs/2607.07847)。
贡献：把持续学习定义成世界在变时能力还涨，并沿空间（新域）和时间（事实漂移）拆开。
机制：同一套协议比提示优化（GEPA、ACE）、监督（SFT、SDFT）、在线 RL（GRPO、SDPO）和上下文压缩（Cartridges、In-place TTT）。更新算子可以改权重、改提示或写外存。他们填遗忘矩阵 $R_{i,j}$，并报 BWT / FWT。正文写提示方法跟得快但伤后面的题；蒸馏稳但改旧事实慢；在线 RL 更会改知识，奖励一吵就歪。何时必须改权重，取决于变化落在哪根轴。
和本课：北港的座位变更是时间轴上的事实漂移；新工具是空间轴。CPU 学习体只写记忆和技能，权重通道未开。毕业协议的 `full` 通道才动计分规则。本课答不了他们八种方法的对比表。
阅读问题：第 7 日座位 A3→B7，按这篇该走外挂覆盖还是必须改权重？用 `seat_conflict_overwritten` 和第 16 课事实行回答。

2. Zheng, Shi, Cai, Li, Zhang, Li, Yu, Ma, 2025, *Lifelong Learning of Large Language Model based Agents: A Roadmap*，[arXiv:2501.07278](https://arxiv.org/abs/2501.07278)。
贡献：把 LLM Agent 终身学习拆成感知、记忆、行动三块，并承认现有系统多为静态。
机制：感知接多模态输入，记忆存变过的知识，行动在环境里落地。用来对照「还差什么」。它不是一份已实现配方。
和本课：记忆+技能对应记忆和行动外存；权重加分对应参数记忆。CPU 没碰感知模块。
阅读问题：北港模拟落在三块的哪几块？哪一块你完全没碰？用 `learner_memory_grows` 和「权重未做」回答。

3. Shenfeld, Pari, Agrawal, 2025, *RL's Razor: Why Online Reinforcement Learning Forgets Less*，[arXiv:2509.04259](https://arxiv.org/abs/2509.04259)。
贡献：同样学会新任务时，on-policy RL 偏向离原模型 KL 最近的解，旧能力掉得少。
机制：遗忘由新任务上的 $\mathrm{KL}(\pi_0\|\pi)$ 预测。SFT 可以落到任意远的解，on-policy 隐式偏 KL 最小。
和本课：加分通道若做，优先 on-policy。本机权重通道关闭，答不了 Fashion 掉分或 KL。
阅读问题：你若用 SFT 灌成功轨迹，Day 1 回放掉了多少？没做加分就写「本课实验答不了，因为权重通道未开」。

4. Lin, Zettlemoyer, Ghosh, Yih, Markosyan, Berges, Oğuz, 2025, *Continual Learning via Sparse Memory Finetuning*，[arXiv:2510.15103](https://arxiv.org/abs/2510.15103)。
贡献：只更新相对预训练更常用的记忆槽，新事实能写进去，旧问答掉得少。
机制：记忆层按 token 查 top-$k$ 槽。用 TF-IDF 对照预训练访问计数，只让 top-$t$ 槽走梯度，其余冻结。摘要：同等新知识下，NaturalQuestions F1 全参掉 89%，LoRA 掉 71%，稀疏记忆掉 11%。
和本课：CPU 记忆是字典覆盖。记忆层那一套本课没跑。`seat_conflict_overwritten` 看见覆盖，看不见稀疏槽。权重加分若做全参 SFT，预期更像那 89%。
阅读问题：把小王座位写进字典，和写进稀疏记忆槽，哪一个本课 CPU 真的跑了？

5. Zweiger, Pari, Guo, Akyürek, Kim, Agrawal, 2025, *Self-Adapting Language Models*，[arXiv:2506.10943](https://arxiv.org/abs/2506.10943)。
贡献：自编辑经内环 SFT 写入权重，外环 RL 学怎样出题。
机制：内环改慢权重。限制节和图 6：连续自编辑时旧段落会掉。成功轨迹才允许进权重，是本课加分通道的筛选对应物。
和本课：主线没改权重。毕业协议的 `full` 通道用最近 6 张工单拟合计分。SEAL 内环本课没跑。本课答不了论文里的 47.0%。
阅读问题：若把幻觉轨迹送去微调，会踩图 6 的连续遗忘，还是第 23 课关筛选的自我强化？本课哪条失败案例在写这件事？

6. Hu, Long, Wang, 2026, *When Continual Learning Moves to Memory: A Study of Experience Reuse in LLM Agents*，[arXiv:2604.27003](https://arxiv.org/abs/2604.27003)。
贡献：外挂记忆并不取消持续学习，只是把瓶颈从改参数挪到检索。
机制：$(k,v)$ 框架拆两轴：经验怎么表示，检索怎么组织。ALFWorld 和 BabyAI 上，抽象流程比细轨迹更好迁移；细粒度组织前向迁移强，遗忘也重。
和本课：技能库是抽象流程；座位名录是键值。`new_tool_attempts_drop` 看见流程复用。CPU 没有检索竞争，因为键是写死的。
阅读问题：若名录和技能抢同一段上下文，座位覆盖还会稳定是 B7 吗？本课实验答不了，因为没有上下文窗口限制。

7. Wang, Mao, Fried, Neubig, 2024, *Agent Workflow Memory*，[arXiv:2409.07429](https://arxiv.org/abs/2409.07429)。
贡献：从成功轨迹抽出可复用工作流，下次当外存提示，不改权重。
机制：工作流是目标描述加步骤。离线从标注轨迹抽，在线只从判定为成功的自轨迹抽。摘要：Mind2Web 相对成功率 +24.6%，WebArena +51.1%。
和本课：技能通道同一类。`new_tool_attempts_drop` 对应「入库后少试」。CPU 只存工具名，没有自然语言工作流。
阅读问题：`nightly_sync` 第一次 5 次、之后 1 次，对应 AWM 的离线还是在线？失败脚本有没有进库？

8. Wu, Wang, Yu, Zhang, Chang, Yu, 2024, *LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory*，[arXiv:2410.10813](https://arxiv.org/abs/2410.10813)。
贡献：测聊天助手的长期记忆，五件事：抽取、跨会话推理、时间推理、知识更新、弃权。
机制：500 道题嵌在可拉长的对话史里。摘要写商业助手和长上下文模型跨会话掉约 30%。他们把记忆拆成建索引、检索、阅读。
和本课：座位变更是知识更新。`seat_conflict_overwritten` 对应「新座位覆盖旧座位」。本课没有 500 题，也没有弃权题。
阅读问题：赵衡请假那道题，按他们五件事该算知识更新还是弃权？本课 CPU 日历有没有这道题？

9. Xie, Zhang, Chen, Li, Zhao, Cao, Hua, Cheng, Shin, Lei 等, 2024, *OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments*，[arXiv:2404.07972](https://arxiv.org/abs/2404.07972)。
贡献：真实电脑环境里评测多模态 Agent，执行式打分。
机制：Ubuntu / Windows / macOS，369 道跨应用题。摘要：人 72.36%，当时最好模型 12.24%。卡在 GUI 定位和操作知识。
和本课：北港是全可观测的表。真实桌面本课没有。本课答不了 12.24%。用来填「本模拟有 / 真实上岗没有」。
阅读问题：OSWorld 缺的是未写明惯例、跨月，还是开放世界？用你报告里那张对照表点名。

10. Wu, Ji, Kawatkar, Kwan, Gu, Peng, Chang, 2026, *LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues*，[arXiv:2605.12493](https://arxiv.org/abs/2605.12493)。
贡献：测 Agent 能不能把环境经验内化成「熟同事」，不再只记用户聊天。
机制：451 道人工题，五件事：静态状态、动态状态、工作流、环境坑、前提意识。历史最长 500 条轨迹、115M token。摘要：AgentRunbook-C 准确率 72.5%，最强 RAG 48.5%。
和本课：技能库接近工作流知识；座位是动态状态。CPU 没有 115M 轨迹。
阅读问题：北港的 `nightly_sync` 上手步数下降，对应他们五件事里的哪一件？

11. Lopez-Paz and Ranzato, 2017, *Gradient Episodic Memory for Continual Learning*，[arXiv:1706.08840](https://arxiv.org/abs/1706.08840)。
贡献：给出准确率矩阵 $R$ 以及 ACC、BWT、FWT。机制发明处，不是本课主阅读。
机制：$R_{d,j}$ 是学完任务 $d$ 之后在任务 $j$ 上的准确率。ACC 是最后一行平均，BWT 看后来有没有伤前面。
和本课：毕业报告 Step 4 要用这套公式。CPU 只给了第 14 日 4 道探针的保持（学习体 1.00，冻结 0.00），不是满的 $14\times 14$。
阅读问题：冻结体保持 0.00 揭穿了只报 ACC 的哪一种谎？若后几天题变简单，哪一个量会先撒谎？

整门课学完，手里有什么，离梁文峰说的那种持续学习还差什么：

转写里那一级台阶是：语言模型、思维链、Agent 之后，瓶颈是持续学习；不是一次很强的训练，而是像人一样做比较长期的持续学习；Agent 能力有限，是因为它不能有效地持续学习；先把持续学习做出来，用它做研究效率会高；之后模型可以自己研发下一版，习惯上叫奇点，其实是渐变；全世界还没找到真正管用的方法。以上均来自未获 DeepSeek 确认的公开转写。

你手里实际有的，按六幕对齐：

- 会把遗忘跑出来，并用准确率矩阵、遗忘、BWT、预衡来打假（第 01-03 课）。
- 分得清上下文、检索、外挂记忆、知识编辑、改权重各自能留下什么、留下之后会冲掉什么（第 04、13、14、16 课）。
- 会用正则、回放、扩结构、梯度约束和 GDumb 这类让人难堪的基线（第 05-08 课）。
- 会在小模型上做续预训练、顺序指令、正交 LoRA、模型合并，并知道合并是事后缝合不是在线学习（第 09-12 课）。
- 见过可塑性丢失、测试时更新、惊讶门、嵌套时间尺度、SEAL 自编辑、on-policy 更不易忘（第 15、17-20 课）。
- 会把技能写成可再调用的脚本，会区分经验来自网页还是环境，会把自改进环的筛选关掉看它崩（第 21-23 课）。
- 会在 14 个模拟工作日里给记忆、技能、冻结对照画曲线，并交出带失败案例的报告（本课）。本机一次运行：学习体保持 1.00，冻结 0.00，座位覆盖成 B7。第 16 课矩阵上，这对应事实/记忆和流程/技能外存两格；权重列仍是加分，没动。
