# 第 16 课：三条路线怎么选：重建、表征、物体槽

> 类型：研究（把第 08、10、14 课对照放到四轴上重审）+ 实战（CarRacing 上 VAE 目标对 JEPA 目标，同一个弯道探针）<br>
> 建议周期：2-3 天<br>
> 硬件：单张 24GB 卡数小时即可；Mac / 纯 CPU 可完成全部步骤，JEPA 训练慢数倍。物体中心的真实验不在本课跑<br>
> 锚定仓库：[ctallec/world-models](https://github.com/ctallec/world-models)（复用第 02 课 VAE 与弯道探针）+ [keon/jepa](https://github.com/keon/jepa)（`ijepa.py` 改数据源）。第三条路预告 [tkipf/c-swm](https://github.com/tkipf/c-swm)，动手交给第 23 课<br>
> 产物：三路线比较报告、CarRacing 上 VAE vs JEPA 同探针对照表、三份对照报告的重审笔记、一张「一杯水被手碰到」的三写法表

## 1. 这一课做什么

第四幕走到收官。第 13 课从零写出 I-JEPA，第 14 课给表征接上动作并在 Two Rooms 里规划，第 15 课拿 V-JEPA 2 的公开权重做探针和微调。三条零件都摸过了：把观察压成状态、按动作预测下一状态、在潜空间里选动作。还缺的是一次正面回答：同一笔算力，该押重建像素、预测表征，还是把状态拆成物体槽？

本课不引进第四个模型家族。要做的是把已经跑过的对照重新摆上坐标系，再补一场此前没有的干净对打。第 08 课在 DMC 上并排 Dreamer 和 TD-MPC2，第 10 课在 Atari 上并排 IRIS 和 DIAMOND，第 14 课在 Two Rooms 上并排 JEPA 规划和 RSSM 规划。这三份报告当时各自有任务、预算和口径。今天用世界域、架构、目标、验证者四根轴把它们标回去，看清楚哪一份真的在比「路线」，哪一份只是路线内部的架构之争。

还要兑现第 02 课埋下的对照：同一批 CarRacing 帧，VAE 重建目标对 JEPA 表征预测目标，下游用同一个弯道线性探针打分。变量尽量只剩训练目标；架构差异如实申报，不当成没看见。

第三条路从今天起叫**物体中心 / 槽化世界模型**。状态不再是一条向量，而是一组槽，每个槽绑定一个物体或部位，转移可以在槽内走动力学、在槽之间走关系。代表工作是 C-SWM、Slot Attention、STEVE、SlotFormer。机制和判据本课讲清楚，真实验明确交给第 23 课：CarRacing 的俯视赛道几乎是一条黏在一起的带子，硬造三个物体槽是自欺。桌宠那张桌子上同时有杯子、手、手机和自己的头，那时槽才有主场。

毕业方向是桌宠。Meta 的 Code World Model 如果出现，只当「验证者硬到什么程度会改路线选择」的场外旁证。

做完你手里会有：三份重审笔记、一张四行探针表、一份全部写成条件句的比较报告，以及一张把「一杯水被手碰到」分别写成重建像素、预测表征、三个槽下一状态的对照。第 17 课会把三种「好」拆开量；物体槽的可解释性会成为新指标。

术语速查：

| 术语 | 一句人话 |
|---|---|
| 三条路线 | 重建观察、预测表征、物体中心槽：世界模型内部状态的三种造法 |
| 四轴 | 给任何世界模型定位的坐标系：世界域、架构、目标、验证者 |
| 世界域 | 观察和动作绑到哪个世界：赛道像素、关节力矩、桌上的杯子、Python 解释器 |
| 验证者 | 判定「预测对不对」的裁判：重建误差、环境奖励、槽排名、解释器执行、真桌子上接下来两秒 |
| 槽 / slot | 一组可交换的向量，每个向量通过竞争注意力绑定到一个物体或部位 |
| 物体中心 | 状态按物体拆开，杯子倒了不必改写手机那一格 |
| 价值等价 | 第 07 课的立场：模型不必忠于外观，只需忠于价值计算 |
| 线性探针 | 冻住表征，只训一个线性回归去读某个量；第 02 课用来读路面弯度 |
| 代理标签 | 拿容易算的量冒充真正想测的量，比如拿未来转向均值冒充路面弯度 |
| 组内差 $\Delta$ | 训好的探针分数减去随机初始化的探针分数，才是这条训练目标真正挣到的信息 |

## 2. 问题

四个问题，从整理旧账到开一枪新的。

第一，三份对照报告怎么拼成一张图。第 08、10、14 课各留下一份对照，但任务、预算、口径都不同，直接摞在一起只是三堆数字。本课先给出四轴坐标系，再把三份证供逐个放上去重审。你会发现有一份根本不是路线之争的证据，有一份的结论比当时写的更强，还有一份的适用范围比当时以为的窄。重审不是把旧结论抄一遍，产出是修订。

第二，重建对表征预测缺一场同场竞技。第 08 课比的是两套完整系统，模型、策略、规划器全不同，赢输很难归因到单个零件。这里把对照缩到最小：同一批帧，只换训练目标，下游用同一个线性探针。变量只剩一个，外加架构差异这个如实申报的混杂。这是你能做到的最干净的一场。

第三，第三条路凭什么算一条路线。前面十五课的状态全是一条向量：32 个数、RSSM 的确定加随机双通道、一串 patch token。物体中心把状态改成一组槽。它有自己的赌注（世界按物体拆开）、自己的病（槽坍成同一个、物体身份对不上）、自己的验证者（槽与物体的对应、挡住一个物体看谁的预测坏）。缺了它，第六幕的桌面状态和第八幕的桌宠都没有选型出发点。本课把机制讲到能填一张「一杯水」表；跑 C-SWM、看槽可视化，是第 23 课的论文复现 #6。

第四，怎么写一份不站队的比较报告。「XX 路线优于 YY 路线」这种句子在这门课里不合格。合格的形态是条件句：在世界域为 X、验证者为 Y 的设置下，实验 Z 显示……。每个论断都压成这种形态，也是第五幕研究手艺的第一次预演。

本课的 VAE vs JEPA 对照是缩小设置：几万帧、小模型、一个探针任务。它能证明的是「在这批数据这个任务上谁的表征更好读」，不能证明哪条路线通向通用智能。物体中心这一侧本课只有纸面互动和第 23 课预告，不把预告写成已经跑过的结果。

## 4. 学习目标

1. 拿到任何一个自称世界模型的新系统，能在一分钟内用四轴语言给它定位：建的是哪个世界、什么架构、预测什么、谁判对错。
2. 对「该押哪条路」给出条件化回答，每个条件后面能跟上自己的实验编号。
3. 独立设计一个「同数据、同探针、只换训练目标」的表征对照实验，并说清它控制了什么、没控制什么。
4. 解释代理标签的适用条件，并能举出一个代理标签整个失效的案例。
5. 用三个槽写出「一杯水被手碰到」的下一状态，并说明为什么一条向量很难回答「杯子会不会倒」。
6. 说出 C-SWM、Slot Attention、STEVE、SlotFormer 各自补上的零件，并说明本课为什么不跑它们、第 23 课跑哪一个。
7. 把 Meta 的 Code World Model 从本课第三条路和本课程毕业方向里划出去：它是代码执行世界的旁证，不是物体槽，也不是桌宠。

## 5. 原理

这一节是全课的论证主体。5.1 和 5.2 搭坐标系，5.3 到 5.5 重审三份证供，5.6 让物体中心槽登场，5.7 处理场外旁证，5.8 设计本课自己的实验，5.9 用一张桌子上的水杯做互动。

### 5.1 三条路线到底在赌什么

先回到贯穿全课的那个循环：观察压成状态，按动作预测下一状态，展开未来，打分，选动作。三条路线争的其实只是一件事：「状态」这个东西里该装什么，以及拿什么手段逼它装对。

第一条路，**重建观察**。状态必须能把原始观察画回来。逼它装对的手段简单粗暴，画不回来就罚。第一幕的 VAE、第 05/06 课的 RSSM、第 09 课的 token、第 10 课的扩散，全是这条路的成员。内部吵得再凶（token 还是扩散），交的税是同一种：像素里每个字节都要养，草地纹理和路面弯度在损失面前人人平等。第 02 课拆过这本账：重建损失按像素面积投票，决策信息在里面只是零头。

第二条路，**预测表征**。状态只需要在抽象空间里对得上「未来的表征」，像素爱丢就丢。省下了养纹理的税，也丢了最硬的锚：没有「画回来对不对」这个外部检查，模型可以摆烂输出常数，预测误差照样是零。所以这条路的全部工程难度都花在防坍缩上：EMA target、stop-gradient、masking 设计，第 13 课逐个砍过。第 07/08 课的价值等价系是这条路的近亲：同样不重建，只是抽象空间选得更激进，只留价值、奖励、策略这三样。

第三条路，**物体中心槽**。状态干脆不用一条向量，用一组槽。每个槽绑定一个物体或部位，转移分成两截：槽自己怎么动，槽和槽之间怎么撞、怎么撑、怎么遮。它赌的是：在物体可数、关系稀疏、需要分开推演的世界域里，硬用一条向量会把「杯子倒了、手机没动」揉成同一个残差。5.6 节专门展开。

三条路线可以写成同一个模板的三种填法。都在学一个转移 $s_{t+1} = f(s_t, a_t)$，差别在状态 $s$ 的形态和训练损失 $\mathcal{L}$ 的取法。重建路线的 $s$ 是连续向量或 token，$\mathcal{L}$ 里有一项观察空间距离 $\lVert \hat{o} - o \rVert$。表征预测路线的 $s$ 也是向量，但 $\mathcal{L}$ 是表征空间距离 $\lVert \hat{z} - \mathrm{sg}(\bar{z}) \rVert$（$\mathrm{sg}$ 是 stop-gradient，$\bar{z}$ 来自 EMA 目标编码器，第 13 课的两件防坍缩法宝）。物体中心路线的 $s$ 是一组槽 $\{z^1,\ldots,z^K\}$，$\mathcal{L}$ 可以是对比学习（C-SWM 不重建像素）、也可以是按槽重建（Slot Attention / STEVE），还可以是槽序列上的自回归预测（SlotFormer）。

三种损失你至少摸过前两种：第一种在 ctallec 仓库 `trainvae.py` 的 `loss_function`（BCE 加 KL），第二种在 keon/jepa 的 `ijepa.py` 训练循环里（对四个目标块的 smooth-L1 取平均）。第三种的对比损失公式在 5.6 节写出，代码落点在第 23 课的 `tkipf/c-swm`。

测试一题：第 08 课的 TD-MPC2 属于哪条？答案是第二条的激进变体。它不重建，预测的是对价值计算有用的东西，防坍缩靠奖励头和 Q 头（外部奖励当锚，比 JEPA 的自一致多一点外部真值）。能把一个系统这样拆开说，才算懂「路线」。

### 5.2 仲裁框架：四根轴，验证者那根最重

「三条路线哪条好」这个问题问坏了，坏在把多维选择压成了一维排名。任何世界模型都是在四根轴上各选一个点：

```text
世界域(观察和动作绑到哪个世界)
架构(用什么网络建动力学)
目标(预测什么)
验证者(谁判对错)
```

所谓三条路线之争，在这套语言里主要是**目标轴**上的选择（预测观察、预测表征、预测槽的下一状态），顶多再捎上架构轴。而目标轴上怎么选，答案不在目标轴自己身上，在另外三根轴上：你的世界域长什么样、你要模型干什么用、以及最关键的，你手里有什么验证者。

验证者是判定「预测对不对」的裁判。裁判的强弱差距很大：

| 验证者 | 强度 | 这门课里谁在用它 |
|---|---|---|
| 观测重建误差 | 弱：真值免费但含大量与决策无关的字节 | 第一幕 V-M-C、第 05/06/09/10 课 |
| 自一致（防坍缩约束） | 最弱：没有外部真值，只防摆烂 | 第 13-15 课 JEPA 系的预训练阶段 |
| 环境奖励与交互 | 中：真值稀疏但如假包换 | 第 04 课梦境验收、第 06/07/08 课 |
| 槽排名 / Hits@1 | 中：不看像素，看预测的槽离真槽近不近 | C-SWM 论文的评测，第 23 课会复现方向 |
| 解释器执行 | 强：跑一遍就有全套真值，免费、无噪声 | Meta 的 Code World Model（5.7 节，旁证） |
| 真桌子上接下来两秒 | 强：事实按时到货，样本少、噪声大 | 第八幕桌宠的毕业验收 |

这张表就是本课的仲裁依据。往下三节重审证供、5.6 节讲第三条路、5.7 节读场外旁证，用的全是它。

用一句话压缩这张表：验证者决定了你能拿到的监督信号的密度乘纯度。重建的信号密（每个像素都是真值）但杂（大部分字节与决策无关）；奖励的信号纯但稀（一局才几个有效比特）；解释器执行两头占全（密且纯），所以 Code World Model 敢在这上面把模型堆到 32B。JEPA 的自一致信号既不密也不纯，纯靠「表征空间里可预测」这个归纳偏置撑着，这是为什么第 13 课必须在防坍缩工程上做到极致，也是为什么第 15 课 V-JEPA 2 的「理解物理」要靠下游探针才能兑现成可测量的东西。物体中心的验证者介于中间：C-SWM 用潜空间排名，不需要把杯子画回来，但要求杯子槽和手槽别对调。

验证者不是抽象概念，它就是损失函数里「真值从哪来」那一行：`trainvae.py` 里真值是输入图像本身；`ijepa.py` 里真值是 EMA 编码器对目标块的输出（注意：这是模型自产的真值）；tdmpc2 里真值是 replay buffer 里的真实奖励；第 23 课的 C-SWM 里真值是经验回放里真实的下一状态，对比损失拿随机抽到的另一帧当负例。

检验你会不会用这套框架：LeCun 说「LLM 是词模型不是世界模型」，这句话在四轴语言里是什么意思？拆解：LLM 的世界域是文本流、目标是预测下一 token、验证者是语料里实际出现的下一个词，三根轴都合法，所以「LLM 是不是世界模型」吵不出结果。真正的分歧在世界域：文本是世界的有损投影，在投影上预测得再准，也不保证对投影源（物理世界）的状态转移有掌握。把口水仗翻译成轴上的坐标，是这课教的第一门手艺。

### 5.3 呈堂证供一：Dreamer vs TD-MPC2（第 08 课）

这份证据说了什么。第 08 课你在同一个 DMC 任务、相近预算下并排跑了 Dreamer（背着解码器）和 TD-MPC2（免重建，靠一致性损失、奖励头、Q 头三根支柱防坍缩），交付了一份方向性对照报告，里面有两条学习曲线和一张「哪些差异对齐了、哪些没对齐」的差异表。

重审要问的三个问题。其一：差异表里，哪些差异真属于目标轴（重建对三支柱），哪些只是工程口径（action repeat、并行环境数、更新频率）？你当时把胜负归因给了前者还是后者？其二：TD-MPC2 的三根支柱里，奖励头和 Q 头吃的是外部真值（环境奖励），一致性损失吃的是自产目标。对照 5.2 的表，它的验证者档位其实比 JEPA 高半级，这一点你当时的报告里写到了吗？其三：如果把任务换成奖励极稀疏的那种，三支柱里有两根会瞬间断粮，你预计哪边先垮？报告里有没有证据支持这个预计（多半没有，如实写「本对照不覆盖稀疏奖励设置」）。

重审后这份证据的真实效力。它支持的论断是：在奖励密集的连续控制里，重建不是必需品，免重建一侧没有因为少了解码器而学不出可用的潜空间。它不支持「免重建更好」这种一般化论断：两套系统除了目标轴，还有几十处没对齐的差异。把效力写窄，证据反而更硬。

四轴定位：世界域是 DMC 连续控制，架构一边是 RSSM 加解码器、一边是 MLP 潜空间加采样规划，目标一边是重建加想象价值、一边是价值等价，验证者是环境回报。这场对照主要打在目标轴上，但架构轴和工程口径没有钉死。

### 5.4 呈堂证供二：IRIS vs DIAMOND（第 10 课）

这份证据说了什么。第 10 课你在同一个 Atari 游戏上并排比了 IRIS（图像离散成 token，自回归预测下一格）和 DIAMOND（扩散模型直接生成下一帧），交付了对照报告：谁的画面更保真、谁的 agent 分数更高、token 化在哪类细节上翻车（弹道、准星这类小而要命的东西）。DIAMOND 论文（arXiv:2405.12399）在 Atari 100k 上报告均值人类归一化分数 1.46，对 IRIS（arXiv:2209.00588）的 1.05；这些是论文数字，你自己单游戏单种子的对照只看方向。

重审要问的三个问题。其一，也是最重要的一个：token 和扩散都在重建像素。这场对照压根不在「重建对不重建」的战线上，它是重建阵营的内战，四轴语言里是纯粹的架构轴之争（离散化压缩对连续去噪）。你当时的报告标题若写了「路线对决」，现在改过来。其二：你存下的那些「细节翻车」帧，支持的是「细节保真影响控制分数」还是只支持「影响观感」？前者需要你把翻车帧和 agent 失分的时刻对上号，报告里对上了吗？其三：两套系统同出一个作者组，天然可比性好，但哪些超参是各自精调过的、哪些是互相照抄的？可比性好也要说清好在哪。

重审后这份证据的真实效力。它支持：选定重建路线之后，观察空间的离散化方式是一等一的大决定，路线内部的差异可以大过路线之间。这条结论对第五幕很值钱，第 19 课「给 IRIS 换连续 token」的手术动机就是它。它同样给「路线之争」泼了盆冷水：吵目标轴之前，先检查你的架构轴选对没有。

四轴定位：世界域是 Atari 像素游戏，架构是离散 token Transformer 对扩散 U-Net，目标两边都是下一帧观察，验证者是像素保真加 Atari 分数。目标轴上它们是同一条路。

### 5.5 呈堂证供三：JEPA 规划 vs RSSM 规划（第 14 课）

这份证据说了什么。第 14 课你在 eb_jepa 的 Two Rooms 环境里，用动作条件 JEPA 世界模型做了规划，并和第 05 课「CEM 在 RSSM 潜空间里选动作」并排记录：同样是潜空间规划，一边的潜空间由重建目标训出，一边由表征预测目标训出。

重审要问的三个问题。其一：两边的规划器是不是同一个搜索算法？如果都是 CEM 一族，差异才能归到表征头上；你的并排笔记里还残留哪些混杂（推演步数、候选数、目标函数形态）？其二：JEPA 侧规划失败的案例长什么样，是预测不准（推演偏了），还是能量面太平（候选分不出高下，搜索原地打转）？这两种失败对应完全不同的病根，前者是模型问题，后者是表征几何问题。其三：Two Rooms 是个低维、干净、动力学简单的环境；把结论外推到 CarRacing 这种像素域，你最担心哪一环先断？（提示：想想第 13 课 masking 设计对「什么信息值得保留」的隐含假设。）

重审后这份证据的真实效力。它支持：表征预测训出的潜空间能够支撑规划，JEPA 不只是表征学习的玩具。第 15 课 V-JEPA 2-AC 用不到 62 小时机器人视频做后训练、零样本搬上真机械臂做抓放，是这条论断的工业级同款证据（论文 arXiv:2506.09985，你没有复现那次训练）。它不支持「JEPA 规划更强」：你的笔记多半显示两边在 Two Rooms 里都能用，分不出高下，环境太简单，这正是效力边界。

还要记一笔第 14 课已经点破的差异：JEPA 的推演是确定性的，GRU 前向，没有任何采样；RSSM 的想象每一步都从先验分布里抽签。Two Rooms 物理确定，所以无妨。桌宠那张桌子上，人会不会看过来是随机过程，确定性推演会把多种可能压成一个点。这条差异第 17 课量「规划好」时还会回来。

四轴定位：世界域是 Two Rooms 俯视物理，架构两边都是潜空间加采样规划器，目标一边是重建、一边是表征预测，验证者是到达目标图的成功率。这场对照打在目标轴上，世界域太干净，外推要小心。

### 5.6 第三条路线正式登场：物体中心槽

前两条路线吵得再凶，共享一个默认设定：状态是一条稠密向量。现在换个世界域想想。你要建「一张桌子」的世界模型：观察是摄像头画面，值得记的状态是杯子在哪、手往哪伸、桌子还撑不撑得住。硬把它压进 512 维向量，三件事立刻别扭：你没法指着第 217 维说它是杯子的倾角；桌上多放一部手机要重训整个编码器；最要命的是，预测错了你不知道错在哪个物体的哪个属性上。物体中心的赌注是：在实体可数、关系稀疏、需要分开推演的世界域里，状态就该是一组槽，预测未来就是预测每个槽的下一状态，外加槽与槽之间的关系。

这条路的四篇代表，按零件分工读，不要把它们当成四个可以横向打榜的系统。它们的世界域、目标和验证者并不相同。

**C-SWM**（Kipf, van der Pol, Welling, ICLR 2020, arXiv:1911.12247）是本课第三条路最像「世界模型」的一篇，也是第 23 课论文复现 #6 的锚。它把状态拆成 $K$ 个物体槽。编码器分成两截：CNN 物体提取器 $E_{\mathrm{ext}}$ 输出 $K$ 张特征图，每张图当一个槽的掩码；共享权重的 MLP 物体编码器 $E_{\mathrm{enc}}$ 把每张掩码压成 $z_t^k \in \mathbb{R}^D$。转移用图神经网络：节点是槽，边是槽间关系，动作按槽分解。一次消息传递写成

$$
e_t^{(i,j)} = f_{\mathrm{edge}}([z_t^i, z_t^j])
$$

$$
\Delta z_t^j = f_{\mathrm{node}}\big([z_t^j, a_t^j, \sum_{i \neq j} e_t^{(i,j)}]\big)
$$

下一状态是平移：$z_{t+1}^k = z_t^k + \Delta z_t^k$。这个加法形式来自知识图谱嵌入 TransE，归纳偏置是「动作在抽象空间里表现为平移」。训练不用重建像素。正例能量是各槽预测距离的平均，负例把当前观察换成回放里随机抽的另一帧：

$$
H = \frac{1}{K}\sum_{k=1}^{K} d(z_t^k + T^k(z_t, a_t), z_{t+1}^k),\quad
\tilde{H} = \frac{1}{K}\sum_{k=1}^{K} d(\tilde{z}_t^k, z_{t+1}^k)
$$

$$
\mathcal{L} = H + \max(0, \gamma - \tilde{H})
$$

论文用 Hits@1 和 MRR 在潜空间里做排名评测：给当前观察和动作，看预测的下一状态能否从一堆参考状态里排到真的那一个。环境是 2D shapes、3D blocks、Atari Pong / Space Invaders、三体物理，经验全部来自随机策略。官方实现是 [tkipf/c-swm](https://github.com/tkipf/c-swm)。第 23 课会按仓库 README 跑 2D shapes：

```bash
python train.py --dataset data/shapes_train.h5 --encoder small --name shapes
```

```bash
python eval.py --dataset data/shapes_eval.h5 --save-folder checkpoints/shapes --num-steps 1
```

本课不要跑这两条。写在这里只是让你看见：第三条路的真实验已经有官方入口，日期到了第 23 课再进仓库。

**Slot Attention**（Locatello et al., NeurIPS 2020, arXiv:2006.15055）补的是「槽怎么从像素里长出来」。C-SWM 的物体提取器是 $K$ 张特征图，槽的身份和 CNN 通道绑在一起，泛化到更多物体不方便。Slot Attention 把槽初始化成从共享高斯抽的 $K$ 个向量，然后做 $T$ 轮（论文默认 $T=3$）竞争注意力：softmax 在槽这一维上归一化，逼槽去抢输入特征，谁抢到谁绑定。更新用 GRU，参数在槽之间共享。两个关键性质：对输入置换不变，对槽顺序置换等变。每个槽都能绑定任何物体，不预先分工「1 号槽永远是杯子」。论文的下游任务是无监督物体发现（重建）和有监督属性预测，官方代码在 google-research 的 `slot_attention` 目录。注意：Slot Attention 本身是编码器零件，还不是完整的 $P(s_{t+1}|s_t,a_t)$。

**STEVE**（Singh, Wu, Ahn, NeurIPS 2022, arXiv:2205.14065；官方仓库 [singhgautam/steve](https://github.com/singhgautam/steve) 把缩写展开为 Slot-Transformer for Videos）把槽从单张图推进视频。作者的核心观察是：此前物体中心方法在简单合成场景上能用，一到复杂自然视频就垮。STEVE 没有为此发明新损失，用的仍是重建观察；它把解码器换成条件于槽的 Transformer，去重建 VQ-VAE 的离散码。论文原话是「既不加架构复杂度，也不引入新目标或弱监督」。对本课的意义是：第三条路也可以走重建目标，槽是状态的形状，损失仍可以落在像素或码本上。目标轴和状态形状是两件不同的事。

**SlotFormer**（Wu, Dvornik, Greff, Kipf, Garg, ICLR 2023, arXiv:2210.05861）补的是「槽有了之后，动力学怎么走」。它先用预训练的物体中心模型（Slot Attention 一族）从每一帧提出槽，再拿 Transformer 在槽序列上自回归预测未来槽。训练最小化特征和图像两个空间的重建损失。论文还展示了把学到的动力学接到 VQA 和目标条件规划上。和 C-SWM 的差别要说清：C-SWM 的转移是槽图上的一次消息传递，显式吃动作；SlotFormer 的转移是时间上的 Transformer，论文主实验是视频预测，规划是下游读出。桌宠若选这条，还得自己把动作条件接进去，第 23 课会讨论这个缺口。

类比：一组槽像一张桌上的便利贴，一张贴杯子、一张贴手、一张贴桌子。预测「手碰到杯子」时，你改杯子那张贴的倾角和接触，不必重写桌子那张。类比失效处：便利贴是人贴上去的，槽是模型抢出来的，没有人保证 2 号槽今天还是杯子；槽身份对调、两个槽抢同一个物体、一个槽吞掉两个物体，是这条路的职业病。第 23 课的验收就是画槽与物体的对应图，并做「挡住一个物体看谁坏」的消融。

判据：什么时候选它。三问。世界域的物体是不是可数且持久（桌上的杯子、手、手机，是；CarRacing 的沥青纹理，否）？你是不是必须分开回答「这一件动了、那一件没动」（桌宠要克制伸手，是；只关心整车过弯，否）？验证者是不是允许你按物体查错（槽可视化、Hits@1、挡住一个物体，是；只有一个总重建损失，否）？三问全「是」，选它。CarRacing 三问全「否」，这是为什么这里不给这条路安排动手。分工，各打各的主场。

翻回第 12 课的三分评测观，给物体中心加一列。C-SWM 不画图，生成真这一项可以得零分，预测准和按物体审计上占优。第 17 课会把槽可解释性收成新指标。

### 5.7 场外旁证：表征路线的赌注，和代码执行世界

LeCun 的赌注要如实转述，再用你的四轴掂量，不要把融资新闻写成技术结论。2022 年的立场文《A Path Towards Autonomous Machine Intelligence》（OpenReview ID: BZ5a1r-kVsf）把 JEPA 写成自主智能体蓝图里的世界模型格：在表征空间预测，丢掉不可预测的细节。第 13 到 15 课的 I-JEPA、eb_jepa、V-JEPA 2 是这张蓝图的可运行切片。2026 年他离开 Meta 后参与创办 AMI Labs（Advanced Machine Intelligence，总部巴黎），公开表述仍是世界模型加 JEPA。TechCrunch 2026-03-09 报道其融资约 10.3 亿美元；产业数字以该报道为准，不当成技术证据。

拿你的四轴和实验掂量这份证词：他对目标轴的论证（像素是噪声、语义是信号）有你第 02 课的损失解剖和本课探针对照撑腰或拆台，几小时后见分晓。注意他的论证主要覆盖物理-感知世界域。搬到代码域时，下面这个反例马上就来。搬到一张桌子上时，光有表征还不够：杯子和手必须是分开的地址，这是第三条路要补的零件，不是 JEPA 论文已经做完的事。

Meta 的 **Code World Model**（Copet 等，Meta FAIR，arXiv:2510.02387）是一个 32B 的开源权重稠密 decoder-only 语言模型。它凭什么敢叫世界模型？可辩护的内核只有一条：它在 Python 解释器和 Docker 环境的观察-动作轨迹上做了中期训练，给定当前程序状态和下一行要执行的代码，预测执行后的程序状态。这里的世界域是**代码执行**。这个世界域自带全课最奢侈的验证者：解释器免费提供转移真值。想要多少条「状态、动作、下一状态」的完美标注轨迹，跑一遍解释器就有多少条，零噪声、零标注成本。对照 5.2 的表：它站在验证者轴的最强档上，所以它可以放心用最普通的架构（decoder-only Transformer）和最普通的目标（自回归预测），裁判够硬，路线选择反而宽松。这是本课核心问题的一个完整答案样本：押哪条路，先看你的世界域送了你什么验证者。

必须划清的三句话，后文不许含糊：

1. Meta 的 Code World Model 建的是代码执行世界，不是本课第三条路。第三条路是物体中心槽。
2. 它也不是本课程的毕业方向。毕业方向是一张桌子上的桌宠。
3. 它的证据价值仅限于「验证者足够硬时，普通架构也能做出可辩护的世界模型」。不要把它的 SWE-bench 数字搬来给 CarRacing 或桌宠打分。

论文报告 SWE-bench Verified pass@1 为 65.8%（带测试时缩放）。这个数字属于代码世界的验证者，本课实验不对它负责。

### 5.8 本课实验的设计：同一批帧、同一个探针、只换目标

三份证供各有效力，但都隔着一层：系统对系统的比较，赢输归因不到单个零件。要正面回答「重建目标和表征预测目标谁的表征更好」，最小实验是把其他一切钉死：同一批帧、同一个下游任务、同一个探针，只换预训练目标。你的家当刚好凑齐这一桌：第 01 课的帧、第 02 课的 VAE 和探针、第 13 课的 I-JEPA 实现。

四个选手同台：训好的 VAE（encoder 取 $\mu$，32 维）、训好的 I-JEPA（目标编码器 patch token 平均池化，128 维）、随机初始化的 VAE encoder、随机初始化的 I-JEPA encoder。后两个是压阵的基线。随机卷积和随机 ViT 的特征在线性探针下经常好得吓人（结构先验白送的），每条路线真正挣到的是「训好减去随机」的那段差值，不是绝对 $R^2$。探针任务沿用第 02 课：从冻结表征线性回归路面横向偏移，岭回归，报 $R^2$，附打乱标签对照。

代理标签的两副面孔。弯度标签从哪来？两条造法，本课都用，效力完全不同。主标签沿用第 02 课 `probe_road.py` 的造法：从像素直接算，画面上半部路面像素质心相对中线的偏移，归一到 $[-1,1]$。它是几何量，跟谁开车无关，是「路往哪弯」的忠实代理。副标签按另一条思路造：取未来 15 步转向动作的均值当弯度代理，直觉是「路往左弯，司机接下来就得往左打方向」。先把丑话说透：这是个代理，而且它代理的成色完全取决于开车的是谁。你第 01 课的数据是布朗噪声随机策略采的，方向盘和路况毫无关系，这个标签在你的数据上就是纯噪声，探针 $R^2$ 会趴在 0 附近，四个选手一起趴。这不是实验失败，这是实验的一部分：代理标签的质量上限是「代理量与目标量的真实相关」，策略不看路，转向就不载有路的信息。想让这个副标签活过来，得用第 04 课训好的 controller 重录几十条轨迹（它看路），第 11 节的改造清单里有这个选做实验。

探针的读数怎么解释，先写下来再跑。记 $R^2_{\mathrm{VAE}}$、$R^2_{\mathrm{JEPA}}$ 为训好的两员，$R^2_{\mathrm{rV}}$、$R^2_{\mathrm{rJ}}$ 为各自的随机基线。看两个量：组内差 $\Delta_{\mathrm{VAE}} = R^2_{\mathrm{VAE}} - R^2_{\mathrm{rV}}$ 和 $\Delta_{\mathrm{JEPA}} = R^2_{\mathrm{JEPA}} - R^2_{\mathrm{rJ}}$。谁的 $\Delta$ 大，谁的训练目标在这批数据上为「读出弯度」多挣了信息。直接比 $R^2_{\mathrm{VAE}}$ 和 $R^2_{\mathrm{JEPA}}$ 也可以，但要口头申报两个没控制的变量：架构不同（卷积对 ViT）、维度不同（32 对 128，维度多天然占探针便宜；PCA 压到同维的对照在第 11 节改造清单里）。

胶水在第 7 节：`extract_frames.py`、`ijepa_cr.py`（`ijepa.py` 副本，动三处）、`probe_compare.py`（复用第 02 课标签函数和岭回归）。

这个实验自带三道自检：打乱标签后所有 $R^2$ 必须掉到 0 附近（防泄漏）；JEPA 表征的逐维标准差不得接近 0（防坍缩，第 13 课的老规矩）；副标签在随机策略数据上必须全员趴 0（上面论证过，如果它居然显著大于 0，先怀疑你的标签代码泄漏了帧信息，而不是庆祝）。

物体中心不进入这张表。CarRacing 的俯视赛道没有可数的持久物体，强行设三个槽，模型多半会把路、草、车贴图拆成纹理块，读出来的 $R^2$ 没有「杯子倒了」那种语义。第 23 课换 2D shapes / 多物体物理，那时槽才有东西可绑。

### 5.9 互动：一杯水被手碰到

先别跑机器。拿一张纸，把同一件事写成三种下一状态。场景就一句话：桌上有一杯水，一只手从侧面碰到杯壁。问：杯子会不会倒？

先自己填空，再对照下面的参考填法。参考不是标准答案，是「状态形状会怎样限制你能问的问题」的示范。

| 写法 | 状态长什么样 | 「手碰到杯」的下一状态怎么写 | 能不能回答杯子会不会倒 |
|---|---|---|---|
| 重建像素 | 一张 RGB 图，杯子、手、桌面、反光挤在同一块像素里 | 下一张 RGB 图：杯沿几个像素挪了，水面高光碎了，手指占的像素变多 | 人眼或许看得出倾斜。模型的损失按像素面积投票，杯沿那一圈几乎没声音；「倒」不是像素距离，是刚体绕接触点转过去 |
| 预测表征 | 一条向量 $z_t$，所有东西揉在一起 | 一条向量 $z_{t+1}$，能量或距离告诉你「和目标像不像」 | 探针也许能读出「接触发生了」。杯子和手没有分开的地址，你问「杯子」时，模型没有一个叫杯子的格子可查 |
| 三个槽 | 杯子槽、手槽、桌子槽，各是一个向量 | 杯子：位置、倾角、是否仍与桌接触；手：速度、接触力方向；桌子：支撑点还在，本身不动 | 杯子槽的倾角过阈值就能答「会倒」。手槽和桌子槽可以单独核对：手是不是还在推，桌子是不是还撑着。答错时你知道错在哪一格 |

填完之后再问自己三个追问，写在同一张纸上。

1. 重建路线若把下一帧画得很像，是否等于知道会倒？不一定。画得像只说明纹理对了，刚体转动的轴可以仍然是错的。第 10 课 DIAMOND 画面保真和控制分数可以不同步，是同一件事的像素版。
2. 表征路线若 $z_{t+1}$ 离「杯子已倒」的目标表征很近，是否等于知道会倒？只在你有这个目标表征的时候成立。第 14 课 Two Rooms 规划就是给一张目标图。桌宠上「别把水推倒」很少有一张目标图可拍，更常见的是一条约束：杯子倾角不要过线。约束需要一个叫倾角的读数，一条揉在一起的 $z$ 没有这个读数，除非你再训一个探针，而探针在第 15 课已经告诉你：量法不同，结论可以反过来。
3. 三个槽若杯子槽和手槽对调了，预测还会对吗？物理转移可能仍然「看起来像」，但你按槽读倾角就会读到手的姿态。这就是槽身份问题，第 23 课用对应图和「挡住一个物体」来查。

桌宠用途在这里已经能说清。第八幕工作空间大约 60 cm × 40 cm，主要风险是把杯子扫下桌。第 32 课「克制」那一件的查询是：想象伸手，杯子槽的下一状态会不会过桌沿。没有槽，查询会退化成整图像不像出事。本课这张表是安全层的接口草稿。第 23 课变成真实验，第 27 课加上碰撞过滤，第 30 课在自己的桌子上训 $P(s_{t+1}|s_t,a_t)$。

改动一（数据集）：在文件里加入下面这个类（放在 `train()` 之前即可），接口对齐 CIFAR10 的「(图像, 标签) 对」，训练循环其余部分一行不用动：

```python
class CarRacingFrames(torch.utils.data.Dataset):
    """CarRacing 帧库。归一化用固定的 0.5/0.5，偏离 CIFAR 统计量属有意简化。"""
    def __init__(self, path='datasets/carracing_frames64.npy'):
        self.frames = np.load(path)
    def __len__(self):
        return len(self.frames)
    def __getitem__(self, i):
        x = torch.from_numpy(self.frames[i].copy()).float().permute(2, 0, 1) / 255.
        return (x - 0.5) / 0.5, 0
```

然后在 `train()` 里找到装数据那几行，transform 流水线（含 `RandomResizedCrop(32, ...)`）加 `datasets.CIFAR10("./data", ...)` 那两句，整段换成一行 `ds = CarRacingFrames()`，后面的 `DataLoader(...)` 保留原样。我们顺手扔掉了裁剪增广：I-JEPA 的监督来自 masking 而非增广，帧库又本来就是统一尺寸，少一个变量少一处嫌疑（文件顶上若有 CIFAR 的 MEAN/STD 常量，删掉或留着不用都行）。

改动二（尺寸）：把 `Encoder` 实例化处的 `img_size` 改为 64、`patch_size` 改为 8（默认是 32 和 4）。这一对改法是特意挑的：64 除以 8 等于 32 除以 4，patch 网格还是 8×8 共 64 个，正弦位置编码的网格形状不变，`Predictor` 和 masking 逻辑零改动。

改动三（存盘）：`train()` 的训练循环结束后，把 EMA 目标编码器的权重存下来。目标编码器就是循环开始前用 deepcopy 从上下文编码器复制出来、参数不参与梯度的那一个（变量名以你的副本为准）：

```python
torch.save(target_encoder.state_dict(), 'jepa_cr_encoder.pt')
```

顺手把 epochs 从默认的 8 提到 20：帧库比 CIFAR-10 单调（一个赛道题材对十类物体），多几个 epoch 很便宜，收益是表征更稳。

### Step 5: 同一个探针，四个选手各跑一遍

存为 `probe_compare.py`。标签函数和岭回归与第 02 课 `probe_road.py` 逐行同款，探针帧同样取测试集前 400 个文件、每 40 帧一采，两课的数字可以直接并到一张表里。

```python
"""probe_compare.py ， 同数据同探针：VAE 目标 vs JEPA 目标。
用法: python probe_compare.py runs/L32_b1 jepa_cr_encoder.pt"""
import sys
from os import listdir
from os.path import join, isdir
import numpy as np
import torch
from torchvision import transforms
from models.vae import VAE
from ijepa_cr import Encoder

vae_dir, jepa_ckpt = sys.argv[1], sys.argv[2]
device = 'cuda' if torch.cuda.is_available() else 'cpu'
K = 15                                    # 副标签：未来 15 步转向动作均值

vae = VAE(3, 32).to(device).eval()        # 训好的 VAE（第 02 课产物）
vae.load_state_dict(torch.load(join(vae_dir, 'vae', 'best.tar'),
                               map_location=device)['state_dict'])
vae_rand = VAE(3, 32).to(device).eval()   # 随机初始化对照

jepa = Encoder(img_size=64, patch_size=8).to(device).eval()
jepa.load_state_dict(torch.load(jepa_ckpt, map_location=device))
jepa_rand = Encoder(img_size=64, patch_size=8).to(device).eval()

tf = transforms.Compose([transforms.ToPILImage(),
                         transforms.Resize((64, 64)), transforms.ToTensor()])

def road_offset(obs_t):                   # 与第 02 课 probe_road.py 逐行相同
    h, w, _ = obs_t.shape
    top = obs_t[:h // 2].astype(int)
    r, g, b = top[..., 0], top[..., 1], top[..., 2]
    road = ~((g > r + 20) & (g > b + 20))
    if road.sum() < 50:
        return None
    return np.nonzero(road)[1].mean() / ((w - 1) / 2) - 1.0

root = 'datasets/carracing'
files = sorted(join(root, sd, f) for sd in listdir(root)
               if isdir(join(root, sd)) for f in listdir(join(root, sd)))[-600:]

feats = {'VAE': [], 'VAE-rand': [], 'JEPA': [], 'JEPA-rand': []}
y_road, y_steer = [], []
for fpath in files[:400]:
    d = np.load(fpath)
    obs, act = d['observations'], d['actions']
    for t in range(0, len(obs) - K, 40):
        y = road_offset(obs[t])
        if y is None:
            continue
        y_road.append(y)
        y_steer.append(act[t:t + K, 0].mean())      # 转向是动作第 0 维
        x = tf(obs[t]).unsqueeze(0).to(device)
        with torch.no_grad():
            for name, m in [('VAE', vae), ('VAE-rand', vae_rand)]:
                mu, _ = m.encoder(x)
                feats[name].append(mu.squeeze(0).cpu().numpy())
            for name, m in [('JEPA', jepa), ('JEPA-rand', jepa_rand)]:
                tok = m((x - 0.5) / 0.5)  # (1, 64, 128) 的 patch token 序列
                feats[name].append(tok.mean(1).squeeze(0).cpu().numpy())

y_road, y_steer = np.array(y_road), np.array(y_steer)
y_shuf = np.random.default_rng(0).permutation(y_road)   # 打乱对照

def ridge_r2(X, y, lam=1e-2):             # 与第 02 课同款岭回归
    n_tr = int(0.8 * len(y))
    Xtr, Xte, ytr, yte = X[:n_tr], X[n_tr:], y[:n_tr], y[n_tr:]
    Xm, ym = Xtr.mean(0), ytr.mean()
    w = np.linalg.solve((Xtr - Xm).T @ (Xtr - Xm) + lam * np.eye(X.shape[1]),
                        (Xtr - Xm).T @ (ytr - ym))
    pred = (Xte - Xm) @ w + ym
    return 1 - ((yte - pred) ** 2).sum() / ((yte - yte.mean()) ** 2).sum()

print('样本数:', len(y_road))
print('%-10s %6s %10s %10s %10s %10s' %
      ('模型', '维度', '弯度R2', '打乱R2', '转向R2', '表征std'))
for name in ['VAE', 'VAE-rand', 'JEPA', 'JEPA-rand']:
    X = np.array(feats[name])
    print('%-10s %6d %10.3f %10.3f %10.3f %10.3f' %
          (name, X.shape[1], ridge_r2(X, y_road), ridge_r2(X, y_shuf),
           ridge_r2(X, y_steer), X.std(0).mean()))
```

执行：

```bash
python probe_compare.py runs/L32_b1 jepa_cr_encoder.pt
```

读表姿势（预期方向，一切以实测为准）。弯度 $R^2$ 列：训好的 VAE 应显著大于 0（第 02 课已经证过一次）；训好的 JEPA 大概率也显著大于 0，这本身就是新闻：一个从没画过一帧图的模型，表征里装着路的位置。两个随机基线多半也不是 0（结构先验白送的），所以结论要看组内差 $\Delta$（5.8 节的算法）。打乱 $R^2$ 列：四行都必须趴在 0 附近，否则流程泄漏，全表作废。转向 $R^2$ 列：随机策略数据上四行一起趴 0 才是正确答案，这列是代理标签的现场教学。表征 std 列：JEPA 行贴 0 说明坍缩，回 Step 4。

两种结局都值得原样写进报告：JEPA 的 $\Delta$ 更大，说明在这批数据上表征预测目标为决策信息多挣了钱，LeCun 的目标轴论证在你的小设置上方向成立；VAE 的 $\Delta$ 更大或两者打平，也不丢人，JEPA 只训了 20 个 epoch 的小 ViT，如实写「本预算下未复现表征预测的优势」，并把架构、维度、预算三个混杂列出来。禁止只报好看的那种。

## 10. 排错

| 症状 | 最可能的原因 | 怎么确认 | 怎么修 |
|---|---|---|---|
| `extract_frames.py` 断言失败 | 第 01 课只采了 100 条冒烟数据 | 数 `datasets/carracing` 里的文件数 | 回第 01 课 Step 2 稳路线补采到 1000 条 |
| `torch.load` 报 UnpicklingError 或 weights_only 相关错 | 新版 torch 默认只加载纯权重，VAE 的 checkpoint 里还有优化器等对象 | 看报错里有没有 weights_only 字样 | 给那次 `torch.load` 加 `weights_only=False`（自己训的文件，来源可信） |
| 加载 VAE 报 size mismatch | 拿了第 02 课 L8/L64 对照组的 checkpoint，或 `LSIZE` 没改回 32 | 看 `runs/` 目录名和 `utils/misc.py` | 用 `runs/L32_b1`，或把脚本里的 `VAE(3, 32)` 换成对应维数 |
| JEPA 特征提取报形状错误 | 你的副本 Encoder 前向输出形状与 (批, token, 通道) 不同 | 打印一次 `m(x).shape` | 按实际形状改池化那行；只要拿到每帧一条向量就行 |
| JEPA 弯度 $R^2$ 趴 0 但表征 std 正常 | 平均池化把位置信息抹了，或训练/探针两侧归一化不一致 | 换成拼接全部 token（维度 8192）重跑探针看是否回升；核对两处 `(x-0.5)/0.5` | 池化方式当超参试两种，报告里写明用的哪种 |
| 打乱列不趴 0 | 探针样本太少或正则太弱，测试集偶然拟合 | 看样本数打印，正常应有几千 | 把 `files[:400]` 的采样步长从 40 减到 20 加样本，或把 lam 加大一档 |
| 转向 $R^2$ 在随机数据上略大于 0 | 不一定是 bug：布朗噪声动作自相关，而车辆贴图的前轮转角会把当前转向微弱漏进画面，当前转向又与未来均值相关 | 把 K 从 15 加到 50，相关应进一步稀释 | 如实记录并写进代理标签的讨论，这依旧是「读司机」，只是司机的手出现在了画面里 |
| MPS 上训练极慢或出 NaN | 半精度或算子回退问题 | 换 CPU 跑几步对照 | 用 CPU 跑小 batch 验证流程，正式训练挪到 CUDA 机器 |
| 24GB 卡显存不足 | 别的进程占着，或你把模型加大了 | `nvidia-smi` | 把 `ijepa_cr.py` 里 batch 从 256 降到 128，等效结果 |
| 想把三个槽也跑进对照表 | 本课没有桌面多物体数据，CarRacing 绑不出杯子 | 问自己槽对应哪个持久物体 | 停。把冲动写成 `DEBATE.md` 第七节的未决问题，第 23 课用 C-SWM 的 2D shapes 兑现 |

## 11. 前沿与改造

前沿怎么做。同一个问题（状态里该装什么），2024-2026 年公开系统仍分三家。DIAMOND 把重建路线的保真推到能当游戏引擎（CSGO 演示是体验档，不是你的 RL 证据）。V-JEPA 2-AC 把表征路线送上真机械臂（arXiv:2506.09985，约 62 小时机器人后训练，零样本抓放是论文结果，第 15 课未复现训练）。物体中心一侧，SlotFormer（arXiv:2210.05861）把槽序列 Transformer 做成视频动力学；C-SWM 仍是动作条件加对比损失加可解释槽这一支最干净的祖先，所以第 23 课复现它。Meta 的 Code World Model（arXiv:2510.02387）证明验证者够硬时普通自回归 LLM 也能做世界模型；世界域是代码执行，不能代言本课第三条路。AMI Labs 把十亿美元量级赌注押在表征一侧（新闻报道，不是你的实验）。这些系统世界域和验证者不同，构不成互相反驳：路线没有全域冠军，只有各自主场。

我们差在哪。规模占一半（数据、参数、卡时），另一半是手艺：统一评测、缩放外推、消融归因。你的三份证供恰恰在这三处最薄。所以第五幕不再引入新论文族。第 17 课把训过的模型放进同一套评测，证明预测准、生成真、规划好可以互相矛盾，并预告槽可解释性；第 18 课问「VAE vs JEPA 结论数据翻十倍会不会翻案」；第 19 课把 JEPA 目标接进 Dreamer 的重建位，是今天这场对决的全尺寸重赛。

机制差距和规模差距要分开写。把 VAE 换成更大的 ViT 是钱能解决的。把一条向量换成一组槽，让「杯子倒了、手机没动」变成两个地址上的预测，是本课教的机制。桌宠若仍用一条 32 维 $z$ 表示整张桌子，「克制」会退化成整图相似度。

动手改造清单（选做，各自独立）：

1. 维度公平性对照：把 JEPA 的 128 维特征 PCA 到 32 维再跑一遍探针，和 VAE 同维对比。预算：几分钟。预期：$R^2$ 略降；如果暴跌，说明弯度信息弥散在整个表征空间里（对照 VAE：KL 项逼着它把信息压紧），这本身就是两种目标塑造的表征几何差异，写进报告。失败：PCA 后 $R^2$ 与随机基线不可区分，且你没有保存 PCA 前后的方差谱，那就分不清是信息丢了还是探针过拟合。
2. 让副标签活过来：用第 04 课训好的 controller 录 50 条轨迹（会看路的司机），重算「未来 15 步转向均值」标签，重跑四行探针。预算：采样半小时加探针几分钟。预期：转向 $R^2$ 从趴 0 集体站起来，且与弯度列排名同方向。这是「代理标签质量取决于行为策略」的完整现场。失败判据：controller 分数本来就低（不到 400），信号弱属正常，先回第 04 课。
3. 迷你缩放预演：把抽帧步长改成 20 和 5，得到 2 万帧和 8 万帧两个帧库，各训一个 JEPA，画「弯度 $R^2$ 随数据量」的三点曲线。预算：单卡一两小时。预期：能看到趋势方向，但三个点撑不起外推，体会一下这句话的分量，就当第 18 课的开胃菜。失败：三点乱跳且没有固定种子，那就什么趋势也不是。
4. 纸面加槽：回到 Step 0 的杯子场景，再加第四个槽「水面」。写出水面槽的下一状态（振荡、溢出、仍在杯内），并说明为什么「杯子没倒但水洒了」在三个槽的写法里会漏掉。预算：二十分钟，不训练。预期：你开始体会槽的粒度是设计问题，不是超参。第 23 课会把这个问题变成「$K$ 设多少」。

顺手复现。I-JEPA 论文（arXiv:2301.08243）的核心论断「不重建像素也能学出可读的高层信息」，在本课的缩小版设置里对应「JEPA 弯度 $R^2$ 显著高于其随机基线」。主线 Step 5 已经顺手做完，在报告里给它单独一句话的位置。预期能复现同方向趋势（$\Delta_{\mathrm{JEPA}}>0$）；不预期复现 ImageNet 线性探针数字。C-SWM 论文「对比训练的结构化世界模型能克服像素重建的局限」，本课只复述、不复现；第 23 课的缩小版对应实验是官方 2D shapes 上的 Hits@1 方向，预期能看到槽与物体的对应，不预期对齐论文表格里的全部环境。

## 12. 论文与延伸

1. Contrastive Learning of Structured World Models（Kipf, van der Pol, Welling, ICLR 2020，[arXiv:1911.12247](https://arxiv.org/abs/1911.12247)）。第三条路的世界模型原论文。带着问题读：物体提取器为什么用 $K$ 张特征图而不是 Slot Attention 那种可交换槽？对比损失的负例是随机观察，不是「打乱槽身份」，这对「杯子和手对调」这种错误有没有惩罚？Hits@1 这个验证者和重建误差、环境奖励各差在哪？第 23 课会跑它的官方仓库，今天先把公式和评测口径读懂。
2. Object-Centric Learning with Slot Attention（Locatello et al., NeurIPS 2020，[arXiv:2006.15055](https://arxiv.org/abs/2006.15055)）。槽怎么从像素里长出来。带着问题读：softmax 为什么在槽这一维归一化，而不是在空间维？置换等变保证了什么，没保证什么（没保证槽 2 永远是杯子）？它是编码器零件，缺了哪两样才变成世界模型（动作条件、时间转移）？
3. Simple Unsupervised Object-Centric Learning for Complex and Naturalistic Videos（Singh, Wu, Ahn, NeurIPS 2022，[arXiv:2205.14065](https://arxiv.org/abs/2205.14065)，仓库写作 STEVE / Slot-Transformer for Videos）。槽遇到自然视频。带着问题读：作者强调没有新损失、只换了解码器，这个主张和本课「目标轴独立于状态形状」是不是同一句话？Transformer 解码器重建的是像素还是 VQ 码？若把 STEVE 的重建目标换成 C-SWM 的对比损失，你预期哪一类视频会先垮？
4. SlotFormer: Unsupervised Visual Dynamics Simulation with Object-Centric Models（Wu et al., ICLR 2023，[arXiv:2210.05861](https://arxiv.org/abs/2210.05861)）。槽上的动力学。带着问题读：它的 Transformer 吃不吃动作？和 C-SWM 的 GNN 一次消息传递相比，长时程一致性靠什么维持？论文把动力学接到规划上的实验，和你第 14 课 Two Rooms 规划是不是同一张图纸？
5. Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture（Assran et al., 2023，[arXiv:2301.08243](https://arxiv.org/abs/2301.08243)）。本课探针实验的论文祖先。带着问题读：I-JEPA 的「高层信息」在原论文里用什么探针量？你的弯道 $R^2$ 对应它的哪一类证据，对应不上的是哪一类（物体计数、深度）？
6. Code World Model: An Open-Weights LLM for Research on Code Generation with World Models（Meta FAIR，[arXiv:2510.02387](https://arxiv.org/abs/2510.02387)，论文标题缩写 CWM）。验证者决定路线的旁证。带着问题读：论文里 world model 的操作定义是哪句？解释器轨迹怎么格式化成观察-动作序列？它是代码执行世界，不是本课第三条路，不是毕业方向。
7. V-JEPA 2: Self-Supervised Video Models Enable Understanding, Prediction and Planning（Assran et al., 2025，[arXiv:2506.09985](https://arxiv.org/abs/2506.09985)），只回读规划章节（V-JEPA 2-AC）。带着问题读：它规划时最小化的那个量，和你第 14 课在 Two Rooms 里用的目标函数是不是一族？它的验证者是什么档位（真机成功率：到货慢、样本少，但极硬）？表征路线上了真机械臂，是否因此就不需要物体槽（提示：Franka 抓放的物体种类少、工作空间干净，桌宠那张桌子更挤）？

9. World Models（Ha & Schmidhuber, 2018，[arXiv:1803.10122](https://arxiv.org/abs/1803.10122)）。用四轴给 2018 年的 V-M-C 定位；V 和 M 分开训练如何让「把 V 换成 JEPA 目标」成为模块级手术；「梦太确定就被钻空子」在三条路线上各长什么样（重建钻误差、表征能量面太平、槽身份对调后能量仍低）。
10. 选读：TD-MPC2（Hansen, Su, Wang, ICLR 2024，[arXiv:2310.16828](https://arxiv.org/abs/2310.16828)）、DIAMOND（Alonso et al., NeurIPS 2024，[arXiv:2405.12399](https://arxiv.org/abs/2405.12399)），重审第 08、10 课数字时回来补方法节。选读 eb_jepa 技术报告（Terver et al.，[arXiv:2602.03604](https://arxiv.org/abs/2602.03604)），对「能量面平坦」没底时补第一章。

第四幕到此收官。你手里有三条路线的实现或预告、三份重审过的对照、一场同探针对照，和一张「一杯水」三写法表。每个结论都拖着「在我的口径下」这条尾巴。第 17 课开始修它：给训过的世界模型建统一评测，证明预测准、生成真、规划好可以互相打架。槽可解释性会出现在那套评测的预告栏里，真正量它要等到第 23 课伸进 `tkipf/c-swm`。
