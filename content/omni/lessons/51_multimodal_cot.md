# 第 51 课：给视觉语言模型加上分步推理

> 内容：阶段化视觉推理、推理 token 与答案 token 分账、以视觉引用为对象的过程奖励<br>
> 建议周期：阅读约 70 分钟；CPU 实验数分钟；浏览器 Lab 一次验收约 10 分钟<br>
> 硬件：无 GPU 可读完全文并跑 CPU 机制实验。复现 LLaVA-CoT 为单节点 8×H100 全参微调；Vision-R1 冷启动用 Llama-Factory 做 2 个 epoch，强化学习在 Verl 上跑两阶段 PTST<br>
> 产物：带阶段标签的推理协议、过程奖励定义、计数题上的空引用反例。不声称复现 MathVista 73.5% 或 MMStar 57.6<br>
> 独立性：需要[第 17 课](17_grpo_rlvr.md)的可验证奖励与组内优势，[第 23 课](23_grounding_ocr_spatial.md)的“答对不等于看见位置”，[第 38 课](38_vla_rlvr.md)的“只改 r、不重推 clip”。无 GPU 时不要根据 CPU 数字报告真实 VLM 成功率

## 1. 看见图以后为什么还要分步写推理

视觉语言模型已经能对一张图吐出短答案。[第 22 课](22_standard_vlm_recipe.md)把冻视觉、训投影、再解冻语言模型的顺序走通；[第 23 课](23_grounding_ocr_spatial.md)证明选择题答对，不等于模型用对了像素。到这一课，系统多了一层更隐蔽的失败：它不但能答对，还能写出一段看起来像推理的文字，而这段文字从来没有点到图上的任何一格。

最小反例仍然是计数。4×4 网格里两只红杯，分别在 $(0,1)$ 和 $(2,3)$。问题是“红色杯子有几个”。正确答案是 `2`。模型可以输出 `2`，因为它在训练里见过无数“杯子成对出现”，或者因为它把注意力放在了旁边的白盘上、却靠语言先验补上了数字。若你只检查最终 token，账本是绿的。若你强制把推理写成可检索的 span，并要求 span 里出现格子编号，空引用会立刻把过程奖励打成 0。

这就是本课要改的模块。视觉编码器可以继续冻着，[第 17 课](17_grpo_rlvr.md)的概率比和 clip 也不必再推一遍。要动的是一次生成怎样切成两套 token，以及“有没有引用视觉证据”怎样单独打分。公开方案里，LLaVA-CoT（[arXiv:2411.10440](https://arxiv.org/abs/2411.10440)）用四个阶段标签逼模型先摘要、再描述相关像素、再推理、最后给结论。Vision-R1（[arXiv:2503.06749](https://arxiv.org/abs/2503.06749)）用冷启动加组相对策略优化（GRPO：Group Relative Policy Optimization，同题多答、组内比平均分）去激励更长的思维过程。两篇论文的奖励对象都还不是格子引用。本课在缩小版里补上这一列：过程奖励认的是推理 span 里的视觉证据，不是答案字符串碰巧等于 2。

[第 17 课](17_grpo_rlvr.md)的 $r$ 盯最终答案能不能通过确定性程序。[第 38 课](38_vla_rlvr.md)把同一套组内结构接到抓取，盯成功谓词和接触。[第 23 课](23_grounding_ocr_spatial.md)的命中是评测探针，还没有写成训练时的 $r_{\mathrm{proc}}$。本课把三课接到同一句验收上：关掉“必须引用格子”之后，答案可以仍然对，引用格为空，过程奖励必须是 0。

和第 08 课的边界再写清楚一次，免得分辨率数字和过程奖励被加在一起。[第 08 课](08_dynamic_vision.md)问：同样的 Thinker、同样那么多视觉 token，动态切片能不能让小物体变得可分。本课问：可分之后，模型有没有把计数步骤写到那些物体所在的格子上。08 课 OCR 或空间题上涨，只说明 encoder 看见了更多像素；如果本课的 $C(y)$ 仍是空集，上涨可能来自语言模型更会猜“常见是两个”。两课的负对照也不同：08 课打乱二维坐标，本课关掉引用开关或把格子写进结论。可以同一张计数图两边都测，必须两个 run ID。也可以链回[第 01 课](01_baseline_reproduction.md)的 trace 纪律：本课每条回复都要能追到 image_id、阶段 span、解析出的 $C(y)$ 和 spec 版本。

公开两篇主文献的奖励对象再提前钉死，避免后面把论文分数抄进本课 Gate。LLaVA-CoT 的监督目标是带标签的整段文本，测试时 SWIRES 用的是另一个多模态奖励模型给阶段打分，都不是“格子是否落在金标集合”。Vision-R1 的 HFRRF 看格式标签加最终数学答案。本课 $r_{\mathrm{proc}}$ 是教学扩展。引用 57.6 或 73.5 时，必须写“那是他们的奖励，不是格子引用率”。Gate 只认空引用那一行。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 分步推理 / CoT | 先写出中间步骤再给答案，而不是一个 token 直接跳出数字 |
| 阶段标签 | 把一次回复切成 SUMMARY / CAPTION / REASONING / CONCLUSION 等可检索区间 |
| 推理 token | 落在推理 span 里、参与过程检查的那些位置 |
| 答案 token | 落在结论 span 里、只对最终答案算分的那些位置 |
| 视觉引用 | 推理 span 里出现的格子、框或区域编号，必须能映射回图像 |
| 过程奖励 $r_{\mathrm{proc}}$ | 只看引用是否碰到真值区域；引用为空则为 0 |
| 答案奖励 $r_{\mathrm{ans}}$ | 只看最终答案是否等于金标 |
| 不忠实推理 | 结论对，中间步骤并没有使用导致该结论的证据 |
| 冷启动 | 先用带思维过程的监督数据教会格式，再上强化学习 |
| PTST | Vision-R1 的渐进思维抑制：先限制长度学会正确想法，再放开长度 |
| 硬格式结果奖励 | 格式与最终答案同时对才给 1，否则 0 |
| SWIRES | LLaVA-CoT 的分阶段回溯搜索：某一阶段全差就退回上一阶段重写 |

## 2. 本课解决的问题

当前系统（以及你按第 22 课训出的任何 VLM）默认验收是最终字符串。短答案 VQA、MathVista 的填空、计数题的整数，都是这个口径。它盖不住三类失败：

1. 跳步。模型看见图之后直接写数字。日志里没有“我看了哪一格”，出了错你无法判断是编码器糊了，还是语言模型在猜。
2. 伪思维链。监督数据里的步骤是人按启发式排好的摘要—描述—推理，缺少提问、反悔、复查。Vision-R1 把这类数据叫做 Pseudo-CoT。它能让格式看起来整齐，不一定让模型真的在用像素。
3. 只奖结果。GRPO 若只看最终数字，组里四条都写对 `2`、三条从未点格，组内优势仍可能全是 0，或者把空引用和真引用打成同一分。奖励投机从[第 17 课](17_grpo_rlvr.md)的 JSON 解析，变成“不看图也能蒙对计数”。

本课的改造范围只包括：阶段切分协议、两套 token 的集合定义、过程奖励 $r_{\mathrm{proc}}$、以及一道可关引用开关的计数教具。不更换[第 02 课](02_multimodal_connector.md)的 connector，不重做[第 08 课](08_dynamic_vision.md)的动态分辨率，不重推 clip。若你要在真实 7B 级 VLM 上复现 LLaVA-CoT 或 Vision-R1，那是第 13 节的改造实验，不是主路径验收。

以下结果不能支持“模型会分步看图”：

- 只报最终准确率，没有推理 span，也没有引用格；
- 把思维链长度当成能力，长度上升而引用仍为空；
- 把 Vision-R1 的硬格式结果奖励抄成本课的过程奖励；
- 把 Lab 里关掉开关后的 `r_{\mathrm{ans}}=1` 写成 MathVista 73.5%；
- 在本课再推导一遍 GRPO 的概率比，却写不出 $C(y)\cap G$。

执行顺序固定：先在 CPU 夹具上证明两套 token 不相交、空引用过程分为 0；再在计数网格上先预测再揭晓“关掉必须引用后答案对、引用格为空”；有 GPU 时才把同一协议接到开源权重。没有 GPU 时，前两步已经构成完整交付。

把本课不解决的问题也写死，避免和第 52 课规格抢题。看见图之后该不该调用计算器、裁剪或搜索，是下一课的 schema，不是本课的 $C(y)$。格子编号不是工具调用。跨会话把原图还是摘要存下来，是第 53 课规格。本课的记忆长度就是一次回复的两段 span。世界模型里的未来帧、三维资产解码器，分别属于第 33–34 课和第 50 课规格，本课不生成下一帧，只要求当前帧上的引用可检查。

失败条件预先写死：

- 重推一遍 GRPO 的 clip，却写不出 $C(y)$ 从哪一段解析；
- 把训练奖励上涨写成看图能力上涨，却没有空引用率；
- 只在必须引用开启时验收，却声称已经造出“答案对、引用空”；
- 把 Lab 里的 $r_{\mathrm{proc}}=0$ 写成 Vision-R1 的 73.5% 或 LLaVA-CoT 的 9.4 个点；
- 把 Wait 词频、平均思维链长度或 SWIRES 墙钟抄进本课 Gate。

这五条里，前三条是对象写错，后两条是把论文数字和夹具数字焊在一起。写实验记录时每条后面跟一个本课夹具字段：span 名、$C(y)$、开关状态、空引用那一行、词频所在表号。字段和红线绑在一起，别人才能复核。

## 3. 开始前需要准备什么

本课不依赖 MiniMind-O 的训练脚本。需要的是第 17 课的组内优势直觉，第 23 课把文字对和格子命中拆开的习惯，以及第 38 课“只改 $r$”的纪律。没有读过第 38 课也可以往下走，但遇到“全组同分没有更新”时，要回到那一课，而不是在本课里重做接触公式。

开始前把笔记本分成两栏。左栏只抄打开过的论文句：表号、均分、数据量、训练步、奖励定义。右栏写本课约定：阶段标签用 `<REASONING>` 与 `<CONCLUSION>`，格子写成 $(i,j)$，金标计数 $a^\star=2$，金标格子 $G=\{(0,1),(2,3)\}$，过程奖励看交是否非空。左栏数字可以对外引用，右栏数字只能当教学夹具。有人把 Lab 里的空引用写成“复现了 Vision-R1 的过思考问题”，属于把右栏抄进左栏。

硬件上，读完加 CPU 实验不需要 GPU。若要跑 LLaVA-CoT 的全参微调，准备单节点 8 张 H100。若要跑 Vision-R1 的冷启动，原文用 Llama-Factory 做 2 个 epoch；强化学习用 Verl，两阶段合计 200 步。Vision-R1 构造 200K 冷启动数据时部署了 Qwen2.5-VL-72B 和 DeepSeek-R1，那是数据工厂，不是你的最低交付。没有这套设备，跳过可选的权重 Step 仍可完成课程。

## 4. 完成后应具备的能力

1. 写出一次回复的阶段切分，并指出 SUMMARY、CAPTION、REASONING、CONCLUSION 各自不许提前做的事。
2. 把生成序列拆成 $\mathcal{T}_{\mathrm{reason}}$ 与 $\mathcal{T}_{\mathrm{ans}}$，证明两个位置集合不相交。
3. 只从推理 span 解析格子编号；写进结论 span 的 $(i,j)$ 不得计入 $C(y)$。
4. 写出 $r_{\mathrm{ans}}$ 与 $r_{\mathrm{proc}}$，并指出 $C(y)=\emptyset$ 时 $r_{\mathrm{proc}}=0$。
5. 对照第 17 课与第 38 课：clip 和组均值不动，变的只是 $r$ 看哪一列。
6. 按原文区分 LLaVA-CoT（结构化 SFT + SWIRES）和 Vision-R1（模态桥冷启动 + PTST + 硬格式结果奖励）。
7. 在计数教具里先提交预测“关掉必须引用后答案对、引用格为空”，再揭晓。
8. 看到“接上 CoT 之后准确率涨了 9.4 个点”时，能追问：有没有阶段标签消融、有没有测试时搜索、过程奖励看的是格式、答案还是视觉引用。

第 4 节的八条里，前四条是公式，中间两条是文献接口，后两条是实验纪律。缺公式，Lab 里的 `r_proc` 会对不上手算。缺文献接口，会把 57.6 和 73.5 写进同一格。缺实验纪律，会先看揭晓再选预测。三条缺一，本课都不算完成。

读完可用下面这段自检，不通过就先别进公式。桌上两只红杯。模型输出 `2`。你应能指出：若推理栏空，过程奖励是 0；若推理栏点了蓝球和白盘，过程奖励仍是 0；若点了两只红杯、结论写成 `3`，答案奖励是 0、过程奖励是 1，合取是 0。若你只能写出“思维链越长越好”，还没有把证据变成可执行的集合。若你写出了 Q 网络和 GAE 的展开，却说不清格子从哪个 span 来，本课的对象写错了。这段自检不计入 CPU 实验，但能避免后面把更新写在错误的标量上。

第 4 节的口头验收可以对着 CPU 实验打印出的字典做。`empty_cite_r_process` 应等于 0，`empty_cite_r_answer` 应等于 1，`empty_cite_r_require` 应等于 0，`process_group_rewards` 应等于 $[1,0,0,0]$。对不上就先改理解，再改进 Lab。Lab 验收另加一条操作纪律：必须先选预测句，再把开关拨到关，再揭晓。三步缺一，Gate 不亮。

## 5. 原理：边造边讲

机制按同一节奏：为什么需要、怎么运转、精确定义、公开实现落在哪、怎么证明做对了。本课没有 MiniMind 源码，代码落点写在公开仓库与本课夹具。GRPO 的概率比与 clip 只引用第 17 课。

### 5.1 直接出答案会跳过看见了什么

早期开源 VLM 的默认生成是短答。LLaVA-CoT 引言把这叫做 direct prediction：问题进来，简短答案马上出去。短答在“这是什么颜色”上够用，在需要组织图像证据的计数、几何、科学问答上会先给出结论，再事后找理由。因为语言模型按 token 顺序写，一旦错误结论已经出现，后续 token 倾向于把它圆上。LLaVA-CoT 附录 A 用 Llama-3.2-11B-Vision-Instruct 在 MMStar 上的两个例子说明：模型会误读题意直接拒答，或声称题目不清而跳过读图。

类比：只报考试分数、不交草稿纸。分数对了，你不知道他有没有看过卷子上的图。类比失效处：语言模型的“草稿纸”也是生成出来的，可以伪造。所以本课不只要求“写步骤”，还要求步骤里出现能映射回像素的引用。

[第 23 课](23_grounding_ocr_spatial.md)已经构造过“答案对、格子错”。那一课的格子来自注意力或框。本课的格子来自模型自己写出来的编号。两者可以同时失败：注意力在错物体上，推理文本也从不提真值格。本课只验收文本引用这一列，避免和 23 课的注意力质量分数兑成一个数。

验证：同一道计数题准备两条回复。一条直接 `2`。一条先写格子再写 `2`。只看准确率，两条一样。看 $C(y)$，第一条是空集。

把“提前给结论”写成时间轴。$t=0$ 图像 token 进语言模型。$t=1$ 模型若先吐 `2`，后续所有 token 的条件里已经包含这个数字。想改口就要写出“我数错了”之类的反省。Vision-R1-cold 里大量 Wait / Alternatively，正是为了给改口留表面形式。LLaVA-CoT 的做法不同：CONCLUSION 之前的三个阶段在数据里被禁止写出最终答案，从监督上切断提前结算。两条路都承认同一件事：自回归一旦把答案写进前缀，纠错成本上升。本课夹具更狠：结论之前必须出现格子，否则过程分直接 0，连“漂亮的反省散文”也不给分。

提前结算还有一种更隐蔽的写法：SUMMARY 里写“我将证明红色杯子有两个”。标签还没到 CONCLUSION，数字已经泄漏。严格协议应把 SUMMARY / CAPTION 里出现 $a^\star$ 记为格式失败。本课夹具只有两段标签，不检查泄漏。改造实验若加这项，必须另开 spec 版本，不要改默认 $r_{\mathrm{proc}}$。默认过程奖励只看格子，不看数字有没有在推理段提前出现。两列失败要分列，才能知道模型是没看图，还是看了图却抢答。

### 5.2 四阶段标签把“看”写成可切分的 span

LLaVA-CoT 把一次回答拆成四个阶段，每个阶段有一对标签：

- `<SUMMARY> ... </SUMMARY>`：用几句话声明接下来要解决什么，不抢先给答案。
- `<CAPTION> ... </CAPTION>`：只描述与问题相关的图像内容。
- `<REASONING> ... </REASONING>`：在摘要和描述之上做逐步分析。
- `<CONCLUSION> ... </CONCLUSION>`：给用户看的最终答案，短或长取决于提问。

四个阶段在一次前向里由模型自己切换，推理时不再额外提示。作者强调 systematic 指多阶段而不是一条直链，structured 指模型能识别自己处在哪一阶段。去掉标签的消融写在 Table 2：完整结构化均分 57.6，去掉标签 55.7，直接用原问答对训练 54.3，基座 49.8。标签不是装饰，它把搜索粒度和损失掩码能对准的边界刻进序列。

本课教学夹具把中间两段收成一个 `<REASONING>`，把结论收成 `<CONCLUSION>`，是为了让格子解析只有一个入口。真正复现 LLaVA-CoT 时必须保留四对标签，CAPTION 才是“相关像素”的法定位置。教学简化要写进报告，不能把两段标签的 CPU 数字写成论文 Table 2。

公开实现：仓库 [PKU-YuanGroup/LLaVA-CoT](https://github.com/PKU-YuanGroup/LLaVA-CoT)。应对齐特殊符号是否以单 token 进词表。若 `<SUMMARY>` 被切成普通子词，阶段掩码等于没加。

阶段顺序是协议的一部分。训练数据里四个阶段按 SUMMARY、CAPTION、REASONING、CONCLUSION 的时间顺序出现。推理时作者写“没有观察到模型不遵守阶段格式”。本课仍把错序写成可检测失败：CONCLUSION 出现在 REASONING 之前，抽取函数按标签名取 span，位置集合仍可不相交，但时间顺序检查应报警。CPU 实验不锁顺序，Lab 也不锁。真实脚本要加一条 `order_ok`。错序时过程分可以仍按 REASONING 内容算，但格式项应记 0，等价于 HFRRF 的第一项失败。不要为了“看起来像在推理”而自动重排标签。

CAPTION 与本课格子的关系再钉一次。LLaVA-CoT 的相关像素写在 CAPTION 里，通常是自然语言，不一定含坐标。Visual CoT 那条相关工作用框。本课用 `(i,j)`。三种表面形式不要塞进同一个正则。若你复现 LLaVA-CoT 并想接本课 $r_{\mathrm{proc}}$，需要另做一层：从 CAPTION 抽名词，再用外挂检测器变框，再映射到格子。那一层的误差属于检测器，必须单列。教学夹具跳过这一层，直接要求模型写格子，是为了让过程奖励保持确定性。

验证：给定一条带标签的字符串，抽取四个 span 的起止下标，断言它们按时间顺序排列且互不重叠。CPU 实验用两段标签做同一件事。

### 5.3 推理 token 与答案 token 必须分账

把一次生成 $y$ 看成位置 $1\ldots T$ 的序列。阶段函数 $s(t)$ 把每个位置标成 `reason` 或 `ans`（以及本课夹具不使用的 `other`）。定义

$$
\mathcal{T}_{\mathrm{reason}}(y)=\{t:s(t)=\mathrm{reason}\},\qquad
\mathcal{T}_{\mathrm{ans}}(y)=\{t:s(t)=\mathrm{ans}\}
$$

分账的第一句是位置集合不相交：

$$
\mathcal{T}_{\mathrm{reason}}(y)\cap\mathcal{T}_{\mathrm{ans}}(y)=\emptyset
$$

同一表面词可以在两段都出现，例如两边都写了“杯子”。那是词面重合，不是位置重合。过程检查只扫描 $\mathcal{T}_{\mathrm{reason}}$ 里的表面形式。若把格子只写在结论里，解析器必须返回空引用。CPU 实验的 `CITE_IN_ANSWER_ONLY` 就是这条。

损失掩码也要分。[第 01 课](01_baseline_reproduction.md)已经要求只对助手目标算交叉熵。本课在此之上再加一列：若你只想训格式，`reason` 与 `ans` 都可以进损失；若你做结果强化学习，优势广播到哪些位置必须预先写死。Vision-R1 的硬格式结果奖励是序列级标量，广播规则与[第 38 课](38_vla_rlvr.md)的轨迹级 $r$ 同类。本课夹具不实现 log-prob，只实现集合。

验证：`token_index_sets` 对五条夹具都返回不相交。缺这一条，后面的 $C(y)$ 会把结论里的数字坐标当成证据。

把一条夹具展开成可手算的位置表，避免只记住“两个集合”这句话。真引用正确的字符串是：

`<REASONING> 格子 (0,1) 与 (2,3) 是红杯 </REASONING> <CONCLUSION> 共 2 </CONCLUSION>`

按空白切词，推理 span 得到 5 个 token：`格子`、`(0,1)`、`与`、`(2,3)`、`是红杯`。结论 span 得到 2 个 token：`共`、`2`。位置编号从 0 起：推理占 $\{0,1,2,3,4\}$，答案占 $\{5,6\}$，交为空。解析器只在前五个位置上跑格子正则，得到 $C(y)=\{(0,1),(2,3)\}$。若实现把整句拼起来再搜，位置 5 之后若出现 `(0,1)` 会被误计。CPU 实验的结论污染夹具把格子写在 `共 2` 之前、但仍在 CONCLUSION 里，过程分必须保持 0。

掩码和分账是两张表。掩码决定哪些位置进交叉熵或政策损失；分账决定哪些位置进 $C(y)$。可以只对答案 token 算 CE，同时仍从推理 span 解析引用——那是“格式已经会了、只微调结论”的设定。也可以对两段都算 CE，引用检查仍然只扫推理段。两张表写进同一个 `reward_spec`，不要用一个布尔“train_reason”同时关掉解析。关掉解析等于本课没上。

标签残缺时怎么办。缺 `</REASONING>` 时，抽取函数返回空 span，$C(y)=\emptyset$，$r_{\mathrm{proc}}=0$。不要尝试“找到下一个标签为止”的启发式补全，否则模型学会故意不写闭合标签，把结论吞进推理，既拿过程分又拿答案分。LLaVA-CoT 在数据过滤里丢掉格式不合的样本，本课夹具把残缺当成过程失败，两者同方向：格式是证据通道的门，不是可以事后修补的装饰。

### 5.4 视觉引用作为过程奖励

格子编号是最小的可验证视觉证据。推理 span 上的引用集合

$$
C(y)=\bigl\{(i,j):\text{字符串 }(i,j)\text{ 出现在推理 span}\bigr\}
$$

金标格子 $G$ 由计数题的真值物体给出。过程奖励

$$
r_{\mathrm{proc}}(y)=\mathbf{1}\bigl[C(y)\cap G\neq\emptyset\bigr]
$$

空集的指示为 0，这是本课最硬的一句。错格子与空集同等处理：$(1,2)$ 和 $(3,1)$ 是蓝球与白盘，与红杯的 $G$ 无交，过程分仍是 0。更严的版本是 $C(y)=G$，教学默认不采用，因为漏点一只杯子仍证明模型至少看过一只。若你改成集合相等，必须在 `reward_spec` 里改版本号。

答案奖励保持第 17 课的干净形式：

$$
r_{\mathrm{ans}}(y)=\mathbf{1}\bigl[\hat a(y)=a^\star\bigr]
$$

$\hat a$ 取结论 span 的最后一个 token。必须引用时合取

$$
r=r_{\mathrm{ans}}\cdot r_{\mathrm{proc}}
$$

关掉必须引用时 $r=r_{\mathrm{ans}}$。关掉之后会出现验收要的那一行：$r_{\mathrm{ans}}=1$、$C(y)=\emptyset$、$r_{\mathrm{proc}}=0$、$r=1$。训练若只用这一列 $r$，空引用会活下来。

组内优势仍用第 38 课的减均值，不重推标准化：

$$
\bar r=\frac{1}{G}\sum_{j=1}^{G}r_j,\qquad \hat A_i=r_i-\bar r
$$

四条都是“答案对、引用空”，且 $r=r_{\mathrm{ans}}$ 时，四个 $r=1$，方差为 0，更新为 0。换上合取之后，只有真引用那条是 1，其余为 0，优势才能分出正负。CPU 实验锁 `process_group = [1, 0, 0, 0]`。

公开方案里没有这一列。Vision-R1 的硬格式结果奖励是

$$
r_i=\mathbf{1}[\text{格式合法}]\cdot\mathbf{1}[\text{最终答案对}]
$$

格式合法不等于点过格子。LLaVA-CoT 的 CAPTION 阶段是监督出来的相关描述，也没有把描述与真值 mask 的交写成 $r$。本课把这一列标成教学扩展，引用论文时必须分开写。

验证：空引用、错引用两条的 $r_{\mathrm{proc}}$ 都是 0；真引用且答案错的合取是 0。

把四条夹具写成一张和[第 38 课](38_vla_rlvr.md)失败组对照的表。38 课用空抓、悬停、擦边、压溃；本课用真引用正确、空引用正确、错格正确、真引用错误。

| 回复 | $C(y)$ | $\hat a$ | $r_{\mathrm{ans}}$ | $r_{\mathrm{proc}}$ | 合取 | 只奖答案 |
|---|---|---|---|---|---|---|
| 真引用正确 | $\{(0,1),(2,3)\}$ | 2 | 1 | 1 | 1 | 1 |
| 空引用正确 | $\emptyset$ | 2 | 1 | 0 | 0 | 1 |
| 错格正确 | $\{(1,2),(3,1)\}$ | 2 | 1 | 0 | 0 | 1 |
| 真引用错误 | $\{(0,1),(2,3)\}$ | 3 | 0 | 1 | 0 | 0 |

只奖答案时，前三行都是 1，若组里再复制一行空引用，四个 1，方差 0。合取时只有第一行是 1，组均值 0.25，优势 $(0.75,-0.25,-0.25,-0.25)$。$\Sigma|\hat A|=1.5$。同一组采样账单，更新账单差在第二列。Lab 的揭晓数字对应第二行：开关关掉后走“只奖答案”列，你仍应把 $r_{\mathrm{proc}}$ 打印出来，否则右上格从日志里消失。

交非空是宽松规则。真引用正确点了两只红杯，若模型只点 $(0,1)$，宽松规则仍给 1，严格相等给 0。教学选宽松，是因为计数题上“至少看过一只”已经能把空引用分开。评测报告必须写用的是哪一档。换成检测框时，宽松对应 IoU 阈值上“至少一个框命中”，严格对应集合匹配。不要在同一张表里混两档。

引用字符串的正则也是协议。本课只认 `(行,列)`，行和列为十进制整数，中间逗号，不要空格也可以，有空格也可以。不认 `格子0-1`、`第0行第1列`、`A2` 这种口语。模型若只写中文位置词，过程分为 0。这不是苛刻，这是可验证：口语位置词要另做解析器，版本号不同。Kosmos-2 用 loc token，Qwen2-VL 用 `<|box_start|>`，本课格子是第三种表面形式。混用三种而不写解析版本，IoU 和 $C(y)$ 会一起坏。

### 5.5 对照第 17、23、38 课：奖励对象换了

三课共用“可验证程序打分 + 组内相对优势”，对象不同。

| 课 | 程序看什么 | 零方差何时出现 | 本课不要重复 |
|---|---|---|---|
| 17 | 最终答案是否通过 verifier | 全对或全错 | clip、KL、hidden case |
| 23 | 框 IoU、注意力质量、POPE 负例 | 评测探针，不训练 | 三种负采样的题本 |
| 38 | 放入成功、接触带、力阈 | 全失败或全成功 | 接触公式与真机数字 |
| 51 | 推理 span 是否引用真值格 | 全空引用或全真引用 | 不重推 17/38 的优势公式 |

第 23 课的命中可以变成 $r_{\mathrm{proc}}$ 的真值来源：若你有框，用 IoU；若你只有格子，用本课的 $C(y)$。不要把 VQA 准确率再写进过程列。第 16 课的 mDPO 要求必须看见媒体，见[第 16 课](16_multimodal_preference_optimization.md)；那是偏好对里的图像条件，不是推理文本里的格子。两课都在打“没看媒体也能得分”，机制不同，报告分列。

把第 17 课的手算迁过来。取 $r=(1,0,0,0)$，减均值得到 $(0.75,-0.25,-0.25,-0.25)$。这就是“一条真引用、三条空引用”的过程组。取 $r=(1,1,1,1)$，优势全 0。这就是关掉必须引用、四条都靠语言先验蒙对的答案组。两组的采样账单一样，更新账单差在 $r$ 的定义。

验证：口头能讲清三列 $r$ 的字段名，并能指出本课零方差组是“全空引用的合取”而不是“全没抓住”。

### 5.6 LLaVA-CoT：结构化 SFT 与分阶段回溯

数据。现成 VQA 大多没有多阶段过程。作者用 GPT-4o 按阶段生成，再过滤格式不合以及结论与原答案不一致的样本，得到 LLaVA-CoT-100k。来源分通用与科学两类：ShareGPT4V、ChartQA、A-OKVQA、DocVQA、PISC、CLEVR，以及 GeoQA+、AI2D、ScienceQA、CLEVR-Math。Table 1 按来源列出条数，合计约 99k 图问对。构造时把原数据集答案提供给 GPT-4o，因此这是带金标的蒸馏，不是模型自己探索。许可与教师模型版本必须进账本；本课不要求你再调用 GPT-4o。

附录 B 把生成写成两段过滤。第一段要求 GPT-4o 按四阶段格式写；写完后检查标签是否齐全。第二段抽出 CONCLUSION，再用另一条提示丢掉拒答以及与原数据集标准答案不一致的样本。于是 100k 并属于“教师在已知金标时能写圆的那部分”，不是 GPT-4o 对这 99k 题的独立意见。金标泄漏进推理过程是这种构造的结构性偏差：CAPTION 可能写成“图中显然有两个红杯”，因为教师已经看见答案。本课 $r_{\mathrm{proc}}$ 不看 CAPTION 里的数字，只看格子。若你自己蒸馏，负对照是把金标从教师提示里拿掉，看格子还在不在。拿掉之后格子消失，说明原来的引用是答案倒灌，不是看图。这项对照本课不做，写在 recipe 里当作已知风险。

训练。基座 Llama-3.2-11B-Vision-Instruct，全参微调，8×H100，llama_recipes。附录 C 的 Table 6 在 HTML 抽取里列名残缺，本课只引用能对上的字段：学习率 $1\times 10^{-5}$、3 个 epoch、padding、最大长度 4096、种子 42。其余优化器开关以 PDF 原文为准，不在这里补名字。

测试时缩放。Best-of-N 一次生成完整回复再挑。分阶段束搜索在每个阶段生成 $M$ 个候选、留 $N$ 个。SWIRES 在此之上加回溯：当前阶段所有候选都低于奖励阈，就认为上一阶段可能错了，退回去重写，最多 $C$ 次。作者观察到 SUMMARY 通常质量高，回溯从 CAPTION 开始。奖励模型是 InternLM-XComposer2.5-Reward。Table 4：无缩放 57.6，加 SWIRES 62.5。图 5 在 MMStar 上比较三条缩放曲线，SWIRES 在更长时间上继续上升，Best-of-N 在约 $10^4$ 秒后趋于平坦甚至略降。具体秒数依赖单节点 A800 的评测设置，不要把横轴抄成你的墙钟。

消融还说明：增益主要落在需要系统推理的技能上。Table 3 把 MMStar 拆成粗感知、细感知、实例推理、逻辑推理、数学、科学技术；作者写结构化推理明显抬后几项，前两项相对较小。HTML 表体数字列不完整，本课只引用作者的文字结论，不编造分技能表。

把 SWIRES 写成可证伪的协议，而不是“测试时更聪明”。每个阶段结束必须有一个可比较的分数；分数来自独立奖励模型，不是政策自己打自己。回溯次数 $C$ 要有上限，否则 CAPTION 会在低分上打转。本课 Lab 没有奖励模型，用开关模拟“这一阶段允不允许空”。关掉必须引用，等价于 CAPTION / REASONING 被跳过。那不是 SWIRES，是消融。报告里不要写“我们实现了 SWIRES”。

验证：能画出“阶段结束才搜索、全差才回溯、从 caption 开始”三条，并能指出本课 CPU 实验没有实现搜索。

附录 D 的伪代码把搜索粒度钉死。先生成一条 SUMMARY，回溯计数 $c\leftarrow 0$。循环里生成 $M$ 条 CAPTION，用奖励模型打分，留 top $N$。再为每条留下的 CAPTION 生成 $M/N$ 条 REASONING，把 $M$ 条推理全部进候选池。若本轮推理满足预设阈值就跳出；否则 $c\leftarrow c+1$，直到 $c\ge C$。最后在留下的推理上各写一条 CONCLUSION，再挑最高分。本课不实现 $M,N,C$ 的默认值，原文把细节放在附录，HTML 抽取未给出三个整数的最终取值。写实验记录时这三项必须来自你打开的附录，不得用本课夹具的 4 条回复冒充束宽。

奖励模型带来的投机与第 17 课的神经网络判分员同类。InternLM-XComposer2.5-Reward 会偏爱某种文风和某种长度。SWIRES 在 CAPTION 阶段若总是留下“描述更华丽但没点到被问物体”的候选，后续 REASONING 会在错误视觉前提上搜索。这就是本课坚持程序化 $C(y)$ 的原因：格子在不在 $G$ 里，不经过第二个网络。测试时你仍可以用奖励模型挑文风，训练时不要把该模型的标量写进 $r_{\mathrm{proc}}$。两条通道并存必须分列。

Table 7 还做了 CoT 设计的进一步实验，HTML 表体只抽出 66.0 / 67.6 与 46.6 / 49.5 / 49.8 / 52.0 / 57.5 这些残缺格子。本课不把残缺表解释成具体消融名。需要用 Table 7 时打开 PDF 原文再填列名。能确定的只有：作者认为有必要再做一轮 CoT 设计验证，并且主文已经用 Table 2 的去标签对照支撑“标签有用”。

### 5.7 Vision-R1：模态桥冷启动，而不是直接 RL

作者先尝试 DeepSeek-R1-Zero 那条路：基座 MLLM 直接 GRPO，系统提示要求 `<think> ... </think><answer> ... </answer>`，格式奖励与结果奖励 1:1。得到的 Vision-R1-Zero 难以激励出带提问和反省的长过程。附录 A：生成长度限制 4K、每题 16 条、训 300 步。消融均分 50.7。直接 RL 在多模态上不是免费午餐。

冷启动数据用模态桥，避免人工写思维链。步骤是：已有 MLLM 先出带描述与步骤的 Pseudo-CoT；再把图、问题、Pseudo-CoT 一并送回 MLLM，生成“答对这题所需要的细节描述”；把描述交给文本推理模型 DeepSeek-R1 写带反省的 CoT；只保留最终答案与金标一致的样本，再做规则过滤。部署的 MLLM 是 Qwen2.5-VL-72B。最终 Vision-R1-cold 约 200K。附录 A 写明它从 LLaVA-CoT 100K 与 Mulberry 260K 出发。附录 D 另列数学、通用问答、科学医疗、图表理解的来源名单，本课不把名单抄成你已经下载了这些数据。

Table 4 用词频说明冷启动数据更像“会反悔的人”：Wait 585719 对 LLaVA-CoT 的 2300，Hmm 75853 对 1，Alternatively 188187 对 251。词频不是能力，但它解释了为什么冷启动之后模型会过长地想。同一份数据拿到 Llama-3.2-11B-V 上 SFT，得到 Vision-R1-LlamaV-CI-11B：MMStar 61.4、MathVista 62.7，高于同表 LLaVA-CoT-11B 的 57.6 与 54.8。这是数据质量对照，不是本课夹具。

验证：能复述模态桥的三跳（Pseudo-CoT、细节描述、文本 R1），并能指出 DeepSeek-R1 本身不看图。信息在桥上会丢。附录图 5 对比了没有 Pseudo-CoT 的朴素描述：R1 会因为缺关键视觉信息而胡写。本课不实现桥，只要求报告里不要把 200K 写成“人工标注”。

### 5.8 PTST 与硬格式结果奖励

PTST 把强化学习分成阶段 $s=1,\ldots,S$，每阶段有长度上限 $L_s$ 和组大小 $G_s$。输出空间 $O^{(s)}=\{o:|o|\le L_s\}$。目标仍是第 17 课那种带 clip 与 KL 的组相对目标，只是采样被限制在 $O^{(s)}$ 里。原文 $\varepsilon=0.2$，$\beta=10^{-2}$。教学主路径取 $S=2$：$L=(4\mathrm{K},8\mathrm{K})$，$G=(16,8)$，各 100 步。第三阶段 16K 存在于公式里，最终发布权重没用它。32B 与 72B 在第二阶段用了额外约 20K 数据（把 2024 年前 AIME 文本渲染成图，再加 MAmmoTH-VL 与 MMIQ 子集），不得和 7B 的 10K 混报。

硬格式结果奖励（HFRRF）把格式和答案绑死：两项同时成立才是 1，否则 0。冷启动已经教会格式，所以强化学习不再靠系统提示约束。它比“格式 0.1 + 答案 1.0”更硬，也更早出现零方差：格式对、答案错，仍是 0。本课的合取 $r_{\mathrm{ans}}\cdot r_{\mathrm{proc}}$ 与它同形，只是第二项从“答案对”换成“引用非空”。不要把 HFRRF 说成已经包含视觉引用。

主结果按表抄，避免只记 73.5。Vision-R1-7B 相对 Qwen2.5-VL-7B：MathVista GEO 80.3（+13.4）、ALG 79.0（+10.3）、GPS 83.2（+16.4）、MWP 80.6（+3.7）、ALL 73.5（+5.4）；MathVerse 52.4（+5.7）；MM-Math 40.2（+6.1）；DynaMath 56.3（+5.6）；四项平均 55.6（+5.7）。摘要写只用 10K 强化学习数据，多项数学基准平均约 6 个点。32B / 72B 的 MathVista ALL 为 76.4 / 78.2。LLaVA-CoT-11B 在同一张表上 MathVista ALL 54.8、MathVerse 20.3、MM-Math 16.5、DynaMath 34.6、平均 31.6，设置与训练目标都不同，禁止把 73.5 减 54.8 写成“RL 比 SFT 高 18.7 个点”。

验证：能写出两阶段的 $(L_s,G_s)$ 与 100+100 步，并能指出 HFRRF 与本课 $r_{\mathrm{proc}}$ 差在第二项。

把 Vision-R1 正文的 GRPO 目标抄过来，证明本课没有改这项。对每个问题 $q$ 从旧政策采 $\{o_i\}_{i=1}^{G}$，

$$
A_i=\frac{r_i-\operatorname{mean}(\{r_j\})}{\operatorname{std}(\{r_j\})}
$$

再最大化带 clip 与 KL 的代理目标。$\varepsilon=0.2$，$\beta=10^{-2}$。本课夹具用减均值 $\hat A_i=r_i-\bar r$，与第 38 课一致，和这篇的标准化形式在零方差组同样得到接近 0 的更新。需要和第 17 课对表时再除标准差。两种形式都不创造新的视觉信息。信息只来自 $r_i$ 是否读了 $C(y)$。

PTST 的长度上限是硬截断还是采样拒绝，原文写成输出空间 $O^{(s)}=\{o:|o|\le L_s\}$，即超长样本不进入该阶段的组。实现若改成“超长就给 0 分但仍留在组里”，零方差结构会变：一组长样本全是 0，短样本才有机会得 1。本课不绑定截断实现，只要求报告写明超长样本是丢组、截断文本，还是打 0 分。三种写法的 $G$ 有效条数不同。

消融 Table 3：Zero 有 GRPO 无冷启动，平均长度 1285、均分 50.7；CI 有冷启动无 GRPO，长度 3566、均分 44.5；Long 有两者但无 PTST，长度 3107、均分 47.7；完整方法长度 2057、均分 55.4。长度从 CI 的 3566 降到 2057，分数反而升。本课 Lab 没有长度轴，不要把“推理 span 更短”当成失败。空引用的 span 可以很短，真引用的 span 也可以很短。长度是过程奖励的干扰项，不是替代项。

Table 5 还说明两阶段设置稳健：固定短长度 4K×16 再 4K×16 均分 54.3；4K×16 再 8K×16 为 55.3；插入 6K 中间阶段为 55.1；一上来 16K 只有 47.7 / 47.9。作者选 4K×16 再到 8K×8。缩小版能复现的方向是“先短后长优于先长”，不能复现 55.4 这个均分。Table 6：没有冷启动只加 PTST 到 51.8；冷启动数据去掉 CoT 再 PTST 掉到 39.8。复杂思维先验对后续 RL 不是可选项。本课最低交付不训 RL，但 recipe 里仍要写：若你做 GRPO，先确认起点模型已经会输出可解析的推理 span，否则 $C(y)$ 恒为空，合取恒为 0，回到第 17 课的 pass@k 预检失败。

### 5.9 不忠实推理：答案对、引用空

LLaVA-CoT 相关工作引用了 Turpin 等人关于思维链不忠实的讨论：模型给出的解释不一定是它真正用过的计算。本课用集合把这件事变成可执行探针，而不依赖打开那一篇的全部实验。

三种可构造的不忠实：

1. 空引用蒙对。推理 span 写“常见是两个”，结论 `2`，$C(y)=\emptyset$。Lab 关掉必须引用时就是这条。
2. 错引用蒙对。推理点了蓝球与白盘，结论仍 `2`。语言先验补上了计数，证据指向干扰物。
3. 真引用答错。点了两只红杯，结论 `3`。证据在，加法错。合取奖励为 0，避免“看对了就给分”把算术错误留在政策里。

第 23 课的列联表在这里变成奖励列联：

|  | $r_{\mathrm{proc}}=1$ | $r_{\mathrm{proc}}=0$ |
|---|---|---|
| $r_{\mathrm{ans}}=1$ | 真看真数 | 蒙对 / 看错 |
| $r_{\mathrm{ans}}=0$ | 看对算错 | 既没看也没数对 |

只报右上加左上的准确率，会把蒙对算进能力。只报过程奖励，会把看对算错当成成功。合取盯左上。关掉必须引用，等于允许右上进训练。验收必须能造出右上格。

忠实还有一层做不到的事：即使 $C(y)=G$，模型内部注意力仍可能在别处。本课不声称文本引用等于[第 23 课](23_grounding_ocr_spatial.md)的注意力命中。两列要同时做时，用两个 run ID。

验证：Lab 揭晓后引用格显示“空”，$r_{\mathrm{ans}}=1$，$r_{\mathrm{proc}}=0$。CPU 实验的 `关掉必须引用后答案对引用空` 锁同一行。

### 5.10 计数探针为什么适合当验收题

计数把“看见”收成可枚举的格子集合，又把“答案”收成一个整数。几何证明题的中间式子很难自动核。自由描述的 CAPTION 需要另一个模型来判是否相关。计数题的 $G$ 可以从渲染脚本得到，不依赖检测器。

教学网格固定 4×4、六个物体、两只红杯、一颗黄星。先验开关被收成“必须引用”。开：推理 span 点真值格。关：推理 span 写语言套话。两条路径的 $a^\star$ 相同，所以准确率无法分开它们。过程奖励可以。

计数也会被钻。模型可以学会“红杯总是两个”而不看图。负对照是把其中一只杯子挪走或改色，金标变成 1，$G$ 只剩一格。本课 Lab 为了让验收稳定，没有做随机挪杯；改造实验 3 要求你在 CPU 夹具里改 $G$。若改完 $r_{\mathrm{proc}}$ 仍对空引用给 1，实现没有读 $G$。

[第 08 课](08_dynamic_vision.md)的分辨率失败会先表现为小物体消失，计数随之错。那种失败应记到 encoder，不要记到本课的过程奖励。探针图必须在 encoder 实际看见的像素上渲染。教学网格是矢量色块，不测分辨率。

验证：同一套公式在“红杯个数”和“黄星个数”上只改 $G$ 与 $a^\star$，代码路径相同。Lab 允许切题，验收不要求两道题都做，但切题后必须重新预测再揭晓。

计数还和[第 44 课](44_document_layout.md)的单元格命中同构：内容对且框错，版面失败。本课是数字对且引用空，过程失败。两课都要求合取。44 课的框来自版面坐标，本课的格来自模型自己写的编号。不要把发票金额的框 IoU 填进 $C(y)$，也不要把红杯格子填进单元格命中。字段名都叫“命中”时，报告必须带对象：字形区域、表格单元格，还是计数格子。

LLaVA-CoT 相关工作提到 Visual CoT 会在答案旁边生成相关区域的框。本课未打开那篇原文，不引用它的基准数字。能从 LLaVA-CoT 正文确定的只有：他们选择用 CAPTION 阶段写相关像素，而不是强制框 token。本课教学用格子编号，是第三条路，比框更粗、比纯文字描述更可执行。三条路的验收不能合成一个“视觉 CoT 准确率”。

## 6. 在公开实现中定位这些机制

本课没有 MiniMind-O 里现成的阶段解码器。对照放到公开仓库和夹具。读代码时带着两个问题：标签是不是单 token；奖励读的是哪一段文本。第二个问题比第一个更容易被实现带跑：很多日志只存 `output_text`，事后用全文正则抓数字。全文正则会把结论里的坐标、甚至问题里的坐标算进 $C(y)$。本课夹具把格子写进结论仍得过程分 0，就是为了抓住这种实现。审查别人的训练代码时，先搜 `find("</REASONING>")` 或等价的 span 切片，搜不到就假设过程奖励是假的。

LLaVA-CoT 仓库 [https://github.com/PKU-YuanGroup/LLaVA-CoT](https://github.com/PKU-YuanGroup/LLaVA-CoT)。应对齐四对标签的字符串、训练是否全参、评测是否走 VLMEvalKit。SWIRES 的 $M,N,C$ 在附录 D 的伪代码里：先生成一个 SUMMARY，再循环生成 $M$ 条 CAPTION、留 $N$ 条，再为每条 CAPTION 生成 $M/N$ 条 REASONING，条件不满足就回溯，最后对留下的推理各写一条 CONCLUSION，用奖励模型挑最好的。你若只做 greedy 解码，不得把 Table 4 的 62.5 抄进自己的行。

Vision-R1 仓库 [https://github.com/Osilly/Vision-R1](https://github.com/Osilly/Vision-R1)。应对齐冷启动是否 Llama-Factory、强化学习是否 Verl、PTST 两阶段的最大长度与组大小、HFRRF 的实现是否真的在格式失败时给 0。系统提示在 Zero 设定里出现，完整 Vision-R1 在冷启动之后不再靠系统提示管格式。

InternLM-XComposer2.5-Reward 的论文为 arXiv:2501.12368，LLaVA-CoT 用它当测试时打分器。本课不要求加载该权重。没有奖励模型时，SWIRES 无法运行；教学用程序化 $r_{\mathrm{proc}}$ 替代“阶段质量”，替代关系必须写明。

本课 CPU 夹具在 `experiments/src/learn_omni_experiments/lessons/lesson_51.py`：`reason_tokens`、`answer_tokens`、`cited_cells`、`process_reward`、`combined_reward`。交互实验在 `web/components/labs/advanced/Lesson51CotLab.tsx`，默认题目是红杯个数，必须引用默认开，验收必须关。改默认值要同步改课文。机制图 `lesson51Diagram` 的事实栏五条都应能对回原文或夹具：100k 加测试时缩放 +9.4、Table 2 的 49.8/54.3/55.7/57.6、MathVista 73.5 对 o1 的 73.9、Wait 词频 585719 对 2300、空引用过程分为 0。事实栏里的过程奖励那一条是本课约定，引用时不要写成 LLaVA-CoT 或 Vision-R1 已经这么训了。

读开源推理脚本时按这个顺序打勾：

1. 阶段标签是否在 tokenizer 里占独立 id。打印一段编码，确认 `<REASONING>` 不是三个普通词。
2. 解析器是否只扫描法定 span。把格子写进 CONCLUSION，过程分必须仍为 0。
3. 奖励版本。HFRRF、本课合取、纯 $r_{\mathrm{ans}}$ 三选一写进配置，禁止默认混加。
4. 组大小与长度上限是否按阶段变化。PTST 若被实现成固定 16K，你在复现 Vision-R1-Long，不是完整方法。
5. 评测解码。有无 SWIRES、有无 greedy、温度多少，分三行记。把缩放后的数字和未缩放的数字加在一起，实验作废。

机制图 `lesson51Diagram` 把图像流到阶段标签，再分成推理 token 与答案 token，汇到过程奖励。读图时核：引用决策是否只连推理节点；答案奖励是否只连答案节点；空引用是否在输出节点的说明里写成 0。若有人把答案节点直接连到“成功”，那张图就画错了。

解析器还要处理三种边界，CPU 实验只覆盖第一种和第三种的简化版，真实脚本必须把三种都写成单测。

1. 重复格子。推理 span 写了两次 $(0,1)$。集合去重后仍是一个格。宽松规则下，若该格在 $G$ 里，过程分为 1。不要按出现次数加权，否则模型学会把同一格复制二十遍刷分。
2. 越界格子。4×4 网格上的 $(8,8)$ 不在画布上。本课默认丢弃越界格，不因此把整条回复打成格式失败。若 $C(y)$ 去掉越界后变空，过程分为 0。想把越界当格式错误，必须在 HFRRF 那一层单独加规则，不要偷偷改 $r_{\mathrm{proc}}$ 的定义。
3. 多余真值格。$G$ 有两只红杯，模型只点一只。宽松给 1，严格给 0。日志同时存 $|C(y)\cap G|$ 与 $|G|$，事后才能改档而不用重跑生成。

和 MiniMind-O 的关系写清，避免有人在 Thinker 里塞 loc 词表却来本课验收。默认 MiniMind-O 视觉路径是冻结 SigLIP2、固定 patch、MLP connector、文字 next-token，没有阶段标签。主路径只能做三件事：用现成短答做 $r_{\mathrm{ans}}$；若你能改解码模板，强迫输出两段标签再解析 $C(y)$；用本课夹具证明公式。前两件有 GPU 才能接到真实权重。第三件无 GPU 即可。加 loc 词表属于第 23 课改造，本课引用的是文本里的 `(i,j)`，不是 Kosmos-2 的 `<loc*>`。两种表面形式可以同时存在，必须两个解析器、两个版本号。

主路径不训练 11B 或 7B。若你要为探针造数据或做第 13 节的小改造，按下面配比记账。数据许可写进报告。

**评测题本（必须）：**

日志里每条回复至少保存：`group_id`、原始文本、两个 span 的起止、$C(y)$、$r_{\mathrm{ans}}$、$r_{\mathrm{proc}}$、合取、$G$、$a^\star$、spec 版本。缺 $C(y)$ 的训练步，事后无法证明当时不是空引用在刷准确率。均值 `reward_mean=0.5` 盖不住 $(1,0,0,1)$ 和 $(0.5,0.5,0.5,0.5)$ 的差别。前者有对比，后者零方差。和第 38 课要求保存 $r$ 向量是同一条纪律，字段从接触距离换成了格子集合。

## 8. 按依赖顺序执行实验

实验分四层。第一层必须在无 GPU 时通过。第二层是浏览器教具。第三层只有在你真的微调开源 VLM 时才跑。第四层写不要做的事。

### Step 1: CPU 机制实验

在 `experiments/` 下核对隔离脚本（本课不改 `registry.py`，编排者接入后再改成 `run.py run 51`）：

```bash
PYTHONPATH=src python3 -c "from learn_omni_experiments.lessons.lesson_51 import run; print(all(run()['checks'].values()))"
```

预期打印 `True`。失败时看 `checks` 里哪一条是 `False`：集合不相交、空引用过程分为 0、关掉必须引用后答案仍对、错格无过程分、只奖答案的全对组没有优势、过程组能把空引用排到零。

手算可以先于脚本。金标 $a^\star=2$，$G=\{(0,1),(2,3)\}$。真引用正确：$r_{\mathrm{ans}}=1$，$r_{\mathrm{proc}}=1$，$r=1$。空引用正确：$r_{\mathrm{ans}}=1$，$r_{\mathrm{proc}}=0$，合取 0，答案列 1。错格正确：过程 0。真引用错误：答案 0、过程 1、合取 0。结论里写格子：过程仍 0。四条合取组成过程组 $(1,0,0,0)$，均值 0.25，优势 $(0.75,-0.25,-0.25,-0.25)$。答案列四条全 1，优势全 0。这六行对不上，不要进入 Lab。

再补一行标准化对照，证明第 17 课的除法在本课答案组上不会救空引用。四个答案列 1 的标准差是 0，加上 $\varepsilon=10^{-8}$ 仍得到四个接近 0 的 $A_i$。四个合取值 $(1,0,0,0)$ 的均值 0.25、总体标准差 $\sqrt{0.1875}\approx 0.433$，标准化后约 $(1.73,-0.577,-0.577,-0.577)$，符号与减均值一致。CPU 实验锁符号和合取向量，不锁标准化口径。写报告时写明用的是减均值还是除标准差；本课夹具主表用减均值。

标量更新的手算：$w\leftarrow w+\eta\hat A$。取 $\eta=0.1$，$w=1$。答案组四个 $w$ 仍是 1.000。过程组四个 $w$ 变为 $1.075$、$0.975$、$0.975$、$0.975$。相对变化只有几个百分点，但这已经是“有更新”和“没更新”的分界。真训练里 $\hat A$ 还会乘 log-prob 的梯度，量级不同，零与非零的分界不变。谁若看见 1.075 就写成“过程奖励已经让计数准确率上升”，属于把教学标量抄进评测表。

### Step 2: 浏览器计数教具

打开本课页面的 Lab。4×4 网格上有两只红杯、一颗黄星。先在四个选项里选一句关于关掉必须引用之后的预测，再把开关拨到关，再按“揭晓引用”。揭晓前不得显示推理 span、$r_{\mathrm{ans}}$、$r_{\mathrm{proc}}$。揭晓后应看到答案对、引用格为“空”、$r_{\mathrm{proc}}=0$。把开关拨回开，引用格应覆盖真值格。教具标题写明教学模拟。

建议顺序：先选预测句，再关掉必须引用，再揭晓，再记下空引用，再开回引用看真值格亮起。切到黄星题时先清揭晓再重新预测。中途改预测或开关会清空揭晓。验收不看你有没有把黄星也做一遍，只看：预测句选对、当前开关是关、答案对、引用为空。

教具内部的计算可以手工复核。红杯金标格子是 `0,1` 与 `2,3`，黄星是 `2,0`。开关打开时，推理 span 必须点出这些格子，$r_{\mathrm{proc}}=1$。开关关闭时，推理 span 变成套话，$C(y)$ 为空，$r_{\mathrm{proc}}=0$，答案仍是正确个数。改题目会清揭晓，防止把红杯的空引用记录当成黄星的验收。默认开关是开，所以只选对预测句、不拨开关，Gate 不会亮。这一条和[第 38 课](38_vla_rlvr.md)必须切到失败批次才能过 Gate 是同一类纪律：验收句针对的是那一个开关状态。

### Step 3: 可选，开源 VLM 上的协议探针

只在有 1×24GB 或以上、且你接受“这不是课程最低交付”时进行。选一个已经会短答计数的小 VLM。先 greedy 解码，解析有没有阶段标签、有没有格子。大多数基座两者都没有，过程分应记 0，即使计数对。再加“请先列出格子再给个数”的提示，看引用是否出现。提示能逼出格式，不等于 SFT 已经内化阶段。若你继续做 LLaVA-CoT 式 SFT，记录：标签完整率、空引用率、计数准确率，三列分列。空引用率不下降时，不要把准确率上涨写成“学会了看图”。

## 9. 评测与测量

分步推理和短答准确率是两张表。混用就是[第 23 课](23_grounding_ocr_spatial.md)反对过的用 VQA 代替 grounding，也是[第 17 课](17_grpo_rlvr.md)反对过的用训练奖励代替隐藏测试。

**训练中间量。** 标签完整率、平均推理 token 数、空引用率、错格率、$r_{\mathrm{proc}}$ 均值、零方差组比例。这些量只说明更新信号在不在，不说明任务能力。Vision-R1 图 1 同时画长度和准确率，就是怕只看一条曲线。建议按步记下空引用率：连续 100 组里有多少条 $C(y)=\emptyset$。比例高于 0.5 且 $r=r_{\mathrm{ans}}$ 时，本课把它当成停训信号之一，先改奖励，不要再加步数。

**任务成功。** 必须带谓词。计数成功是整数相等。引用成功是 $C(y)\cap G\neq\emptyset$。合取成功是两者同时成立。MathVista ALL、MMStar、HallusionBench 是另一张公开表，抄写时带解码设置。LLaVA-CoT 用 VLMEvalKit；MMBench 用 V1.1 test，MathVista 用 testmini。换套件必须换行。

**本课最低测量。**

| 量 | 定义 | 通过 |
|---|---|---|
| 位置集合交 | $\mathcal{T}_{\mathrm{reason}}\cap\mathcal{T}_{\mathrm{ans}}$ | 空 |
| 空引用 $r_{\mathrm{proc}}$ | $C(y)=\emptyset$ | 0 |
| 关掉引用后的 $r_{\mathrm{ans}}$ | 空引用且数字对 | 1 |
| 错格 $r_{\mathrm{proc}}$ | $C(y)$ 与 $G$ 无交 | 0 |
| 过程组 $r$ | 真/空/错格/看对答错 | $(1,0,0,0)$ |
| 答案组方差 | 四条空引用且 $r=r_{\mathrm{ans}}$ | 0 |

公开数字抄进笔记本时，用下面这张禁止合并表。

| 系统 | 设置 | 数字 | 奖励 / 监督 |
|---|---|---|---|
| Llama-3.2-11B-Vision-Instruct | 基座，短答 | Table 2 均分 49.8；Vision-R1 表 2 MMStar 49.8、MathVista 48.6 | 原指令微调 |
| LLaVA-CoT Direct Training | 原问答对 SFT | 均分 54.3 | 短答 CE |
| LLaVA-CoT w/o tags | 100k 去标签 | 均分 55.7 | 无阶段 CE |
| LLaVA-CoT | 100k 带标签 | 均分 57.6 | 阶段 CE |
| LLaVA-CoT + SWIRES | 同上 + 测试时回溯 | 均分 62.5；摘要 +9.4 | 阶段 CE + 奖励模型选阶段 |
| Vision-R1-Zero | 直接 RL，4K×16，300 步 | 均分 50.7 | 格式+结果 1:1 |
| Vision-R1-CI | 200K 冷启动 | 均分 44.5；Llama-3.2 上 MMStar 61.4 | 复杂 CoT SFT |
| Vision-R1-Long | CI 后 16K×4，300 步 | 均分 47.7 | HFRRF |

LLaVA-CoT 摘要的 9.4 个点包含测试时缩放，§4.2 的 5.8 个点是训练阶段均分。两句话都来自原文，不要合成一个“提高了百分之九点四的 SFT”。Vision-R1 的 73.5 与 o1 的 73.9 只在 MathVista ALL 上相邻，o1 在 GEO / ALG 等子项上原文标为未填。缺的格子不要补。

评测再加两个负对照。把解析器改成全序列搜 $(i,j)$，结论污染夹具的过程分会变成 1，这是 bug。把 $G$ 改成空集，所有 $r_{\mathrm{proc}}$ 应为 0；若真引用仍得 1，实现没有读 $G$。两个负对照都失败时，主表数字作废。

把第 23 课的列联表迁到本课评测页，避免两课数字加在一起。23 课的右上格是“VQA 对、格子错”，证据来自框或注意力。本课的右上格是“答案对、引用空”，证据来自推理文本。同一张计数图可以同时进两课：23 课问注意力有没有落在红杯上，本课问文本有没有写出 $(0,1)$。允许注意力命中而文本空，也允许文本有格子而注意力在别处。两列都空才是最干净的捷径。报告里禁止写“接地已通过因此 CoT 已通过”。

公开基准再拆一层解码。LLaVA-CoT 主文训练阶段的数字默认是模型自己切阶段、一次前向，不含 SWIRES；Table 4 才加缩放。Vision-R1 主表是 RL 之后的 greedy 或常规采样，原文未把 SWIRES 接到 Vision-R1 上。有人把 LLaVA-CoT+SWIRES 的 62.5 和 Vision-R1 的 73.5 横着减，差在基准集合、基座、是否数学专项、是否测试时搜索。本课对照表已经分列，评测页不要再合成“SOTA 差”。HallusionBench 在 LLaVA-CoT 的六项里，测的是语言幻觉和视觉错觉，不是格子引用率。即使该项上涨，也不等于 $r_{\mathrm{proc}}$ 上涨。

样本量和区间。[第 31 课](31_vla_evaluation.md)的 Wilson 区间同样适用于计数准确率。50 图、准确率 0.8，区间仍然很宽。本课最低交付不报公开基准百分比。若你在可选 Step 3 报了空引用率，同时报 $N$。$N<50$ 只准写案例。ConRFT 那种 20 次真机的警告在这里变成：20 道计数题的空引用率 0.1，换三道题就能翻倍。不要用 20 道题打 LLaVA-CoT 的六项均分。

## 11. 根据症状定位失败环节

| 症状 | 先查 | 不要先做 |
|---|---|---|
| 准确率涨、空引用率不降 | $r$ 是不是只等于 $r_{\mathrm{ans}}$ | 加长度上限 |
| 过程分全是 0 | 解析器是否扫错 span，标签是否被切碎 | 换基座模型 |
| 过程分全是 1 | 是否在全序列搜格子，结论污染是否漏检 | 宣布 CoT 成功 |
| 标签完整、计数仍错 | $G$ 是否与渲染一致，物体是否被 encoder 糊掉 | 加 SWIRES |
| 长度升、分数降 | 是不是 Vision-R1-Long 那种过思考 | 再加 16K |
| GRPO 步在走、权重不动 | 合取后是否整组为零 | 加大学习率 |
| 与论文 57.6 差一截 | 解码有没有 SWIRES，评测套件是否 V1.1 / testmini | 把 9.4 个点当预算 |
| Lab 揭晓后引用不是空 | 是否还开着必须引用 | 改公式系数 |
| 结论里写了格子却得了过程分 | 解析是否越界 | 加正则到全序列 |

再补一组和本课公式直接相关的症状。四个合取值几乎相等：要么 $G$ 覆盖了所有被点的格，要么解析总是返回空。优势之和不是 0：把不同题的 $r$ 拼在一起减均值。标准化形式在零方差组爆掉：$\varepsilon$ 写成了 0，应改回第 17 课的 $\varepsilon$。这些检查只需要打印长度为 $G$ 的向量和 $C(y)$ 集合。

再补一组和两篇主文献直接相关的症状。复现 LLaVA-CoT 时标签完整但 MMStar 几乎不动：先查是不是用了 Direct Training 那条原问答对，再查评测有没有走 VLMEvalKit、MMBench 是不是 V1.1。复现 Vision-R1 时长度顶到 16K、均分往下掉：先对照你是不是在跑 Long 而不是 PTST。冷启动之后计数套话变多、空引用率上升：先看蒸馏数据里 Wait / Alternatively 是否被当成必须模仿的表面特征，再决定要不要在 $r_{\mathrm{proc}}$ 里惩罚空引用。这些检查仍然不需要 8×H100，只需要日志里的 span 和 $C(y)$。

- 明确声明：未复现 73.5%、62.5% 或 9.4 个点。

交付物不要求思维链好看。要求能从一次“答对了”反推：推理 span 从哪到哪、解析出哪些格、$G$ 是什么、过程分是不是 0。这一条和第 01 课的 trace 纪律同类，对象从 codec 编号换成了引用集合。做不到反推的实验，即使公开基准上升，也不算本课交付。

报告第一页建议用四行固定模板。任务：数哪一种物体。起点：哪个 SFT 哈希、有无阶段标签。奖励：纯答案、合取还是 HFRRF。结果：空引用率、合取成功率、公开基准若有则附录。四行之外的 8×H100 训练曲线，有则附录，无则写未做。模板看起来死板，但能挡住“我们做了视觉思维链”这种没有 $C(y)$ 向量的句子。

交付物不要求思维链文风像 DeepSeek-R1。要求能从一次“答对了”反推：推理 span 从哪到哪、解析出哪些格、$G$ 是什么、过程分是不是 0。做不到反推的实验，即使公开基准上升，也不算本课交付。这一条和第 01 课追 codec 编号、第 38 课追奖励向量同类。对象换了，纪律不换。谁若只交一段漂亮的中文推理、没有格子集合，等于把第 23 课已经拆开的两列又焊回去了。交卷前用 30 秒过一遍：打开 Lab 揭晓截图或文字记录，确认引用格那一栏写着“空”；打开 CPU 的 `checks`，确认八条都是 True；打开公式页，确认 $r_{\mathrm{proc}}$ 的定义里有空集得 0。三处对不上，先别写“本课完成”。Gate 亮了只证明你走过开关和预测，不证明你能向别人复述 $C(y)$ 的定义。复述时把空集得 0 说成“格式不对得 0”，对象就又滑回 HFRRF 去了。对象滑了，第 51 课等于没上。把这一句写进实验记录的最后一行：过程奖励的对象是推理是否引用了视觉证据。写完再去碰 8×H100，也不迟。没有 GPU 的人交这三样就够：公式页、CPU 的八条 True、Lab 的空引用揭晓。有 GPU 的人多交空引用率，仍然不许把 73.5 写进同一格。73.5 是 MathVista ALL，空引用率是本课过程列，两列永远分着记账。谁把它们加在一起，验收按协议失败处理，不管思维链写得多长。长度不是证据，格子才是。空格子上的长句子，过程奖励分仍然只能是零。把这句话贴在公式页最下面，和 $C(y)=\emptyset$ 写在同一行。

## 13. 前沿对照与改造方向

**公开方案。** 2024–2025 年的视觉分步推理可以按监督信号分成三条，不要兑成“都在做 o1”。

结构化监督：LLaVA-CoT 用四阶段标签和 GPT-4o 蒸馏。Mulberry 在 Vision-R1 的对照里以 260K 出现，本课未打开其原文，不写它的搜索算法。测试时搜索：LLaVA-CoT 的 SWIRES 把束搜索粒度对齐到阶段，并用独立奖励模型打分。强化学习激励：Vision-R1 先冷启动再 GRPO，奖励是硬格式加最终答案；PTST 处理过思考。Qwen2.5-VL 的技术报告（[arXiv:2502.13923](https://arxiv.org/abs/2502.13923)）是 Vision-R1 的基座来源，公开配方以通用视觉指令为主，其技术报告未公开“过程奖励必须引用格子”这一列。Qwen2.5-Omni（[arXiv:2503.20215](https://arxiv.org/abs/2503.20215)）覆盖听、说、看和文本 / 视觉 GRPO，第 17、18 课已经划过界；它没有给出 4×4 计数上的引用奖励实验。Moshi 是语音全双工，与本课无关。

**差距。** 规模差距：8×H100 全参、72B 数据工厂、200K 冷启动、Verl 上的 200 步组相对，钱能堆。机制差距：span 分账、空引用过程分为 0、合取与否的开关，本课能做。评测差距：六项均分、MathVista 子项、是否含测试时搜索，不是把 Lab 调光滑能填的。算法差距：SWIRES 与 PTST 谁该先上，公开结果按任务分裂；缩小版只能复现“空引用必须得 0”，不能复现 73.5 对 54.8。

三条通道各自的投机也要写清。结构化监督会蒸馏出漂亮但不看图的 CAPTION。测试时搜索会讨好奖励模型的文风，不一定增加引用。结果强化学习会在计数先验上蒙对。共同审计是：训练 $r$ 与评测谓词分列，空引用率进账本，版本进配置。缺审计时，曲线越漂亮越不可信。

**动手改造清单。**

1. 把 CPU 夹具的 $r_{\mathrm{proc}}$ 改成要求 $C(y)=G$。预算：改一处函数，秒级。预期：漏点一只红杯时过程分从 1 变 0。失败：改完空引用仍得 1，或答案列被一起改掉。
2. 允许结论 span 里的格子计入 $C(y)$。预算：CPU 数分钟。预期：`CITE_IN_ANSWER_ONLY` 的过程分变成 1，原检查失败。失败：改完仍为 0，说明解析还停在推理 span，文档与代码不一致。这条用来证明默认实现为什么禁止越界。
3. 把金标改成只有 $(0,1)$，答案仍写 `2`。预算：改夹具常数。预期：真引用夹具的过程分变成 1 或 0 取决于是否仍包含 $(0,1)$；空引用仍为 0。失败：过程分不随 $G$ 变。
4. 若有 1×24GB：对会短答的小 VLM 加两段标签做 200 步 LoRA。预算：单卡数小时级。预期：标签完整率上升；空引用率若不同步下降，不得把计数准确率写成成功。失败：准确率升、空引用率不变，而报告只写了准确率。

**顺手复现映射。** 第 23 课“答案对、格子错”对应本课右上格，$r_{\mathrm{ans}}=1$、$r_{\mathrm{proc}}=0$。第 17 课“全 1 组没有更新”对应关掉必须引用后的答案组。第 38 课“只改 $r$”对应合取开关。LLaVA-CoT“去掉标签均分下降”对应阶段切分不是装饰，缩小版只能看到解析失败，看不到 57.6 对 55.7。Vision-R1“HFRRF 两项同时成立才给 1”对应合取，方向可复现，73.5 不可复现。这些映射全部是方向性的。谁把 9.4 个点写进自己的四条玩具回复报告，就算评测造假。

改造实验的失败判定再补两条公共规则。任何一次更新都要保存：权重哈希、`reward_spec` 版本、$C(y)$ 集合、$r$ 向量。缺 $C(y)$ 的结果不能进对照表。任何一次声称“过程奖励更好”的比较，必须在同一组回复上同时报 $r_{\mathrm{ans}}$ 与 $r_{\mathrm{proc}}$；换了题目就不能把差值记在奖励上。

预算表再强调一次机制与规模的分界。改正则、改 $G$、允许结论污染计入引用，这三件事在 CPU 上就能失败或通过。开 200 步 LoRA 是可选的规模动作，失败判定仍然是“空引用率和合取”，不是“是否接近 73.5%”。有人把可选档的一次成功跑写成课程通过，属于用规模数字代替机制验收。本课通过条件在第 10 节，不在档 C。

真要接到 MiniMind-O 或任意小 VLM，还有一条规模课不教的账单：解码预算。阶段化回复比短答长数倍。LLaVA-CoT 最大序列 4096，Vision-R1 第二阶段 8K。教学夹具只有几十个 token。谁若把夹具里的两条 span 写成“已经处理了 8K 过思考”，属于把右栏抄进左栏。写 recipe 时最大生成长度是单独一行；超长截断规则是另一行。PTST 的意义就在这两行会变。

5. 第 38 课的稀疏对 dense。带着问题读：空引用的过程分，和全失败组的稀疏成功，为什么是同一张零纸上的不同字段。回到[第 38 课](38_vla_rlvr.md)第 5.3 节。
6. Qwen2.5-VL 技术报告（arXiv:2502.13923）。带着问题读：Vision-R1 选它做基座时，公开配方有没有格子级过程奖励？没有的话，73.5 相对 68.1 的 +5.4 应当记在后训练，不记在动态分辨率。摘要：[abs/2502.13923](https://arxiv.org/abs/2502.13923)。

读 LLaVA-CoT 时再带一个计算题：基座 49.8 到带标签 57.6，差 7.8 个点；到 SWIRES 的 62.5，差 12.7 个点。摘要 9.4 个点落在这两段之间，说明它是“100k + 测试时缩放”的打包句，不是某一张表的单格。有人只写 9.4 不写解码，本课视为漏报。读 Vision-R1 时带一个对照题：CI 均分 44.5 低于 Zero 的 50.7，说明冷启动单独看会过思考；加上 PTST 才到 55.4。不要把冷启动曲线的早期下跌写成数据失败。读 HFRRF 时带一个单位题：它的第二项是最终答案，本课第二项是引用集合，两项永远分列。

读完材料回头看：政策一行权重都可以先不动，奖励程序已经能决定一次更新有没有把“看见图”算进去。同一道计数题，答案列给出四个 1，过程列给出 $(1,0,0,0)$。你现在应该能拿着任意一篇写了视觉思维链的论文，在五分钟内把它拆回阶段标签、$r$ 看哪一段、空引用怎么办、评测有没有测试时搜索，并决定这列数字能不能进自己的对照表。下一课规格转向看见图之后何时该调用工具：计算器、裁剪、深度、搜索。那是另一张 schema，不是把格子编号写进思维链就算调用了工具。本课停在这里：分步写推理是为了留下可检查的证据；证据为空时，过程奖励必须是 0。

若还要把机制讲给另一个人听，只用两条回复和一个开关。开：推理点 $(0,1)$ 与 $(2,3)$，答案 `2`，$r_{\mathrm{proc}}=1$。关：推理写套话，答案仍 `2`，$r_{\mathrm{proc}}=0$。第一句：直接出答案会跳过看见了什么。第二句：两套 token 必须分账。第三句：奖励对象是引用，不是数字。第四句：关掉必须引用，右上格一定能造出来。四句齐了，再打开 LLaVA-CoT 的 57.6 或 Vision-R1 的 73.5，才知道那些数字站在哪一种 $r$ 上。站错 $r$，数字再高也回答不了本课的问题。机制验收看的是空引用和集合不相交，不是看哪篇论文的百分数更大。百分数留给你以后真去复现时，带着第 23 课的列联表和第 17 课的 verifier 版本再写。现在先保证：引用格为空则过程奖励为 0，关掉必须引用后答案仍可对。这两句能手算、能过 CPU 实验、能在 Lab 里先预测再揭晓，第 51 课就可以收工。

把四句再落到一次组更新上。组里四条：真引用、空引用、错格、看对答错。合取向量 $(1,0,0,0)$。只奖答案时前三条都是 1，若再复制一条空引用就四个 1，政策不更新。合取打开后，只有真引用被抬高。你付的是四次解码的账单，买到的是“以后更可能把格子写进推理 span”。这和[第 38 课](38_vla_rlvr.md)用接触 dense 买到“以后更可能再近一点”是同一笔经济账，货物从接触距离变成了引用集合。货物写错，强化学习只是在付钱看世界，还没有在改“看见图”这件事。
