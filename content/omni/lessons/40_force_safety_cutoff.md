# 第 40 课：在力超限时切断动作块

> 内容：力门限、SAFE_HOLD 与不可回放的接触<br>
> 建议周期：4–6 天<br>
> 推荐硬件：无 GPU 可读完全文并跑 CPU 实验；真机核对需要力/力矩传感<br>
> 最终产物：力超限切断协议、SAFE_HOLD 状态机、倒水教具验收记录

## 1. 力超限为什么不能像语音那样重说一遍

第 07 课的全双工路由把助手输出写成可暂停的缓冲：控制头输出 `PAUSE` 时，停止可听声音，保留当前 branch 的 KV、播放边界，以及还没送进扬声器的 pending PCM（PCM：可直接播放的原始音频）。用户说“改成杭州”之前那半句“火车下午三点”如果还没播出，系统可以不让它出声；即便已经播出，听众听到的也只是空气里的声波，世界没有被机械地改写。`REPLAN` 丢掉未播 PCM，从安全 checkpoint 开新 branch。说错一句话，代价是语义和时间，不是碎杯子。

第 30 课把同一张状态机接到控制时钟上。动作块（action chunk：一次观察预测未来 $H$ 步关节目标）里还没下发的步，对应未播放 PCM。`REPLAN` 之后旧剩余步不得再执行。传送带夹具里物体被挪走，是运动学跳变，没有接触力。手臂若只是在空气里画错一条轨迹，丢掉剩余步就够了。

本课改的是接触已经发生的那一层。倒热水、插刀、把玻璃杯按到桌沿时，力/力矩传感器（force/torque sensor：测末端或关节受到的力和扭转）会在某一步 $i$ 读到过大的接触合力 $F_i$。策略网络此时往往还握着这块 chunk 的后半段：继续倾斜、继续下压、继续闭合。若调度器把后半段当成“已经规划好的未来”执行完，物理世界会沿着错误方向再走几十到几百毫秒。洒出去的水、移位的杯子、已经发生的挤压，没有 `undo`。

本课要动的模块不是视觉编码器，也不是第 07 课的 channel fusion 或 AEC。要动的是动作队列上的力门限（force gate：每步用 $\|F_i\|$ 与 $F_{\max}$ 比较的硬开关）和切断后的保持姿态（SAFE_HOLD：剩余步清零，末端停在当前关节目标，等待人类接管）。验证手段是两条能复现的夹具：阈值低于峰值时，超限步之后剩余步为 0、末端坐标不再增加；杯子位移停在超限后的数值，不能写回超限前。对照臂是同一时刻的语音 `PAUSE`：未播 PCM 帧数为 0，文本缓冲允许重说。

不要把本课写成“给 VLA 加一个更谨慎的 prompt”。语言层的拒绝，挡不住已经下发的关节增量。也不要把失败检测器（failure detector：根据模型内部特征或任务进度估计“这次会失败”）当成力门限。检测器回答的是任务成不成功；力门限回答的是这一步还许不许可做。两者可以叠，不能互相代替。

第 38 课会把接触写成可验证奖励，用来在失败轨迹上仍能排序更新。那是训练。第 39 课会把长程失败写成子目标栈的 pop 与重试。那是记忆。本课夹在两次失败处理之间：接触这一拍已经越线，栈还来不及 pop，奖励还来不及回传，队列里却还有 $H-i-1$ 步。这 $H-i-1$ 步必须先清掉。清掉之后，HOLD 给人类和上层栈留出墙钟。不清掉，pop 到的新子目标会接到一根还在往下压的手臂上。

π0 的 $H=50$ 在 50 Hz 上是 1 秒。1 秒足够把壶从刚碰杯沿推到把杯口打翻。OpenVLA 原版逐步自回归大约 3–5 Hz，单步慢，但逐步仍可能在接触中加力。OFT 并行块在 LIBERO 上整块执行。整块执行对静态套件友好，对倒水中途超限不友好。本课不要求你改这些模型的网络。要求你在它们吐出的块后面加一道与模型无关的门。门的输入是牛顿，不是 token。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 接触合力 $F_i$ | 第 $i$ 步执行后，力/力矩传感器给出的三维力，本课取欧氏范数 |
| 力门限 $F_{\max}$ | 允许继续执行剩余步的上限；超过则切断，单位牛顿 |
| 动作块 / chunk | 一次推理吐出的 $H$ 步动作，见[第 25 课](25_action_tokenization.md)、[第 30 课](30_closed_loop_control.md) |
| 剩余步 | chunk 里尚未下发的 `step_index`；切断后必须变成空表 |
| SAFE_HOLD | 切断后的保持姿态：末端不再推进，等待接触解除或人类接管 |
| 人类接管 | 操作者获得控制权；接触未解除时禁止自动 `REPLAN` |
| 危险示范过滤 | 训练前丢掉峰值力超过门限的示教，避免模仿不安全接触 |
| pending PCM | 第 07 课里已解码、未播放的音频帧；对应本课未执行关节目标 |
| SBU | Succ-But-Unsafe：任务成功谓词为真，但轨迹违反安全条款的比例 |

## 2. 本课解决的问题

第 30 课解决“过期块还能不能做”。本课解决“力已经超限的块还许不许可做”。过期块描述的是已经过去的时间，丢弃它不会改变当前接触。超限块描述的是正在发生的挤压，继续它会把接触写成事故。

常见失败是调度把整块 chunk 当成事务：要么全做，要么在推理完成前全部作废。接触发生在块的中间一步。事务语义会逼你做完后半段，或者幻想“整段回滚”。机械臂没有回滚。已经送到低层 PID 的目标，相当于已经送进扬声器的波形，第 07 课也不回收。

实验围绕下面的问题组织：

> 在长度为 $H$ 的动作块上，若第 $i$ 步的接触力满足 $\|F_i\| > F_{\max}$，
> 必须丢弃 $i{+}1$ 以后的剩余步，进入 SAFE_HOLD，保持当前姿态。
> 额外控制滴答不得推进末端。物体在超限步产生的位移不得写回超限前。
> 同一时刻的语音 `PAUSE` 只丢掉未播放 PCM，物理世界保持不变。

只有同时满足以下条件，实验才算实现了力切断：

1. 每步记录 `step_index`、`force_n`、`ee_mm`、`cup_mm`、`remaining`、`mode`；
2. 超限判定用严格大于：$\|F_i\| = F_{\max}$ 不切断，$\|F_i\| > F_{\max}$ 切断；
3. 切断后 `remaining = 0`，执行表不再出现更大的 `step_index`；
4. SAFE_HOLD 期间末端坐标与切断瞬间相同；
5. 物体位置在超限后不等于超限前，回放不得把它改回去；
6. 对照的语音 `PAUSE` 把剩余 PCM 置 0，并允许文本缓冲重置。

这六条每一条都在堵一种假安全：只在损失里加碰撞惩罚、运行时仍走完 chunk，是假的；切断后立刻 `REPLAN` 把杯子“规划”回原位，是假的；把视觉失败分数当成力，没有牛顿量纲，也是假的。

出现以下任一情况时，不得把结果标成可用的力切断：

- 超限后剩余步仍大于 0，后半段 chunk 继续倾斜或下压；
- SAFE_HOLD 期间末端仍按原增量推进；
- 回放把杯子坐标写回超限前，并称之为 `PAUSE`；
- 用任务成功率或 LIBERO 平均代替接触力时间线；
- 把 200 N 的仿真代理抄进真机，当成 ISO/TS 15066 认证；
- 实现第 07 课的 channel fusion、AEC 或 microstep 音频路由，并声称这就是本课。

## 3. 开始前需要准备什么

本课可不接机械臂、不训 7B。开始前在实验记录里分开写上游事实和本课约定。事实来自论文表与原文句子，约定是本课为了整数时钟和夹具复现而定的符号。

**上游事实：**

- [第 07 课](07_full_duplex_routing.md)规定：`PAUSE` 冻结 pending PCM 且保留同一 branch；`REPLAN` 才丢弃未播 PCM，并把旧 branch 标为 `superseded`；
- [第 30 课](30_closed_loop_control.md)规定：动作块的剩余步对应未播放 PCM；`REPLAN` 后旧剩余步不得进入执行表；过期判定与本课力判定是两道独立的门；
- SafeVLA（arXiv:2503.03480，NeurIPS 2025 Spotlight）把 VLA 安全约束写成约束马尔可夫决策过程（CMDP：最大化任务回报，同时让各类安全成本的期望不超过上限），相对任务向强化基线 FLaRe 把累计安全成本降低 83.58%，成功率 +3.85%；
- SafeVLA-Bench（arXiv:2606.00773）在 LIBERO 与 RoboCasa-365 上把成功和安全拆开：桌面高成功率策略仍有 13% 到 15% 不安全回合，厨房成功轨迹里 36% 到 56% 违反至少一条有效安全条款；接触力主档取 200 N，作者写明这是 ISO/TS 15066 的仿真侧代理；
- SAFE（arXiv:2506.09937）用 VLA 最后一层特征预测任务失败分数，并声明检测开销小于 1 ms；它测的是失败，不是牛顿。

**课程约定：**

- 符号：$H$ 为块长度，$i$ 为已执行步下标（从 0 计），$F_i$ 为该步后的接触合力，$F_{\max}$ 为门限。切断规则用严格大于。
- 末端用一维毫米 `ee_mm` 代替 7 维关节，每执行一步加 `EE_STEP_MM`。SAFE_HOLD 的断言是这根坐标不再增加。
- 杯子位移 `cup_mm` 在接触力超过 20 N 后按 $F_i-20$ 累加，只增不减，用来锁“不能 undo”。
- CPU 实验 $H=8$，力序列为牛顿整数 `(4, 6, 9, 14, 22, 35, 52, 74)`，默认 $F_{\max}=50$。浏览器教具 $H=12$，峰值 210 N。两套数字不同，规则相同。
- 本课不实现音频编码器、AEC、channel fusion。语音对照只保留“剩余 PCM 帧数”和“文本能否重置”两个字段。

最小独立组件：

- 一个长度为 $H$ 的动作块缓冲；
- 一个每步可读的力标量或三维力；
- 一个 `GENERATING | SAFE_HOLD | HUMAN` 状态机；
- 一份确定性 replay，可重复得到同一条执行表。

不需要的东西同样写清。不要重训 SafeVLA 或 π0；不要在本课实现第 07 课的 listener；不要把 LIBERO 装进 CPU 实验；不要把教具阈值写成人体疼痛阈值。视觉编码器可以缺席：夹具用预定力序列代替真实接触力学，因为本课断言的是调度协议，不是接触模型是否保真。MuJoCo 欠采样冲击力这件事，SafeVLA-Bench 自己写在限制里；本课用整数牛顿躲开该争议。

若已有第 30 课的 `remaining` 列表，切断就是在超限步把它清空，并把 `mode` 写成 `SAFE_HOLD`，而不是标 `stale` 或 `replan`。过期是时间问题，超限是接触问题，日志里的 `reason` 必须分开。第 30 课的传送带夹具把扰动做成位置跳变，本课把扰动做成力尖峰。两套夹具不要合成一个“又跳又撞”的脚本再声称同时验收两课：跳变测 freshness，力尖峰测 HOLD，混在一次运行里失败无法归因。可以先后跑，不要并行改四个旋钮。

输出：

```text
force-v1-continue-chunk
force-v1-safe-hold
force-v1-human-takeover
```

## 4. 完成后应具备的能力

倒水现场往往只剩一句“撞翻了”。下面十条把这句话拆开。完成后，拿到任意一次超限，你应能完成以下检查：

1. 写出 $\|F_i\| > F_{\max}$ 时的剩余步去向，并指出等号不切断；
2. 说明 SAFE_HOLD 与第 07 课 `PAUSE` 的相同点（都停住未发生的输出）和失效点（接触已经改写了物体）；
3. 从时间线追到 `cutoff_step`、`ee_at_cutoff`、`cup_before`、`cup_after`；
4. 证明额外控制滴答不增加 `ee_mm`；
5. 把危险示范过滤写成训练侧的同一道不等式，而不是运行时的替代品；
6. 对照 SafeVLA 的 CMDP 与 SafeVLA-Bench 的 SBU：一个改训练，一个改记账，都不是本课的硬切断；
7. 说明 SAFE 失败检测器触发后仍要落到 SAFE_HOLD 或人类接管，不能只记一个分数；
8. 区分“模型不会倒水”和“调度在超限后仍走完 chunk”；
9. 写出假阳性（门限低于倾倒力）和假阴性（门限高于撞杯力）各自会逼出什么现场行为；
10. 在日志里把 `force_trip`、`stale`、`replan` 分成三个 `reason`，并能指出接触未解除时为什么禁止自动 `REPLAN`。

## 5. 原理：边造边讲

难点不在多线程，在承诺的方向：哪些输出还没发生、可以丢；哪些接触已经发生、必须停。下面按同一节奏展开：为什么需要、怎么运转、精确定义、在哪核对、怎么证明做对了。

### 5.1 音频缓冲可丢，接触力不能 undo

第 07 课把播放缓冲分成四层：codec 已生成、PCM 已 decode、PCM 已发送、PCM 已播放。`PAUSE` 停在“已发送之前”。还没出扬声器的帧，听众没听见，世界也没被声音推动。恢复时可以从同一播放边界继续，这是 `PAUSE/RESUME` 复用同一 branch 的物理前提。

机械臂上没有与“未播放 PCM”完全同构的层。关节目标一旦交给低层跟踪器，电机就开始用力。力传感器读到的是已经发生的相互作用。你可以丢掉还没下发的剩余步，不能收回已经作用在杯子上的冲量。把 `PAUSE` 翻译成“末端瞬移回 200 ms 前”，等于发明一种物理学。

类比：打电话说错可以道歉重说；把热水倒到键盘上，关掉麦克风没有用。类比失效处：音频也有不可回收的部分，已经播出的半句听众听见了。第 07 课并不假装能擦掉空气里的声波，它只擦缓冲。本课同样只停未来，不改过去。差别是过去在手臂上会留下物体位移、温度和裂纹，过去在语音里通常只留下语义。倒水夹具把这条差别写成两个字段：`world_unchanged=True` 只属于音频对照；杯子的 `cup_mm` 在超限步之后必须大于超限前。

第 30 课已经警告过：手臂上的 `PAUSE` 通常保持最后姿态，仍可能顶着物体。本课把“仍可能顶着”升级成硬规则。SAFE_HOLD 的保持姿态，就是承认接触可能还在。保持不是回退。回退需要另一条有意识的撤离轨迹，而且必须在力降下来之后，由人类或专门的撤离策略发出，不得复用超限时的那块 chunk。

### 5.2 力/力矩门限与切断公式

设块为 $\mathbf{A}=[a_0,\ldots,a_{H-1}]$。调度器按控制周期执行。第 $i$ 步执行完毕后，传感器给出 $F_i\in\mathbb{R}^3$。本课用欧氏范数

$$
\|F_i\|=\sqrt{F_{i,x}^2+F_{i,y}^2+F_{i,z}^2}
$$

CPU 实验对 $(30,40,0)$ 断言范数为 50。这是 3-4-5 直角三角形乘上 10，用来锁实现有没有把范数写成绝对值之和或只取 $z$ 分量。教学实现用四舍五入到整数牛顿，避免浮点在边界上吵。$(0,0,52)$ 的范数必须仍是 52，防止有人把二维公式抄到三维时丢掉一维。

切断规则：

$$
\|F_i\| > F_{\max}
\quad\Rightarrow\quad
\text{discard }\{a_{i+1},\ldots,a_{H-1}\},\quad
\text{mode}\leftarrow\texttt{SAFE\_HOLD}
$$

等号不切断。$F_{\max}=52$ 且 $\|F_6\|=52$ 时，第 6 步不算超限；要等到后面真正大于门限的步。这和[第 30 课](30_closed_loop_control.md)过期用 `>=` 相反：时间上“恰好等于窗口”已经没有可执行的未来，力上“恰好等于门限”仍视为刚刚压在上限上。两套边界写进同一份日志时，不要共用一个 `exceeded` 布尔名。力用 `force_trip`，时间用 `stale`。

为什么在第 $i$ 步之后才比，而不是之前？因为 $F_i$ 是执行 $a_i$ 的结果。门限保护的是还没发生的 $a_{i+1}$。第 $i$ 步造成的位移已经进了世界，夹具用 `cup_before_mm`（执行 $a_i$ 前）和 `cup_mm`（执行后）把这笔账留下。有人希望“超限则连第 $i$ 步也撤销”。传感器读数来自该步，撤销需要反向动作，反向动作本身可能更大。本课协议不自动反向。

力矩可以并入同一道门。把关节力矩 $\tau$ 与额定 $\tau^{\max}$ 比较，任一关节超限同样切断。SafeVLA-Bench 把 `joint_torque` 列成执行类条款，主档用 $|\tau_i|<\tau_i^{\max}$。本课 CPU 实验只锁力范数，避免和 Franka 的 87 N·m 额定搅在一起。真机要把力门限和力矩门限写成两个独立 `reason`，不要用一个标量混报。

ISO/TS 15066 为协作应用的功率与力限制提供按人体部位区分的力、压强上限。本课不把任何教学阈值写成认证值。SafeVLA-Bench 把接触力条款的主档实例化成 200 N，并写明这是仿真侧代理；VSI 的严重锚点对同一条款取 500 N，作者把它标成 Table A.2 手背准静态接触痛阈的量级。把 200 N 抄进真机安全文件，或把教具滑条上的 90 N 写成人体阈值，都属于张冠李戴。倒水夹具的 $F_{\max}$ 只用来触发协议，单位牛顿是为了和论文代理同一量纲，不是合规测试。

### 5.3 SAFE_HOLD：剩余步为 0，末端不推进

切断之后，动作队列必须变成空。用第 30 课的语言：`remaining = []`，且 `current is None` 不得再被同块补回。任何在超限之后到达的、属于同一 `chunk_id` 的后半段，`reason="force_trip"`，不得标成 `receding_uncommitted` 或 `replan`。后一种标签会让诊断以为有人故意重规划，掩盖真正的超限。

SAFE_HOLD 的第二条是末端冻结。设切断瞬间末端坐标为 $x^\star$。对随后每个控制滴答

$$
x_{t+1}=x^\star
$$

CPU 实验默认切断在 $i=6$、$\|F_6\|=52$、$F_{\max}=50$，此时已执行 7 步，`ee_mm=28`。再跑 4 个 hold 滴答，坐标仍是 `[28, 28, 28, 28]`。教具用同样规则：切断后壶的倾角停住，不再按 chunk 后半段增加。

冻结不是阻抗控制（impedance control：把末端做成带刚度、阻尼的弹簧，让接触力随变形上升）。阻抗可以在接触中继续微动。SAFE_HOLD 是硬保持：本课协议在超限后不允许策略再写增量。真机若用阻抗做柔顺，必须另写一条“柔顺仍受 $F_{\max}$ 约束”的运行时，不能借本课的 HOLD 当弹簧。夹具没有弹簧，避免有人把 28 mm 的平台理解成还可以往前“柔一点”。

重力补偿和硬保持也要分开。有的协作臂在软件停住之后仍开着重力补偿，人手一碰，臂会漂。漂是人在接管，不是策略在推进。CPU 实验的 HOLD 滴答没有人推，所以末端必须严格等于 $x^\star$。真机日志若在 HOLD 期间看到末端因重力或人推而动，应标 `source=human_or_gravity`，不得标 `source=chunk`。只要 `chunk` 还在写增量，协议就失败。夹具用四个相同的 28 mm 把“策略没写增量”锁死，不模拟重力下垂。下垂是真机标定问题，写在硬件笔记里，不要靠改 `EE_STEP_MM` 去“更真实”。

第三条：物体坐标不得回绕。切断步执行前杯子在 `cup_before_mm`，执行后在 `cup_mm`。回放这两次读数必须能复现，且 `cup_mm != cup_before_mm`。默认夹具里这两个数是 17 mm 和 49 mm。若某次实现把杯子写回 17，等于在日志里 undo 接触。验收失败。物体在 HOLD 期间也不许被积分器“弹回”。夹具的杯子位移只在 `GENERATING` 且执行了该步时增加；`discard_hold` 和 `hold` 两类事件必须保持 `cup_mm` 不变。若你的物理引擎在冻结命令下仍用残余速度推杯子，日志里要分开 `cup_from_chunk` 与 `cup_from_residual`。本课断言只锁前者。残余速度是接触动力学，真机存在，教学夹具设为零，避免有人把残余滑移当成 undo 成功。

### 5.4 继续执行 chunk 才是事故

不切断时，同一条力序列会把杯子推到 103 mm，末端走到 32 mm。103 相对 49，是后半段 chunk 在超限之后继续倒、继续撞的结果。现场常见的“模型太猛”，有一部分是策略，有一部分是调度拒绝在第 6 步放手。

动作分块本意是降低决策次数，让 $H$ 步内部连贯。ACT 用它压短有效视野，π0 用 $H=50$ 覆盖 50 Hz 的灵巧轨迹。连贯的代价是：错误的接触一旦开始，后半段会把同一方向坚持到块结束。第 30 课用 $k<H$ 的后退视野缩短承诺；本课在 $k$ 之外再加一道力门。两道门正交。$k=2$ 仍可能在第 1 步超限；超限后那 1 步剩余也必须丢掉。不能说“我们 $k$ 很小所以不必测力”。

开环窗口 $H/f$ 仍然有效。力门限不取代 freshness。一块又过期又超限的动作，两条 `reason` 都要记。处理顺序建议：先看力，再看过期。已经在挤杯子，没有资格讨论这块观察新不新。

倒水把“故意接触”和“事故接触”放在同一根力轴上，这是抓取所没有的麻烦。壶嘴靠上杯沿、液体冲击杯壁、杯底对桌面的法向，都会抬高 $\|F\|$。门限必须高于完成倾倒所需的接触，低于把杯子推离原位的接触。教具把这条写成可调滑条：90 N 在 12 步序列上于 102 N 处切断，仍允许前面几步的倾倒接触；220 N 高于峰值 210 N，整块跑完，杯子被推到未门限轨迹。现场若把 $F_{\max}$ 设得比倾倒力还低，壶永远倒不完，操作者会关掉门限。关掉门限比设错阈值更危险，因为日志里连 `force_trip` 都不会出现。本课验收要求你触发一次切断，不是要求你把阈值拧到最小。

假阳性（门限过低、正常倾倒被切断）和假阴性（门限过高、撞杯仍继续）要分开记。假阳性的代价是任务失败、需要人类再倒一次；假阴性的代价是热水和碎杯。本课协议在两者之间不给自动折中公式。折中是风险评价，属于 ISO 10218 / TS 15066 的系统集成，不是 VLA 调度器的超参搜索。调度器只保证：你选定的 $F_{\max}$ 一旦被越过，剩余步必须为零。

低层跟踪器在 HOLD 之后仍可能对已有接触出力。PID 或阻抗跟踪的是“保持 $x^\star$”，若 $x^\star$ 已经顶进杯子，保持本身就是持续力。SAFE_HOLD 保证的是命令不再朝错误方向走，不保证接触力立刻掉到零。要把力降下来，必须有一条撤离：沿接触法向退、张开夹爪、或人用手控拉开。撤离动作是新的短轨迹，`chunk_id` 必须新，`reason` 不得继承 `force_trip` 那块的剩余步。夹具不实现撤离，所以 HOLD 末尾杯子停在 49 mm 而不是回到 0。有人把 49 mm 当成 bug，想在 HOLD 里把杯子“弹回”。弹回是 undo，验收必须失败。

### 5.5 传感器时钟和控制时钟

力传感器通常比策略滴答快。腕部六维力/力矩计常见 1 kHz；关节电流估计的力矩可能与电机环同频；策略块可能是 10–50 Hz。本课 CPU 把一步对应一个力标量，等于假设你已经在该控制周期内做完峰值提取。真机必须写明：与 $F_{\max}$ 比较的是周期内峰值、末点、还是均值。末点和均值会把短冲击洗掉。改造清单第 1 条要求用 `max`。主课文把这条提前写成协议：比较量是该步窗口内的 $\|F\|$ 峰值，记为 $F_i$。日志同时存 `force_peak_n` 与 `force_end_n`，诊断才能分开“脉冲超限、末点未超”和“持续超限”。

采样延迟也要进时间线。力读数的 `available_at` 是采样时刻加滤波延迟，不是图像的 `t_obs`。切不得用视觉帧时间去对齐力。第 07 课和第 30 课已经为音频和动作准备了两套 `available_at`；本课第三套叫 `force_available_at_ms`。三套混用会让 320 ms 音频块去跟牛顿比，或者让 50 Hz 动作步去跟 1 kHz 力样本逐点执行 50 次切断。切断决策落在控制周期上：每个 $1/f$ 至多一次 `force_trip`，内部 1 kHz 样本只贡献峰值。

没有腕部传感器时，有人用关节力矩 $\tau = J^\top F$ 反推接触。反推依赖雅可比和摩擦模型，误差在奇异点附近放大。本课允许用 $\|\tau\|_\infty$ 做第二道门，但必须在日志标 `source=joint_torque_est`，不得标 `source=wrist_ft`。SafeVLA-Bench 的关节力矩条款按执行器额定，和接触力条款是两家。两家同时越线，记两次违规，不要合成一个“不安全分数”再丢细节。

滤波不要把超限滤掉。低通太重，52 N 的尖峰会变成 40 N 的慢坡，门限 50 N 就失效。夹具无力滤波，所以这条只写在真机笔记：先比峰值，再存滤波后的力给示波器。训练用的示范若经过重低通，过滤阈值和运行时阈值会对不上。数据卡要写截止频率。

### 5.6 人类接管

SAFE_HOLD 不是自动续任务。接触未解除时，新的语言指令、新的视觉 `REPLAN`、新的流匹配积分，都可能把末端继续往杯子里送。本课把权限交给人类接管（human takeover：操作者切到手控或示教器，系统只保持姿态并记录）。CPU 实验从 SAFE_HOLD 进入 `HUMAN` 后，再跑 3 个滴答，末端仍是 28 mm，杯子仍是 49 mm，`remaining` 仍是 0。

接管期间策略前向可以停，也可以继续算但不许下发。下发权在操作者释放之前必须是关的。释放条件至少包括：力降到门限以下、操作者确认、旧 `chunk_id` 作废。本课不规定撤离轨迹的形状。规定的是：撤离不得复用超限块的剩余步。那些步的 `reason` 已经是 `force_trip`，它们描述的是“继续倒”，不是“退开”。

手控常见三种入口，协议对三种都成立。示教器速度限制模式：人推着臂走，系统只记录。重力补偿模式：臂漂在当前姿态，人轻轻拉开接触。紧急停止：断驱动，HOLD 的软件保持被硬件制动取代。无论哪一种，软件队列里的剩余步都必须已经是空的。否则急停解除后，旧 chunk 会从第 $i{+}1$ 步接着倒。这是现场最阴的一种“我已经按了急停怎么还在动”：急停切的是电机，队列里还躺着未来目标。本课 CPU 在进入 `HUMAN` 之前就把 `remaining` 置 0，就是为堵这一条。

接管日志至少记：谁在何时按下、当时 $\|F\|$、当时末端、当时杯子、旧 `chunk_id`。第 01 课的 trace 纪律在这里变成安全调查：没有这五个字段，事后只能靠回忆。夹具用常数 28 mm 和 49 mm 代替真实标定，字段集合必须与真机方案相同。

ConRFT（arXiv:2502.05450）在在线强化阶段用人类干预保证探索安全，并在八项真机任务上于 45–90 分钟内做到平均成功率 96.3%。那是训练期的人在回路，用来限制试错把机器人拆掉。本课的接管是推理期的最后一道门。两者都承认：接触丰富的操作不能把安全完全交给回报函数。不要把 ConRFT 的 96.3% 写进本课交付物，它测的是任务成功，不是切断协议。

### 5.7 危险示范过滤

运行时切断是补救。训练若在模仿峰值力 80 N 的示教，策略会学会在接触里加力。危险示范过滤（dangerous demonstration filtering）用同一道不等式扫数据集：一条轨迹的峰值 $\|F\| > F_{\max}$ 则整条不进模仿损失。CPU 实验对峰值 `[40, 55, 80, 12]`、$F_{\max}=50$，断言保留 `[40, 12]`、丢掉两条。

这和 OpenVLA-OFT 过滤失败示范不是同一件事。OFT 按任务成功谓词丢掉没完成的轨迹，目的是提高 LIBERO 成功率。力过滤按传感器峰值丢掉成功但过猛的轨迹。SafeVLA-Bench 的 SBU 说明：成功谓词为真，仍可能家具撞击、旁物被推、持物过倾。只按成功过滤，会把 SBU 样本当正例喂给行为克隆。

过滤会发生在三个时刻，不要并成一个开关：

| 时刻 | 输入 | 动作 | 本课是否实现 |
|---|---|---|---|
| 数据集构建 | 带力通道的示教 | 峰值超限则丢条 | CPU 计数器 |
| 训练采样 | 仍漏进来的高力片段 | 损失 mask 掉超限步之后 | 不实现，只要求记录 |
| 运行时 | 当前 $F_i$ | SAFE_HOLD | 主路径 |

没有力通道的 OXE 子集，不能假装滤过。写“我们用了 Open X-Embodiment”而不写哪些轨迹有接触力，等于力过滤未做。本课不编造 OXE 里有力通道的比例。没有的就标 `force_channel=absent`，运行时更要依赖真机传感器，而不是数据集声明。

### 5.8 训练期约束：SafeVLA 的 CMDP

硬切断保的是这一步。训练可以减少走到切断的次数。SafeVLA 把问题写成 CMDP：策略 $\pi_\theta$ 最大化语言条件的任务回报，同时对每个安全成本 $c_i$ 满足

$$
\mathbb{E}_{\pi_\theta}\Big[\sum_{t=0}^{\infty}\gamma^t c_i(s_t,a_t)\Big]\le b_i
$$

可行策略集合是所有满足上述不等式的 $\pi_\theta$。拉格朗日松弛把约束写成

$$
\min_\theta\max_{\lambda\ge 0}\Big[-\mathcal{J}_r(\theta)+\sum_i\lambda_i\mathcal{J}_{c_i}(\theta)\Big]
$$

作者强调先满足安全、再在可行域里抬任务回报。固定惩罚系数做不到同样的折中：他们的消融显示，动态乘子比任何满足同一成本上限的固定惩罚有更高成功率。

安全谓词分成状态-动作级 $\phi$ 和轨迹级 $\psi$。违反 $\phi$ 的那一步记成本 1；$\psi$ 在这段探索里把成本记在违片段的最后一步，作者承认信用分配仍开放。成本阈值 $b_i$ 取 FLaRe 收敛成本的 20%，Safety-ObjNav 上 FLaRe 收敛累计成本写为 11.5982。这是 SafeRL 里避免拍脑袋绝对值的做法，不是物理牛顿。

对象成本 $c_{\mathrm{object}}$ 按被扰动物体的个数分级。记物体 $i$ 在相邻两步的位移为 $\Delta d_i$、姿态变化为 $\Delta\theta_i$，阈值为 $D$ 与 $\Theta$。两个及以上物体越限记 2，恰好一个记 1，否则记 0。机器人成本 $c_{\mathrm{robot}}$ 更简单：碰撞集合与禁区相交则记 1。这些成本测的是“动了不该动的东西 / 撞了不该撞的几何”，仍然不是腕部牛顿。你可以在 Safety-CHORES 里把累计成本压下去，同时在真机倒水时没有任何 $F_i$。本课把它们放在训练与评测层，运行时仍读 $\|F_i\|$。

ISA 还报告：加上约束之后的成本分布与任务成败大致脱钩，FLaRe 则是失败轨迹成本更高。逻辑回归和 Pearson 检验在 FLaRe 上给出成本与成功的显著负相关（$p<0.01$），ISA 上拒绝该相关。作者的解释是：学会安全之后，失败也较少靠撞墙来“尝试”。这对倒水的启示是：切断后的 HOLD 会降低后半段继续累积的接触成本，即使任务已经失败。CPU 夹具里未切断走到 103 mm、切断停在 49 mm，就是这条性质的逐步版。它不证明 83.58%，只证明“停住后成本不再随剩余步增加”。

他们的集成安全方法（ISA）还包括建模与诱发。Safety-CHORES 在 ProcTHOR 的约 15 万室内场景和 Objaverse 资产上，把转角卡住、盲区碰撞、易碎摆设、危位点、危险设备写成可诱发组件。去掉这些组件、只在单房间训，累计成本从 1.854 升到 5.01，成功率从 0.865 降到 0.645，甚至差过启发式的奖励塑形。约束算法相同、诱发不足，安全对不齐。

相对 FLaRe，ISA 把累计安全成本平均降低 83.58%，成功率 +3.85%。极端失败设定里任务成功率接近 0，FLaRe 平均成本 71.68，ISA 为 2.20，SPOC 为 14.63。作者还报告 ISA 消掉了累计成本大于 10 的轨迹，不安全行为严重程度上界降到 FLaRe 的 1/35。这些数字来自仿真移动操作，初始模型是 SPOC-DINOv2，不是 OpenVLA-7B 桌面套件。本课引用它们，只为说明：训练期约束改变的是成本分布，不替代运行时 $\|F_i\|>F_{\max}$。ISA 训练后的策略仍可能在某一步碰到未建模的接触；那一步还是要切断。

仿真到真机，作者用双 Realman RM75-6F、PsiBot G0-R 手和 RealSense D455，部署 Safety-PickUp，并列出感知用 FoundationPose、动作空间解耦、数字孪生调 PID、数据管道一致四条。公开材料没有给出真机接触力时间线或切断次数。其技术报告未公开该细节。本课不把项目页视频写成力门限已在真机验证。

OOD 扰动（颜色、光照、材质、四者同时）写在 Table 2。Safety-ObjNav 上平均成功率下降 0.042，累计成本上升 1.090；PickUp 与 Fetch 的成本变化更小，有的组合成本甚至下降。作者据此说学到的安全行为不是贴在训练集表面上的。本课不把这张表抄成“加了 CMDP 就可以不上力传感器”。OOD 测的是视觉域，不是接触力学域。把桌布换成另一种颜色，和把玻璃杯换成更脆的杯子，不是同一类偏移。倒水夹具的力序列在所有“视觉 OOD”下都一样，因为它根本没有图像。要测接触 OOD，得换力序列或换 $F_{\max}$，这正是教具滑条在做的事。

FLaRe 本身（arXiv:2409.16578）是大规模 RL 微调框架，目标是任务表现，没有本课这种逐步力门限。SafeVLA 把它当“只优化成功”的对照，不是当反派。本课同样：没有 CMDP 也能先装力门限；有 CMDP 也不能拆掉力门限。

### 5.9 评测期：成功不等于安全

[第 31 课](31_vla_evaluation.md)禁止把仿真成功率当成真机能力。SafeVLA-Bench 补了一刀：同一条成功轨迹仍可能不安全。它用信号时序逻辑（STL：对连续轨迹给出满足与否以及距离阈值的裕度）写任务相关条款，并报四个数：宿主成功率 SR、安全满足率 Safety、Succ-But-Unsafe（SBU）、Violation Severity Index（VSI，最严重违规的归一化深度，落在 $[0,1]$）。

八条默认条款覆盖场景接触、持物、执行。接触力三家（臂撞家具、持物撞家具、任意接触峰值）主档 200 N；旁物位移 5 mm；持物倾斜 $15^\circ$；抓取滑动 2 cm；关节力矩按额定；自碰为二元。作者反复声明：这些是可审计的仿真代理，不是 LIBERO 或 RoboCasa 的硬件认证。任务注册表会关掉自相矛盾的条款：酒架插入需要大倾角，持物倾斜条款不适用；抽屉开合的目标就是让抽屉动，旁物位移不能把抽屉当旁物。

LIBERO 上三个平均 SR 超过 94% 的 SFT 策略，平均 Safety 只有 85% 到 87%，仍留 13% 到 15% 不安全回合。缺口在 LIBERO-Spatial 最大：Cosmos-Policy-2B、GR00T-N1.7、π0.5 的 SR 在 97.5% 到 99.0%，Safety 落到 74.5% 到 80.0%。π0.5 平均 SR 最高（96.6%），Safety 不是最高；π-RL-130 用 92.4% 的 SR 换到平均 Safety 90.3%、VSI 0.053。OpenVLA-7B 平均 SBU 最低（5.8%），因为许多不安全回合本身就失败了，但平均 VSI 最高（0.113）：失败时的最严重违规更深。

RoboCasa-365 atomic-seen 上，四条完整策略在成功条件下的不安全比例 $P[U\mid S]$ 为：π0 37.7%，π0.5 36.5%，GR00T-N1.5 55.8%，RLDX-1-FT-RC365 39.5%。也就是论文摘要里写的 36% 到 56%。频率和严重度再次拆开：π0 的 SBU 最低（12.2%），VSI 却最高（0.197）。

阈值敏感性：力天花板从 200 N 放到 500 N，LIBERO 平均 Safety 从 86.5% 升到 89.9%，RoboCasa-365 从 48.8% 升到 78.2%。全部放宽后，成功但不安全仍不是零（LIBERO 0.9%，RoboCasa-365 7.9%）。本课需要这条：调 $F_{\max}$ 会改变记账，不会把“成功即可”变回充分条件。教具滑条正是这条敏感性的最小版本。把滑条拉到 220 N，倒水整块跑完，杯子被推得更远，任务若只看“壶倾到了”甚至可以标成功。那就是 SBU。

OmniGuide 曾报告 GR00T-N1.6 在 RoboCasa 上任务成功 24.2%、无碰撞 7.0%。SafeVLA-Bench 引用这个 17 个百分点的缺口，作为“排行榜不报过程”的例子。本课不展开 OmniGuide 的引导场，只借用这句话：过程量（力、位移、倾斜）必须单独记账。

### 5.10 失败检测不是力门限

SAFE 把 VLA 最后一层特征映射成失败分数 $s_t$，再用函数型共形预测（conformal prediction：用校正集构造覆盖保证，使成功轨迹的分数以 $1-\alpha$ 的概率落在带内）给出时变阈值。分数越线就报警，然后停止、回退或叫人。它在 OpenVLA、π0、π0-FAST 的仿真和真机上测过多任务泛化。仿真平均 ROC-AUC 上，SAFE-MLP 在未见任务上到 78.00，SAFE-LSTM 到 77.04，强于只需单次前向的嵌入距离基线。真机上 SAFE-MLP 在 π0-FAST+Franka 未见任务 64.16、OpenVLA+WidowX 未见任务 88.42（均为 ROC-AUC）。开销：SAFE-LSTM 约 230 万参数、0.73 ms；文中测到的 π0 前向约 149 ms。

把 SAFE 的越线直接接进本课状态机，合理的落点是 SAFE_HOLD 或人类接管，而不是自动 `REPLAN` 完成本来已经在挤的动作。失败分数没有牛顿量纲。漏抓、振荡、物体滑出，SAFE 的定性例子里都有；那些事件的力可能仍低于 $F_{\max}$。反过来，一次短促超限可能任务最终仍成功，失败检测器不一定报警，力门限必须报警。

STAC 用连续两块动作的重叠段不一致性检测失败，原文采样可到 256 个动作。SAFE 作者测到 π0 采 10 个样本相对 1 个慢 152%，π0-FAST 慢 221%（RTX 3090，JAX）。本课硬切断必须能在单个控制周期内完成比较和清队列，不能等 10 次流匹配。失败检测是旁路；力门限是主路。

[第 17 课](17_grpo_rlvr.md)的可验证奖励和第 38 课将讨论的接触 dense 奖励，改变的是训练更新。零方差的稀疏成功组不产生更新；dense 接触仍可排序。那是梯度信号。本课的 $F_i$ 是运行时许可。不要把奖励塑形当成切断。SafeVLA 已经拿 FLaRe-RS（把安全成本直接减回报）当弱对照：启发式惩罚没有 CMDP 的可行域，更没有逐步硬门限。

### 5.11 与 CONTINUE / PAUSE / REPLAN 对照

四动作必须分清对象。下面这张表是本课和第 07、30 课的接口，不许把四行并成一个 `stop`。

| 动作 | 音频时钟（第 07 课） | 控制时钟（第 30 课） | 接触（本课） |
|---|---|---|---|
| `CONTINUE` | 继续说，消费 pending PCM | 执行当前块剩余步 | 仅当 $\|F_i\|\le F_{\max}$ |
| `PAUSE` | 停嘴，保留 PCM 与 branch | 冻结剩余步，物体仍可能被传送带带走 | 不足以描述超限：可能仍顶着物体 |
| `REPLAN` | 丢 PCM，新 branch | 旧剩余步作废，新推理 | 接触未解除时禁止自动触发 |
| `SAFE_HOLD` | 无对应：音频没有接触力 | 无对应：第 30 课夹具无力 | 清剩余步，保持姿态，转人类 |

`PAUSE` 和 `SAFE_HOLD` 最容易被抄错。相同点：都停止未来输出。不同点：`PAUSE` 假设世界可逆或至少未被执行器改写；`SAFE_HOLD` 假设世界已被改写。音频对照夹具把 `world_unchanged=True` 和 `transcript_resettable=True` 绑在 `PAUSE` 上。力夹具把 `object_rewound=False` 绑在 `SAFE_HOLD` 上。两个布尔朝相反方向。若有人实现“超限则 `PAUSE` 并重置杯子”，CPU 实验的 `object_cannot_rewind_past_contact` 必须为 False。

第 48 课才会问语音打断和手臂重规划能否共用一张状态表。本课提前钉死一列：音频 `PAUSE` 不等于力切断。一次点击不得同时 undo 已播放音频和已发生的接触。本课实验里它们是两次事件、两份日志。

### 5.12 状态机

状态机只处理动作队列和力，不处理麦克风。

| 当前状态 | 事件 | 下一状态与处理 |
|---|---|---|
| `GENERATING` | $\|F_i\|\le F_{\max}$ | 保持 `GENERATING`，执行 $a_{i+1}$ 若仍有剩余 |
| `GENERATING` | $\|F_i\| > F_{\max}$ | 进入 `SAFE_HOLD`，`remaining=0`，记录 `ee_at_cutoff` |
| `SAFE_HOLD` | 控制滴答 | 末端不变，不取新 chunk |
| `SAFE_HOLD` | 人类接管 | 进入 `HUMAN`，下发权关闭 |
| `HUMAN` | 操作者释放且力低于门限 | 旧 `chunk_id` 作废；新观察才能开推理 |
| 任意 | 过期 chunk 到达 | 按第 30 课丢弃，不得覆盖 `force_trip` |

`GENERATING` 在块自然结束且从未超限时进入 `DONE`。`DONE` 的 `remaining=0` 和 `SAFE_HOLD` 的 `remaining=0` 不得混用：一个是做完，一个是被切断。CPU 实验对 $F_{\max}=74$（等于峰值，严格大于不成立）断言 `mode=DONE`、`cutoff_step is None`、末端 32 mm。对 $F_{\max}=50$ 断言 `mode=SAFE_HOLD`、末端 28 mm。两个 0 剩余步，法律世界不同。

确定性来自同一份力序列、同一个 $F_{\max}$、同一滴答顺序。不要用 `time.time()`。不要为了“更真实”给力加噪声；噪声扫描应作为单独实验，每次扫描内部仍确定。

### 5.13 六种把切断抄错的配方

1. **用碰撞几何冒充力。** 网格相交是 0/1，没有牛顿。SBU 里大量是力超限而不是网格刺穿。
2. **用失败分数冒充力。** SAFE 的 $s_t$ 可以早报警，也可以在超限时仍低。主路必须读传感器。
3. **用 `REPLAN` 冒充 HOLD。** 新块可能继续朝杯子走。接触未解除时新计划不是特权。
4. **用奖励减碰撞冒充门限。** 梯度改变的是下次更新，不挡住当前剩余步。
5. **用 ISO 表格冒充教具阈值。** 200 N 是 SafeVLA-Bench 的仿真代理。教具 90 N、CPU 50 N 是为了让序列在中间切断。
6. **用成功谓词关闭切断。** “反正最后会成功”正是 SBU。倒水若只看壶是否倾到，撞翻杯子仍能记成功。

### 5.14 倒水的力预算写在门限上

给 VLA 的指令通常是“把水倒进杯子到七分满”。这句话不包含牛顿。策略若只在语言空间里“小心一点”，生成的仍是长度为 $H$ 的连续动作。小心必须被翻译成：哪一步的 $\|F_i\|$ 允许继续倾、哪一步必须 HOLD。力预算（force budget：任务允许的接触力上限，以及超过后的处理）是这份翻译。本课的 $F_{\max}$ 就是预算的单一上限。更细的预算可以按阶段分档：接近杯沿时上限低，稳定倾倒时上限略高，离开时再降低。分档是改造，不是默认。默认只有一档，避免还没测力就先做一套阶段机。

倾倒阶段本身会产生力，所以“力大于零”不能当切断条件。接触起点 20 N 在夹具里只用来产生杯子位移，不触发 HOLD。HOLD 看的是 50 N 或你设的 $F_{\max}$。两道阈值不要合成一个。20 N 是“开始推杯子”的运动学开关，50 N 是“后半段禁止执行”的安全开关。有人把接触起点直接当 $F_{\max}$，倒水会在刚碰杯沿时切断，任务必失败，操作者随后会把门限关掉。这是假阳性逼出的假阴性。

液体增加了不可回放的种类。杯子移位是刚体位移，夹具用毫米记录。洒出的水是质量转移，夹具没有单独字段，教具用杯位移超过 80 mm 改变杯子颜色作为洒出的示意。真机应另记海绵或天平，不要用视觉“地面湿了”当唯一证据：光照会骗人。本课不实现液体仿真。不可回放的最小集合是杯子刚体位姿；液体只作为叙事，提醒你：undo 在这里连刚体都做不到，更不必说水。

语音对照里那句“把热水倒进杯子里到七分满”被切成 12 个字。`PAUSE` 在切断步之后把后半句划掉。重说可以从空缓冲开始，听众听到的是一句新的完整指令。机械臂没有对应操作。把后半句动作“重说一遍”就是把剩余 chunk 再执行一遍，而这正是本课禁止的。教具把这两个面板并排，是为了让同一只手同时看到：字可以划掉，杯子不能划掉。

## 6. 在公开实现中定位这些机制

本课没有 MiniMind-O 源码可改。对照公开论文的公式、表和限制段落，把切断、约束、评测、检测钉到具体位置。数字以论文表或可定位的句子为准。

### 6.1 第 07 课：PAUSE 真正丢掉什么

读[第 07 课](07_full_duplex_routing.md) Step 9 的状态表和 5.4 节。`PAUSE` 保存 branch，冻结 pending PCM，不删除这些 frame。`REPLAN` 才取消 pending PCM。本课 SAFE_HOLD 更接近“永久冻结当前输出，且不允许把冻结的后半段在恢复时继续”。恢复权在人类，不在 `CONTINUE`。把第 07 课的 `CONTINUE` 接到 SAFE_HOLD 上，等于允许超限块的剩余步在人松手之前偷偷恢复。

核对：第 07 课验收要求 `PAUSE/RESUME` 复用同 branch。本课验收要求切断后没有 Resume-into-same-chunk。日志字段可以共用 `branch_id`，但力切断必须另写 `mode=SAFE_HOLD`。不要接入 listener、AEC、channel fusion。若你同时开着双工会话，音频 `available_at` 与力采样时刻必须分字段。用音频块去跟 $F_{\max}$ 比大小，没有量纲。

第 07 课的 context corruption 是新旧语义混在一句里。接触侧的对应物是：HOLD 之后仍把超限块的后半段拼到撤离动作前面，末端轨迹新旧混走。CPU 实验用 `executed_after_cutoff == []` 卡住这件事。若你在真机日志里看到 `step_index` 在 `force_trip` 之后仍递增，就是接触版的 context corruption。不要用“轨迹看起来还算平滑”当反驳：平滑的错误方向仍然是错误方向。

### 6.2 第 30 课：剩余步队列

读[第 30 课](30_closed_loop_control.md)的 `drop_remaining`。`REPLAN` 把 `remaining` 里每个 `step_index` 写入 `discarded`，`reason="replan"`。本课复制该函数，改 `reason="force_trip"`，并且在写入之后把 `mode` 设为 `SAFE_HOLD` 而不是立刻 `start_inference`。第 30 课的 REPLAN 会马上开新推理；本课禁止。

核对：第 30 课 CPU 默认 $f=10$、$H=8$、$k=4$。本课 CPU 也用 $H=8$，但没有 $f$ 和 $k$：力序列逐步提供，不模拟墙钟。不要把 350 ms 的 REPLAN 事件抄进 `lesson_40.py`，否则会有人以为超限要等控制事件队列。力在执行步内同步可读。

### 6.3 SafeVLA：约束写在训练，不写在逐步门限

读 arXiv:2503.03480 第 3 节 CMDP 定义、第 4.3 节拉格朗日、第 5.2 节主结果。初始 IL 模型是 SPOC-DINOv2。训练步数：Safety-ObjNav / PickUp 1500 万步，Safety-Fetch 2500 万步。评估指标是成功率 SR 与累计成本 CC。ISA 相对 FLaRe 的 83.58% 与 +3.85% 写在摘要，引用时不要改成“成功率提高 83.58%”。成本降、成功略升，方向相反。

核对 Safety-CHORES 的任务三类：Safety-ObjNav、Safety-PickUp、Safety-Fetch。它是移动操作，不是 LIBERO 桌面。不要把 0.865 的 SR 写进 LIBERO 表格。附录若讨论其他 SafeRL 算法，本课主路径只锁拉格朗日这一支。作者说轨迹级成本记在违片段最后一步，是探索性选择；本课运行时切断不依赖这段信用分配。

### 6.4 SafeVLA-Bench：把成功和安全拆开

读 arXiv:2606.00773 第 3.3 节 SBU/VSI 定义、Table 4 与 Table 5、附录阈值敏感性。SBU $=\Pr[\text{success}\wedge\neg\Phi_{\mathrm{safe}}]$。VSI 对每条适用条款把负稳健性按阈值和严重锚点裁剪到 $[0,1]$，再取最坏条款。自碰作为二元哨兵，一旦违反就把该回合打满。

核对：LIBERO SFT 每格 $n=200$，π-RL-130 每套件 $n=2000$；RoboCasa-365 每模型 $n=900$（18 个任务族 × 50）。作者用 Wilson 区间报比例、bootstrap 报 VSI。本课 CPU 不重算这些区间。教具只演示“成功倒水 / 不安全推杯”可以同时为真。

200 N 与 500 N 的句子在第 3.1 节和 VSI 锚点段。引用时带上“仿真代理”四个字。MuJoCo 欠采样冲击、RoboCasa 的力是按角色投影的逐步峰值聚合，作者写在第 5 节限制。本课整数力序列故意不声称冲击保真。

条款不是全局开关。酒架插入（LIBERO-Goal 任务 9）按构造需要 60–90° 持物倾斜，默认持物倾斜条款会把每次成功标成不安全。抽屉开合的目标就是让抽屉动，旁物位移不能把抽屉当旁物。作者用标签-规则注册表而不是一份黑名单：任务带上信号标签、机制模板、物体属性，条款声明自己的前置与失效条件。RoboCasa 上从无任务适用的体坐标系漂移条款改到带注册表的世界系条款后，成功违规率从 84% 降到 27%。本课倒水夹具没有注册表，因为任务单一：倾倒。若你把同一套力门限接到“按开关”上，开关本身需要接触，必须另给一档 $F_{\max}$ 或关掉该任务的力条款。不要把倒水的 50 N 默认抄到所有操作。

### 6.5 SAFE：旁路检测

读 arXiv:2506.09937 第 4 节特征探测与共形带、Table 1、第 6.4 节开销。特征取自最后一层、在解码成 token logits 或速度场之前。MLP 把逐步分数累加，LSTM 输出 $[0,1]$。校正带在成功轨迹的 seen 分割上标定。未见任务是跨任务泛化，不是跨机体保证。作者在限制里写明未测跨机体、仿真到真机的检测器迁移、无动作视频。

核对：失败检测需要先部署策略并采集成功/失败 rollout 再训检测器。力门限不需要失败标签，需要传感器。现场若两样都没有，既不能检测失败也不能切断力，只能停机。不要在报告里写“我们用了 SAFE 所以不必装力传感器”。

SAFE 的训练损失也说明它和力门限正交。MLP 支路把失败轨迹的分数往时间上限推、成功轨迹往 0 推，用的是轨迹级标签 $y_i$，不需要知道哪一拍开始失败。力门限恰恰需要知道哪一拍。LSTM 支路用逐步二元交叉熵，标签仍是整段成功或失败，逐步监督是把同一个 $y_i$ 广播到每一步。广播标签会在失败轨迹的早期步骤也抬分数，这就是它能“早报警”的来源，也可能在接触尚未发生时就喊停。早停对安全通常可接受，对倒水可能变成假阳性。接到本课状态机时，SAFE 越线默认进 HOLD 或叫人，不要默认进 `REPLAN` 把剩下的水倒完。

特征取自最后一层、解码之前。OpenVLA 是 token logits 之前，π0 是速度场之前。换模型必须重训探测头，不能把 OpenVLA 的 MLP 接到 π0 的动作专家上。力门限没有这个包袱：牛顿不依赖词表。这是硬门限相对学习检测器的工程优势，也是它无法预测“即将漏抓但力还很小”的原因。两套一起用时，日志写 `trip_source=force|safe_score|human`，事后才能知道是谁按的刹车。

## 7. 数据与训练 recipe

切断协议不改 next-token 或流匹配损失，但数据字段决定你能不能做过滤和事后 SBU。

每条示教至少写：

- `control_hz`、`horizon`、`chunk_id`、`step_index`；
- `force_n` 或 `force_xyz`，缺省则 `force_channel=absent`；
- `ee_pose`，用于核对 HOLD 是否真冻；
- `object_pose`，用于核对不可回绕；
- `success` 与任何已有的碰撞旗标，分开存，禁止用成功覆盖力。

ACT 的力往往隐含在 leader/follower 关节差里，由电机 PID 消化，数据集不一定有牛顿。ALOHA 原文采集 50 Hz 关节。把 follower 轨迹当动作目标时，块里没有显式力。本课不要求你给 ACT 补力通道；要求你在自己的倒水数据里不要沿用“关节即安全”。Diffusion Policy 推荐位置控制，位置块同样可以在接触中打出力尖峰。π0 的 $H=50$ 在 50 Hz 上是 1 s 开环：1 s 足够把一杯水倒完并撞翻。开环窗口越长，越需要逐步力门，而不是块结束再看成功谓词。

训练侧最小 recipe：

1. 有力通道的数据，先按峰值过滤，再行为克隆；
2. 无力通道的数据，单独分桶，不得与过滤后的数据平均成一条“已安全”曲线；
3. 后训练若走 CMDP 或奖励塑形，运行时仍保留硬门限；
4. 评测同时报 SR 与超限次数，禁止只报 SR。

本课 CPU 与教具的力序列是合成的。它不替代带 ATI 或关节力矩估计的真机日志。合成序列的唯一职责是让切断点落在块中间，好断言剩余步与冻结。换一条单调更小的力，切断可能永不发生，那不是协议失败，是阈值高于峰值；教具的验收要求你把阈值降下来触发一次。

OpenVLA 预训练来自 OXE 约 100 万条 episode，控制频率以 3–10 Hz 相对位姿为主。其中哪些含接触力，本课不编数字。写数据卡时留下 `force_channel` 一列即可。OFT 在 LIBERO 上过滤失败示范，提高的是成功谓词，可能提高 SBU。本课不在 LIBERO 上重跑 STL；只要求你在自己的倒水日志里同时存 `success` 和 `force_trip`。

合成倒水力序列不是流体力学。它只保证三件事：块中间某步超过默认门限；超限前杯子已经有非零位移；未切断时位移继续增大。满足这三件，才能同时验收 HOLD、不可回绕、继续 chunk 更糟。如果你自己换序列，先检查这三件，再改断言里的 17、49、103。不要为了让曲线更好看而把超限步放到 $i=0$：第 0 步就切断，`cup_before` 往往是 0，不可回绕的对比会退化成“从零到有”，审阅者会怀疑你没测到接触中途切断。默认把切断放在 $i=6$，就是为了留下一段已经在接触、但尚未越安全门的前缀。

## 8. 按依赖顺序执行实验

实验分两层。CPU 层证明切断规则。教具层证明阈值可调、超限后姿态保持、杯子不可回绕，并且必须先预测再揭晓。没有 GPU 的读者把 Step 0 到 Step 6、Step 8 做完即完成本课主路径。Step 7 在记录里标 `skipped-no-force-sensor`，不要留空让人以为你测过真机牛顿。

CPU 与教具故意用不同的 $H$ 和力峰值。CPU 用 8 步、峰值 74 N、默认门限 50 N，切断落在 $i=6$。教具用 12 步、峰值 210 N，滑条 20–220 N，默认 90 N 附近切断。不要因为两组参数不同就认为协议不一致：不等式是同一套。

CPU 实验当前 `checks` 名称是验收清单的机器版。对照阅读时逐条打开：

- `force_norm_matches_3_4_5` 锁 $\|F\|$ 的 3-4-5 三角形；
- `strict_greater_trips_at_52_over_50` 与 `equal_to_threshold_does_not_trip_at_that_step` 锁边界；
- `remaining_steps_after_cutoff_are_zero` 锁剩余步；
- `safe_hold_does_not_advance_ee` 锁 28 mm 平台；
- `object_cannot_rewind_past_contact` 锁 17 mm 与 49 mm，并对照未切断的 103 mm；
- `audio_pause_drops_pcm_and_can_reset` 锁语音对照；
- `human_takeover_keeps_hold_pose` 锁接管；
- `no_trip_runs_full_chunk` 锁未超限走完；
- `dangerous_demos_filtered_by_peak_force` 锁训练侧过滤；
- `event_replay_is_deterministic` 锁可复核。

任意一条翻成 False，先看切断步是不是 6，再看是否用了 `>=` 而不是 `>`。把 $F_{\max}$ 改成 52 而不改断言，切断会挪到第 7 步。

隔离实现位于 `experiments/src/learn_omni_experiments/lessons/lesson_40.py`。文件对外暴露 `force_norm`、`cutoff_chunk`、`enter_human_takeover`、`pause_audio`、`filter_dangerous_demos` 和 `run`。编排者登记后，在 experiments 目录运行：

```bash
python3 run.py run 40
```

登记完成前，把 `src` 加入模块路径再调用 `run()`，结果应与登记后一致。不要改 `lesson_id`。教具与 CPU 都声明自己不是真机。写报告时用两句话分开：切断协议在夹具上可复核；SafeVLA 的 83.58%、SafeVLA-Bench 的 13% 到 15%、ConRFT 的 96.3% 来自各自论文的任务与硬件，未经本课复现。

### Step 0：冻结符号与范数

在记录里写死 $H$、$i$、$F_{\max}$ 的单位。实现整数范数。对 $(30,40,0)$ 断言 50。

```bash
python3 -c "from math import isclose; assert round((30*30+40*40)**0.5)==50"
```

### Step 1：逐步执行并记录力

实现 `cutoff_chunk`。每步先推进末端，再累加杯子位移，再比较门限。断言执行步的 `force_n` 来自序列本身，而不是来自末端坐标。

### Step 2：超限切断夹具

$F_{\max}=50$，序列第 6 项为 52。断言 `cutoff_step==6`、`discarded==[7]`、`remaining==0`、`mode==SAFE_HOLD`。手算：执行 $0..6$ 共 7 步，末端 $7\times 4=28$ mm。第 7 步不得进入 `executed`。

| 步 | 力 (N) | 末端 (mm) | 杯累加 (mm) | 剩余 | 模式 |
|---|---|---|---|---|---|
| 0–3 | 4,6,9,14 | 4–16 | 0 | 7–4 | GENERATING |
| 4 | 22 | 20 | 2 | 3 | GENERATING |
| 5 | 35 | 24 | 17 | 2 | GENERATING |
| 6 | 52 | 28 | 49 | 0 | SAFE_HOLD |
| 7 | 74（不执行） | 28 | 49 | 0 | SAFE_HOLD |

杯子在第 6 步之前是 17 mm。回放不得写回 17。

逐步累加可以手算，用来核对实现有没有把位移放在比较之前或之后。接触起点 20 N，位移为 $\max(0, F_i-20)$：

$$
i=4,\ F=22 \to +2,\ \mathrm{cup}=2;\quad
i=5,\ F=35 \to +15,\ \mathrm{cup}=17;\quad
i=6,\ F=52 \to +32,\ \mathrm{cup}=49
$$

第 6 步比较时 52 已经大于 50，所以 +32 属于“已经发生、不能收回”的那一笔。有人想把切断改到比较之前：先看力再决定是否执行 $a_6$。夹具里 $F_6$ 是执行 $a_6$ 的结果，先看后做需要一个接触模型。本课不假设你有可靠的接触模型，所以协议是做完再切。真机若有高质量的力预测器，可以提前一拍阻断，那是改造清单第 4 条的 CBF 滤波，不是默认路径。默认路径必须在没有预测器时仍然安全。

未切断的对照把第 7 步 74 N 也做掉：$+54$，杯 $=103$。103 与 49 的差，就是“继续 chunk”这句话的毫米代价。教具把同一逻辑拉长到 12 步，峰值 210 N，滑条默认为 90 N 时切断落在 102 N 的那一步。CPU 与教具对表时，把教具阈值也设成 50 N，切断步同为 6，末端步长不同（CPU 每步 4 mm，教具每步 5 mm），不要混用 28 mm 和教具读数。

### Step 3：等号边界与未超限

$F_{\max}=52$ 时，第 6 步不切断，第 7 步 74 切断。$F_{\max}=74$ 时全程不切断，`mode=DONE`，末端 32 mm。两条夹具证明边界和“做完也是 remaining=0”不会被误判成 HOLD。

### Step 4：HOLD 滴答与人类接管

切断后追加 4 个滴答，末端序列四个 28。再进入 `HUMAN`，3 个滴答仍是 28，杯子仍是 49。若接管时末端变成 0，说明有人把 HOLD 理解成回原点。

### Step 5：语音对照

在同一 `pause_step=6` 上跑 `pause_audio`。断言剩余 PCM 为 0、文本可重置、`world_unchanged=True`。不要在这个函数里移动杯子。杯子移动只属于 `cutoff_chunk`。

### Step 6：倒水教具

打开本课 Lab。先选择预测，再调 $F_{\max}$。验收要看到：超限后末端停在当前姿态；剩余步为 0；杯子位移大于超限前。推荐从 90 N 触发切断，再把滑条拉到 220 N 看整块跑完、杯子更远。不要把教具毫米写成 ISO 力。重置会清掉发现标志和预测。调滑条会隐藏上次揭晓，但已找到的切断与不可回放标志保留，方便对照语音面板。

教具内部力序列前 8 项与 CPU 相同，后 4 项继续升高到 210 N。因此把教具阈值设为 50 N，切断步也是 6，可以和 CPU 对表。峰值不同，所以 90 N 会在第 8 步（102 N）切断。报告里写清用的是哪一套序列。

预测选项必须在运行前选。四个选项里只有“进入 SAFE_HOLD，末端停在当前姿态，剩余步为 0，杯子停在超限时的位置且不能回退”能通过。其余三个分别对应本课要拆掉的错误假设：继续并回绕、语音式 undo、自动回原点。选错之后教具仍会揭晓数字，但验收不通过。把阈值降到峰值以下才能点亮“已看到超限后停在当前姿态”和“杯子停在超限后位置，不能回退”两枚标志。只选对预测、把滑条留在 220 N，整块跑完，标志不亮。只触发切断却把杯子理解成可回绕，第二枚标志不亮。两枚都亮且预测正确，才算教具通过。

右侧语音面板把同一切断步映射成停嘴。已说出的字保留，后面的字划掉，剩余 PCM 帧数为 0。句子允许从空缓冲重说。这一侧的世界没有杯子坐标，所以 `world_unchanged` 在 CPU 里为真。不要把划掉的字理解成杯子被擦掉。并排的目的就是让这两个真值同时可见：一边可重说，一边不可回放。

### Step 7：可选，读一次真机力

若有带力/力矩传感的手臂，倒水或按压示教 10 条，按 100 Hz 记 $\|F\|$。标出第一次超过你的工作门限的时刻，检查随后是否仍在下发 chunk 剩余步。测不到就写未测。不要把仿真 200 N 填进这张表冒充实测。

### Step 8：把 $F_{\max}$ 扫成曲线

固定力序列，扫门限。记录切断步、剩余步、最终杯位移、是否 HOLD。预期：门限低于峰值时切断步随门限右移，杯位移单调不减；门限不低于峰值时无切断，杯位移等于未门限轨迹。横轴用牛顿，不要用无单位滑条百分比。

## 9. 评测与测量

本课主指标不是成功率。主指标是协议是否被遵守。

| 指标 | 定义 | 通过 |
|---|---|---|
| 剩余步 | 切断后 `remaining` | 等于 0 |
| 末端冻结 | HOLD 滴答的 `ee_mm` | 全等于 `ee_at_cutoff` |
| 不可回绕 | `cup_mm` 与 `cup_before_mm` | 不相等，且回放不写回 |
| 边界 | $\|F\|=F_{\max}$ | 不切断 |
| 语音对照 | 剩余 PCM | 0，且 `world_unchanged` |
| 过滤 | 超峰值示教 | 不进入 kept |
| 确定性 | 两次 trace | 字节级一致 |

次指标才是任务层：倒水是否倒进杯、是否洒出。次指标用于解释 SBU，不用于代替主指标。SafeVLA-Bench 的 SR/Safety/SBU/VSI 是论文评测，不是本课 CPU 输出。引用时写套件名、模型名、$n$。

Wilson 区间留给第 31 课。本课若数真机超限次数，N 太小就报原始计数，不要点估计到小数点后两位还当结论。

把教具当评测时，只允许报协议遵守率：在触发切断的那些次运行里，有百分之多少满足剩余步为 0 且末端冻结。默认实现应当是 100%。若不是，先修调度，不要修力序列去“提高成功率”。协议遵守率和倒水成功率必须分两行。前者是本课主指标；后者受壶口几何、水量、摩擦系数影响，夹具没有这些量，报了也无法复核。

对照论文数字时写清分母。SafeVLA 的 83.58% 是相对 FLaRe 的累计成本降幅，分母是 FLaRe 的 CC。SafeVLA-Bench 的 13% 到 15% 是 LIBERO 高 SR 策略的不安全回合比例，分母是全部回合，不是成功回合；RoboCasa 的 36% 到 56% 才是成功条件下的 $P[U\mid S]$。两类分母混写，桌面和厨房会看起来一样糟或一样好。本课夹具的 17 mm 与 49 mm 没有分母，它们是一次确定轨迹上的两个读数。不要把 49/17 写成“不安全倍数 2.9”再拿去和 VSI 比。VSI 有自己的严重锚点和 $K_\phi\in[2,5]$，夹具没有锚点。

## 10. 验收条件

同时满足以下各项，本课才算完成：

1. 课文与代码使用同一套规则 $\|F_i\| > F_{\max}$，等号不切断；
2. CPU 实验全部 `checks` 为 True，覆盖范数、剩余步、HOLD、不可回绕、语音对照、接管、过滤、确定性；
3. 教具在先提交预测的前提下，触发一次 SAFE_HOLD，并看到杯子不能回到超限前；
4. 文档用表格对照第 07 课状态机，并写明不实现音频路由；
5. 引用 SafeVLA、SafeVLA-Bench、SAFE 的数字能指到摘要、表号或句；未公开的真机力时间线写“其技术报告未公开该细节”；
6. 不把仿真代理 200 N、教具 90 N 或 CPU 50 N 标成 ISO 认证；
7. 不把教具或 CPU 结果标成 SOTA 或真机倒水能力。

缺任何一条，只算“写了力阈值”，不算完成切断协议。

```text
cutoff_step
remaining
ee_mm

cup_after_mm

```

`prediction` 必须是 `hold-irreversible`。`remaining` 必须为 0。`cup_after_mm` 必须不等于 `cup_before_mm`。未触发切断的记录不能当验收。

## 11. 根据症状定位失败环节

| 症状 | 先查 | 典型原因 | 处理 |
|---|---|---|---|
| 超限后仍继续倒 | `remaining` | 把整块当事务，或用了 `>=` 导致边界错位 | 超限步清空队列，`reason=force_trip` |
| HOLD 时末端仍走 | 额外滴答的 `ee_mm` | HOLD 只改了旗标，执行器仍读旧 chunk | 执行器在 HOLD 必须忽略 `current` |
| 杯子回到超限前 | 回放是否写物体 | 把 PAUSE 的缓冲回收抄到物体坐标 | 物体只增不减，另写撤离策略 |
| 等号就切断 / 等号不该走 | 比较符 | 与第 30 课 `>=` 混用 | 力用 `>`，过期用 `>=` |
| 未超限被标 HOLD | `mode` | 块结束的 `remaining=0` 被当成切断 | `DONE` 与 `SAFE_HOLD` 分状态 |
| 切断后自动抓回杯子 | 是否立刻推理 | 抄了第 30 课 REPLAN 即 `start_inference` | 接触未解除禁止自动 REPLAN |
| 语音对照里杯子也动 | `pause_audio` | 两个函数共用物体状态 | 音频对照不得写 `cup_mm` |
| 两次 replay 不一致 | 事件排序 | 把墙钟或随机力混进主夹具 | 力序列写死，噪声单独扫 |
| 真机已挤杯、日志无力 | 传感器 | 只有视觉失败分数 | 主路接牛顿，旁路才能接 SAFE |
| 过滤后 SBU 仍高 | 过滤用的是成功还是力 | 只丢失败示范 | 峰值力单独过滤 |
| 报告写了 83.58% 成功率 | 引文 | 把成本降幅抄成成功升幅 | 回读 SafeVLA 摘要两句 |
| 200 N 写进合规文件 | 来源 | 把仿真代理当 ISO 表 | 标“代理”，去读 15066 与实测 |

诊断顺序固定：先看力时间线和 `mode`，再看剩余步，再看物体坐标是否被回绕，最后才怀疑策略网络。没有力时间线，不许调模型。把[第 01 课](01_baseline_reproduction.md)的 trace 纪律原样搬过来：切断日志不得改变已经执行的关节数值，只追加 `force_trip` 与 HOLD 字段。

## 13. 前沿对照与改造方向

**公开方案。** 2025–2026 年把 VLA 安全拆成三条并行的线。训练线：SafeVLA 用 CMDP 和诱发环境，在 Safety-CHORES 上相对 FLaRe 把累计成本降 83.58%，并报告极端失败时成本 2.20 对 71.68。评测线：SafeVLA-Bench 证明 LIBERO 高 SR 仍有 13% 到 15% 不安全回合，RoboCasa 成功轨迹的 36% 到 56% 带违规，接触力主档用 200 N 仿真代理。检测线：SAFE 用最后一层特征做多任务失败探测，未见任务仿真 ROC-AUC 约 78，开销小于 1 ms。运行时安全滤波的前史是控制障碍函数（control barrier function）二次规划，Ames、Xu、Grizzle、Tabuada 在 IEEE TAC 2017 给出把安全约束写成实时 QP 的标准形式；SafeVLA-Bench 把它列为相关工作，本课不实现 QP。这些方案都没有取消逐步力门限。它们分别减少走到超限的概率、把超限记账、在任务失败时早停。硬切断仍然要读牛顿。

**差距。** 本课缩小版没有视觉编码器、没有 AI2-THOR、没有 7B 权重，只有整数力序列和姿态冻结。规模差距：1500 万到 2500 万步的 SafeRL、LIBERO 每格 200 个回合、真机力传感标定，钱和设备可以补。机制差距：剩余步清零、HOLD 不推进、物体不回绕、音频对照不共用物体状态，不买卡也必须做。缺这套协议，把 π0 的 $H=50$ 接到倒水上，1 s 的开环足够在第一次接触后把后半段倒完。缺这套协议，把 SafeVLA 的约束训练权重部署到无力传感器的手臂上，CMDP 学到的“小心”没有可执行的最后防线。

另一处机制差距是接触力学保真。SafeVLA-Bench 承认 MuJoCo 欠采样冲击，RoboCasa 的力是聚合峰值。缩小版用逐步整数牛顿，故意不模拟冲击脉冲。真机冲击可能在一个控制周期内超过门限又落回。协议仍应按该周期的峰值比 $F_{\max}$，而不是按周期均值；均值会把脉冲洗掉。夹具没有脉冲，所以这条必须写在真机笔记里，不能从 CPU 的 52 N 外推。

Helix、Gemini Robotics 的产品演示若没有给出力时间线、$F_{\max}$ 和切断次数，本课不许把流畅视频换算成接触安全成立。第 48 课才会讨论双时钟共用状态表。本课只保证：力切断这一列不能被音频 `PAUSE` 合并。产品演示里手臂停住，可能是 HOLD，也可能是任务做完，也可能是视频剪辑。没有力通道和 `mode` 字段，三种情况不可分。缩小版的价值是把“停住”拆成可复核的剩余步与末端坐标，而不是把演示里的停住当成已经实现本课。

**动手改造清单。**

1. **周期内峰值。** 改 `cutoff_chunk`：每步接受长度为 $m$ 的力子采样，用 `max` 而不是末点与 $F_{\max}$ 比。预算：CPU，单文件，小于 0.5 人日。预期：末点 40、中间 80 的步必须切断。失败判定：仍用末点 40 放过，或两次 replay 不一致。
2. **力与过期双门。** 把第 30 课的 `stale` 和第 40 课的 `force_trip` 串在同一 replay。预算：CPU，1 人日。预期：又过期又超限的块两条 `reason` 都在；HOLD 优先于新推理。失败判定：过期丢弃之后仍执行了超限步的后续，或超限后仍 `start_inference`。
3. **SBU 记账。** 给倒水夹具加成功谓词“壶倾角超过 60°”。预算：浏览器或 CPU，不训网络。预期：高 $F_{\max}$ 时成功且杯位移大，记 SBU；低 $F_{\max}$ 时可能任务失败但杯位移小。失败判定：只报成功，不报杯位移。
4. **CBF 滤波对照。** 在二维点质量上实现一道最简单的线性约束：下一步位置不得让力模型超过 $F_{\max}$，用投影代替 QP。预算：CPU，1–2 人日，不接真机。预期：滤波后较少触发 HARD HOLD，但 HARD HOLD 仍作为滤波数值失败时的后备。失败判定：滤波替代了 HOLD，超限步仍执行后半段 chunk。

**顺手复现。** SafeVLA-Bench“提高力阈值则 Safety 上升、SBU 仍非零”的方向，应能在倒水滑条上用杯位移再现：阈值从 50 拉到 220，最终杯位移从切断后的平台变成未门限轨迹，任务倾角谓词可能仍真。绝对数不必等于 86.5% 或 48.8%。SAFE“失败分数与接触力不是同一通道”在夹具上只能做定性：你可以在切断步把失败分数设成很低，协议仍必须 HOLD。SafeVLA“极端失败时仍应低成本”对应本课：任务已经不可能成功（杯子已倒），HOLD 后成本不再随剩余步增加。未切断则会从 49 mm 走到 103 mm。方向同向即可，不必复现 71.68 这个仿真数字。

CPU 夹具上一条可复现的方向对照如下。$F_{\max}=50$ 时切断步 6、杯 49 mm、末端冻结 28 mm；$F_{\max}=74$ 时无切断、杯 103 mm、末端 32 mm。把 49 与 103 的差当成“继续剩余步的额外伤害”，把 28 与 32 的差当成“HOLD 少走的末端行程”。SafeVLA 的 CC 是多类成本在整段轨迹上的和，量纲不是毫米；本课只借“停住之后不再累加”这一方向。若你的实现里 $F_{\max}=50$ 的杯位移反而大于 $F_{\max}=74$，说明切断没有发生，或物体在 HOLD 里被错误地继续积分。先修协议，再谈和论文同向。

## 14. 论文与必读材料

1. [SafeVLA: Towards Safety Alignment of Vision-Language-Action Model via Constrained Learning](https://arxiv.org/abs/2503.03480)（arXiv:2503.03480，v4）。带着问题读：CMDP 里 $b_i$ 取 FLaRe 收敛成本 20% 是在约束什么，不是在约束牛顿？轨迹级成本记在违片段最后一步，对倒水这种逐步接触是否太晚？去掉诱发组件后成本升到 5.01，说明环境设计与约束算法哪一个先成为瓶颈？极端失败 SR 接近 0 时，2.20 对 71.68 能否支持“失败也要失败得安全”？真机段落列出的四条 sim-to-real 策略，哪一条替代了力传感器，哪一条没有？摘要的 83.58% 是成本降幅，读任何二次转述时核对是不是被抄成成功率。

2. [SafeVLA-Bench: A Benchmark for the Success-Safety Gap in Vision-Language-Action Models](https://arxiv.org/abs/2606.00773)（arXiv:2606.00773）。带着问题读：SBU 和 VSI 为什么不能互相替代？OpenVLA-7B 低 SBU、高 VSI 讲述了哪类失败？200 N 主档和 500 N 严重锚点如何同时依赖 ISO/TS 15066 又否认自己是认证？任务注册表关掉酒架倾斜和抽屉旁移，若倒水夹具不加注册表，会不会把“倒”本身判成违规？附录里力阈值放到 500 N 之后 RoboCasa Safety 跳到 78.2%，说明记账对代理阈值有多敏感，还是说明模型变安全了？

3. [SAFE: Multitask Failure Detection for Vision-Language-Action Models](https://arxiv.org/abs/2506.09937)（arXiv:2506.09937，v2）。带着问题读：最后一层特征分离的是任务成功/失败，还是接触力大小？共形带保证的是成功轨迹的假阳性，如何接到 SAFE_HOLD？0.73 ms 相对 149 ms 可以进控制周期，但它仍需要失败标签才能训。现场只有力传感器、没有失败检测器时，本课协议是否已经充分？STAC 多采样的 152%–221% 延迟，为什么不能当硬切断的实现？

4. [FLaRe: Achieving Masterful and Adaptive Robot Policies with Large-Scale Reinforcement Learning Fine-Tuning](https://arxiv.org/abs/2409.16578)（arXiv:2409.16578）。带着问题读：它优化的是任务回报，安全成本在哪里（若原文没有逐步力，就写“未给出”）？SafeVLA 把它当最强任务向 RL 对照，本课能否只引用 SafeVLA 表内的 FLaRe 数字，而不把 FLaRe 正文的任务成功率当成接触安全？

5. [第 07 课 全双工路由](07_full_duplex_routing.md) 与 [第 30 课 频率、分块和延迟](30_closed_loop_control.md)。带着问题读：pending PCM 与剩余关节目标的类比在哪一步失效？`PAUSE` 保持姿态时，若已经顶着杯子，第 30 课的传送带夹具为什么暴露不了，本课为什么必须另写杯子位移？两课的 `available_at` 能不能和力采样时刻共用一个字段？

读这五份时带一张空白的层表：训练约束、运行时门限、评测条款、失败检测、音频对照。缺的格子写“未给出”。读完仍空着的格子，不要用另一篇的数字填上。SafeVLA 的 1.854 是 Safety-CHORES 上 ISA 的累计成本，不能写进 LIBERO 的 Safety 列。SafeVLA-Bench 的 200 N 不能写进 CPU 夹具当 $F_{\max}$。SAFE 的 ROC-AUC 不能写成切断延迟毫秒。第 07 课的停止延迟阈值不能当成 $F_{\max}$。

把层表贴在实验记录首页。每次引用一个数字，先看它属于哪一层，再决定能不能进本课主指标。主指标只有协议遵守：剩余步、末端冻结、物体不回绕。其它层的数字是对照，不是替代。对照写得越清楚，越不容易在毕业课里把语音打断和手臂切断点成同一次点击。本课的毕业接口只多一列：`SAFE_HOLD`。列在表里，不等于已经和音频调度共用一张运行时。共用是第 48 课的题目；本课若提前把两列事件合成一次点击，第 48 课的验收会失去对照。先把力这一列做对，再谈能不能合。若你现在就想画双列状态表，只许把 `SAFE_HOLD` 画成与 `PAUSE` 并列的空槽，槽里写“剩余步为零、末端冻结、物体不回绕”，不要把 PCM 回收箭头画进杯子坐标。空槽可以提醒下一课，不能代替本课已经完成的切断器。切断器的验收仍然只看：超限后剩余步为零、SAFE_HOLD 不推进末端、杯子不能回到超限前。这三句话能在 CPU 实验、倒水教具和课文公式里同时指出来，也请抄进实验记录首页。本课至此结束。

第 07 课的音频路由到此为止只借用状态机，本课没有实现它。下一课处理另一件统一性问题：图像离散 token 和文本怎样共用一套 next-token。身体侧的不可回放，到语言侧会变成另一套不可偷看的未来像素。两件事都叫“不能当没发生”，对象不同。
