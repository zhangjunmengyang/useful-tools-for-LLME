# 第 22 课：复现视觉语言模型的标准训练配方

> 内容：冻结顺序、投影对齐与灾难遗忘<br>
> 建议周期：3–5 天阅读与 CPU 实验；若复现公开规模另计卡时<br>
> 硬件：无 GPU 可完成阅读、浏览器开关实验和 CPU 机制实验；复现 LLaVA-1.5 公开配方约 8×A100 一天<br>
> 产物：三阶段冻结清单、可训练参数表、旧文本回归探针、`recipe-v1` 实验记录

## 1. 视觉语言模型的标准训练顺序

第 21 课把图和字拉进同一空间：对比学习训练出的视觉编码器，已经能给一张图一个靠近对应文字的向量。MiniMind-O 里的 SigLIP2 正是这样一块冻结的眼睛。[第 02 课](02_multimodal_connector.md)在 MiniMind-O 里比较 MLP、Perceiver Resampler 和 Q-Former 三种连接器，问的是“特征怎么压缩、token 数怎么控”。本课换一个问题：业界把现成的视觉塔接到现成的语言模型上时，**先冻谁、先训哪一段、数据按什么顺序喂**。少一步，模型不是不能出字，而是你会分不清它到底学会了看图，还是把原来会的语言忘掉了。

视觉语言模型（VLM，Vision-Language Model：同时吃图像和文字、用同一套 next-token 目标吐文字的模型）通常有三块：

- 视觉编码器（vision encoder，常见实现是 ViT：Vision Transformer，把图切成 patch 再编码）；
- 投影或连接器（projection / connector：把视觉特征变成语言模型能读的向量）；
- 语言模型（LLM）。

标准教学顺序来自 LLaVA 的两阶段，本课再把它拆成三档可训练集合，方便数参数、对梯度：

1. 冻 ViT、冻 LLM，只训投影 $W$；
2. 仍冻 ViT，训 $W$ 和 LLM 上的 LoRA（低秩适配：原权重不动，只训一对小矩阵）；
3. 需要更细的视觉时，再考虑解冻 ViT。

LLaVA 原文第二阶段更新的是整颗 LLM，不是 LoRA。本课把第二档写成 LoRA，是为了让“可训练参数计数”能手算，并和后来公开模型的省显存做法对齐。第三档在 LLaVA 里默认不做：它始终冻视觉编码器。Qwen2-VL 一类系统会在中段解开视觉塔，因为它们要为动态分辨率重训 ViT，那是另一条配方，后文分开记。

[第 08 课](08_dynamic_vision.md)处理的是分辨率、切片和 M-RoPE，不决定本课的冻结顺序。第 08 课的实验契约是：encoder 侧 patch 数可以随切片变，进入 Thinker 的视觉 token 仍固定 64，位置编码另比。那份契约假定眼睛本身冻结。若有人在第 08 课的 dynamic 臂上顺手解冻 SigLIP2，分辨率变量和冻结变量会缠在一起，两课的结论一起作废。本课不重做三种 connector 的结构实现；需要结构对照时回到第 02 课。本课要交付的是一张冻结时间表、一套按模块计的参数账，以及“对齐升了、旧文本掉了”能被开关触发的实验。

和第 02 课的接口合同再写清楚。第 02 课允许的变量是 connector 类型和 query 数，不允许的变量是 Thinker 是否解冻（阶段 A）以及解冻顺序故事。本课允许的变量是冻结集合和阶段顺序，不允许的变量是再引入第三种 connector。两课都做反事实图像检查，但第 02 课用它判断模态有没有被用，本课用它判断投影有没有对上。同一种检查，归因对象不同，必须分开放进两份报告。

做完这课你手里会有：一份写清“此刻谁可训练”的 recipe 卡；一张 $W$ / LoRA / ViT 的参数表，能和 CPU 实验对上；一组旧文本探针，防止只看图文分数就宣布成功。下一课会检查模型有没有看对位置：配方对了，不等于指代、OCR 和左右关系也对。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 投影 $W$ | 把视觉特征线性映到 LLM 词嵌入维的矩阵；LLaVA 第一阶段只训它 |
| 视觉 token | 投影之后、插进文本序列里的那串向量，位置上当作普通 token 读 |
| 冻结 / 解冻 | `requires_grad=False` 或 True：冻结模块前向仍计算，反传梯度被 mask |
| 两阶段训练 | LLaVA：先对齐投影，再在视觉指令数据上更新 LLM |
| LoRA | 冻住 $W_0$，只训 $B,A$，前向为 $W_0+\frac{\alpha}{r}BA$ |
| 灾难性遗忘 | 学新任务后，旧能力明显下降；本课探针是纯文本任务 |
| 视觉指令微调 | 把“看图回答/描述/推理”写成对话，用来教 LLM 跟视觉指令 |
| 格式提示 | 在问题末尾写明“用一个词回答”或“选字母”，避免短答数据和闲聊互相污染 |
| gated xattn | Flamingo 插进冻结 LM 的门控交叉注意力，初始化时门为 0，不打乱原 LM |
| Q-Former | BLIP-2 里那组可学习 query，从冻结 ViT 抽取固定条数的视觉表示 |

## 2. 本课解决的问题

把 CLIP 或 SigLIP 的视觉塔接到 Vicuna 或 Qwen 上，程序可以立刻跑起来：图像进 ViT，特征乘一个随机初始化的 $W$，再和文本 embedding 拼在一起做语言模型损失。loss 会降，因为 LLM 很会拟合文本。降 loss 证明不了三件事：

- 视觉特征是否已经落在词嵌入能读的位置；
- 指令跟随是不是靠语言先验蒙的；
- 原来的纯文本能力还在不在。

本课的研究问题可以写成一句：从已经对比对齐过的冻结视觉编码器出发，若打乱“只训投影，再动 LLM，最后才考虑 ViT”的顺序，图文对齐、指令跟随和旧文本能力会怎样一起变。

和[第 02 课](02_multimodal_connector.md)的边界如下。第 02 课固定 MiniMind-O 的 encoder 与 Thinker，比较三种 connector 的 token 数、延迟和反事实分数。本课不比较这三种实现，只把投影当作“把 $Z_v$ 送到 $d_{\ell}$ 维”的最小接口，讨论公开 VLM 的数据配比与解冻顺序。Q-Former 和 gated xattn 在本课里只作为冻结策略的对照，不展开它们的注意力公式。

出现以下任一情况，不得把一次训练标成合格配方：

- 只报图文或 VQA 分数，没有纯文本回归；
- 第一阶段就解冻 ViT 和 LLM，却把增益全部记在“视觉更强”上；
- 投影还是随机的，就开始全量更新 LLM；
- 把 LLaVA 的 595K 对齐数据和 158K 指令数据混成一个 stage，事后无法拆开归因；
- 用第 02 课的 connector 消融数字，解释本课的解冻顺序；
- 把浏览器玩具分数写进和 LLaVA-1.5 表 3 同一张对比表；
- 用 Qwen2.5-VL 的 4.1T token 当自己的训练量，却仍冻着随机投影。

合格配方的最小证据链是：阶段 A 的梯度 mask 记录、阶段 B 的三项指标、一份纯文本逐条表。缺证据链的漂亮曲线，本课记为未完成。

## 3. 开始前需要准备什么

本课可独立阅读。若已读第 21 课对比学习，冻结 ViT 为什么能当眼睛会更清楚；没读过也可以把“视觉塔输出已经和文字近”当作本课的上游事实，不必在这里重推导 InfoNCE。第 21 课的温度和负样本会影响这双眼睛的几何，但不会改变本课的冻结顺序：几何再好，随机 $W$ 仍然需要先被训到词嵌入邻域。

**上游事实（来自论文，本课不改）：**

- LLaVA 用 CLIP ViT-L/14 作视觉编码器，线性层把网格特征映到 Vicuna 的词嵌入维；第一阶段冻 ViT 和 LLM，只训投影，数据是从 CC3M 滤出的 595K 图文对；第二阶段仍冻 ViT，更新投影和 LLM，数据是 158K 视觉指令（对话 58K、详细描述 23K、复杂推理 77K）。预训练 1 个 epoch、学习率 $2\times 10^{-3}$、batch 128；指令 3 个 epoch、学习率 $2\times 10^{-5}$、batch 32。ScienceQA 上完整流程 90.92%，与 GPT-4 做 judge 合奏后 92.53%；7B 相对 13B 低 1.08 个百分点。这些数字全部来自原论文表 7 与表 8，抄写时保留表号。
- LLaVA-1.5 把线性层换成两层 MLP，预训练图文对改记为 558K，指令阶段 665K，并加上学术 VQA 与格式提示；13B 检查点用约 1.2M 公开数据，在单机 8×A100 上约一天训完。
- BLIP-2 的 Q-Former 约 188M 参数、32 个 768 维 query；预训练两阶段都冻视觉塔和 LLM。
- Flamingo-80B 在约 80B 总参数里，可训练的门控交叉注意力等模块为 10.2B。

**本课约定：**

- 教学三阶段的可训练集合是：只训 $W$；训 $W$+LoRA；再解冻 ViT。它用来计数和做梯度 mask，不宣称这就是 LLaVA 仓库的默认开关。
- CPU 实验的维度固定为 $d_v=8$、$d_{\ell}=12$、LoRA $r=2$，必须和课文公式一致。
- 浏览器实验是玩具指标，分数不可写入真实模型报告。

无 GPU 时的完成标准：读完全文、通过本页开关实验、跑通 `lesson_22.py` 的全部 `checks`。有 1×24GB 时，可以用很小的公开 caption 子集复现“只训投影”的梯度掩码，不必追 VQA 榜。

实验记录里要分开写事实和约定。事实例子：LLaVA 第一阶段 595K、学习率 $2\times 10^{-3}$。约定例子：本课玩具 $d_v=8$。混着写会导致别人按 595K 去核对你的 96 个参数。建议在笔记页顶上放两行：

```text
upstream: LLaVA-v1.5 paper tables 2-4, BLIP-2 tables 1-2
course: toy d_v=8 d_l=12 r=2, browser scores are simulated
```

第二行禁止出现可执行命令，只登记维度。若要把公开论文的超参抄进同一页，再加一行 `paper_lr_stage1: 2e-3` 这类字段，并注明来源表号。没有表号的学习率不要抄。LLaVA 附录对 ScienceQA 另有 12 epoch、先推理后答案等设定，那是任务微调，不要写进通用两阶段卡里冒充预训练配方。

## 5. 原理:边造边讲

六个机制。每个仍走直觉、机制、数学、代码、验证。代码落点写的是公开实现里会反复出现的写法，不是 MiniMind-O 的 connector 注册表。

### 5.1 投影把视觉特征送进词嵌入维

随机初始化的 $W$ 输出的向量，对 LLM 来说几乎是噪声。若此时就更新 7B 级语言模型，梯度会主要用来“忽略这串噪声、继续拟合文本”，视觉通路学得很慢，语言通路却被带偏。

机制上，ViT 给出网格特征 $Z_v\in\mathbb{R}^{T\times d_v}$。LLaVA 用 CLIP ViT-L/14，取最后一层 Transformer 之前的网格特征；$T$ 由分辨率和 patch 大小决定，$d_v$ 是视觉隐层维。线性投影把每个位置映到 LLM 隐层维 $d_{\ell}$：

$$
H_v = Z_v W^{\top}
$$

课文和 CPU 实验把同一件事写成列向量形式 $H=WZ$，只是把 $W$ 的形状记成 $d_{\ell}\times d_v$，与实现时 `nn.Linear(d_v, d_l)` 的权重布局一致。LLaVA 原文公式是 $H_v=W\cdot Z_v$，符号约定是“$W$ 在左边”。计数时不要和转置纠缠：元素个数永远是 $d_v\cdot d_{\ell}$。

LLaVA-1.5 把单层换成两层 MLP，仍不压缩 token 数。两层的元素个数是 $d_v d_h + d_h d_{\ell}$（再加偏置）。本课计数主表用单层 $W$，避免和第 02 课的 MLP 结构消融抢题。

验证：打印投影前后 shape，确认只改最后一维；再检查第一阶段 optimizer 的参数 id 是否全部来自投影模块。CPU 实验里 $d_v=8$、$d_{\ell}=12$，单层 $W$ 恰有 96 个元素。

### 5.2 三阶段可训练参数

不数参数，就无法解释“为什么先训小的”。只训 $W$ 时，更新量比全量 LLM 小两到三个数量级，显存和走偏风险都可控。

记 ViT 参数集合为 $\theta_v$，投影为 $\theta_W$，LLM 为 $\theta_{\ell}$，LoRA 为 $\theta_r$。三阶段的可训练集合：

$$
\begin{aligned}
\Theta_1 &= \theta_W, \quad |\Theta_1| = d_v d_{\ell} \\
\Theta_2 &= \theta_W \cup \theta_r, \quad |\theta_r| = \sum_{m} r(d_{\mathrm{in}}^{(m)}+d_{\mathrm{out}}^{(m)}) \\
\Theta_3 &= \theta_W \cup \theta_r \cup \theta_v
\end{aligned}
$$

对一块 $d_{\mathrm{out}}\times d_{\mathrm{in}}$ 的基座矩阵，LoRA 的 $A\in\mathbb{R}^{r\times d_{\mathrm{in}}}$、$B\in\mathbb{R}^{d_{\mathrm{out}}\times r}$，元素个数 $r(d_{\mathrm{in}}+d_{\mathrm{out}})$。CPU 实验只在第一层 LLM 矩阵上插一组 LoRA，$d_{\mathrm{in}}=d_{\mathrm{out}}=12$，$r=2$，故 $|\theta_r|=48$。ViT 用两层 $8\times 8$，共 128。于是：

| 阶段 | 可训练模块 | 元素个数 |
|---|---|---|
| 1 只训投影 | $W$ | 96 |
| 2 投影 + LoRA | $W$ 与 $A,B$ | 144 |
| 3 再解冻 ViT | 上一项加 ViT | 272 |

若第二阶段改成全量 LLM（LLaVA 原设置），可训练数从“投影加几千万 LoRA”跳到“整颗 7B”，本课玩具就不这么设。公开规模只需记住数量级：LLaVA 第一阶段的线性投影，在 $d_v=1024$、$d_{\ell}=4096$ 时是 $1024\times 4096=4194304$ 个元素；BLIP-2 预训练可训练参数为 188M；Flamingo-80B 可训练 10.2B。

验证：CPU 实验的 `stage1_trainable`、`stage2_trainable`、`stage3_trainable` 必须等于上表。改 $r$ 而不改公式，检查应失败。

### 5.3 梯度 mask：冻结不是删掉前向

冻结若做成“不跑这个模块”，视觉特征会变成常量，和“跑前向、挡梯度”不是同一件事。VLM 需要 ViT 继续产生 $Z_v$，只是不让它被图文损失改写。

在 PyTorch 里，冻结就是 `p.requires_grad=False`，优化器也不接收这些参数。反传时，计算图在这些叶子上不累积梯度，等价于把 $\partial\mathcal{L}/\partial\theta$ 乘了 0。本课把这层叫梯度 mask。

设损失为输出与目标的平方误差。即使数学上 $\partial\mathcal{L}/\partial\theta_v$ 和 $\partial\mathcal{L}/\partial\theta_{\ell}$ 都不为零（视觉误差会穿过 $W$ 回到 ViT，也会进入 LLM），阶段 1 的协议仍要求：

$$
\widehat{\nabla}_{\theta_v}\mathcal{L}=0,\quad
\widehat{\nabla}_{\theta_{\ell}}\mathcal{L}=0,\quad
\widehat{\nabla}_{\theta_W}\mathcal{L}\neq 0
$$

帽子表示 mask 之后的优化器用梯度。CPU 实验先算未 mask 的反传，确认 ViT 与 LLM 的原始梯度非零，再在阶段 1 把它们置零。这一条负对照不能省：否则“梯度是 0”可能只是实现写错、整网都没接上。

验证：`stage1_vit_and_llm_grads_are_masked` 为真，且 `unmasked_vit_and_llm_grads_are_nonzero` 也为真。

### 5.4 损失只在助手回答上算

图文对里有提示、有图像占位、有回答。若把用户问题也算进损失，模型会学着复读问题，或把视觉 token 当可预测的“伪文本”。

LLaVA 把多轮对话展开成一条自回归序列，只对助手 token 计算：

$$
\mathcal{L}=-\sum_{i\in M}\log p(x_i\mid x_{<i}, H_v)
$$

$M$ 是助手位置集合。图像对应的位置通常不进 $M$：视觉 token 是条件，不是要预测的词。这和[第 01 课](01_baseline_reproduction.md)的 assistant-only mask 是同一纪律，只是多了一段不可预测的视觉前缀。

LLaVA-1.5 进一步在学术 VQA 的问题末尾加上格式提示，例如 “Answer the question using a single word or phrase.”。短答数据和长对话共用一个 LLM 时，没有格式提示，模型会把短答风格泛化到闲聊，或反过来。InstructBLIP 只微调 Q-Former、不微调 LLM 时，这个问题更重：短答控制全压在视觉软提示上，Q-Former 容量不够。

验证：任意一条训练样本打印 label，确认图像占位和用户侧为忽略值（PyTorch 里常用 `-100`）；再准备同一问题的“详细描述”和“一词回答”两种提示，检查输出长度是否跟着提示变。

### 5.5 为什么先冻视觉：遗忘从哪来

视觉塔已经在海量图文对上对比训练过。第一阶段若解冻它，等于用当前这点 caption 数据去改一套已经成型的几何。LLM 同样已经在文本上成型。两边同时动，中间的 $W$ 还是随机的，梯度方向不稳定。

Flamingo 把这件事写成架构约束：冻结预训练 LM，只在层间插入 gated xattn-dense，并用 $\tanh\alpha$ 把门控初始化在 0，保证训练起点等于原 LM。它在 3B 模型上的消融（论文表 3，4-shot 综合分）给出了数量：从零训练 LM 相对其冻结设定总体分从 70.7 降到 57.8；解冻已经预训练的 LM 降到 62.7；去掉 tanh 门控降到 66.5。这些数字来自 Flamingo 自己的 3B 短程消融，不能直接抄到 7B LLaVA 上当预期分数，但方向一致：动已经训好的语言塔，要付遗忘或不稳的税。

BLIP-2 提供另一条证据。Q-Former 先在冻结 ViT 上做图文表示学习（ITC、ITM、ITG），再接到冻结 LLM 上做生成。论文写明：若跳过第一阶段表示学习，OPT 这类解码器 LLM 会在生成阶段出现灾难性遗忘，zero-shot VQA 随训练进行明显变差。Q-Former 把 32×768 的瓶颈当作“先帮 LLM 选好该看的视觉信息”，减轻 LLM 自己去对齐的负担。

Prismatic VLMs 在 LLaVA-1.5 数据上做了更靠近本课开关的消融：把通常冻结的视觉骨干一起全量微调，定位类任务明显变差。作者没有主张永远不能动 ViT；他们给出的条件更窄：在那份公开指令数据的规模和 next-token 目标下，解冻 CLIP 会把细粒度空间特征冲掉。

过早解冻的典型症状因此不是对齐分数下降。对齐往往还升，因为 ViT 在迎合当前 caption。跌的是旧文本探针，以及需要稳定局部特征的定位。浏览器实验把这一条做成验收：必须找到一组开关，使对齐相对基线升至少 30，同时旧文本跌至少 18。

### 5.6 标准顺序的适用边界

标准顺序有前提：视觉塔已经是对比学习产物，分辨率固定，投影只做维数映射。前提不成立时，公开系统会改顺序，不能把改动叫作“没按标准做所以错了”。

Qwen2-VL 的视觉塔不是原样冻结的 CLIP。它去掉绝对位置编码、改 2D-RoPE，并做 Naive Dynamic Resolution。训练分三阶段：先主要训 ViT（约 600B token 量级的图文关系、OCR 与分类）；再解开全部参数，继续约 800B，合计约 1.4T token；指令微调阶段再锁 ViT，只动 LLM。这里第一阶段解冻 ViT，是因为位置编码和分辨率策略都是新的，必须让眼睛适应变长 token。

Qwen2.5-VL 把预训练扩到约 4.1T token，三阶段分别是 1.5T（只训 ViT）、2T（ViT 与 LLM）、0.6T 长上下文。后训练的 SFT 与 DPO 明确冻结 ViT。72B 对话模型在纯文本 MATH 上为 83.0，对照 Qwen2.5-72B 的 83.1，用来说明多模态后训练没有把语言能力打穿。这是“后段锁眼睛、保语言”的现代写法。

PaliGemma 走相反的极端：多模态预训练（Stage1）故意不冻 ViT 和 Gemma，只给 ViT 很慢的学习率预热，避免随机投影刚接上时把视觉表示打坏。它的目标是可迁移的基座，而不是开箱闲聊。论文消融写明：冻 LM 明显更差；冻不冻 ViT 在迁移总分上接近，但需要空间关系的预训练困惑度在解冻 ViT 时更好。

Molmo 认为，在 PixMo-Cap 这种高密度描述数据上，单独的“只训连接器”阶段可以省掉，改为给连接器更高学习率和更短 warmup，让它在联合预训练开头先跑起来。Prismatic 也报告：在 LLaVA-1.5 的数据配比下，去掉投影预热、直接单阶段训投影和 LLM，综合分不掉，还能省约 20–25% 计算。

这些结果不否定本课开关实验。教学实验的起点是“现成 CLIP + 随机 $W$ + 现成 LLM”。在这个起点上，先训 $W$ 仍然是最干净的因果隔离。换了动态分辨率 ViT、换了十亿级 caption、换了要迁移到三十多个下游任务的基座，顺序可以改，但必须另开实验 ID，并把遗忘探针一起改。

### 5.7 学习率必须和冻结集合绑在一起

LLaVA 第一阶段学习率 $2\times 10^{-3}$，第二阶段 $2\times 10^{-5}$，差一百倍。第一阶段只更新几百万参数的投影，可以用较猛的步长把随机 $W$ 拉进词嵌入邻域；第二阶段若仍用 $10^{-3}$，冻结的视觉塔虽然不更新，LLM 会被打飞。LLaVA-1.5 因为改成 MLP，还把预训练学习率减半，附录写明原因是投影容量变大。

把学习率和冻结集合写成一张卡：

| 阶段 | 可训练 | 典型峰值学习率 | 若抄错 |
|---|---|---|---|
| 对齐投影 | $W$ | $10^{-3}$ 量级 | 用 $10^{-5}$ 会几乎不动，误判“投影没用” |
| 指令 / LoRA | $W$ 与 $\theta_r$ | $10^{-5}$ 量级 | 用 $10^{-3}$ 会毁掉文本方向 |
| 解冻 ViT | 加上 $\theta_v$ | 视觉侧再低一档 | 与 LLM 同学习率时，定位和旧特征先坏 |

Qwen2.5-VL 在第一阶段只训 ViT，用 caption、知识和 OCR，学习目标是让眼睛配合已经存在的 LLM；那和“随机 $W$ 去适配冻住的 CLIP”不是同一优化问题，学习率策略也不能互抄。MiniMind-O 默认冻 SigLIP2，更接近 LLaVA 第一阶段的眼睛，应抄 LLaVA 这一侧的学习率数量级，而不是抄 Qwen 中段解冻 ViT 的数量级。

验证：optimizer 的 param group 必须按模块拆开。CPU 实验没有学习率，只检查 mask；GPU 微型实验要在日志里打印每个 group 的 lr。

### 5.8 LoRA 前向如何挡住基座梯度

阶段 2 若全量更新 LLM，可训练参数从 $10^6$ 跳到 $10^9$。LoRA 把增量写成低秩：

$$
h' = W_0 h + \frac{\alpha}{r} B(Ah)
$$

$W_0$ 的 `requires_grad=False`。误差回传到 $A,B$，不累积到 $W_0$。CPU 实验里 $\alpha=4$、$r=2$，故 $\alpha/r=2$；$A$ 为 $2\times 12$，$B$ 为 $12\times 2$。阶段 2 打开 LoRA 后，`llm_w1` 的 mask 后梯度必须仍为 0，`lora_a` 的梯度必须非 0。这是“训 LLM”的省显存写法：语言能力可以改，但改动被限制在低秩子空间，旧文本方向更不容易被整体搬动。

类比：全量微调像把整本词典重写，LoRA 像在页边加注。类比失效处：低秩子空间仍可能改高频功能词的行为，所以旧文本探针不能省。ShareGPT 这类无图文本指令，作用是给低秩增量一条“继续说人话”的监督，LLaVA-1.5 把它和视觉指令混在一起。

验证：保存 $W_0$ 的哈希或逐元素副本，阶段 2 结束后必须逐元素相等；只比较 loss 不够。

### 5.9 门控插入：另一条“冻 LM”的数学

Flamingo 不把 $H_v$ 拼进词表，而在冻结 LM 层之间插入：

$$
x \leftarrow x + \tanh(\alpha)\, f_{\mathrm{xattn}}(x, Z)
$$

$\alpha$ 初始化为 0，$\tanh(0)=0$，训练第一步的输出等于原 LM。这是“冻语言”在残差结构上的硬保证。消融去掉门控后，3B 模型总体分从 70.7 降到 66.5。对本课的意义：投影进词表的 LLaVA 路线，没有这道门，第一阶段必须冻 LLM 来扮演同一角色。若有人在 MiniMind-O 里给 Thinker 加视觉 cross-attention，应先问门控初值是不是 0，再问冻结集合。

BLIP-2 第二阶段把 Q-Former 输出经全连接接到 LLM 隐层维，拼在文本 embedding 前面当软提示。LLM 仍冻。生成损失只更新 Q-Former 和这层 FC。这和“只训 $W$”同类：可训练模块是视觉到语言的接口，不是语言本体。

### 5.10 MiniMind-O 里这张表怎么用

MiniMind-O 的 SigLIP2、SenseVoice、Mimi 默认冻结，Thinker 可训练。它已经走在“冻眼睛”上。第 02 课比较 connector 时，阶段 A 冻 Thinker 只训连接器，正是本课 $\Theta_1$ 在 omni 系统里的对应物。本课不重复那三臂的 token 数实验，只要求：若你在 MiniMind-O 上做视觉指令数据，先确认 vision projector 是否已经过对齐阶段；若 projector 仍接近随机就去训 Thinker LoRA，把结果写成“connector 赢了”会和第 02 课的归因边界冲突。

音频侧同样适用这张冻结表，但本课不把音频数字写进验收。语音 codec 的 token 膨胀是第 15 课的配比问题。本课只提醒：解冻视觉塔的 run，必须同时看文本 golden 和音频 golden，因为共享 Thinker。

### 5.11 阶段 1 的一次更新在算什么

把 CPU 实验的前向写成逐步账，避免“mask 了就对”的口头结论。输入 $x\in\mathbb{R}^{8}$，两层 ViT 得到 $z_2\in\mathbb{R}^{8}$，投影 $W\in\mathbb{R}^{12\times 8}$ 得到 $h=Wz_2$，再经过带 LoRA 的 LLM 得到 $\hat y\in\mathbb{R}^{12}$。损失 $L=\frac12\|\hat y-y\|^2$。

阶段 1 的协议是：前向整网都跑，反传也先得到所有模块的原始梯度，再把 $\nabla_{\theta_v}L$ 和 $\nabla_{\theta_\ell}L$、$\nabla_{\theta_r}L$ 写成全零，只留下 $\nabla_W L$。Adam 因此只改 $W$。下一轮前向时，ViT 仍然用同一组权重产生 $z_2$，变化只来自 $W$。若你观察到 $z_2$ 在阶段 1 里逐 step 改变，实现已经把 ViT 解冻了。

手算投影梯度的形状：$\hat y$ 对 $h$ 的反传是一个 12 维向量 $g_h$，再与 $z_2$ 做外积，得到 $12\times 8$ 的 $\nabla W$。元素个数 96，和 $|\Theta_1|$ 相同。CPU 实验打印的 `stage1_projector_grad_abs_max` 必须大于 $10^{-8}$；`stage1_vit_grad_abs_max` 与 `stage1_llm_grad_abs_max` 必须是 0.0，不是“很小”。浮点噪声若出现非零，说明 mask 写成了乘以一个小系数，协议失败。

阶段 2 打开 LoRA 后，多了一条 $g_h$ 来自 $A,B$ 的路径。基座 $W_0$ 的外积照样能算出来，但被 mask 掉。负对照 `unmasked_llm_grad_abs_max` 就是这条被挡住的路径，实验里大约 $1.8\times 10^{-2}$ 量级，用来证明“不是 LLM 没有梯度，是协议不允许用”。

阶段 3 解除 ViT 的 mask。$g_h$ 穿过 $W$ 到达 $z_2$，再穿过两层 $8\times 8$ 回到输入。此时视觉塔开始为当前 caption 改几何。浏览器实验把这一步和“同时训 LLM”绑在一起，才会让旧文本跌过阈值：只解冻 ViT、LLM 仍冻时，旧文本几乎不动（玩具里 90 到 84），因为语言方向还锁着。失败臂需要三处一起动，和 Flamingo“解冻预训练 LM”的方向一致。

### 5.12 从一篇新论文抽出 recipe 卡

以后每读一篇 VLM，强制填八格，缺格就标 `unknown`：

1. 视觉塔来自哪份对比或分类预训练，是否改了位置编码；
2. 接口是线性、$n$ 层 MLP、Q-Former 还是门控插入；
3. 预训练每个阶段的可训练模块；
4. 每个阶段的数据种类和数量，单位是图像数还是 token 数；
5. 学习率是否按模块分组；
6. 指令阶段是否仍冻眼睛；
7. 有没有纯文本或无图指令混入；
8. 有没有旧能力探针（纯文本、定位、OCR 分桶）。

这八格能填满，才允许在讨论里用“他们也是两阶段”这种句子。填不满时，只引用你确实看见的格。Qwen2.5-VL 的 4.1T 是 token 数，LLaVA 的 595K 是图文对数，两者不能横着比“谁数据更多”而不写单位。

对 MiniMind-O 的官方视觉通路，八格可以这样填：眼睛是冻结 SigLIP2；接口默认两层 MLP；官方 mini 训练不把解冻 SigLIP2 当作主路径；数据按任务分阶段，见第 01 课；学习率以官方脚本为准；指令阶段眼睛仍冻；是否混纯文本以你用的 parquet 为准；旧能力探针要用第 01 课的 golden。本课要改的是第 3 格和第 8 格的记录方式，不要去重做第 02 课的第 2 格。

### 5.13 公开规模的参数数量级（带假设）

下面这张数量级表声明了假设，用来建立直觉，不进入 CPU `checks`。

假设 A：视觉塔是 CLIP ViT-L/14 量级，约 $3\times 10^8$ 参数，本课不声称这是某张表的精确值，只作数量级。假设 B：语言模型是 7B 级因果 LM。假设 C：线性投影 $d_v=1024$、$d_{\ell}=4096$，元素个数 $4194304$。假设 D：LoRA 只打在 32 层的 $q,k,v,o$ 四个 $4096\times 4096$ 矩阵上，$r=64$，则

$$
|\theta_r|=32\times 4\times 64\times (4096+4096)=67108864
$$

于是教学三阶段在公开 7B 设定下大约是：

| 阶段 | 可训练数量级 | 占 7B 的比例 |
|---|---|---|
| 只训线性 $W$ | $4\times 10^6$ | 约 0.06% |
| $W$ + 上述 LoRA | $7\times 10^7$ | 约 1% |
| 再加视觉塔 | $4\times 10^8$ | 约 5% |
| 全量 LLM + $W$ + ViT | $7\times 10^9$ | 接近 100% |

LLaVA 第二阶段走的是最后一行里“全量 LLM + $W$、ViT 仍冻”，可训练约 7B。BLIP-2 预训练走第一行的加强版：188M 的 Q-Former，约为 7B 的 3%。Flamingo-80B 走中间路线：10.2B 可训练，占总参数 80B 的约 13%。这些比例解释了为什么“先训接口”在工程上几乎总是被选：它便宜，而且把遗忘的主开关留到后面。

若你把假设 D 的 $r$ 改成 8，LoRA 降到约 840 万，阶段 2 几乎回到阶段 1 的量级。秩不是越小越好：秩太小，指令跟随抬不起来，你会误判“必须解冻 ViT”。秩的扫描属于本课改造清单第 2 条。

### 5.14 少一步分别会怎样

把标准顺序拆成四个“少一步”对照，便于写失败报告。

**少掉阶段 1，直接训 LLM。** 视觉 token 仍接近噪声。LLM 会学到“看见这串不可读前缀就改用语言先验”。图文对齐指标可能因为文本先验而看起来不差，错配图像对照会揭穿。ScienceQA 上 LLaVA 给出了 5.11 个百分点的原论文差距；你的缩小版未必能看到这么大的数，但错配对照应该仍能做。

**少掉阶段 2，只发布阶段 1。** 模型会描述图，却不会按复杂指令推理，也不会稳定地用一词或一段话切换格式。LLaVA-Bench 无指令微调的 21.5 分就是这个状态。若产品需求只是 caption，可以停在阶段 1，但报告必须写“未做指令阶段”。

**少掉旧文本探针，只看 VQA。** 阶段 C 会显得最强。这是本课浏览器验收专门堵的洞。

**少掉冻结，三处一起动。** 对齐上升、旧文本下降。若数据极大、课程极长，像 Qwen2.5-VL 中段那样，这个洞可以被数据和后段再冻结补上。教学数据和 128 条 caption 补不上。

四个对照都要在笔记里预注册，做了哪个写哪个。没做的写“未做”，不要用其他对照的数字顶替。

## 6. 在公开实现中定位这些机制

读公开仓库时，按“冻谁、算谁的 loss、数据是哪一阶段”三条线找，不要先陷进 connector 类型。

**冻结。** LLaVA 训练脚本把视觉编码器设为不更新，第一阶段再把 LLM 也排除出 optimizer。Hugging Face 的 `LlavaForConditionalGeneration` 把投影叫 `multi_modal_projector`，视觉塔叫 `vision_tower`。你自己写教学代码时，最小实现是三个参数组：

```python
def trainable_params(model, stage: str):
    groups = []
    for name, param in model.named_parameters():
        train = False
        if "projector" in name or name.endswith("W"):
            train = True
        elif stage in {"lora", "vit"} and "lora_" in name:
            train = True
        elif stage == "vit" and name.startswith("vit"):
            train = True
        param.requires_grad = train
        if train:
            groups.append(param)
    return groups
```

阶段名 `proj` / `lora` / `vit` 对应本课 $\Theta_1,\Theta_2,\Theta_3$。不要在这里注册三种 connector 后端，那是第 02 课的接口。

读别人的训练脚本时，先搜 `requires_grad`、`freeze`、`trainable`、`vision_tower`、`mm_projector`。LLaVA 仓库把第一阶段叫 feature alignment pretraining，第二阶段叫 visual instruction tuning。Hugging Face `LlavaProcessor` 负责把 `<image>` 换成视觉特征长度；你若自己写 collator，必须用 projector 实际输出长度，不能用 1。长度对不上时，常见症状是 loss 正常下降但推理时图像条件错位，输出像没看见图。

若你在本地用 Hugging Face 复现冻结，最小检查脚本的核心是：阶段 1 结束后 `vision_tower` 每个参数的绝对差分为 0，`language_model` 绝对差分为 0，`multi_modal_projector` 绝对差分非 0。把三个差分打进 trace。不要只打印 `requires_grad` 的布尔值：布尔值只能说明意图，差分才能说明优化器有没有偷偷改到冻结塔。

**损失。** 找 `labels` 里被写成忽略值的区间。视觉 token 展开之后，序列变长，占位符 `<image>` 一个 token 可能变成几十到几百个特征位置，必须按真实视觉长度记账，否则 mask 会错位。第 18 课的 toy 用 256 个视觉位置做的就是这件事；本课只需保证阶段 1 的监督仍在文本 caption 上。

公开实现里还有一个容易漏的点：多轮对话只把第一轮和图像拼在一起，后续轮只有文本。LLaVA 原文公式 (2) 把第一轮的图像和问题顺序随机对调，其余轮不再放图像。这影响“图像条件覆盖哪些 token”，不影响冻结集合，但会影响你打印 mask 时的预期长度。

**数据阶段。** LLaVA 第一阶段把图文对扩成单轮“请简要描述”对话，监督是原 caption。第二阶段才使用 158K 指令。LLaVA-1.5 的附录把 665K 指令按来源拆开，并给每类写了格式提示。如果你把 COCO caption 和 VQAv2 短答倒进同一个 DataLoader 且不加提示，这不是 LLaVA-1.5 配方。

BLIP-2 的代码路径不同：预训练阶段根本不把 LLM 放进反向图，Q-Former 的输出经全连接层接到冻结 LLM 的 embedding 前。InstructBLIP 在指令阶段仍然只训 Q-Former，但把指令文本也送进 Q-Former，让 query 按问题取视觉特征。Flamingo 则是在 LM 块之间插层：视觉特征不进入分词 embedding，由 cross-attention 读取 Perceiver 的固定 64 个视觉 token。三种写法对“冻 LLM”是同一纪律，对“视觉如何进 LM”结构不同；结构对比已经在第 02 课做过，本课只记冻结集合。

## 7. 数据与训练 recipe

配方是数据和冻结绑在一起的。只抄阶段名、不抄数据，阶段会失去原论文里的含义。

### 7.1 LLaVA：小数据两阶段

第一阶段：CC3M 过滤到 595K 图文对，扩成简短描述指令，1 个 epoch，学习率 $2\times 10^{-3}$，batch 128。第二阶段：158K 指令，3 个 epoch，学习率 $2\times 10^{-5}$，batch 32。视觉编码器始终冻结。ScienceQA 上的消融：跳过第一阶段直接在 ScienceQA 上从头训，准确率 85.81%，完整流程 90.92%，差 5.11 个百分点。这条消融说明“先对齐投影”在中等规模任务上不是装饰。

LLaVA-Bench (COCO) 用 GPT-4 打相对分：无指令微调 21.5，完整三类指令 85.1。指令数据本身比再堆 10 倍 caption 更直接地改变“会不会按人的要求回答”。In-the-Wild 子集上 LLaVA 总体 67.3，对复杂推理相对 GPT-4 参考为 81.7，仍显著高于 BLIP-2 的 38.1 和 OpenFlamingo 的 19.1。这些是指令跟随能力的证据，不是视觉塔解冻的证据：三篇对比里视觉编码器都没有在第二阶段被当作主更新对象。

对话格式值得单独记。LLaVA 把每张图扩成多轮，第一轮把图像和问题随机左右放置，其余轮只放问题。监督 token 只覆盖助手回复和结束符。系统提示沿用 Vicuna。本课 CPU 实验没有对话结构，因为它只验证梯度 mask；GPU 微型实验若用真实对话，必须把图像占位从损失里拿掉，否则阶段 1 会把视觉位置当成要预测的词，和“视觉是条件”相反。

ScienceQA 消融还有几条和冻结有关：用 CLIP 最后一层特征比用最后一层之前低 0.96 个百分点；先答后想比先想后答收敛慢；7B 比 13B 低 1.08 个百分点。和本课直接相关的仍是“跳过预训练掉 5.11 分”。其他几条说明：即使冻结眼睛，取哪一层特征、推理链顺序、模型宽度仍然影响任务分。这些变量本课不扫，写进“未做”即可。

### 7.2 LLaVA-1.5：MLP、格式提示、学术任务

改动写在论文第 3 节和表 2。线性投影换成 MLP；加入 VQAv2 后 MME 从 809.6 升到 1197.0，再加格式提示到 1323.8。短答数据和对话数据能够共存，关键是提示把输出格式说死，并且 LLM 被微调，而不是只靠 Q-Former 做前缀控制。指令阶段 665K，来源包括 LLaVA 原 158K、ShareGPT 约 40K、VQAv2 83K、GQA 72K、OCRVQA 采样 80K、Visual Genome 86K 等，附录表 7 逐项列出。预训练仍用原图文对，分辨率升到 336 后，8×A100 上预训练约 6 小时、指令微调约 20 小时。视觉塔仍然冻结。

论文还报告：随机丢掉最多 50% 指令样本，整体仍能保住全量设定 98% 以上的分数。本课不把这条写成“可以随便减数据”，只把它当成“在那份已经很密的 665K 里存在冗余”的证据。

### 7.3 BLIP-2 与 InstructBLIP：冻双塔、训瓶颈

BLIP-2 预训练图像约 129M，第一阶段 250k step，第二阶段 80k step。可训练主体是 188M 的 Q-Former。zero-shot VQAv2 上，ViT-g + FlanT5-XXL 为 65.0（test-dev）/ 65.2（val），论文对比 Flamingo-80B 的 56.3，并写明可训练参数少约 54 倍。第一阶段三个损失共享参数：图像文本对比、图像条件生成、图像文本匹配，靠不同的自注意力 mask 控制 query 和文本谁能看见谁。本课不实现这三个损失，只借用它的冻结结论：接口可以很忙，两侧塔仍然冻。下游 caption / VQA 微调时，他们会解冻图像编码器和 Q-Former，仍冻 LLM；那是任务微调，不是预训练配方。微调 caption 时图像分辨率提到 364，VQA 提到 490，附录表 7 和表 8 列出。解冻眼睛出现在“已经有了对齐好的 Q-Former 之后”，不是出现在随机接口阶段。这和本课阶段 C 的位置不同，报告里要写清。

InstructBLIP 把 26 个公开数据集改写成指令，13 个 held-in 训练，13 个 held-out 做零样本。采样概率与样本量平方根成正比，避免小数据集被淹没。指令感知的 Q-Former 把问题文本送进 query 的自注意力。微调下游时保持 224 分辨率、冻视觉编码器，可训练参数仍约 188M；论文对比若解冻视觉编码器则升到约 1.2B。ScienceQA 带图部分，FlanT5-XXL 的 InstructBLIP 微调到 90.7%。16×A100（40G）上指令调优在 1.5 天内完成。

### 7.4 Flamingo：交错网页与 few-shot

Flamingo 的主数据是 M3W 这类从网页抽的交错图文，外加 ALIGN 1.8B 图文对、LTIP 3.12 亿、VTP 2700 万视频文本，单图单句 caption 只是其中一部分。交错数据支撑 in-context few-shot：推理时可在提示里放最多 32 个图文例子，尽管训练时每个交错序列最多 5 张图。可训练部分是 Perceiver Resampler 和插入 LM 的门控层。本课不实现 Perceiver；只要记住：冻结 LM 加少量可训层，是和“投影进词表”并列的第二条标准路。

### 7.5 2024–2025 年公开系统的数据量级

Qwen2-VL 预训练合计约 1.4T token（先约 600B，再约 800B），指令阶段用 ChatML 组织图文、文档、多图、视频和 agent 交互。Qwen2.5-VL 预训练约 4.1T，SFT 约 200 万条，文本与多模态各约一半。这些数字用来标定“公开互联网规模”，不是本课 CPU 实验的预算。

LLaVA-OneVision 把 LLaVA 的两阶段扩成课程：Stage-1 只训投影，558K；Stage-1.5 全模型看约 4M 高质量知识（重写 caption、OCR、中文和纯文本）；Stage-2 先 3.2M 单图指令，再 1.6M 单图/多图/视频混合。视觉学习率是 LLM 的五分之一。它保留“先对齐投影”，但在后段解开全模型，并用图像上的长序列去迁移视频。

Molmo 的 PixMo-Cap 含 712k 张图，描述平均 196 词，用 60 到 90 秒口述再转写，避免标注员直接粘贴专有 VLM 的输出。预训练在这些描述上更新全部参数，微调再混入指向、问答和公开学术集。指向数据有 230 万条，用来让模型边指边数。

PaliGemma 的 Stage1 在 224 像素上看 10 亿样本，任务混合包括 caption、OCR、VQA、检测和分割；Stage2 用更少样本升到 448 与 896。它的目标是可迁移基座，预训练阶段不走 LLaVA 式闲聊指令。

### 7.7 LLaVA-1.5 指令混合物怎样避免短答吞掉闲聊

附录表 7 的份量值得抄一次，因为它就是“数据 recipe”四个字的具体化：LLaVA 158K 无额外格式提示；ShareGPT 40K 无图；VQAv2 83K、GQA 72K、OKVQA 9K、OCRVQA 80K 使用 “Answer the question using a single word or phrase.”；A-OKVQA 66K 使用 “Answer with the option’s letter...”；TextCaps 22K 要求一句 caption；RefCOCO 48K 与 Visual Genome 86K 使用区域描述或框坐标。合计 665K。评测时，VQAv2 / GQA / TextVQA / MME / POPE 继续用短答提示，ScienceQA / MMBench / SEED 用选项字母提示，VizWiz 额外要求信息不足时输出 Unanswerable。

若有人把这 665K 展平后删掉所有格式字段再训，得到的模型会在 MME 上倒退回接近原 LLaVA 的 809.6 一带。表 2 已经把“只加 VQAv2、再加格式提示”拆开了：VQAv2 把 MME 从 809.6 拉到 1197.0，格式提示再拉到 1323.8。本课验收要求你在自己的指令数据里同样登记格式字段，即使只有 200 条。

### 7.8 本课教学 recipe（缩小版）

主路径不训练真实 7B。若有 1×24GB，用下列冻结表做微型复现，数据用公开 COCO caption 子集加几十条纯文本探针即可：

| 阶段 | 数据 | 可训练 | 学习率量级 | 停的条件 |
|---|---|---|---|---|
| A 对齐 | 图文 caption | 仅 $W$ | 高于后续一档 | caption 有效 loss 稳定下降，纯文本探针变化小于预定阈值 |
| B 指令 | 短 VQA + 一句描述 | $W$ + LoRA | 低于 A | 指令跟随升，纯文本回退小于阈值 |
| C 对照 | 与 B 相同 | $W$ + LoRA + ViT | 与 B 相同 | 用作失败臂：允许对齐更高，纯文本必须记下跌幅 |

A 与 B 是主臂。C 是为了复现“过早或过晚解开 ViT”的方向，不是默认发布臂。任何把 C 的 VQA 分数写进主结论而不报文本回退的报告，视为无效。

## 8. 按依赖顺序执行实验

实验分两条路：人人要跑的 CPU 机制实验，以及有卡才做的可选冻结消融。浏览器开关实验在课文页内完成，不占这张表的 GPU 预算。

### 8.1 CPU 机制实验（必做）

在 `experiments/` 目录执行：

```bash
PYTHONPATH=src python3 -c "from learn_omni_experiments.lessons.lesson_22 import run; print(all(run()['checks'].values()))"
```

编排者把本课写入 `registry.py` 之后，也可以：

```bash
python3 run.py run 22
```

脚本构造 $d_v=8$ 的视觉向量、两层 ViT、$12\times 8$ 的 $W$、两层 LLM 和一组 $r=2$ 的 LoRA。前向是 $H=WZ$ 再加 LoRA 增量，损失是与固定目标的平方误差。矩阵数值写死在源文件里，不读磁盘上的权重，也不访问网络。若你本地改了 $d_v$ 却没改公式断言，`stage1_trainable_equals_projector` 应变 False。这是有意的：检查保护的是协议，不是某一组魔法数字。提交教学作业时请保持 8 与 12，方便和课文表格对读。检查项如下：

1. 阶段 1 可训练元素等于 96，且等于 $d_v d_{\ell}$；
2. mask 后 ViT、LLM、LoRA 梯度绝对值为 0，投影梯度非 0；
3. 未 mask 时 ViT 与 LLM 梯度非 0（负对照）；
4. LoRA 元素个数等于 $r(d_{\mathrm{in}}+d_{\mathrm{out}})=48$；
5. 阶段 2 可训练 144，且基座 LLM 梯度仍为 0、LoRA 梯度非 0；
6. 阶段 3 可训练 272，ViT 梯度恢复，基座 LLM 仍为 0。

全部为 True 才算本课机制验收通过。它不读取网络、不写大文件、不用 GPU。

### 8.2 浏览器开关实验（必做）

打开本课页面的“三阶段解冻开关”。必须先在三个选项里选出“过早解冻 ViT 时旧文本能力会跌过阈值”，再运行。默认开关是阶段 1（冻 ViT、训投影、冻 LLM），对齐会升、旧文本几乎不动，不能通过验收。把 ViT 解冻并同时打开投影和 LLM，对齐增益至少 30、旧文本跌幅至少 18，验收才亮。这是教学模拟。

### 8.3 可选 GPU 冻结消融

仅在有卡、并且已经有一份冻结好的 CLIP 与小 LLM 时做。顺序固定：

1. 过拟合 128 条 caption，只训 $W$，确认 ViT 与 LLM 的 `.grad` 为 `None` 或全 0；
2. 在同一起点上开 LoRA，确认基座 LLM 权重哈希不变；
3. 从同一起点解冻 ViT 做对照，记下纯文本探针；
4. 禁止在第 3 步改善了 caption 之后，回写第 1 步的结论。

数据必须在实验开始前冻结 hash。不要在这一步比较 Resampler 和 Q-Former。

### Step 0: 登记起点

写下视觉塔名字与是否冻结、LLM 名字、投影形状、$d_v$ 与 $d_{\ell}$、将要使用的三阶段开关。CPU 实验用内置矩阵，这一步填“toy $8\to 12$”。

### Step 1: 只训投影

跑 CPU 实验或 GPU 阶段 A。记录可训练参数和 mask 后的梯度范数。失败则先查参数名字符串有没有把 ViT 漏进 optimizer。

### Step 2: 打开 LoRA

确认 $|\Theta_2|=|\Theta_1|+r(d_{\mathrm{in}}+d_{\mathrm{out}})$。GPU 路径再加一条纯文本探针。

### Step 3: 解冻 ViT 的对照

不要覆盖阶段 1 的 checkpoint。对照臂单独存。若对齐升而文本跌过你预先写的阈值，记为符合本课失败臂，而不是训练事故。

### Step 4: 写配方卡

一张表，三行阶段，列包括：数据、可训练模块、学习率、文本探针、图文指标。缺列则本课未完成。

### Step 5: 负对照必须留下原始梯度

CPU 实验已经内置未 mask 的梯度范数。若你重写一份教学脚本，至少保留一次“全部 `requires_grad=True` 的反传”。若未 mask 时 ViT 梯度已经是 0，说明前向没把视觉误差接到损失上，后面所有冻结结论都无效。

### Step 6: 不要在本课引入第三条结构臂

有人会想顺便比较 MLP 和 Q-Former。停。那是第 02 课的实验 ID。本课只允许冻结集合变化。结构一变，参数量和 token 数一起变，你又说不清是顺序的功劳。

### 8.4 可选 GPU 的最小数字协议

若只有 1×24GB，不要下载 7B。用一个小于 0.5B 的因果 LM 加冻结的小 ViT（或冻结的随机卷积当假眼睛，只要声明它不是 CLIP）。图文对 2 千到 1 万条就够看方向。记录：

- 阶段 A 的 100 step 内，投影权重的 Frobenius 范数应明显离开初始化；ViT 权重范数变化低于你预注册的 $\varepsilon$（建议 $10^{-6}$ 相对变化）；
- 阶段 B 结束后，20 条纯文本题对错表；
- 阶段 C 与 B 的文本对错表并排。

卡时估计：上述规模在 24GB 上每个阶段数十分钟到两小时，取决于序列长度。超过半天还没跑完，先减分辨率和 $T$，不要去解冻 ViT 指望它“更快收敛”。

没有 24GB 时，跳过 8.4，CPU 加浏览器即为完整主路径。不要因为没有 GPU 就跳过三项指标的定义：浏览器实验已经强制你触发“对齐升、文本降”的失败臂，这和有卡时看探针是同一条纪律。

8.4 若真做了，把三个阶段的日志各留一份。最低限度的字段：step、可训练参数个数、投影梯度范数、ViT 梯度范数、LLM 梯度范数、caption loss、文本探针。阶段 A 的 ViT 与 LLM 范数必须是精确的 0 或 `None`。若框架在冻结参数上仍填 0.0 张量而不是 `None`，在笔记里写明，避免和“有梯度但被置零”的 mask 实现混淆。CPU 实验采用显式置零，对应后一种，便于手算。

## 9. 评测与测量

三项指标必须同时出现。名称可以自定，定义不能含糊。

**图文对齐。** 给定图像，模型生成的描述是否覆盖可见物体与关系。可用 caption 的 CIDEr，或教学里的“关键词命中率”。LLaVA 第一阶段的目标就是这件事。BLIP-2 的 ITC/ITM 也在测对齐，但那是 Q-Former 内部损失，不要和生成指标混成一个数字。

**指令跟随。** 同一张图，换问题或换格式提示，输出是否跟着变。LLaVA-1.5 用 MME、MM-Vet、LLaVA-Bench-in-the-Wild 等；教学可用“一词回答 / 完整句子 / 拒绝回答”三组提示。若三种提示得到同一段长描述，指令跟随失败。

**旧文本能力。** 关掉图像，只跑原 LLM 会的纯文本题：常识问答、数学短题、按格式输出。Qwen2.5-VL-72B 在报告里列出 MMLU-Pro 71.2、MATH 83.0、IFEval 86.3，并与 Qwen2.5-72B 对照。教学没有这些榜，就固定 20 条纯文本题，训练前后逐条打对错。平均 VQA 上升而这 20 条掉一半，配方不合格。

辅助测量：

- 可训练参数量、实际 optimizer 参数量，二者必须相等；
- 各模块梯度 L2，阶段 1 的 ViT/LLM 应为 0；
- 学习率：LLaVA 第一阶段比第二阶段高两个数量级，抄反会毁掉冻结塔；
- 反事实图：全黑或错配图像。若分数不掉，对齐指标是假的。这一条和第 02 课相同，本课用来检验配方，不用来选 connector。

公开论文里的定位和幻觉数字，本课只当“下一课探针的预告”，不当成本课验收。LLaVA-1.5 讨论过：分辨率不够时，模型会学会在细节上看不见的地方编造；把输入升到 448 后，同样带一点幻觉的描述数据不再那么容易把模型带偏。这句话的操作含义是：如果你在低分辨率、冻 ViT 的设定下看到大量幻觉，先别解冻 ViT 当药，先问眼睛有没有看清。第 23 课会把“看清没有”变成可算的命中和幻觉率。

不要把 ScienceQA 90.92% 或 LLaVA-1.5 的 VQAv2 80.0 写进自己的缩小版报告当复现成功。那些数字属于原论文的数据与算力。缩小版只声明方向：先对齐是否让早期 loss 更稳、解冻 ViT 是否让文本探针下降。

三项指标的教学基线（浏览器实验内置，不得外传为模型分数）：

| 开关 | 对齐 | 指令 | 旧文本 | 是否触发验收 |
|---|---|---|---|---|
| 全冻 | 24 | 30 | 90 | 否 |
| 冻 ViT，训投影 | 64 | 38 | 89 | 否（对齐升，文本几乎不动） |
| 冻 ViT，训投影和 LLM | 72 | 70 | 80 | 否（文本轻降，未过阈值 18） |
| 解冻 ViT，训投影和 LLM | 80 | 68 | 51 | 是（对齐 +56，文本 −39） |

阈值写进页面：对齐增益 $\ge 30$，旧文本跌幅 $\ge 18$。改玩具公式可以，但必须让“过早三处一起动”成为能单独触发验收的一格，否则学生找不到失败臂。

## 10. 验收条件

机制验收（无 GPU 也可）：

- CPU 实验全部 `checks` 为 True；
- 浏览器实验先预测“旧文本能力”，再找到对齐上升且旧文本跌过阈值的开关组合；
- 课文中的 $|\Theta_1|=96$、$|\Theta_2|=144$、$|\Theta_3|=272$ 与脚本输出一致。

配方验收（若做了 GPU 微型实验）：

- 阶段 A：caption 损失下降，纯文本探针相对起点变化不超过你预注册的阈值（建议先写 3% 正确率或固定条数）；
- 阶段 B：指令跟随升，纯文本回退仍在阈值内；
- 阶段 C 对照：对齐可以高于 B，但纯文本回退必须大于 B，否则“过早解冻有害”这一条在该规模下不成立，应写成有效负结果，而不是改阈值去凑。

报告验收：

- 冻结表、数据 hash、学习率、三项指标分列；
- 明确声明未比较三种 connector；
- 未把浏览器分数写成模型能力。

## 11. 根据症状定位失败环节

| 症状 | 先查 | 不要做 |
|---|---|---|
| 阶段 1 loss 下降，但错配图像分数不掉 | 投影是否学到捷径、mask 是否把视觉条件丢掉 | 立刻解冻 LLM |
| 阶段 1 的 ViT `.grad` 非空 | optimizer 参数组、`requires_grad` | 把非空当成“视觉在学习”的好消息 |
| 指令阶段开始后纯文本探针陡降 | 是否同时解冻了 ViT；学习率是否仍停留在阶段 1 的 $10^{-3}$ 量级 | 用 VQA 平均分覆盖探针 |
| 短答 VQA 升、闲聊崩成一词 | 格式提示是否缺失，数据是否未按来源加前缀 | 再加更多 VQAv2 |
| 闲聊还行，OCR 和定位差 | 分辨率和冻结 ViT 的交互；对照第 08 课，不要在本课临时改切片器 | 把问题记成“投影太弱”而不做分桶 |
| LoRA 打开后基座权重哈希变了 | merge 是否误写回 $W_0$；是否把基座也塞进了 Adam | 继续训并指望它自己回来 |
| 与第 02 课数字对不上 | 实验 ID 是否混用 | 用 connector 的 Pareto 解释冻结顺序 |
| 阶段 1 caption 很好，指令阶段一开就胡言 | 学习率是否仍是 $2\times 10^{-3}$；LoRA $\alpha/r$ 是否过大 | 立刻解冻 ViT 当救场 |
| 纯文本还在，中文或多语掉了 | 指令数据是否全是英文 VQA；有无 ShareGPT 类无图对话 | 把多语掉分写成视觉遗忘 |
| 定位掉、caption 升 | 是否解冻了对比预训练的 ViT | 加更多 caption 去“补定位” |
| 同一 checkpoint 两次评测差很大 | 格式提示、解码温度、是否 greedy | 改冻结表 |

Flamingo 的综合消融、BLIP-2 的 OPT 遗忘曲线、Prismatic 的解冻 ViT 定位下跌，都是同一张诊断表在不同架构上的行。抄分数无意义，抄“缺哪条探针就看不见那一行”有意义。

和[第 15 课](15_joint_multimodal_sft.md)的分工再写一次，避免两课抢同一张遗忘表。第 15 课管的是多种任务桶在同一阶段交错时，音频 token 是否压过文本、要不要 replay。本课管的是单次视觉适配里，眼睛、投影、嘴巴谁先动。一个 checkpoint 可以同时违反两课：解冻 ViT 又按样本数混进大量长音频。报告里要分两行写，一行引用本课阶段 C，一行引用第 15 课的 token-balanced 表。不要写“发生了灾难性遗忘”这种没有模块归属的句子。

三项指标在真实评测里都有噪声。教学建议每个探针至少 20 条，报告时同时给对错表，不要只给百分数。20 条里对错差 1 条就是 5 个百分点，刚好能吞掉你预注册的 3% 回退线。若只能做 20 条，就把回退线写成“条数”而不是百分比，例如“最多错多 1 条”。浏览器实验没有噪声，因为它是查找表；不要用它来练习“误差棒怎么画”，只用它练习“失败臂怎么触发”。

玩具指标不是随机数。浏览器实验把八种开关编成一张查找表，基线是全冻时的 24 / 30 / 90。只训投影时对齐跳到 64，旧文本留在 89：对应阶段 1 只移动 $W$。冻 ViT 同时训投影和 LLM 时，对齐 72、指令 70、旧文本 80：对应阶段 2，文本轻降 10，低于阈值 18。三处一起动时对齐 80、旧文本 51：对齐增益 56，文本跌幅 39，单独触发验收。其余五格用来防止学生靠乱点蒙中：只训 LLM 时对齐几乎不动；只解冻 ViT 时对齐略升到 38，达不到 30 的增益线。你改这张表可以，但必须保持“失败臂唯一可过验收”这一性质，否则 Gate 失去教学意义。

## 13. 前沿对照与改造方向

**公开方案。** LLaVA 家族把“冻眼睛、训投影、再训 LLM”做成可复现基线；LLaVA-1.5 证明在公开数据上加 MLP 和格式提示就能在当时一批榜上超过更重的 Q-Former 预训练。BLIP-2 / InstructBLIP 把可训练部分压缩到 Q-Former，两侧塔冻结，用表示学习给生成垫底。Flamingo 用门控交叉注意力把冻结 LM 变成可 few-shot 的视觉语言模型。Qwen2-VL 与 Qwen2.5-VL 把动态分辨率做成原生，训练中段解开 ViT，指令阶段再锁上，并用大量交错和文档数据。Qwen2.5-VL 还报告纯文本指标与 Qwen2.5 基座接近：72B 对话模型 MATH 83.0 对照 Qwen2.5-72B 的 83.1，IFEval 86.3 对照 84.1，说明锁眼睛的后训练可以保住甚至略增格式遵循。这些对照只在原报告的评测协议下成立，本课不得把 83.0 抄到玩具模型上。PaliGemma 选择小模型、解冻预训练、拉长多任务预训练，做成迁移基座。Molmo 用口述稠密描述避开蒸馏专有 VLM，并靠指向数据把计数变成可检查的动作。Prismatic 在同一套 LLaVA-1.5 数据上扫设计轴，发现单阶段可行、解冻 ViT 伤定位、DINOv2 与 SigLIP 特征拼接有益。LLaVA-OneVision 则在后段用混合图像与视频数据做任务迁移。

**差距。** 规模差距：公开模型的预训练从 LLaVA 的 $10^5$ 图文对，到 BLIP-2 的 $10^8$ 图像，再到 Qwen2.5-VL 的 $10^{12}$ token。钱可以买数据和卡时，买不来“你有没有把冻结集合写进报告”。LLaVA-1.5 用 1.2M 公开样本在 8×A100 上约一天训完 13B，是本课“机制可复现”的上限参照：24GB 实验应该复现方向，不该复现那天的绝对分。

机制差距：本课能解决的是顺序、mask、三项指标和参数账。本课不能解决的是原生动态分辨率（第 08 课）、是否看对位置（第 23 课）、动作 token（第 24 课）。MiniMind-O 继续把 SigLIP2 当冻结模块，等于默认走本课阶段 1 的眼睛；若有人在 MiniMind-O 上解冻 SigLIP2，必须按本课阶段 C 那样单开对照，并跑文本与音频回归，因为那是 omni 系统，遗忘不只有纯文本。

Qwen2.5-Omni 一类系统会把视觉配方和音频双工叠在同一套权重上。其技术报告若未逐模块公开冻结表，对应格子写 `unknown`，不要用本课的 LLaVA 表去填。能确定的只有：眼睛若来自已经对比预训练的塔，先对齐接口这一条仍然值得当作默认假设，再用该系统自己的消融推翻。

**动手改造（在缩小版上执行，写清失败判定）：**

1. **把阶段 1 从线性 $W$ 换成两层 MLP，仍冻 ViT 与 LLM。** 改投影模块定义，不改冻结表。预算：CPU 上只改计数公式；GPU 微型用同一 128 条 caption、相同 step。预期：可训练参数变成 $d_v d_h+d_h d_{\ell}$，caption 损失下降速度不低于线性层。失败判定：梯度 mask 被破坏，或纯文本探针在阶段 1 就掉过阈值（说明优化器误收了 LLM）。
2. **阶段 2 用 LoRA $r\in\{2,4,8\}$ 扫遗忘。** 只改 LoRA 秩和对应学习率，数据与冻结表不变。预算：CPU 改 $r$ 必须让公式和矩阵元素一致；GPU 每档同一纯文本探针。预期：$r$ 增大则指令跟随升、文本回退也升，画出单调折中。失败判定：三档文本回退无差异且指令分无差异，说明步数太少，升预算后再下结论。
3. **阶段 2 加入一定比例纯文本指令（ShareGPT 类）。** LLaVA-1.5 用约 40K 纯文本对话。教学可在指令集里混 10%、30% 无图样本。预算：与阶段 B 相同卡时的两个 run。预期：旧文本探针回升，图文对齐不显著下降。失败判定：对齐明显下降，说明无图样本挤占了本已很小的视觉监督，应降比例而不是解冻 ViT 来补。
4. **把 Qwen2-VL 的“先训 ViT”搬到固定分辨率 CLIP 上（负迁移实验）。** 第一阶段解冻 CLIP、冻 LLM、训 $W$+ViT。预算：与阶段 A 相同。预期：在教学数据规模下，旧文本也许还在（LLM 仍冻），但阶段 B 接上之后遗忘会早于标准臂出现，或定位类玩具任务变差。失败判定：若该臂三项指标全面优于标准臂，写成“此规模下 CLIP 仍有适配空间”，不要改标准臂的定义去迁就它。

改造实验的公共纪律：一次只改一个变量；失败判定写在训练开始前；卡时超过预算就降数据，不降探针。四条都做完也只说明缩小版上的方向，不能改写 LLaVA-1.5 表 3 的公开分数。

### 13.1 十个常见记错

1. 把 BLIP-2 的 188M 写成总参数。总参数是 3B 到 12B 级，188M 是可训练部分。
2. 把 LLaVA 的 595K 和 LLaVA-1.5 的 558K 混成一个数。过滤后的预训练图文对在两篇里的记法不同，抄的时候跟论文走。

5. 把 InstructBLIP 的 ScienceQA 90.7% 写成零样本。那是微调数字。
6. 把 LLaVA-1.5 的 VQAv2 80.0 写成零样本。表注有星号，训练见过该集图像。
7. 把 PaliGemma 的 10 亿样本 Stage1 理解成 10 亿参数。

9. 把 Prismatic 单阶段理解成“永远不需要阶段 1”。那是在 558K+665K 已经对齐过的数据配比上。

这十行可以当报告互审清单。命中任意一行，把该段改掉再提交。

写改造实验时还要预留对照臂的磁盘。阶段 C 若覆盖了阶段 A 的权重，你就失去了“只训投影时 ViT 哈希不变”这条证据。命名建议：`align-proj-only`、`instr-lora`、`unfreeze-vit-ctrl`，三份互不覆盖。哈希算法与第 01 课的 checkpoint 指纹同一套即可，不必新发明。

若改造 3 把无图文本加到 30% 之后，对齐掉下去，正确动作是把比例降到 10% 再测，而不是把 ViT 解冻来“找回视觉”。解冻眼睛会同时改变两课的变量：本课的冻结集合，以及第 15 课的模态配比所作用的共享层。一次只动一个旋钮，是这两课共同的实验纪律。

**顺手复现映射：**

- LLaVA“跳过投影对齐则 ScienceQA 掉 5.11 分”对应缩小版比较阶段 A 再 B 与直接 B。预期同方向：直接 B 的早期梯度更炸、文本探针更差；若 26M 或更小规模上看不见差异，记“效应小于噪声”。
- BLIP-2“没有表示学习则 OPT 遗忘”对应缩小版比较“随机 $W$ 直接训 LLM”与“先训 $W$ 再训 LoRA”。预期同方向。
- Flamingo“解冻预训练 LM 掉分”对应阶段 B 全量 LLM 对 LoRA。预期全量臂文本探针更差。
- Prismatic“解冻 ViT 伤定位”对应阶段 C。预期对齐不降、细粒度玩具任务降。
- Qwen2.5-VL“后训练冻 ViT、纯文本接近基座”对应阶段 B 结束时的文本探针应接近起点。规模不够时只比方向。

## 14. 论文与必读材料

每篇只带本课需要的问题。结构细节能在第 02 课解决的，不在这里重读一遍。

读的时候在纸上画三列：可训练模块、数据、学习率。缺一列就回去翻原文，不要用二手综述补。

### [LLaVA](https://arxiv.org/abs/2304.08485)

带着问题读：第一阶段冻哪些参数、数据从 595K 图文对扩成什么指令、第二阶段为什么仍冻 ViT。把 ScienceQA 跳过预训练的 85.81% 对 90.92% 抄进笔记，并写明这是原论文设置，不是你的 GPU 结果。再问：158K 指令里三类各做什么，去掉复杂推理会伤哪类回复。表 4 在 COCO 子集上的数据消融（完整 85.1，去掉指令微调 21.5）用来回答“对齐阶段算不算指令微调”。答案：不算。对齐阶段只是把 caption 写成一句描述请求，真正改变回复风格的是第二阶段。

把公式 $(1)$ 的 $W$ 和本课 CPU 实验的 $12\times 8$ 矩阵对上：元素个数公式相同，数值不同。不要把 595K 抄进自己的数据目录假装训过。

### [LLaVA-1.5](https://arxiv.org/abs/2310.03744)

带着问题读：MLP、格式提示、学术 VQA 各自在表 2 的哪一行产生跳变。665K 里 ShareGPT 没有图，却能改善多语言和长回复，作者把它解释成组合能力。问自己：若删掉格式提示，短答数据和对话数据还能不能混。分辨率 336 与后来的 AnyRes-HD 只作记录，实现留给第 08 课。

表 3、表 4 的公开对比用来建立“简单接口加公开数据”的坐标：7B 模型预训练 558K、指令 665K，VQAv2 78.5、GQA 62.0、MME 1510.7。13B 再把 MM-Vet 从 31.1 拉到 36.1。这些分数带星号的表示训练见过该任务图像，读的时候把星号抄下来，避免和零样本混谈。计算成本写在正文：336 分辨率下 8×A100 预训练约 6 小时、指令约 20 小时。本课 CPU 实验的 96 个参数和这 20 小时没有换算关系。

### [BLIP-2](https://arxiv.org/abs/2301.12597)

带着问题读：188M、32 query、129M 图像、两阶段 step 数。图 5 关于“没有表示学习则生成阶段崩”的论述，用自己的话写成冻结协议。对照本课：Q-Former 相当于容量更大的 $W$，两侧塔相当于本课的冻 ViT 与冻 LLM。不要在本课实现 ITC/ITM。

表 2 把不同 LLM 的可训练参数都写在 103M 到 108M 附近，总参数从 3.1B 到 12.1B。问：为什么换更大的 FlanT5，可训练参数几乎不涨？答案就在冻结协议里。再读第 4.1 节末尾：更强的图像编码器或更强的 LLM 都能抬分数，作者据此称 BLIP-2 是通用的“收割单模态进步”的方法。本课把它翻译成：冻结集合选对了，升级眼睛或升级嘴巴才是可替换零件。

### [InstructBLIP](https://arxiv.org/abs/2305.06500)

带着问题读：为什么指令要进 Q-Former；平方根采样在解决什么数据失衡；为何微调时仍冻 LLM 也能在 ScienceQA IMG 到 90.7%。把它和第 02 课“只比结构”的设定分开：这里比的是指令数据和冻结范围。

第 3.4 节指令微调对多任务学习的对照：held-in 分数接近，held-out 只有指令格式明显更好。这和“把数据集 concat 起来就算 joint”的差别，第 15 课从配比角度讲过，本课从冻结角度再记一笔：若不调 LLM，多任务短答会通过视觉软提示抢控制权，所以 InstructBLIP 必须把指令也送进 Q-Former。

### [Flamingo](https://arxiv.org/abs/2204.14198)

带着问题读：gated xattn 的 $\tanh\alpha$ 初值为 0 解决什么初始化问题；表 3 解冻 LM 的掉分；M3W 交错数据如何支撑 32-shot。Perceiver 输出 64 token 这一事实够用，结构公式回第 02 课。

表 1 的 16 项 few-shot 不要逐条抄进本课报告。只取和冻结有关的信息：单套权重、32 个例子、不开梯度，就能在多项上超过用成千上万标注微调的系统。代价写在讨论里：分类仍落后对比模型，in-context 对提示敏感。对本课：few-shot 能用的前提是训练时见过交错，并且 LM 没有在视觉数据上被改到认不出自己的语言先验。

### [Qwen2-VL](https://arxiv.org/abs/2409.12191)

带着问题读：三阶段分别更新谁；为何第一阶段要动 ViT（动态分辨率与 2D-RoPE）；1.4T token 里哪些监督落在文本 token 上。问：若把这套顺序套到冻结 SigLIP2 的 MiniMind-O 上，第一阶段解冻眼睛会伤害什么。动态分辨率的切片实现不要在本课重写。

224×224、patch 14、2×2 合并后约 66 个视觉 token，这个数字用来理解“接口仍是投影，只是 token 数随图变”。M-RoPE 把位置拆成时间、高、宽，本课不实现；只要知道解开 ViT 的动机包括让这套位置编码在变分辨率下成立。

### [Qwen2.5-VL](https://arxiv.org/abs/2502.13923)

带着问题读：4.1T 的三阶段 token 表；SFT/DPO 冻 ViT；纯文本表 4 与 Qwen2.5 基座的对照。把它当作“后段锁眼睛保语言”的证据，不要再开一个动态分辨率实验。

表 2 的 1.5T / 2T / 0.6T 和序列长度 8192 / 8192 / 32768 一起抄。第三阶段加长视频和长文档，同时解开 ViT 与 LLM。后训练又把 ViT 锁上。问：为什么预训练中段要动眼睛、对齐用户之后又锁上？作者的理由是细粒度感知和原生分辨率需要眼睛参与，而对话阶段要保住 Qwen2.5 的语言能力。本课浏览器实验的“过早解冻”对应的是：在还没有足够视觉数据、投影还没稳时就走中段那一招。

### [LLaVA-OneVision](https://arxiv.org/abs/2408.03326)

带着问题读：Stage-1 / 1.5 / 2 的可训练模块和学习率；为何单图先训到很强再混视频。问：任务迁移依赖的是解冻顺序还是视觉 token 的序列形态。视频数字只作记录，本课验收不引用。

表 1 写明 Stage-1 只训投影，学习率 $1\times 10^{-3}$；之后全模型，视觉 $2\times 10^{-6}$，LLM $1\times 10^{-5}$。这是本课 5.7 节学习率表的现场版。AnyRes 把一张图变成很长的 token 串去模拟视频，属于表示策略，归第 08 课和第 09 课，本课只借用它的冻结课程。

### [Molmo](https://arxiv.org/abs/2409.17146)

带着问题读：PixMo-Cap 为什么用口述；为何作者认为可以跳过只训连接器；指向数据怎样把计数变成可检查输出。问：若没有口述这种高密度描述，跳过阶段 1 还是否成立。

712k 图、平均 196 词、1.3M 转写；指向 230 万条。消融写明 PixMo-Cap 从 0 增到 712k，caption F1 和 11 项均分都升。用 GPT-4o 给同一批图写 caption，学术均分可以略高，作者仍坚持不用专有 VLM 蒸馏。对本课：阶段 1 能不能省，取决于你有没有同等密度的描述数据。教学用的 128 条短 caption 不具备这个条件，所以必须保留阶段 1。

### [PaliGemma](https://arxiv.org/abs/2407.07726)

带着问题读：Stage0 用现成 SigLIP 与 Gemma、Stage1 解冻二者、ViT 学习率预热。问：它和 LLaVA 的“冻眼睛”哪一条前提不同（数据量、任务混合、是否以闲聊为目标）。线性连接器与 MLP 在全解冻时分数接近，用来防止本课把 MLP 神化。

Stage1 看 10 亿样本。消融表明完全跳过 Stage1 最差；冻 LM 明显差；重置任一单模态预训练再训会严重掉点。这些句子支持本课两件事：现成单模态权重是资产；接口阶段的数据量决定你能不能解冻眼睛。

### [Prismatic VLMs](https://arxiv.org/abs/2402.07865)

带着问题读：单阶段能否取代投影预热；解冻视觉骨干为何伤 RefCOCO；DINOv2 与语言对比特征拼接补了什么。把它当作本课开关实验在受控公开数据上的独立复现，而不是新架构课。

作者复现 LLaVA-1.5 后做单因素改动。单阶段相对两阶段综合更好且省 20–25% 计算；解冻 ViT 的 p 值为 0.00381，定位任务掉得最明显。读的时候区分“他们的数据已经是 558K+665K 的成熟混合物”和“你手头只有随机投影加几千 caption”。前者可以讨论省掉阶段 1，后者不能。

若时间只够精读三篇：LLaVA、BLIP-2、Qwen2.5-VL。第一篇给标准顺序，第二篇给冻双塔和遗忘曲线，第三篇给“现代系统何时解开眼睛、何时再锁上”。其余篇目用来防止你把标准顺序说成唯一真理。

读完应能一句话回答本课标题里的顺序：从现成对比视觉塔出发，先让 $W$ 把 $Z_v$ 送进词嵌入维，再让语言模型学会在视觉条件下说话，最后才讨论要不要动眼睛。少第一段，归因会糊；过早动眼睛，旧文本探针会先响。下一课不改这张冻结表，只检查模型看没看对地方。若你已经在 MiniMind-O 上训过视觉指令，回去打开那次 run 的冻结表：SigLIP2 若一直冻着，你其实已经走过本课阶段 1 的眼睛设定，缺的只是把投影和对齐阶段单独记账。把那次 run 补上文本探针，往往比重新训一个 7B 更有用。

课程到这里停在配方，不停在“模型变聪明了”这种无法验收的句子。配方卡、参数账、梯度 mask、三项指标，四件东西齐了，第 22 课才算结束。下一课的指代和 OCR 探针会默认你已经有一张不撒谎的冻结表；表若撒谎，位置探针再准也定位不到失败模块。把表做实，是你现在唯一必须完成的工程。

附录式备忘：CPU 实验里阶段 1、2、3 的可训练数是 96、144、272；全解冻（含 LoRA 与基座 LLM）是 560，这个 560 只出现在 metrics 里供对照，不是推荐配方。浏览器失败臂是“解冻 ViT + 训投影 + 训 LLM”。预测题的正确项是旧文本能力。三件事能在不开网页的情况下默写出来，本课的核心协议就算进了长期记忆。数字可以忘，协议不能忘。

若要把本课当作第 24 课 VLA 的前置：动作 token 进词表之后，冻结纪律仍然适用。先让视觉投影稳定，再把动作监督打开，否则关节编号会去改写已经对齐好的图文方向。第 24 课会单独写动作分箱；本课只需把“新模态先对齐接口”这条纪律交出去。GUI 点击同样如此：屏幕是另一双眼睛，不是另一套可以随便解冻的 LLM。

最后核对一次公开数字的出处，避免口口相传。LLaVA 595K / 158K / 90.92% / 85.81% / 85.1 来自 2304.08485。LLaVA-1.5 的 558K / 665K、MME 809.6 到 1510.7、8×A100 约 6 小时加 20 小时来自 2310.03744。BLIP-2 的 188M、32 query、129M 图、VQAv2 65.0、54 倍来自 2301.12597。Flamingo 10.2B / 80B、冻结消融 70.7 / 57.8 / 62.7 来自 2204.14198。Qwen2-VL 的 1.4T 与三阶段来自 2409.12191。Qwen2.5-VL 的 4.1T、MATH 83.0 来自 2502.13923。InstructBLIP 平方根采样与 ScienceQA 90.7% 来自 2305.06500。PaliGemma 10 亿样本 Stage1 来自 2407.07726。Molmo 712k 图、196 词来自 2409.17146。Prismatic 单阶段与解冻 ViT 有害来自 2402.07865。数字只能指回这些篇目的表或段落；技术报告没写的细节继续写“未公开”。写作业时把出处表贴在报告最后一页，审阅者按表号回查，不必翻你的聊天记录。没有出处的数字一律删掉，宁可少写，也不要为了篇幅去编成功率或卡时。本课的增量必须来自机制、公式、协议和文献，注水的形容词帮不上忙。若汉字统计仍然不够，优先补实验协议里的失败判定，不要补排比句。失败判定写得越具体，以后的第 24 课动作实验越能沿用同一套记录格式：先写开关，再写探针，最后才写分数。这是整条视觉地基课共用的实验文法。视觉地基三课的分工可以记成：第 21 课解决眼睛从哪来，第 22 课解决眼睛怎么接到嘴上、先动哪一块，第 23 课解决接上之后有没有看对地方。三课都做完，才有资格谈动作和屏幕。现在先把第 22 课的冻结表交出来。表上至少要有三行阶段、一列可训练模块、一列学习率、一列旧文本探针。缺列的表和下周的动作课对不上账，等于没交。补齐这四列，本课的汉字和工程都够了。交表之前再跑一遍 CPU 检查，确认 96、144、272 三个数还在，确认浏览器失败臂还能被你亲手拨出来。两件事都过，第 22 课才算关上。LLaVA 在 ScienceQA 上还试过用 CLIP 最后一层特征，比用最后一层之前低 0.96 个百分点；作者猜测最后一层更偏全局。冻结眼睛时，“取哪一层”仍是可调旋钮，只是本课不把它放进主开关，以免和解冻顺序抢归因。若要扫层号，单独开实验，冻结表保持阶段 1 不变，只改特征取出位置，这样归因才干净。层号扫描的预期是：靠前的层更局部，对 OCR 和计数可能更好，最后一层更抽象。失败判定是各层分数差不超过探针噪声，那就维持 LLaVA 的默认取法。
