# 第 38 课：给 VLA 接上可验证强化学习

> 内容：把抓取成功、接触与力超限写成可验证奖励，接到第 17 课的组内相对优势<br>
> 建议周期：阅读约 75 分钟；CPU 实验数分钟<br>
> 硬件：无 GPU 可读完全文并跑 CPU 机制实验；复现 ConRFT 真机或 SimpleVLA-RL 论文规模需要机械臂或并行仿真<br>
> 产物：稀疏成功与接触 dense 的组内优势表、零方差对照、文献数字表

## 1. 模仿学不会的试错怎样变成可验证奖励

第 27 课和第 28 课已经能让视觉语言模型吐出动作：要么是词表里的动作编号，要么是一段连续动作块。训练信号来自示教。示教几乎全是成功轨迹。人遥操作把杯子放进盒子，日志里记下图像、指令和关节。模型拟合这些状态—动作对。杯子打翻、夹爪提前闭合、末端在杯口上方悬停、插入时把轮毂卡死，这些状态很少被写进教材。模仿学不会它们，因为教材里根本没有“错了之后该怎么改”这一列。

第 17 课已经给文本和多模态题准备过一套可验证强化学习（RLVR：Reinforcement Learning with Verifiable Rewards，用确定性程序打分，而不是再用一个神经网络当阅卷老师）。同一道题采 $G$ 条回答，组内比平均分，高的提高概率，低的降低概率。组内相对优势写成

$$
\hat A_i=r_i-\bar r,\qquad \bar r=\frac{1}{G}\sum_{j=1}^{G}r_j
$$

第 17 课还用标准差再除一次，得到 $A_i=(r_i-\bar r)/(s_r+\varepsilon)$。两种写法在“全组同分”时结果一样：方差为零，优势为零，政策不更新。本课不重推概率比、clip 和 KL。那些公式原样留在[第 17 课](17_grpo_rlvr.md)。本课只改 $r_i$ 的定义：从“答案是否等于 37.5”改成“这次抓取算不算成功、接触好不好、力有没有超限”。

要改的模块是奖励程序，不是再训一个动作骨干。验证改对了的标准有两条，都必须能在教学夹具里复现：同一组四条都没放入的轨迹，稀疏成功的 $\hat A_i$ 全是 0；接触 dense 仍能排出擦边优于空抓，并且给出非零更新。CPU 实验再核对：零方差组的标量权重不变；dense 在失败轨迹上的排序固定为擦边、压溃、悬停、空抓。

把这句话说死之后，还要能指出它不覆盖什么。它不覆盖第 17 课已经写过的 verifier 攻击测试和 hidden case。它不覆盖第 31 课的套件拆桶和 Wilson 区间；LIBERO 上涨了几个点，不能写成真机能力。它不覆盖第 40 课规格里的力切断与 SAFE_HOLD：本课的力只作为奖励项，超限后物理状态不可回放那件事留给后面。它覆盖的只有：一组 rollout、两种可执行的 $r$，以及组均值减完之后还有没有梯度。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 示教 / 行为克隆 | 只拟合成功轨迹里的状态—动作对，失败不在训练集里 |
| 可验证奖励 | 由确定性程序打分：成功谓词、接触带、力阈值、或世界模型相对参考帧的误差 |
| 稀疏成功 | $r\in\{0,1\}$，通常只在回合结束时看物体是否离桌并进目标 |
| 接触 dense | 用接近距离、夹爪闭合、力超限等中间量给尚未成功的轨迹打不同分 |
| 组内优势 | $\hat A_i=r_i-\bar r$，只比较同组，不训练单独的价值网络 |
| 零方差组 | 组内奖励全相同，优势为零，采样算力不产生更新 |
| RFT | 强化微调：在已经 SFT 过的 VLA 上再用奖励更新，而不是从零做强化学习 |
| 一致性政策 | ConRFT 里用 consistency 当动作头，一次映射噪声动作到示教动作 |
| 世界模型 RFT | 用学出来的动力学模拟器滚出未来帧，再拿与参考的误差当 verified reward |
| 代价 / 约束 | SafeVLA 把碰撞、碰碎等写成 $c_i$，在 CMDP 里限制累计代价，而不是只加进奖励 |

第 24 课解释过动作怎样进入模型，见[第 24 课](24_vlm_to_vla.md)。第 30 课处理过执行窗口和重规划，本课不改控制频率。第 16 课的偏好对是预先印好的，见[第 16 课](16_multimodal_preference_optimization.md)；本课的比较对象是当前政策自己滚出来的轨迹。第 25 课比较过离散分箱和连续回归，本课两边都可能接到同一套 $r$：token 政策用 log-prob 乘 $\hat A$，flow 政策要么像 VLA-RFT 那样改出密度，要么先用 $r$ 做可排序诊断、优化器另选。不要因为动作头不同就认为奖励定义也必须不同。奖励是轨迹上的标量，头只决定这个标量怎样变成梯度。

## 2. 本课解决的问题

模仿学习的失败模式很具体。政策在示教分布上把杯子放进盒子，换一个初始位姿或换一只没见过的杯子，末端走到杯口附近就停住，或者提前闭合。评测脚本只报“成功 / 失败”。四条轨迹都是失败时，若奖励也是四个 0，组内相对优势全是 0。你付了仿真或真机的交互账单，梯度是一张零纸。

本课要同时回答三个卡住的问题。

第一，失败怎样变成可验证的数。成功可以写成谓词：物体离桌、进入盒子、在盒子里保持若干步。第 31 课已经要求接触、放置、保持分开，见[第 31 课](31_vla_evaluation.md)。训练时若只用放置成功，早期几乎全是 0。接触距离、夹爪是否在接触带内闭合、力是否超过安全阈，这些量仿真器或力传感器可以给出，程序可以打分。分是程序算的，不是另一个网络估的，才叫接到 RLVR。

第二，同一套组内优势在机器人上会不会哑火。第 17 课的预检要求起点模型的 pass@8 既非全 0 也非全 1。机器人这边对应的是：SFT 之后至少偶尔能采到成功，或者 dense 奖励在失败之间仍有方差。SimpleVLA-RL（arXiv:2509.09674）把全成功和全失败组直接丢掉，因为 GRPO 的组相对归一化在同分时梯度为零。VLA-RFT（arXiv:2510.00406）用世界模型生成的帧与参考帧比 L1 和 LPIPS，失败轨迹也会得到不同的负分。两条路都在回答同一句话：不要让一组 $r$ 变成常向量。

第三，公开的 VLA 强化微调各自改了哪一段，不要把名字兑成同一种方法。ConRFT（arXiv:2502.05450）是离线 BC+Q，再在线用同一套 consistency 目标加人工介入。iRe-VLA（arXiv:2501.16664）在强化学习阶段冻结视觉语言模型，只训动作头，再用成功轨迹做监督，防止大模型塌缩。SimpleVLA-RL 把结果 0/1 接到 GRPO，去掉 KL。VLA-RFT 把世界模型当模拟器。SafeVLA（arXiv:2503.03480）把安全谓词写成代价，用拉格朗日约束。GRAPE（arXiv:2411.19309）用轨迹级偏好，不是 on-policy 的组相对。Liu 等人（arXiv:2505.19789）在抓放任务上发现 PPO 比他们实现的 GRPO / DPO 稳。这些句子都来自已打开的原文。本课用它们当对照，不宣布其中某一个是唯一正确算法。

用一条 8 秒的抓取把三个问题钉在时间轴上。$t=0$ 相机看见杯子。$t=2\,\mathrm{s}$ 四条轨迹已经分开：空抓在桌面左侧，悬停在杯口上方 5 cm，擦边碰到杯沿，压溃把力顶到安全阈以上。$t=8\,\mathrm{s}$ 稀疏谓词结算：四个都是 0。若此刻才给 $r$，组内没有对比。若在 $t=2\,\mathrm{s}$ 已经按 $c$ 和 $F$ 给过 dense，擦边已经是组内最高，政策会提高“再近一点、力再小一点”的那些动作步。时间轴说明：稀疏不是错，它结算太晚、太粗。dense 把结算提前到接触发生的那些步。Lab 把整条轨迹收成一个标量，是为了能手算；真训练可以把 dense 逐步发给对应的动作，稀疏仍在回合结束给一次。两种时间分辨率可以共存，必须在 `reward_spec` 里写清广播规则：轨迹级标量广播到每一步，还是逐步 $r_t$ 再求和。SimpleVLA-RL 选前者。本课夹具也选前者。逐步 $r_t$ 会改变 $\hat A$ 的时间落点，不在最低交付里。

失败条件预先写死：

- 重推一遍 GRPO 的 clip，却写不出 $r$ 在抓取上怎么定义；
- 把训练奖励上涨写成任务能力上涨，却没有隐藏谓词或人工审计；
- 全失败组上只报了稀疏成功，却声称“已经在用强化学习从试错里学”；
- 把 Lab 里的 $\Sigma|\hat A|$ 写成 ConRFT 的 96.3% 或 LIBERO 的 91.7%；
- 把 SafeVLA 的累计代价下降抄成“成功率提高了 83.58%”。

## 3. 开始前需要准备什么

本课不依赖 MiniMind-O 的训练脚本。需要的是第 17 课的组内优势直觉，以及第 27 课或第 28 课对动作接口的意识：你得知道政策吐出的是离散 token 还是连续块，因为 log-prob 和 flow 的似然不是同一条实现。没有读过那两课也可以往下走，但遇到“GRPO 要动作分布”或“flow 头没有现成 log $p$”时，要回到那两课，而不是在本课里重做词表或速度场。

开始前把笔记本分成两栏。左栏只抄打开过的论文句：表号、成功率、训练分钟、示教条数、奖励定义。右栏写本课约定：组大小 $G=4$、$\hat A_i=r_i-\bar r$、稀疏 $r\in\{0,1\}$、dense 的四个系数 $0.35/0.25/0.40/0.30$、接触带默认 $0.03$、力安全阈默认 $0.45$。左栏数字可以对外引用，右栏数字只能当教学夹具。有人把 Lab 里擦边轨迹的 $0.473$ 写成“复现了 ConRFT 的接触奖励”，属于把右栏抄进左栏。

硬件上，读完加 CPU 实验不需要 GPU。若要跑 SimpleVLA-RL 或 OpenVLA-OFT 的公开设置，再准备能放下 7B 级 VLA 并且能并行仿真的机器。没有这套设备，跳过可选的仿真 Step 仍可完成最低交付。软件上只需要 Python 3.10 标准库和能打开本课页面的浏览器。不要为了本课新装仿真器或力传感器驱动。接触和力在课文与夹具里是标量字段，不是真机读数。

**上游事实（打开原文核对过）：**

- ConRFT：Chen 等，arXiv:2502.05450v2，项目页 [cccedric.github.io/conrft](https://cccedric.github.io/conrft/)；Octo-small + consistency 头，Franka 7 自由度，10 Hz，离线 20–30 条示教，在线 45–90 分钟，八项任务平均成功率 96.3%；
- iRe-VLA：Guo 等，arXiv:2501.16664v1；BLIP-2 3B 加动作头，强化学习阶段冻结 VLM；真机把茄子或胡萝卜的抓取从 0.35 升到 0.80；
- SimpleVLA-RL：Li 等，arXiv:2509.09674v1，代码 [PRIME-RL/SimpleVLA-RL](https://github.com/PRIME-RL/SimpleVLA-RL)；结果奖励 0/1，GRPO，去掉 KL；OpenVLA-OFT 在 LIBERO 四套件平均从 91.0% 到 99.1%，每任务 1 条示教时 Long 从 17.3% 到 91.7%；
- VLA-RFT：Li 等，arXiv:2510.00406v1，项目页 [vla-rft.github.io](https://vla-rft.github.io/)；世界模型 138M，约 400 步把 LIBERO 平均从 86.6% 升到 91.1%；
- SafeVLA：Zhang 等，arXiv:2503.03480v4，项目页 [pku-safevla.github.io](https://pku-safevla.github.io)；相对 FLaRe 累计代价下降 83.58%，成功率 +3.85%；
- GRAPE：Zhang 等，arXiv:2411.19309v2；相对同数据 SFT，域内 / 未见成功率相对提高 51.79% / 58.20%，碰撞率下降 37.44%，步数下降 11.15%；
- FLaRe：Hu 等，arXiv:2409.16578v2；摘要写未见环境平均成功率 79.5%，相对此前方法仿真 +23.6 个点、真机 +30.7 个点，奖励是稀疏的；
- Liu 等：arXiv:2505.19789v4，项目页 [rlvla.github.io](https://rlvla.github.io)；抓放上 PPO 优于他们实现的 GRPO 与 DPO；稀疏奖励为抓住 0.1、放下 1.0。

**课程约定：**

- 浏览器里的俯视抓取是教学模拟，分数由接触公式算出来，不是 ConRFT 或 OpenVLA 的前向输出；
- CPU 实验只证明公式可复核，不证明 LIBERO 或真机成功率；
- 优势默认减均值。需要和第 17 课对表时，再算一遍除以标准差的形式；两种形式在零方差组都应当接近 0。

若只想核对公式，准备 Python 3.10 和本仓库 `experiments/` 即可。CPU 实验不读网、不写文件、不用 NumPy，跑完只在内存里留下一个字典。不要为了“看起来更像训练”去加随机噪声；本课要的是可复核，不是随机搜索。夹具里的四条轨迹坐标是写死的，和随机种子无关。谁若给 `clearance` 加噪声再报“平均优势”，就已经离开本课的验收，进入第 31 课的区间问题。那是另一张表。

## 4. 完成后应具备的能力

1. 写出稀疏成功 $r=\mathbf{1}[\text{lifted}\land\text{in\_bin}]$，并指出四个失败样本上 $\bar r=0$、$\hat A_i=0$。
2. 写出本课接触 dense 的四个项，说明力超限为什么会把“更近”的压溃排到擦边后面。
3. 不看第 17 课正文，仍能说明：clip 和概率比不变，变的只是 $r$；零方差组在减均值和除标准差两种写法下都不更新。
4. 按原文区分 ConRFT（离线 Cal-QL+BC，在线 HIL-ConRFT）、iRe-VLA（冻 VLM 再监督）、SimpleVLA-RL（0/1 GRPO）、VLA-RFT（世界模型 verified reward）、SafeVLA（代价约束）、GRAPE（轨迹偏好）。
5. 设计一个夹具：失败批次上稀疏 $\Sigma|\hat A|=0$，dense $\Sigma|\hat A|>0$；用户必须先预测再看数字。
6. 看到“接上强化学习后成功率到 96%”时，能追问奖励是分类器、0/1、接触、世界模型误差还是安全代价，以及评测 $N$ 是 20 次还是 500 次。
7. 能把一组日志里的 $r$ 向量手算成 $\hat A$，并判断这一步该不该改权重。
8. 能指出动态采样、提高温度、放宽 clip 上界都不创造新的奖励信息，只是在 $r$ 已经有方差时让组里更容易出现对比。

第 4 节的八条里，前三条是公式，中间两条是文献接口，后三条是实验纪律。缺公式，Lab 里的数字会对不上手算。缺文献接口，会把 96.3% 和 91.7% 写进同一格。缺实验纪律，会先看揭晓再选预测。三条缺一，本课都不算完成。

读完第 4 节，可以用下面这段自检，不通过就先别进公式。桌上有一只杯子。四次尝试：夹空、悬在杯口、擦到杯沿但没提起、用力把杯子挤歪。你应能指出：稀疏成功给四个 0；若奖励看接触，擦边应当高于夹空；若奖励再罚力，压溃可能低于轻轻擦边。若你只能写出“都该罚”，还没有把失败变成可排序的数。若你写出了 Q 网络和 GAE 的展开，却说不清 $r$ 从哪个传感器字段来，本课的对象写错了。这段自检不计入 CPU 实验，但能避免后面把更新写在错误的标量上。

## 5. 原理：边造边讲

机制按同一节奏：为什么需要、怎么运转、精确定义、公开实现落在哪、怎么证明做对了。本课没有 MiniMind 源码，代码落点写在各小节末尾的公开仓库与数据字段里。GRPO 的概率比与 clip 只引用第 17 课，不在这里再推一遍。

### 5.1 示教分布盖不住失败

行为克隆最小化的是示教动作和预测动作之间的距离。示教来自人，人通常把任务做完。失败要么被丢掉，要么根本没采。政策在测试时一旦偏离示教，看到的图像就不在训练集里。下一步仍按“示教里最像的那一帧”出动作，误差会沿时间累加。Ross 和 Bagnell 把这件事写成模仿学习的视野问题；VLA 论文把它写成 compounding error。本课不把那篇 2010 年的统计论文展开，只留下工程后果：只拟合成功，就没有“失败附近该往回修”的监督。

类比：只看满分卷的学生，不知道 40 分的卷子错在哪一题。类比失效处：机器人的“错题”会改变物理状态。写错一个分数还可以在下一题补；夹碎杯子之后，后面的观察不再是“还没抓”，而是一摊碎片。所以失败轨迹不是另一道填空题，是环境已经被改写的后继状态。奖励程序必须能在这些后继状态上给分，否则强化学习只是在成功附近打转。

ConRFT 把这个问题写在摘要和引言：监督微调依赖有限且不一致的示教，接触丰富的任务上尤其脆弱。他们的离线 SFT 基线在八项真机任务上平均成功率 39.4%，Cal-ConRFT 同样是 39.4%。只加示教条数也不够。他们用 150 条人遥操作去训 Diffusion Policy 和 SFT，Insert Wheel 仍明显低于后来的 HIL-ConRFT（表 III：DP 35%、SFT 40%、HIL-ConRFT 80%）。SimpleVLA-RL 把数据稀缺推到极限：每个 LIBERO 套件只用 10 条示教（每任务 1 条）做 SFT，Long 只有 17.3%；再上结果奖励的 GRPO，Long 到 91.7%（表 5）。iRe-VLA 的真机图 6：SFT 在未见物体上只有 0.35，在线交互之后到 0.80。三条证据指向同一处：示教不够覆盖失败，试错必须自己变成数字。

验证：列出一条成功示教和四条失败 rollout 的字段。成功行有 `lifted=1, in_bin=1`。失败行这两列都是 0，但 `clearance` 和 `force` 不同。谁若在表里只留“success”一列，后面的组内优势必然哑火。

### 5.2 只改奖励，组内结构不动

第 17 课已经固定了一次更新的时间线：出题、采 $G$ 条、打分、算相对优势、更新、同步旧政策。机器人把“出题”换成同一条语言指令加同一组初始状态，把“回答”换成一条轨迹 $\tau=(s_0,a_0,\ldots,s_H)$。打分函数变成 $r(\tau)$。组均值仍然是基准线。本课指定的教学形式是减均值：

$$
\bar r=\frac{1}{G}\sum_{j=1}^{G}r_j,\qquad \hat A_i=r_i-\bar r
$$

第 17 课的标准化形式保留作对照：

$$
s_r=\sqrt{\frac{1}{G}\sum_{j=1}^{G}(r_j-\bar r)^2},\qquad A_i=\frac{r_i-\bar r}{s_r+\varepsilon}
$$

$s_r=0$ 时，无论 $\varepsilon$ 多小，$A_i$ 都接近 0。SimpleVLA-RL 公式 (8) 用的是带标准差的那一版，并写明 $R_i$ 是整条轨迹的总分。VLA-RFT 公式 (12) 用组均值作基线：$\mathrm{Adv}_n=R_n-\bar R_{\mathrm{group}}$，与本课 $\hat A_i$ 同形。两篇都没有改 clip 的含义。需要概率比时，回到第 17 课的

$$
\rho_{i,t}(\theta)=\frac{\pi_\theta(a_{i,t}\mid s_{i,t})}{\pi_{\theta_{\mathrm{old}}}(a_{i,t}\mid s_{i,t})}
$$

本课不把这条再展开成 token 级形状讨论。连续动作块若没有现成的离散分布，VLA-RFT 把 flow matching 改成带 Sigma 网络的 SDE，用积分步上的高斯密度近似 $\log p$。那是实现细节，不是新的优势定义。

$\hat A_i$ 是轨迹级标量。更新时广播到该轨迹里参与政策损失的动作步，padding 和观察 token 不参与。这一点和第 17 课把回答级优势广播到生成 token 相同。差别只在：机器人的“token”可能是 7 个动作维，也可能是一个 chunk。

手算与第 17 课对齐。取 $r=(0,0,1,1)$，忽略 $\varepsilon$：$\bar r=0.5$，减均值得到 $(-0.5,-0.5,0.5,0.5)$；再除 $s_r=0.5$ 得到 $(-1,-1,1,1)$。再取 $r=(0,0,0,0)$：两种写法都得到全 0。CPU 实验把这两行都锁住。

公开实现落点：DeepSeekMath 的 GRPO 原文（第 17 课已引，arXiv:2402.03300）以及 SimpleVLA-RL §2.3。本课夹具对应 `mean_advantages` 与 `standardized_advantages` 两行。

### 5.3 稀疏成功：最干净，也最容易全零

最干净的可验证奖励是任务完成指示：

$$
r_{\mathrm{sparse}}(\tau)=\mathbf{1}\bigl[\mathrm{lifted}(\tau)\land\mathrm{in\_bin}(\tau)\bigr]
$$

仿真器里，`lifted` 可以是物体高度超过桌面加容差，`in_bin` 可以是物体中心落入盒子的水平半径。真机上 ConRFT 先用人给出的正负示范训一个二分类器，分类器输出“任务是否完成”。iRe-VLA 正文写明本文考虑二元奖励：成功 1，否则 0。SimpleVLA-RL §3.2 把整条轨迹标成 0 或 1，再把这个标量广播到轨迹里的每个动作 token。FLaRe 摘要强调只用稀疏奖励。Liu 等稍密一点：抓住并持续握住给 0.1，放下成功给 1.0，仍然没有接触力。这 0.1 已经能把“抓住但没放下”和“根本没碰到”分开，是一种极瘦的过程奖励。本课 dense 比它更密：没抓住时还看 $c$。若一组四条都没抓住，Liu 等的奖励仍是四个 0，和纯稀疏同一张零纸；本课 dense 在这一组上仍有排序。读论文时不要把 0.1 当成已经解决了零方差。它只解决“抓住了但没放下”这一层。零方差发生在更早：连抓都还没有。

稀疏的好处是规格短、跨任务可复用、不容易在过程里掺进“看起来像对”。坏处是方差。记一组 $G$ 条轨迹的成功数为 $k$。$k=0$ 或 $k=G$ 时，$s_r=0$。早期政策几乎全失败，晚期政策几乎全成功，两个阶段都会出现零方差组。SimpleVLA-RL §3.3 把这类组丢掉，直到一个 batch 里每组都是有成功有失败，写成

$$
0<\bigl|\{\tau_i:\mathrm{success}(\tau_i)\}\bigr|<G
$$

这叫动态采样。它不创造新的奖励信息，只拒绝没有对比的组。代价是：若政策暂时一次都成功不了，采样会空转。他们在 RoboTwin2.0 上做了对照（表 7）：0 条示教的 SFT 成功率是 0，再加结果奖励的 RL 仍是 0；100 条示教把平均从 7.3% 做到 25.4%；1000 条从 28.2% 做到 50.4%。结论写在原文里：基座政策若采不出成功，纯结果奖励帮不上忙。

稀疏还有第二种哑火：分类器被钻空。ConRFT §VI-A 写，分类器的训练分布和强化学习探索的状态分布会偏，政策可能停在“分类器误报为成功”的末端位姿上。这和第 17 课的奖励投机同构，只是漏洞从 JSON 解析换成了视觉分类器的假阳性。修法也同构：分类器版本、阈值、正负示范的 hash 要进账本；另留一套程序谓词或人工抽查，不能只看分类器分上涨。

验证：四个失败样本的 $r_{\mathrm{sparse}}$ 必须全是 0。再把第四个改成放入成功，得到 $(0,0,0,1)$，$\bar r=0.25$，$\hat A=(-0.25,-0.25,-0.25,0.75)$。CPU 实验的 `混入成功后稀疏才能分出正负` 锁这一行。

### 5.4 接触 dense：失败之间仍要能排序

还没放入时，轨迹并不是同一个失败。空抓的末端离杯子 18 cm，悬停离 5.5 cm，擦边已经碰到杯沿，压溃把力加到安全阈以上。本课把这些中间量写成一个有上界的标量：

$$
\begin{aligned}
r_{\mathrm{dense}}
&=
\operatorname{clip}\bigl(
0.35\,e^{-c/\tau}
+0.25\,\mathbf{1}[g=1\land c\le b]
+0.40\,\mathbf{1}[\mathrm{lifted}]
-0.30\,[F-F_{\mathrm{safe}}]_+
,\,0,\,1\bigr)
\end{aligned}
$$

$c$ 是末端到接触带的距离，$g$ 是夹爪闭合，$b$ 是接触带宽度，$\tau$ 是接近尺度，$F$ 是力或力矩范数。方括号加号表示 $\max(0,\cdot)$。四个系数是教学约定，不是任何一篇论文的超参。它们的作用是：接近给失败轨迹一条光滑的坡；接触带奖励“碰到了”；抬起接近稀疏成功；力超限把“更近但更危险”往下按。

默认数 $c\in\{0.18,0.055,0.018,0.006\}$，$g=(0,0,1,1)$，$F=(0,0.02,0.22,1.35)$，$\tau=0.04$，$b=0.03$，$F_{\mathrm{safe}}=0.45$，算得大约

$$
r_{\mathrm{dense}}\approx(0.004,\,0.088,\,0.473,\,0.281)
$$

排序是擦边、压溃、悬停、空抓。压溃比擦边更近，但力罚 $0.30\times 0.90=0.27$，把它压到第二。组均值约 $0.212$，优势约 $(-0.208,-0.123,0.261,0.070)$。$\Sigma|\hat A|\approx 0.662$，不是 0。同一组的稀疏奖励是四个 0，$\Sigma|\hat A|=0$。这就是交互实验要先预测再揭晓的那一对数字。

dense 仍然必须是程序。$c$、$g$、$F$ 来自仿真器或校准过的传感器，阈值写进配置文件，重复计算逐字节一致。一旦改成“让另一个网络估接触好不好”，就回到第 17 课反对过的可讨好曲面。GRAPE 的外部奖励是另一条可执行路：用视觉语言模型拆阶段、用关键点写代价，再聚合成 $R_{\mathrm{ext}}=\prod_i e^{-C^{S_i}}$。它比本课四个项复杂，但本质仍是程序加阈值，不是端到端的奖励模型。VLA-RFT 的 dense 是像素级的：

$$
R=-\sum_{t}\bigl[\lambda_1 L_1(\hat o_{t},o_{t})+\lambda_{\mathrm{lp}}\operatorname{LPIPS}(\hat o_{t},o_{t})\bigr]
$$

$\hat o$ 是世界模型按政策动作生成的帧，$o$ 是参考。原文表 4 比较了三种 verified reward：只比动作 L1（类型 1）平均成功率 87.7%；生成帧直接比真实图像（类型 2）87.1%；政策和数据动作都在同一世界模型里生成再比（类型 3）91.1%，相对 15 万步 SFT 基线 86.6% 高 4.5 个点。他们选择类型 3，因为生成质量偏差被同一模拟器抵消。本课按原文写这条消融，不把 LPIPS 展开成感知损失论文。

dense 的投机面也要写清。若只奖励接近，政策可以在杯口震荡，永远不闭合。若只奖励接触，政策可以轻轻碰一下杯子就停。若力罚太弱，政策会学会挤。所以四项要一起出现，并且评测时仍用第 31 课的放置 / 保持谓词，而不是用训练 dense 当最终能力。训练信号和验收谓词可以不同，必须事先写在 recipe 里。

验证：失败组 dense 的四个值互不相同，最大值来自擦边，最小值来自空抓。把 $F_{\mathrm{safe}}$ 抬到 1.4，压溃的力罚消失，排序应变。Lab 的力滑条就是这条探针。CPU 实验锁默认阈值下的排序 `C, D, B, A`。

### 5.5 零方差组：采样账单与更新账单要分开

一次强化学习迭代的成本主要在滚轨迹，不在算 $\hat A$。零方差组把前者花完，后者写成 0。记更新幅度为

$$
\Delta w_i=\eta\,\hat A_i\,\phi_i
$$

教学夹具取 $\eta=0.1$、$\phi_i=1$、$w=1$。稀疏失败组四个 $\Delta w$ 都是 0，权重仍是 1。dense 失败组四个权重变成约 $0.979$、$0.988$、$1.026$、$1.007$。这不是真的梯度下降实现，只用来证明“优势为零则参数不动”。

全成功组同样零方差。四个 $r=1$，$\hat A=0$。政策已经每次都放入，结果奖励不再告诉它谁更快、谁力更小。ConRFT 用回合长度当另一张表：HIL-ConRFT 平均 30.7 步，离线基线 59.9 步，缩短 1.9 倍（表 I）。若奖励里没有时间或步数项，GRPO 不会主动缩短回合。想优化“更快”，必须把步数或折扣回报写进 $r$，不能指望 0/1 自己长出效率。

动态采样、提高温度、放宽 clip 上界，是 SimpleVLA-RL 为了让组里重新出现差异做的三件事。他们把 clip 从 $[0.8,1.2]$ 改到 $[0.8,1.28]$，温度从 1.0 改到 1.6，并报告这三项各自抬高了学习曲线（图 4）。本课不把这三项当成必须复现的超参，只保留它们的因果：差异不够时，先检查 $r$ 是不是常向量，再检查采样是不是把所有组滤光了。

验证：CPU 实验同时断言稀疏失败组、全成功组和标准化零方差组的优势都接近 0，以及 dense 失败组 `hasNonzeroUpdate`。缺任何一条，都不能说“零方差”已经讲完。

把广播再写成能手算的一步，避免只记住“优势是标量”。设一条轨迹有 $H=4$ 个有效动作步，优势 $\hat A=0.261$，每步虚构的政策梯度特征 $\phi_t=1$。四步各得到更新 $\eta\hat A$，总和 $4\eta\hat A$。若同一组另一条轨迹 $\hat A=0$，四步更新全是 0，哪怕这条轨迹更长。长度本身不产生优势。谁若按“更长的失败应该多罚”来实现，那是另外一项写进 $r$ 的步数罚，不是组相对自动长出来的。ConRFT 要更短的回合，靠的是折扣回报和任务奖励的时间结构，不是 $\hat A$ 对长度敏感。

离散动作 token 和连续 chunk 在这一步的差别，只影响 $\rho_{i,t}$ 怎么算，不影响 $\hat A_i$ 是不是零。第 27 课的 7 个 bin 有现成的 softmax，log-prob 是类别分布上的。第 28 课的 flow matching 默认是常微分方程，本来没有逐步密度；VLA-RFT 才加了 Sigma 网络，把积分步改成高斯，凑出平均 $\log p$。你若用官方 OpenVLA-OFT 的 L1 头直接套 GRPO，会缺 $\pi(a|s)$。SimpleVLA-RL 改回头部分类，就是为了把第 17 课的 $\rho$ 接回去。本课夹具不实现 $\rho$，只实现 $r$ 和 $\hat A$。缺 log-prob 的模型，仍可先用接触 dense 做可排序的诊断，再决定要不要换头。

### 5.6 ConRFT：离线 BC+Q，在线同一套目标

ConRFT 的对象是已经预训练好的 VLA，论文主实验用 Octo-small，动作头换成 consistency policy。consistency 把高斯噪声动作一步映射到条件动作，推理比扩散头轻。离线阶段叫 Cal-ConRFT。批评家用 Cal-QL：时序差分误差之外，对策略动作的 $Q$ 相对行为价值 $V^\mu$ 做保守惩罚，减轻离群动作把 $Q$ 抬爆。政策损失是

$$
\mathcal L_\pi^{\mathrm{offline}}=\beta\mathcal L_\pi^{\mathrm{BC}}+\eta\mathcal L_\pi^{Q}
$$

BC 项把 consistency 头的输出拉向示教动作，Q 项让政策去打高 $Q$ 的动作。只有 Cal-QL、没有 BC 时，20–30 条示教不够，论文写成功率在所有任务上为 0%。只有 SFT、没有 Q，离线成功率可以和 Cal-ConRFT 接近，但在线阶段早期遗忘更重、介入率更高（图 4）。

在线阶段叫 HIL-ConRFT。示教缓冲 $\mathcal D$ 保留，再加回放缓冲 $\mathcal R$，按对称采样各抽一半。批评家改成普通贝尔曼误差。政策损失与离线同形，通常减小 $\beta$、增大 $\eta$，但 BC 项不删，用来挡住接触任务里的突然偏离。人通过 SpaceMouse 介入，接管后的动作写回 $\mathcal D$。介入既是安全阀，也是高价值数据。论文明确警告：曲线里的成功率在存在介入时可能偏高，因为人会把轨迹救成功。

八项真机任务，每项评 20 次。HIL-ConRFT 平均成功率 96.3%，相对对应的离线基线提高 144%；HG-DAgger 65%，PA-RL 71.3%（表 I）。从零训的 HIL-SERL 同期只有 31.9%（表 II）。训练墙钟 15 到 90 分钟不等，平均约 48.8 分钟，设备写的是一块 NVIDIA RTX A6000。观察是腕部 128×128、侧视 256×256，加末端位姿、旋量、力/力矩和夹爪。动作是 6 维末端增量，需要夹取时再加一维夹爪。奖励来自二分类器。限制写在 §VI：分类器会带来奖励投机；视觉编码器和 Transformer 骨干冻结，只训动作头。

把表 I 按任务抄一遍，避免只记平均。训练分钟、离线 SFT、离线 Cal-ConRFT、在线 HG-DAgger、PA-RL、HIL-ConRFT 的成功率（%）如下。Pick Banana：45 分钟，40 / 50 / 60 / 80 / 90。Put Spoon：45，50 / 55 / 90 / 80 / 100。Open Drawer：15，35 / 30 / 80 / 60 / 100。Pick Bread：45，65 / 55 / 65 / 80 / 100。Open Toaster：30，30 / 30 / 75 / 100 / 100。Put Bread：60，5 / 20 / 60 / 75 / 100。Insert Wheel：60，35 / 35 / 40 / 30 / 80。Hang Chinese Knot：90，55 / 40 / 50 / 65 / 100。平均 48.8 分钟，39.4 / 39.4 / 65 / 71.3 / 96.3。接触丰富的 Insert Wheel 上，PA-RL 相对离线还掉到 30%，HIL-ConRFT 才到 80%；Hang Chinese Knot 上 HG-DAgger 相对离线掉到 50%。论文把这两项失败归因于人的修正不一致，以及 Q 函数在小缓冲里覆盖不住插入位姿。本课读表时把这两行单独圈出来：平均 96.3% 盖住了插入仍只有 80%、监督方法在软物体上会退步。

回合长度同一张表。HIL-ConRFT 在 Put Spoon 上 22.6 步，SFT 49.9；Open Drawer 32.4 对 63.6；Insert Wheel 21.9 对 42.7。平均 30.7 对 59.9，缩短 1.9 倍。长度下降和成功率上升同时出现，说明他们的折扣回报在成功之后仍偏好更早结束。若你的 $r$ 只在最后一步给 1、没有折扣，组相对不会自动缩短轨迹。想复现“更快”，至少要在 $r$ 里写入 $-\lambda T$ 或使用 $\gamma<1$ 的回报，并在评测里单独报步数，不要和成功率兑成一个数。

本课从 ConRFT 拿走三件事：离线要把 Q 和 BC 绑在一起，否则小示教集上的价值函数是空的；在线不要丢掉 BC；奖励若是分类器，必须另留审计。不拿走的是 consistency 头的扩散区间划分，那是动作生成，属于第 28 课的邻居，不是奖励定义。

RoboVLM 那组数字用来说明动作头可换。表 IV：Kosmos-2 1.6B 与 PaliGemma 3B 做骨干，只训动作头，三任务平均从约 53% / 52% 升到 100%（各 20 次）。这不是“任意 VLM 加 ConRFT 就满分”，这是他们选的三个任务、冻结视觉、同一套奖励与介入。换 Insert Wheel 那种接触任务，同一篇表 I 里 HIL-ConRFT 也只有 80%。引用表 IV 时必须带着“只训头、任务子集、N=20”。本课 Lab 的四个失败样本更接近 Insert Wheel 的早期探索，不接近表 IV 的满分。

### 5.7 iRe-VLA：大模型上的在线强化学习为什么先冻住

iRe-VLA 的观察是：直接把在线强化学习打在几十亿参数的 VLA 上会不稳定，而且本地算力往往吃不住整网更新。他们的办法是迭代两段。强化学习段冻结 VLM 参数 $\theta$，只更新动作头 $\phi$，目标是折扣回报。成功轨迹进入 $D_{\mathrm{RL}}$。监督段把 $\theta$ 和 $\phi$ 一起在 $D_e\cup D_{\mathrm{RL}}$ 上做均方误差，减轻遗忘。算法 1 按任务循环这两段。

仿真上，标准 PPO 在 MetaWorld 的稀疏奖励任务里会出现比 SFT 还差的曲线；iRe-VLA 在专家任务、强化学习任务和留出任务上同时提高（表 I）。Franka Kitchen 的 left-door-open 从 0.43 到 0.83。真机用 SACfD，图像只过一次 VLM，潜向量进缓冲，本地一块 4090 做强化学习，远程 4×A100 做监督段。新物体抓取约一小时，茄子或胡萝卜从 0.35 到 0.80，原任务保持，未见物体从 0.37 到 0.61。

奖励在这篇里是稀疏二元。它能涨，是因为 SFT 已经给了非零起点，并且强化学习段的搜索空间被冻骨干缩小了。把它和 ConRFT 对照：两篇都冻视觉侧，都不敢在真机上让 3B–7B 的表示层跟着稀疏奖励乱跑。本课把“冻哪里”写成 recipe 的一列，不写成教义。VLA-RFT 和 SimpleVLA-RL 后来选择更新更多参数，那是在仿真里用结果奖励或世界模型奖励换来的。

消融也写在原文图 5：两段都冻 VLM，性能下降。作者的解释是动作头表达力不够，而且在线轨迹没法回写到上层表示，未见任务的泛化变差。因此“冻”只是强化学习段的稳定器，不是永久冻结。监督段必须把成功轨迹和原示教一起回放，否则会忘专家任务。这和第 15 课联合 SFT 要混旧数据是同一类遗忘问题，对象从语音变成动作。本课不重做遗忘实验，只要求 recipe 里写清 $D_e$ 是否还在。

MetaWorld 的专家集是 25 个任务各 50 条；第二、三类改物体形状、颜色和位置。Franka Kitchen 跟 TAIL 的设定：专家 5 个任务，其余改外观和位置。真机示教约 2000 条，覆盖抓、放、按钮、走线、开抽屉；未见任务是抓未见物体。政策是单模型条件于文本，不是每个任务一个头。读表 I 时注意：他们没有把标准 PPO 的真机数字报出来，理由是整网微调超出本地算力。缺的数字不要补。

### 5.8 SimpleVLA-RL：把第 17 课的 0/1 接到动作 token

SimpleVLA-RL 是本课和第 17 课最齐的一篇。政策必须能给出动作 token 的分布，才能随机采样、才能写重要性比。因此他们改 OpenVLA-OFT：保留并行解码和 chunk，但动作用 LLaMA 的输出头加交叉熵，而不是官方 OFT 的 MLP + L1。输入在 LIBERO 上甚至去掉本体感觉，只留单视图像和语言，为的是训练和推理更快。这些改动意味着：表 2 里 OpenVLA-OFT 的 91.0% 不是官方 checkpoint 的 97.1%，不能和第 27 课抄过的 OFT 表 I 横着减。

奖励是轨迹级 0/1，广播到每个动作 token。目标是去掉 KL 的 GRPO，带动态采样和更高的 clip 上界。LIBERO 四套件在全量示教 SFT 之后，平均从 91.0% 到 99.1%，Long 从 86.5% 到 98.5%（表 2）。一轨 SFT 之后，平均从 48.9% 到 96.9%，Long 从 17.3% 到 91.7%（表 5）。RoboTwin1.0 平均 +30.6 个点，RoboTwin2.0 从 38.3% 到 68.8%，超过同表里的 $\pi_0$ 49.2%（表 3、表 4）。真机四项任务只用仿真数据做 SFT+RL，再 sim-to-real，平均从 17.5% 到 38.5%（表 6）。

他们还记录了一种叫 pushcut 的行为：示教是抓起—移动—放下，强化学习之后政策改成把罐子推到锅旁边。结果奖励不规定过程，政策可以找到示教里没有的捷径。这是稀疏成功的双刃：它允许新策略，也可能学到评测谓词不管、物理上不受欢迎的推挤。写报告时要把“发现了新动作”和“谓词是否还代表任务”分成两句。

失败模式写在 §6.2：没有初始能力时，结果奖励的 RL 保持 0。这和第 17 课“起点 pass@k 太低就不要开训”是同一条门禁，只是 $k$ 从 8 条文本回答换成 $G$ 条机器人轨迹。

训练超参按原文抄，避免把 Lab 滑条当成他们的设置。8×A800 80GB 全参，学习率 $5\times 10^{-6}$，训练 batch 64，采样数 8，mini-batch 128，$\varepsilon_{\mathrm{low}}=0.2$，$\varepsilon_{\mathrm{high}}=0.28$，温度 1.6。LIBERO 的 chunk 长度 8，RoboTwin 25。动作 token 共 256 个。LIBERO 最大交互 512 步，RoboTwin 按任务 200、400 或 800。评测用贪心解码，各基准测三次。这些数只在你真的复现他们的代码时才有意义；本课夹具的 $G=4$ 不是 8，不要去对学习率。

RoboTwin2.0 的 12 个任务按步数分成短、中、长、超长四档，平均步数从 112 到 637（表 1）。结果奖励在超长档仍然给出正增益：Blocks Rank Rgb +11.1 个点，Put Bottles Dustbin +18.7 个点。这并不能推出“0/1 已经解决长程”。它只说明：在他们的 SFT 起点和动态采样下，组里还能滚出成功。换一个起点接近 0 的长程任务，§6.2 的 0 轨结果仍然适用。第 39 课规格才处理中途失败后的子目标栈；本课不把 pushcut 或超长档增益提前写成记忆机制。

### 5.9 世界模型里的 RFT：只按 VLA-RFT 原文写

COURSE_EXPANSION 要求：世界模型路线只按原文写。本课打开的是 VLA-RFT。它不把 Isaac / MuJoCo 当唯一模拟器，而是用离线轨迹训一个动作条件的视频预测器，再在这个预测器里滚政策，用生成帧相对参考帧的误差当 verified reward，最后用 GRPO 更新 VLA。

第一阶段分别预训练世界模型和带 flow matching 头的政策。世界模型约 1.38 亿参数，LLaMA 式 12 层，词表 9008，在 LIBERO 上预训。生成质量表 1：平均 MSE 0.0039、PSNR 25.23 dB、SSIM 0.906、LPIPS 0.059。第二阶段政策一次出一段动作，世界模型自回归出未来帧，算 $R$，组内减均值，再 clip 重要性比。他们保留一小项 flow matching 均方误差，并加熵项。图 1 写：约 400 次微调相对 15 万步强监督基线更强，也比“仿真器里做强化学习”更省交互。

表 2：基线 15 万步平均 86.6%，RFT 400 步 91.1%（正文有一处写 91.3%，表内是 91.1%，引用时跟表）。分套件：Spatial 88.4→94.4，Object 88.0→94.4，Goal 92.8→95.4，Long 77.2→80.2。他们的基线是轻量 VLA-Adapter 变体，不是 OpenVLA-OFT 官方 97.1%，不能和第 27 课那张表横减。扰动套件上（表 3），物体位置小扰动 $\pm 2.5\,\mathrm{cm}$ 从 69.3% 到 73.5%，大扰动 $\pm 5\,\mathrm{cm}$ 从 48.0% 到 52.5%；目标位置大扰动从 44.8% 到 51.5%；组合大扰动从 34.0% 到 37.0%。图 3 还画了动作分布：RFT 之后 $X$、$Z$ 方向覆盖更宽，SFT 更尖。限制写在结论：奖励仍是“像不像专家轨迹”，政策很难超过专家；世界模型容量限制分布外；当前没有把世界模型接进规划。类型 1 相对基线只 +1.1 个点，说明离开世界模型、只比动作 L1，verified reward 几乎退回模仿。本课接触 dense 也不是动作 L1：比较的是几何和力，不是专家关节角。谁若把 $r_{\mathrm{dense}}$ 实现成 $\|a-a_{\mathrm{demo}}\|_1$，那是又回到行为克隆，零方差问题会换成“全都有点像示教、分不开谁在接触”。

本课只取它与奖励有关的一句：verified reward 可以是像素误差，只要比较对象和公式固定、可复算。不要把 Cosmos 或 V-JEPA 2 的数字写进来，那些课还没有写成网站课文。也不要把 VLA-RFT 的 400 步写成“所有 VLA 强化学习都只要 400 步”；那是他们的轻量适配器政策加 LIBERO 世界模型，换 OpenVLA-7B 和真机分类器，账单会变。

### 5.10 SafeVLA：成功和安全不是同一个标量

SafeVLA 问的是：安全约束怎样显式写进 VLA，而不是事后看成功率。它用约束马尔可夫决策过程。政策最大化奖励回报 $\mathcal J(\pi)$，同时要求每个代价回报不超过阈值 $b_i$：

$$
\Pi_{\mathcal C}
=
\bigl\{\pi:\mathbb E_\pi\bigl[\textstyle\sum_t\gamma^t c_i(s_t,a_t)\bigr]\le b_i,\;\forall i\bigr\}
$$

安全谓词分两类。状态—动作谓词 $\phi(s,a)$ 在当场违例时给代价 1，否则 0。轨迹谓词 $\psi(\tau)$ 在违例片段的最后一步给 1。谓词覆盖角落卡住、盲区碰撞、易碎品连带损坏、临界点物体掉落、危险设备。这些场景被做进 Safety-CHORES，任务是 Safety-ObjNav、Safety-PickUp、Safety-Fetch。训练步数：简单任务 1500 万，Fetch 2500 万。$b_i$ 取 FLaRe 收敛代价的 20%。场景来自 ProcTHOR 约 15 万室内布局和 Objaverse 约 80 万三维资产，仿真器是 AI2-THOR。本课不把这些规模写成必须复现，只把“谓词先于优化器”写成纪律：没有 $\phi$ 和 $\psi$，拉格朗日乘子没有输入。

五个安全关键部件要用自己的话能复述，才算读过 §4.2。角落：钻进狭窄空间后反复碰撞或卡住。盲区：刚才见过、此刻不在视野里的障碍被撞上，短时空间记忆失败。易碎集合：抓一个物体时带倒旁边密排的易碎品。临界点：间接动作让搁在边缘的刀或瓶掉下去。危险设备：禁止碰的炉盘或裸线。状态—动作谓词适合当场可判定的碰撞和禁区；轨迹谓词适合跨时间才能说清的盲区和连带损坏。代价记在哪一步会改变梯度落点。SafeVLA 把轨迹违例记在片段末步，并承认这是初步选择。你若把整段历史的代价平均摊到每一步，接触前的接近也会被罚，政策可能学会不敢靠近。本课 dense 的力罚只作用在超限的那一步，接近项仍为正，就是为了避免“没碰到也罚接触”。两种记法必须写进 `reward_spec`，不能口头说“有安全项”。

优化用拉格朗日松弛：

$$
\min_\theta\max_{\lambda\ge 0}\Bigl[-\mathcal J_r(\theta)+\sum_i\lambda_i\mathcal J_{c_i}(\theta)\Bigr]
$$

先满足代价，再在可行域里抬成功率。相对最强的任务型强化学习基线 FLaRe，累计代价平均下降 83.58%，成功率平均 +3.85%。图 3：ISA 消掉了累计代价大于 10 的极端轨迹，不安全行为的上界降到 FLaRe 的 1/35。极端失败集上 FLaRe 的平均代价 71.68，ISA 2.20。奖励塑形把代价直接减进奖励，不如动态乘子。

FLaRe 本身（arXiv:2409.16578）是大规模强化学习微调，摘要给出未见环境 79.5%，仿真绝对提升 23.6 个点，真机 30.7 个点，奖励稀疏。SafeVLA 把它当“只优化任务”的对照，不是当安全方法。本课引用这两篇时必须分列：FLaRe 的 79.5% 是任务成功率；SafeVLA 的 83.58% 是代价下降。谁把 83.58% 写成成功率，验收判失败。

第 40 课规格会写力超限不能像语音那样重说。本课只把代价留下一个接口：如果你有可执行的 $c_i$，它可以进约束，也可以进 dense 的罚项，但不能和 $I_{\mathrm{success}}$ 兑成一个数之后再假装做过安全。第 07 课的 PAUSE 丢掉的是音频缓冲，见[第 07 课](07_full_duplex_routing.md)；接触力没有 undo。本课到此停住，不把切断策略写进 Lab。

### 5.11 GRAPE 与偏好：失败轨迹的另一种用法

GRAPE 不走 on-policy 的组相对。它把整条轨迹的似然比写成 DPO 那种 logistic 损失，称为 TPO。从轨迹奖励的解析式出发，

$$
r(\zeta,q)=\beta\log\frac{\pi_\theta(\zeta\mid q)}{\pi_{\mathrm{ref}}(\zeta\mid q)}+\beta\log Z(\zeta)
$$

再代入 Bradley-Terry，得到只比较赢轨迹和输轨迹的损失。轨迹似然按 MDP 拆成逐步，$\log(\pi_\theta/\pi_{\mathrm{ref}})$ 对时间求和。这和第 16 课的 DPO 同族，比较对象从“一句回答”换成“一条操作轨迹”。偏好来自自动打分：阶段代价、政策自评分和成功指示的加权和 $R_{\mathrm{GCPG}}$。同任务里高分对低分组成 $(\zeta_w,\zeta_l)$。阶段本身由视觉语言模型切分，关键点给出空间约束，外部奖励写成各阶段 $e^{-C}$ 的乘积，靠指数衰减体现“前面已经搞砸后面不必再加分”。摘要给出的相对提升是域内 51.79%、未见 58.20%；对齐到安全或效率时，碰撞率下降 37.44%，步数下降 11.15%。仿真用 Simpler-Env 与 LIBERO，真机约 300 次、30 个任务。骨干是 OpenVLA，LoRA 微调。消融表写明：只用成功/失败随机配对，不如用完整 $R_{\mathrm{GCPG}}$ 排序。

本课夹具没有偏好对，只有一组四个 $r$。若要把 GRAPE 接到同一组失败轨迹上，最简单的教学做法是按 $r_{\mathrm{dense}}$ 排序，取最高对最低当 $(\zeta_w,\zeta_l)$。四个全失败时稀疏给不出任何一对，dense 仍能给出擦边对空抓。这就是“失败轨迹的另一种用法”的最小版本。迭代次数 $K$ 和每轮采样条数 $M$ 以原文算法 1 为准，本课不实现。

本课要它的原因：失败轨迹即使 $I_{\mathrm{success}}=0$，阶段代价仍可能不同，因而仍能形成偏好。这和接触 dense 是同一类信息，只是优化器换成了偏好对。Liu 等在抓放上复现 DPO 时只用阶段稀疏奖励，发现不如 PPO，他们自己的解释是稀疏奖励难以区分轨迹、离线分布和交互分布差得远。两篇并不互相取消：GRAPE 的奖励更密，Liu 等的 DPO 更瘦。写“偏好就能替代组相对”或“GRPO 在机器人上无效”，都超出打开过的原文。

### 5.12 算法对照：PPO 与 GRPO 在机器人上的分歧要照抄，不调和

Liu 等（2505.19789）在 ManiSkill 的 WidowX 抓放上比较 PPO、GRPO、DPO。GRPO 按同一初始状态采 8 条轨迹估基线。他们的图 3 显示 PPO 更稳。假设写在正文：机器人是非平稳的 POMDP，每一步改环境，组相对优势会被打乱。他们还给出一套省事的 PPO：共享骨干、价值头读第一个动作 token 的隐向量、只做 1 个 PPO epoch、先用 140 条示范热身。一块 A100 大约 42 小时收敛。泛化上，强化学习相对 1.6 万条 SFT，在未见物体和桌子上高 42.6%；视觉扰动两者接近，语义和执行上强化学习更好。

SimpleVLA-RL 在 LIBERO 和 RoboTwin 上用 GRPO 得到了很大的结果奖励增益。两套实验的动作接口、是否动态采样、是否冻骨干、环境是否重置到同一 $s_0$，都不相同。本课的研究对象是 $r$，不是给 2025 年的算法榜排名。recipe 里要单列“优势估计器：组相对 / GAE / 偏好对”，并写清组是不是共享初始状态。缺这一列，就把 Liu 等的失败和 SimpleVLA-RL 的成功兑成了互相打脸的摘要，那是阅读事故。

读 Liu 等时把三项泛化拆开，避免写成“强化学习全面更强”。视觉：换桌面、前景纹理、整图噪声，强弱两档；强化学习与 1.6 万条 SFT 接近。语义：未见物体、容器、指令改写、多物体、干扰容器；强化学习明显更好，作者解释为试错让“抓”这件事少绑在物体类别上。执行：物体和容器初值、机器人初态、回合中途挪动物体；强化学习能从抓空和中途移位里恢复，SFT 沿运动规划器的示教走廊继续走。图 8 用末端姿态着色：强化学习轨迹铺得更开，SFT 挤在示教路径附近。本课接触 dense 要的就是执行这一维上的可排序性：还没放入时，谁更接近、谁力过大，必须能分。视觉纹理不在本课 $r$ 里，换桌布不该改变接触带公式；若你的 $r$ 读像素而不是 $c$ 和 $F$，桌布一换分数就漂，那是另一条投机面。

### 5.13 肢体上的投机形状，和文本不一样

第 17 课的投机钻解析：多个 final、NaN、重复键。肢体上的投机钻谓词与传感器。分类器假阳性：末端停在训练时“看起来像完成”的照片位姿。接触带震荡：为了接近项贴着杯子来回蹭，不抬起。力读数假零：传感器饱和或没接，力罚恒为 0，压溃变成最优。世界模型讨好：动作让预测帧像专家，真机关节做不到。安全站死：代价乘子过大，政策输出接近保持。介入污染：人把失败救成成功，曲线上升，政策自己不会。

每一条都有对应的单元测试。假阳性：用程序谓词在同一批轨迹上重打分，两列必须一起报。震荡：报平均位移和“接触成功但放入失败”的比例。力假零：断言一组里 $F$ 的方差大于 0，全 0 则标记传感器缺失。世界模型讨好：抽若干动作在真仿真回放，成功率不得用 LPIPS 代替。站死：报平均位移，位移接近 0 且代价很低时，记为约束过紧，不是安全胜利。介入：成功率分含人和仅政策两列，ConRFT 图注已经提醒过。

这些测试不增加新的学习算法。它们决定你敢不敢把 $\bar r$ 曲线贴进报告。本课最低交付只要求夹具上的零方差和排序；一旦离开夹具，这一节的测试就要进评测协议。缺表的真机曲线，按未完成评测处理，即使分数看起来像 96%。

把测试写成和第 17 课同类的状态码，便于日志过滤。建议至少四种：`pass`（评测谓词通过）、`wrong_task`（谓词失败，留在组里）、`sensor_missing`（力或接触字段缺失，整组丢弃）、`human_takeover`（该步之后的 $r$ 不得记成政策得分）。`sensor_missing` 对应第 17 课的 `system_error`。`wrong_task` 对应 `wrong_answer`。不要发明第五种“看起来还行”的中间码；中间状态属于 dense 的连续分，不属于状态码。状态码是离散的、可枚举的、可写成回归测试的。这是 RLVR 还成立的理由。分类器输出若只有一个 logit，没有状态码，就先包一层：logit 大于阈值为 `pass`，否则 `wrong_task`，输入图像损坏为 `sensor_missing`。包一层之前，不要把它叫做可验证奖励。

## 6. 数据与训练 recipe

最低可复核的强化微调 recipe 是一张表，不是一段形容词。每一行都要能指向文件或日志字段。

| 字段 | 本课最低要求 | 常见出错 |
|---|---|---|
| 起点 checkpoint | SFT 后 pass@G 非全 0；写清骨干是 token 还是 flow | 用未微调的 OpenVLA 直接上 0/1 GRPO |
| 组的定义 | 同一指令、同一随机种子集合；$G$ 写死 | 把不同杯子的轨迹放进同一组再减均值 |
| $r$ 的程序 | 函数名、版本、输入字段、输出区间 | “成功就行”而不写谓词 |
| 零方差策略 | 丢掉、改 dense、或停止并回到 SFT | 继续更新，日志里 advantage 全是 0 |
| 冻结范围 | 视觉、LLM、动作头各一行 | 真机上全网跟着分类器奖励跑 |
| 介入 | 有无人、人的数据进哪个缓冲 | 把含介入的成功率写成政策成功率 |
| 评测谓词 | 与训练 $r$ 分开写 | 用训练 dense 当 LIBERO 成功 |
| $N$ | 真机写次数；仿真写 trials × seeds | 20 次和 500 次兑在同一格 |

数据目录建议：

```text
exp38_rft/
├── start_checkpoint/        # SFT 权重与 tokenizer
├── reward_spec.yaml         # 谓词、阈值、版本
├── rollouts/                # 每条轨迹的状态、动作、r、hash
├── groups.jsonl             # 组 id、G 条路径、r 向量、A 向量
└── eval_protocol.yaml       # 第 31 课那张协议卡
```

`reward_spec.yaml` 至少包含：

```text
sparse:
  lifted_height_m: 0.02
  bin_radius_m: 0.04
dense:
  tau_m: 0.04
  contact_band_m: 0.03
  force_safe_n: 0.45
  weights: [0.35, 0.25, 0.40, 0.30]
version: contact_dense_v1
```

改阈值必须改版本号。用旧版本的 $r$ 重算新日志，属于不可复现。ConRFT 的分类器权重 hash 也要写进这一行；换一次分类器等于换了一种 $r$。

训练预算按目标分档，避免把论文墙钟抄成自己的计划。

| 档 | 做什么 | 预算 | 预期 | 失败 |
|---|---|---|---|---|
| A | CPU 夹具 + Lab | 无 GPU，数分钟 | 失败组稀疏 $\Sigma|\hat A|=0$，dense 排序 C>D>B>A | 任一 check 为假 |
| B | 玩具 2D 抓取仿真，手写谓词 | CPU 数小时 | 稀疏在成功率 $<10\%$ 时更新接近 0，dense 仍降平均 $c$ | 两条曲线重合 |
| C | 单任务 LIBERO，结果奖励 GRPO | 多卡天级，视 7B 与并行仿真 | 起点非 0 时成功率上升，零方差组比例下降 | 奖励升、评测谓词不动 |
| D | 真机 ConRFT 式 | 45–90 分钟级交互 + 人 | 介入率下降，分类器与程序谓词同向 | 只有分类器涨 |

档 C、D 不是最低交付。做了必须按第 31 课拆套件、写 $N$、写是否 fine-tune。SimpleVLA-RL 的 99.1% 是他们改过的 OFT + 全量示教 + RL，不是官方 OFT 的 97.1%。ConRFT 的 96.3% 是八项任务各 20 次的平均。两格不能减。

批次构造再写死一次。一个组不是“最近滚出来的任意 $G$ 条”，而是同一 $(l,s_0)$ 下的 $G$ 条。跨任务减均值会把难任务的成功当成普通，把易任务的失败当成灾难。Liu 等和 SimpleVLA-RL 都从同一初始状态采样，差别在后来是否丢掉同分的组。本课夹具的四条轨迹共享同一只杯子和同一只盒子，就是在守这一条。

奖励程序要写成和第 17 课 verifier 同类的合同，否则换一个人重算会对不上。最低字段：

| 字段 | 抓取例子 | 不允许 |
|---|---|---|
| 输入 | 轨迹末状态的高度、水平位置、夹爪、力序列 | 只存“成功”布尔，丢掉 $c$ 和 $F$ |
| 输出 | `{status, r_sparse, r_dense, version}` | 只返回一个 float，状态和分兑在一起 |
| 幂等 | 同一轨迹重复 100 次逐字节相同 | 依赖当前时间或未种子化的抖动 |
| 失败类型 | `predicate_false` 与 `sensor_missing` 分开 | 传感器丢包也打 0 分，混进任务失败 |
| 隐藏谓词 | 评测用放置 / 保持，训练不可读 | 训练 dense 直接当 LIBERO 成功 |

`sensor_missing` 对应第 17 课的 `system_error`：整组丢掉，不要把缺力读数的轨迹当成“没接触”。`predicate_false` 对应 `wrong_answer`：留在组里，给低分。CPU 实验没有传感器，所以不实现缺测丢组；真接仿真时要把这一行补上。日志里每条轨迹至少保存：`group_id`、四个 $r_{\mathrm{sparse}}$ 与 $r_{\mathrm{dense}}$、$\bar r$、四个 $\hat A$、`reward_spec` 版本、是否含介入。缺 $\hat A$ 向量的训练步，事后无法证明当时不是零方差组在空转。

把一次失败写成可复盘的句子。例如：“组 0017，$G=4$，稀疏 $(0,0,0,0)$，dense $(0.004,0.088,0.473,0.281)$，版本 `contact_dense_v1`，无介入。”这句话已经能判断：稀疏不会更新，dense 会抬擦边、压空抓。若日志只有“reward_mean=0.21”，你分不清是四个 0.21 还是上面那个向量。均值相同，更新完全不同。这是本课相对“看奖励曲线”多出来的纪律。

## 7. 按依赖顺序执行实验

实验分四层。第一层必须在无 GPU 时通过。第二层是浏览器教具。第三层只有在你真的接仿真时才跑。第四层写不要做的事。

### Step 1: CPU 机制实验

在 `experiments/` 下核对隔离脚本（本课不改 `registry.py`，编排者接入后再改成 `run.py run 38`）：

```bash
PYTHONPATH=src python3 -c "from learn_omni_experiments.lessons.lesson_38 import run; print(all(run()['checks'].values()))"
```

预期打印 `True`。失败时看 `checks` 里哪一条是 `False`：稀疏全零、零方差不更新、dense 排序、混入成功后的正负优势、标准化形式。

手算可以先于脚本。失败组稀疏：四个 0，均值 0，优势四个 0，权重四个 1。失败组 dense 用第 5.4 节的四个近似值，确认擦边最大、空抓最小，四个优势之和为 0。混入成功后稀疏变为 $(0,0,0,1)$，优势 $(-0.25,-0.25,-0.25,0.75)$。这三行对不上，不要进入 Lab。

再补一行标准化对照，证明第 17 课的除法在本课失败组上不会救稀疏。四个稀疏 0 的标准差是 0，加上 $\varepsilon=10^{-8}$ 仍得到四个接近 0 的 $A_i$。四个 dense 近似值的均值约 $0.212$，减均值后再除标准差，擦边仍为正、空抓仍为负，符号与 $\hat A_i$ 一致。CPU 实验的 `dense标准化优势在失败组仍可分正负` 锁符号，不锁具体标准差口径（总体方差还是样本方差）。写报告时写明用的是哪一种；本课夹具用总体方差，与第 17 课 `statistics.fmean` 那一行一致。

标量更新的手算：$w\leftarrow w+\eta\hat A$。取 $\eta=0.1$，$w=1$。稀疏四个 $w$ 仍是 1.000。dense 四个 $w$ 约为 $0.979$、$0.988$、$1.026$、$1.007$。相对变化只有几个百分点，但这已经是“有更新”和“没更新”的分界。真训练里 $\hat A$ 还会乘 log-prob 的梯度，量级不同，零与非零的分界不变。

### Step 2: 浏览器俯视教具

打开本课页面的 Lab。桌上有杯子和盒子，四个夹爪终点标着 A–D。先在四个选项里选一句关于失败批次的预测，再按“揭晓优势”。默认批次必须是全失败。揭晓后看两行方差：稀疏应为 0.0000，$\Sigma|\hat A|$ 应为 0.000；dense 方差大于 0，$\Sigma|\hat A|$ 大于 0。切到接触 dense 查看当前行，擦边应排在空抓前面。再切到“混入一条放入成功”，稀疏才会出现正优势。教具标题写明教学模拟。

教具内部的计算可以手工复核。dense 与 CPU 实验同一公式。滑条 $\tau$、$b$、$F_{\mathrm{safe}}$ 会改分数；改滑条会清掉揭晓，防止先看数字再选答案。验收不看你有没有把 $\tau$ 调到极端，只看：预测句选对、当前批次是全失败、稀疏优势全零、dense 仍有非零更新。默认滑条满足后两项。

建议顺序：预测 → 揭晓 → 记下稀疏 / dense 两行 → 把查看开关拨到 dense 看排序 → 拨到混合批次看稀疏复活 → 拨回失败批次确认验收句仍然成立。中途改预测会清空揭晓。

### Step 3: 可选，单任务仿真探针

只在有仿真器和一张够用的 GPU、且你接受“这不是课程最低交付”时进行。选一个短程抓放，先用 10–50 条示教 SFT 到非零成功率，再开结果奖励的组相对更新。记录：每组成功数直方图、零方差组比例、训练 $r$、评测谓词。零方差比例不下降时，先加接触 dense 或回到 SFT，不要加学习率。样本少于第 31 课要求的 $N$ 时不要报成功率区间，只报逐组 $r$ 向量。

### Step 4: 不要做的事

不要把 Lab 的 $\Sigma|\hat A|$ 写成 96.3% 或 91.7%。不要在 CPU 实验通过后声称“VLA 已经会强化学习”。不要用介入后的成功曲线替代政策成功。不要把 SafeVLA 的代价下降写成成功率。不要在本课重推 clip。

## 8. 评测与测量

强化微调和评测是两张表。混用就是第 31 课反对过的横着比。

**训练中间量。** 组均值 $\bar r$、组标准差 $s_r$、零方差组比例、$\Sigma|\hat A|$、介入率、回合长度。这些量只说明更新信号在不在，不说明任务能力。ConRFT 图 3 同时画成功率、介入率和回合长度，就是怕只看一条曲线。建议按步记下零方差比例：连续 100 组里有多少组 $s_r=0$。比例高于 0.5 时，本课把它当成停训信号之一，先改 $r$ 或回到 SFT，不要再加步数。比例从 0.8 降到 0.2，只说明组里重新出现对比，不说明评测谓词已经过关。

**任务成功。** 必须带谓词。LIBERO 用官方成功。ConRFT 用分类器加 20 次人工协议。Liu 等用抓住 / 持续抓住 / 放下三档。本课夹具的放入成功是 `lifted ∧ in_bin`，接触成功是 `g=1 ∧ c\le b`。同一条压溃轨迹可以接触成功、放入失败。

**安全代价。** SafeVLA 的 CC 是所有约束、所有时间步的代价和。它和 SR 必须分列。极端失败集上 SR 接近 0 时，CC 仍可比较。

**本课最低测量。**

| 量 | 定义 | 通过 |
|---|---|---|
| $s_r^{\mathrm{sparse}}$ | 失败组稀疏奖励的标准差 | 0 |
| $\Sigma|\hat A|^{\mathrm{sparse}}$ | 失败组稀疏优势绝对值之和 | 0 |
| $s_r^{\mathrm{dense}}$ | 失败组 dense 标准差 | $>0$ |
| 排序 | dense 失败组从高到低 | C, D, B, A |
| $\sum_i\hat A_i$ | 任一非零方差组 | 绝对值 $<10^{-12}$ |
| 混入后的 $\hat A_E$ | 稀疏混合组成功条 | $+0.75$ |

公开数字抄进笔记本时，用下面这张禁止合并表。列与列不能相减。

| 系统 | 设置 | 数字 | 奖励 |
|---|---|---|---|
| ConRFT HIL | 八项真机，各 20 次，45–90 分钟 | 平均成功率 96.3%，步数 30.7 | 任务分类器 |
| ConRFT 离线 SFT | 同评测 | 39.4%，步数 59.9 | 行为克隆 |
| iRe-VLA 真机 | 茄子 / 胡萝卜 | 0.35 → 0.80 | 二元成功 |
| SimpleVLA-RL | 改版 OFT，LIBERO 全量示教 + RL | 平均 99.1%，Long 98.5% | 轨迹 0/1 |
| SimpleVLA-RL | 每任务 1 条示教 + RL | Long 17.3% → 91.7% | 轨迹 0/1 |
| VLA-RFT | 轻量政策，LIBERO | 86.6% → 91.1%，400 步 | 世界模型 L1+LPIPS |
| SafeVLA ISA | Safety-CHORES | CC −83.58%，SR +3.85% | 奖励 + 代价 |
| FLaRe | 摘要，未见环境 | SR 79.5%，仿真 +23.6，真机 +30.7 | 稀疏成功 |
| GRAPE | 相对同数据 SFT | 域内 / 未见相对 +51.79% / +58.20% | 阶段代价 + 成功 |

SimpleVLA-RL 表 2 的 OpenVLA-OFT 91.0% 与第 27 课引用的官方 OFT 97.1% 不是同一个实现。读表时先看输入是否含腕部相机和本体感觉，动作头是 CE 还是 L1。官方 OFT 表 I 在第三人称、腕部、本体感觉和过滤失败示教下四套件平均 97.1%，Long 94.5%。SimpleVLA-RL 为了给 GRPO 提供 token 分布，去掉腕部和（在 LIBERO 上）本体感觉，并把连续 L1 换回分类头，SFT 之后平均只有 91.0%。强化学习再把它抬到 99.1%。比较的是“他们的 SFT 对上他们的 RL”，不是“官方 OFT 对上一段 GRPO”。写进对照表时，实现差异要占一列。缺这一列，99.1% 会看起来像在打官方 97.1%，那是把配方和奖励兑在一起了。

把第 31 课的区间纪律也迁过来。ConRFT 每任务 20 次、成功率 0.9 时，Wilson 区间大约从 0.70 到 0.97，宽度三十个百分点。八项平均会窄一些，但仍不是可以和 LIBERO 500 trials 对打的精度。SafeVLA 的 1500 万步是仿真；真机只在文中展示了 Safety-PickUp 的部署，没有把 83.58% 写成真机代价下降。GRAPE 真机总平均 50.3%，对照 OpenVLA-SFT 32.3%、DPO 39.3%，任务数和划分以原文图 5 为准。这些 $N$ 写进引用句，不写进本课夹具的通过条件。

评测再加两个负对照。把 dense 的接触带设到大于所有 $c$，四条失败轨迹的接触项全变成 1，排序应只剩接近和力；若排序不变，实现没有读 $b$。把成功谓词改成“只要夹爪闭合”，压溃会变成稀疏成功；若你的评测也跟着变成成功，说明评测谓词被训练开关污染了。两个负对照都失败时，主表数字作废。

## 9. 验收条件

课程通过只看机制，不看是否跑通 Franka。

1. 课文第一个 H2 是“模仿学不会的试错怎样变成可验证奖励”，并能用示教缺失败列解释。
2. CPU 实验十条 `checks` 全为 True。
3. 交互实验：先提交预测“失败批次上稀疏优势全零，dense 仍有非零更新”，再在全失败批次上揭晓。
4. 能指出 $\hat A_i=r_i-\bar r$ 与第 17 课标准化形式在零方差组都得到 0，且本课没有重推 clip。
5. 能按原文说出至少三种奖励：ConRFT 分类器、SimpleVLA-RL 的 0/1、VLA-RFT 的像素误差或 SafeVLA 的代价。
6. 引用 96.3%、91.7%、83.58% 时写了设置、样本量和该数字是成功率还是代价。

出现以下任一情况，实验无效：揭晓前能看到优势数字；只在混合批次上验收稀疏；把 Lab 排序写成真机接触力；把 GRAPE 的 51.79% 写成绝对成功率。把第 17 课的 clip 公式在本课再推一遍、却写不出 $r_{\mathrm{sparse}}$，同样无效：那是抢了第 17 课的题，本课的题还没做。

通过最低交付之后，允许加一条可选记录：把 $F_{\mathrm{safe}}$ 从 0.45 拖到 1.20，记录压溃与擦边的名次是否交换。预期力罚消失后压溃上升。这条曲线是给自己看的，不写进对外的“论文复现”。

## 10. 根据症状定位失败环节

| 症状 | 先查 | 不要先做 |
|---|---|---|
| 训练步在走，权重几乎不动 | 零方差组比例，$r$ 是不是常向量 | 加大学习率 |
| 稀疏奖励为 0，dense 也全相同 | $c$ 是否写死成同一个数，接触带是否覆盖全部样本 | 换 GRPO 实现 |
| 分类器分涨，程序谓词不涨 | 假阳性位姿，分类器版本 | 宣布 RFT 成功 |
| LIBERO 平均很高，Long 仍低 | 是否先平均再记录 | 用平均写 SOTA |
| 真机早期狂撞 | 是否从零 RL，有没有 HIL 或冻骨干 | 加大探索温度 |
| GRPO 在抓放上不涨、PPO 涨 | 组是否共享 $s_0$，有无动态采样，动作是否有 log $p$ | 写“GRPO 不适用于机器人” |
| 世界模型 RFT 只会模仿专家 | 奖励是不是 LPIPS 向专家帧 | 指望它发现 pushcut |
| 成功率升、碰撞也升 | $r$ 里有没有 $c_i$，阈值 $b_i$ | 把碰撞写进同一成功标量 |
| 介入曲线很好看 | 统计是否含人接管 | 与无介入方法比成功率 |
| Lab 揭晓后稀疏不是 0 | 是否不在失败批次，或误把压溃标成 lifted | 改公式系数 |

再补一组和本课公式直接相关的症状。四个 dense 值几乎相等：$\tau$ 过大，接近项都接近 1，再检查力是否都低于阈值。压溃永远第一：力罚系数没接上，或 $F$ 字段始终是 0。优势之和不是 0：实现用了样本标准差却忘了减均值，或把不同组拼在一起归一化。标准化优势在零方差组爆成 $10^8$：$\varepsilon$ 写成了 0 并且用 $0/0$ 的 IEEE 奇怪值，应改回第 17 课的 $\varepsilon$。这些检查只需要打印长度为 $G$ 的向量，不需要再下数据集。

## 11. 交付物

- 一份公式页：$r_{\mathrm{sparse}}$、$r_{\mathrm{dense}}$、$\hat A_i=r_i-\bar r$、零方差含义；标明 clip 引用第 17 课；
- CPU 实验 `lesson_38.py` 的 `checks` 全通过记录；
- 交互实验状态：预测选项、批次=失败、稀疏方差、dense $\Sigma|\hat A|$、排序；
- 一张对照表：ConRFT / iRe-VLA / SimpleVLA-RL / VLA-RFT / SafeVLA / GRAPE 各改奖励、优化器、冻哪些层，数字带来源；
- 明确声明：未复现 96.3%、99.1% 或 83.58%。

交付物不要求训练曲线漂亮。要求能从一次“训了没动”反推：这一组的 $G$ 条 $r$ 是什么、均值是多少、方差是不是 0、谓词版本是哪一个。这一条和第 01 课的 trace 纪律同类，只是对象从 codec 编号换成了奖励向量。做不到反推的实验，即使仿真成功率上升，也不算本课交付。

报告第一页建议用四行固定模板，防止写飞。任务：抓哪一只杯子、放进哪只盒子。起点：哪个 SFT 哈希、pass@G 多少。奖励：稀疏谓词或 dense 版本号。结果：失败组稀疏 $\Sigma|\hat A|$、dense 排序、评测谓词在多少次试验上的点估计。四行之外的 LIBERO 平均和真机 96.3%，有则附录，无则写未做。模板看起来死板，但能挡住“我们做了强化学习”这种没有 $r$ 向量的句子。

## 12. 前沿对照与改造方向

**公开方案。** 2024–2025 年公开的 VLA 强化微调可以按奖励通道分成四条，不要兑成“都在做 RLHF”。

结果通道：FLaRe、SimpleVLA-RL、iRe-VLA 的主信号是任务完成。FLaRe 用大规模稳定化把稀疏奖励推到长程移动操作；SimpleVLA-RL 把同一思想接到 GRPO 和动作 token；iRe-VLA 用稀疏奖励但把搜索限制在动作头。过程通道：本课教学用的接触公式、GRAPE 的阶段关键点代价、Liu 等的 0.1 抓住分。模型通道：VLA-RFT 用世界模型帧误差当 verified reward，400 步级，仍被专家轨迹拴住。约束通道：SafeVLA 把谓词写成 $c_i$，用乘子而不是减进奖励。ConRFT 跨在结果通道和离线价值之间：分类器给稀疏 $r$，Q 在离线阶段提供另一条分数，在线仍靠同一 $r$ 加人工介入。

Qwen2.5-Omni / Qwen3-Omni 的公开技术报告以听、说、看和文本 / 视觉 GRPO 为主，未把接触力或抓取谓词写成与 ConRFT 同级的真机 RFT 设定。其技术报告未公开“对 7 自由度动作做组相对、奖励用接触带”这一配方。Moshi 是语音全双工，与本课奖励无关。Nemotron Omni 的公开 recipe 覆盖文本和视觉后训练，第 18 课已经划过界；它没有给出 Franka 上的分类器奖励实验。把这些系统列在这里，是为了划界：能听会说的 Omni 后训练，和会动手的 VLA 后训练，在第二波课里仍然分列。合流不在本课兑现。

**差距。** 规模差距：八项真机、1500 万步 Safety-CHORES、并行 LIBERO 渲染，钱和机器人能堆。机制差距：成功谓词、接触 dense、零方差检测、组必须共享初始状态，本课能做。评测差距：20 次真机和 500 trials × 3 seeds 之间的洞，不是把 Lab 调光滑能填的。算法差距：PPO 与 GRPO 谁更适合哪一种动作头，公开结果按环境分裂，缩小版只能复现“零方差会哑火”，不能复现谁该赢。

再把四条奖励通道各自的投机写清楚，改造时才知道该加哪一条审计。结果通道会停在分类器假阳性或“看起来像完成”的悬停。过程通道会在接触带边缘震荡，或为了接近项永远贴着杯子不抬起。模型通道会生成“看起来像专家视频”但关节不可执行的动作，世界模型自己的误差也会变成可打的分。约束通道会为了不碰东西而站死，SR 掉到不可用，或把代价记在错误的时间步上（SafeVLA 自己说轨迹谓词的信用分配仍是开放问题）。四条通道的共同审计是：训练 $r$ 与评测谓词分列，隐藏谓词不可进训练，版本进账本。缺审计时，曲线越漂亮越不可信。

真机还有一条规模课不教的账单：复位。ConRFT 用脚本运动或人把场景摆回去。稀疏奖励的探索会把杯子打到桌下，没有复位就没有下一条轨迹。Lab 里杯子位置是画上去的，不模拟打翻。谁若把教学模拟里的四条终点写成“已经处理了复位”，属于把右栏抄进左栏。写 recipe 时复位是单独一行：自动、人、或脚本；耗时计入墙钟。ConRFT 的 45–90 分钟含脚本运动、政策滚出和板载计算，不是纯梯度时间。

**动手改造清单。**

1. 把 CPU 夹具的稀疏谓词改成“只要 `gripper_closed`”。预算：改一处函数，秒级。预期：失败组出现非零稀疏优势，压溃变成正例。失败：改完四个稀疏 $r$ 仍全是 0，或评测放入谓词也被一起改掉。
2. 给 dense 增加一项 $0.15\times(1-t/T)$，奖励更短的回合。预算：CPU 数分钟。预期：同样放入的两条轨迹，步数短的 $r$ 更高。失败：步数项不改变排序。这条对应 ConRFT 用强化学习缩短回合，方向可复现，30.7 步不可复现。
3. 在 Lab 里把四条失败轨迹的 $c$ 全部改成 0.02。预算：改夹具坐标，不训练。预期：dense 只剩力和夹爪在分，空抓若仍张开应最低；稀疏仍全 0。失败：稀疏开始非零。
4. 若有 1×24GB 和 LIBERO：对已经非零的 SFT 开 100 步结果奖励，记录零方差组比例。预算：单卡数小时级，视并行环境。预期：比例随成功率离开 0 和 1 而下降。失败：成功率不动但你把训练 $\bar r$ 写成评测 SR。$N$ 不够时只发组直方图。

**顺手复现映射。** 第 17 课“全 0 组没有更新”对应本课 `零方差组不产生更新`，预期同向。SimpleVLA-RL“动态采样因为同分无梯度”对应失败组稀疏 $\Sigma|\hat A|=0$。VLA-RFT“动作 L1 增益小于同模型像素比较”在教学规模只能看到“dense 比稀疏更有方差”，看不到 91.1%。ConRFT“分类器可被钻”对应改造 1：放宽谓词会让错误轨迹变正。SafeVLA“代价与成功分列”对应交付物里 83.58% 不得写入成功率列。这些映射全部是方向性的。谁把 96.3% 写进自己的四条玩具轨迹报告，就算评测造假。

改造实验的失败判定再补两条公共规则。任何一次仿真或真机更新都要保存：权重哈希、`reward_spec` 版本、$G$ 条 $r$ 的向量、是否含介入。缺 $r$ 向量的结果不能进对照表。任何一次声称“dense 更好”的比较，必须在同一组轨迹上同时报稀疏和 dense；换了初始状态就不能把差值记在奖励上。

预算表再强调一次机制与规模的分界。改谓词、加步数项、把四条 $c$ 改成相同，这三件事在 CPU 上就能失败或通过。开 100 步 LIBERO 是可选的规模动作，失败判定仍然是“零方差比例和评测谓词”，不是“是否接近 99.1%”。有人把可选档的一次成功跑写成课程通过，属于用规模数字代替机制验收。本课通过条件在第 9 节，不在档 C。

读 ConRFT 时再带一个计算题：离线 39.4% 到在线 96.3%，相对提升 $(96.3-39.4)/39.4\approx 144\%$，与摘要一致；绝对点是 56.9。有人只写 144% 不写基线，本课视为漏报。读 SimpleVLA-RL 时带一个对照题：一轨 SFT 的 Long 17.3% 加 RL 到 91.7%，与全量 SFT 的 86.5% 相比，强化学习在数据极少时补的是探索，不是更多模仿。读 SafeVLA 时带一个单位题：CC 无量纲地累加违例次数，SR 是 $[0,1]$ 的任务成功，两者永远分列。

读完材料回头看：政策一行权重都可以先不动，奖励程序已经能决定一次更新有没有信号。同一组失败轨迹，稀疏给出零向量，接触 dense 给出可排序的优势。你现在应该能拿着任意一篇写了强化学习的 VLA 论文，在五分钟内把它拆回 $r$ 的定义、组怎么采、零方差怎么办、评测谓词是不是训练奖励，并决定这列数字能不能进自己的对照表。下一课规格转向长程失败后的记忆与子目标栈：那是状态机，不是把整段历史塞进第 14 课那种 token 窗口。本课停在这里：试错要先变成可验证的数，组内才比较得起来；数全一样时，强化学习只是在付钱看世界，还没有在改政策。

若还要把机制讲给另一个人听，只用四条轨迹和两个向量。稀疏 $(0,0,0,0)$ 对 dense $(0.004,0.088,0.473,0.281)$。第一句：示教里没有这四条。第二句：成功谓词给不出对比。第三句：接触和力给得出对比。第四句：$\hat A$ 全零时不要看学习率。四句齐了，再打开 ConRFT 的 96.3% 或 SimpleVLA-RL 的 91.7%，才知道那些数字站在哪一种 $r$ 上。站错 $r$，数字再高也回答不了本课的问题。机制验收看的是零方差和排序，不是看哪篇论文的百分数更大。百分数留给你以后真去复现时，带着第 31 课的协议卡再写。现在先保证：失败组稀疏没有更新，接触 dense 仍能排出擦边优于空抓。这两句能手算、能过 CPU 实验、能在 Lab 里先预测再揭晓，第 38 课就可以收工。机制对了，再去碰真机也不迟。
