# 第 55 课：测量端侧量化对各模态 token 的损伤

> 类型：端侧部署，INT8 / INT4 对各模态 token 的损伤测量，不改训练并行，也不改推理图<br>
> 建议周期：阅读约 70 分钟；浏览器 8/4 bit 实验约 10 分钟；CPU 分模态误差数分钟<br>
> 硬件：无 GPU 可完成本课阅读、教学模拟与 CPU 机制实验。复现 GPTQ / AWQ / QVLA 论文表需要对应论文里的 GPU 与权重<br>
> 产物：一张分模态损伤表、同一隐藏向量上的 8/4 bit 手算、动作 bin 跳类记录<br>
> 独立性：对照 [第 13 课](13_distributed_8gpu.md) 的训练并行和 [第 46 课](46_omni_serving.md) 的 stage graph，本课只处理推理权重量化后的语义损伤。动作分箱沿用 [第 24 课](24_vlm_to_vla.md)、[第 25 课](25_action_tokenization.md)

## 1. 量化以后哪一类 token 先坏

把一个已经能看图、写字、吐关节的模型搬到笔记本或机载计算机上，第一反应往往是“压到 8 bit 或 4 bit”。压的对象是权重或激活：每个浮点数改成更少的整数档，再在用的时候乘回步长。内存少了，带宽压力小了。接下来的问题通常被写成一个总分：困惑度涨了多少、MMLU 掉了几分、LIBERO 平均还剩多少。本课把这个总分拆开。

同一条序列里至少有三类要被模型当成 token 或当成和下一个 token 等价的预测对象。文字经过词表，变成离散编号。图像经过视觉编码器，变成一串连续向量，有时再映到词嵌入空间。动作若走 [第 24 课](24_vlm_to_vla.md) 的均匀分箱，连续末端位姿会变成箱号；若走 [第 25 课](25_action_tokenization.md) 的连续头，则是一段实数向量。量化改的是同一套线性层。三类输出对同一点误差的反应不同。文本下一个词只要最大 logit 还压过第二名，top-1 就不换。视觉重建的欧氏距离可以涨一截，粗分类仍指向同一槽。动作箱是硬边界：值只要越过 $a^{\min}+k\Delta$，箱号立刻换。箱号一换，反量化后的关节命令跳过半个箱宽，夹爪或俯仰角就不再是原来那一档。

类比：把一把尺子的刻度变粗。读一篇长文时，你仍能认出下一个词是“杯子”还是“桌子”，因为这两个词的得分离得很开。读一张图时，杯子轮廓糊一点，你还知道那是杯子。读机械臂的俯仰角时，真值正好压在 $-0.5$ 这条刻度线上，尺子一粗，读数就滑到隔壁格。类比失效处：语言模型的间隔不是天生的，它来自训练后的 logit 差；动作箱宽来自你事先选的 $B$，和语义无关。把“字没读错”写成“手臂也没偏”，是把两把尺子兑成一把。

本课要量的不是吞吐曲线，而是同一条序列上哪一类 token 先换身份。[第 13 课](13_distributed_8gpu.md) 问八张卡切开以后 loss 和梯度还是否同一份训练语义。[第 46 课](46_omni_serving.md) 问理解、语言 decode 和动作专家能不能锁进同一条 CUDA graph。两边都碰 GPU，两边都不回答“4 bit 之后箱号会不会变”。本课的单位是比特、箱宽和 top-1。要验证的结果很具体：同一隐藏向量进三个头，8 bit 时七维动作箱与文本 top-1 都和全精度一致；4 bit 时俯仰角从箱 2 跳到箱 1，文本 top-1 仍是标签 0。CPU 实验和浏览器 Lab 都是教学夹具。通过只说明你读懂了分模态损伤协议，不说明 QVLA 的 1.49× 或 GPTQ 在 A100 上的 3.25× 被你复现了。没有论文里的 GPU 时，主路径是读完公式、跑通 CPU、在浏览器里先预测再揭晓；论文数字只许对照，不许当作自己的测量。

完成接口可以用三句话验收第 1 节。第一句：量化步长由张量绝对值最大值决定，离群值会吃掉有效档。第二句：文本 top-1 看间隔，动作 bin 看硬边界，二者对同一误差的判决不同。第三句：8 bit 可以全稳，4 bit 可以只坏动作。三句都能用 CPU 数字或 Lab 屏幕指认，再往下读公式。指认不了，先回头把 $h=[1.0,0.5,-0.25,0.125]$ 和俯仰角那一行 $[-0.40,-0.10,0.20,0.00]$ 抄到纸上，用手算一遍点积。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 量化 | 把连续浮点数映到有限整数档，再用步长乘回近似值 |
| 反量化 | 整数档乘回步长，得到可参与后续计算的近似浮点 |
| PTQ | 训练后量化：权重已经训完，用少量校准样本决定网格，不再回传 |
| QAT | 量化感知训练：训练时就模拟低比特，让权重适应网格 |
| W8A8 / W4A16 | 权重 8 bit 且激活 8 bit；或权重 4 bit、激活仍 16 bit |
| absmax | 用张量绝对值最大值当量程，对称地切出整数网格 |
| 按行量化 | 权重矩阵每一行自己有一个步长，互不借用最大值 |
| 离群通道 | 少数特征维的幅度远大于其余维，会撑大步长、挤掉有效档 |
| top-1 | 一组 logit 里得分最高的那个类别 |
| 间隔 / margin | 最大 logit 减去第二大 logit |
| 均匀分箱 | 把一维连续区间切成 $B$ 个等宽箱子，只存箱号 |
| 箱宽 $\Delta$ | $(a^{\max}-a^{\min})/B$；本课俯仰角 $\Delta=0.25$ |
| 跳类 | 量化后文本 top-1 换词，或动作箱号换格 |
| 端侧 | 在机器人机载计算机或本地消费级设备上推理，不把权重送回训练集群 |

把默认夹具写成一张表，后面 Lab 和手算都认这组数。浏览器可以在 8 bit 与 4 bit 之间切换；表里的全精度动作是点积结果，不是另写的示教。

| 头 | 全精度输出 | 8 bit | 4 bit | 判决 |
|---|---|---|---|---|
| 文本 top-1 | 0 | 0 | 0 | 未跳 |
| 文本 CE | 0.164270 | 0.163382 | 0.153974 | 甚至略降 |
| 视觉重建 L2 | 0 | 0.002226 | 0.049148 | 变大，粗类仍同槽 |
| 动作 pitch | $-0.5$，箱 2 | $-0.5$，箱 2 | $-0.514286$，箱 1 | 4 bit 跳类 |
| 其余六维动作箱 | 4,3,4,4,7,2 | 同左 | 同左 | 未跳 |

七维全精度动作和箱号写在这里，后面手算只对其中贴边的一维展开，其余六维用来证明“不是整条手臂都碎了”。

| 维 | 全精度 $a_d$ | 所在格子 | 箱号 | 4 bit $a_d$ | 4 bit 箱号 |
|---|---|---|---|---|---|
| $x$ | $0.04$ | $[0,0.25)$ | 4 | $0.054286$ | 4 |
| $y$ | $-0.225$ | $[-0.25,0)$ | 3 | $-0.200$ | 3 |
| $z$ | $0$ | $[0,0.25)$ | 4 | $0$ | 4 |
| roll | $0.10$ | $[0,0.25)$ | 4 | $0.107143$ | 4 |
| pitch | $-0.50$ | $[-0.50,-0.25)$ | 2 | $-0.514286$ | 1 |
| yaw | $0.80$ | $[0.75,1]$ | 7 | $0.80$ | 7 |
| gripper | $0.30$ | $[0.25,0.375)$ | 2 | $0.30$ | 2 |

$x$ 离左边界 $0$ 还有 $0.04$，离右边界 $0.25$ 还有 $0.21$。4 bit 只把它推到 $0.054$，远没到线。$y$ 离左边界 $-0.25$ 还有 $0.025$，4 bit 把它往右推到 $-0.20$，更安全。pitch 没有“还有多少”：它就坐在 $-0.50$ 这条线上。部署日志若只报七维平均绝对误差，pitch 的换箱会被 $x$ 和 yaw 的稳定稀释掉。本课因此要求跳维列表，而不是平均 $L_1$。

三套数字不要和论文表兑。OPT-175B 的 WikiText2、OpenFlamingo 的 CIDEr、OpenVLA 的 LIBERO 平均，单位都不是“本课的箱号”。本课反复强调的边界是判决函数。4 bit 在定长文本、间隔很大的词上仍然可以合法；本课反对的是用那一次合法去给贴边的关节签字。

## 2. 本课解决的问题

当前课程能在八卡上对账训练语义，也能画出理解、decode 与动作专家不该合录的 stage graph。缺的是：权重已经被压成整数以后，同一条多模态序列上哪一个输出先换身份。Hugging Face 式的 `load_in_4bit` 或 llama.cpp 的 `Q4_K_M` 往往只报一个生成质量或一个内存占用。VLA 论文若只报 LIBERO 平均，会把离散箱跳档和连续 L1 的轻微漂移兑在一起。本课把该诊断收成四个可证伪命题。

1. 存在一组固定权重和隐藏向量，使得按行 8 bit absmax 之后，七维动作箱与文本 top-1 都与全精度相同。
2. 同一组权重上，4 bit 会让俯仰角越过箱边界，其余六维箱号不变。
3. 同一 4 bit 设置下，文本 top-1 仍是原标签；文本 CE 不允许被写成“已经坏了”，因为本课夹具里它甚至略降。
4. 视觉重建 L2 在 4 bit 高于 8 bit，但这件事单独不能支持“视觉也跳类”；粗类仍取重建向量的最大分量。

四条都通过，只能说明分模态协议可审计。它们不能说明 GPTQ 在 OPT-175B 上相对 RTN 的 2.17 点困惑度差距可以搬到你的笔记本，也不能说明 QVLA 在 LIBERO 上相对 SmoothQuant 的 22.6% 可以写成 MiniMind-O 的成绩。定长、单头、文本-only 的 8 bit 推理，仍然可以是合法部署；本课反对的是用一个文本数字给动作签字。

把四个命题和夹具的对应写死。命题 1 两边都测：Lab 必须先揭晓 8 bit，CPU 的 `bins_8 == bins_fp`。命题 2 主要靠两边的 pitch：全精度与 8 bit 为箱 2，4 bit 为箱 1。命题 3 只认 top-1，不认 CE 升降方向。命题 4 用 `vis_l2_4 > vis_l2_8`。有人用 GPTQ 的 8.37 代替 pitch 箱号，或用 Lab 的 CE 略降写成“量化提高了语言能力”，属于用错尺子。四个命题全部是判决语义，没有一个需要 7B 权重。权重只出现在论文数字列，那一列永远单独放。

下列结果不能支持本课结论，先写下来防止事后找补：

- 只报平均重建 $L_2$ 或平均 CE，不拆文本 top-1 和动作箱号；
- 把 CPU 上的 pitch 跳箱写成 LIBERO 或真机成功率；
- 用自造的“INT4 延迟降一半”代替 GPTQ 摘要的 3.25× 或 QVLA 的 1.49×，且不写模型与设备；
- 把 W8A8 的 SmoothQuant 表和 W4A16 的 AWQ 表加在同一根“都是 8 或 4”轴上；
- 把 BitVLA 的 1.4GB 写成 OpenVLA-OFT 的 INT4 体积。

报告要分开三类内容：

- **论文事实：** GPTQ Table 5、SmoothQuant Table 1、AWQ Table 6–7、BitVLA Table I–II、QVLA 摘要四元组。必须带模型名和设置。
- **课程约定：** 同一 $h$、按行 RTN、半格朝正无穷、$B=8$、俯仰角贴在 $-0.5$。
- **待验证假设：** 在这组约定上，8 bit 全稳，4 bit 只让 pitch 换箱，文本 top-1 不变。这条由本课实验直接检验，不外推到未测机体。

本课明确不解决的问题：不训练 MiniMind-O；不实现 GPTQ 的 Cholesky 更新；不比较 FSDP2 和 ZeRO-3（那是第 13 课）；不比较 fused CUDA graph 和 stage graph（那是第 46 课）；不把屏幕点击和机械臂写成同一种身体（那是 [第 32 课](32_gui_agent_grounding.md)）。本课只引入量化损伤的分模态尺子。

和相邻课的边界再钉死一次。[第 13 课](13_distributed_8gpu.md) 的单位是训练 step：参数怎么分片、专家怎么 all-to-all，验收是 loss / 梯度 / 一步更新与单进程参考一致。本课的单位是比特与箱号：同一条前向在全精度、8 bit、4 bit 下输出是否换类。第 13 课的 CUDA 设备是训练网格里的 rank；本课即使在同一张卡上跑，也不切分片。[第 46 课](46_omni_serving.md) 关心捕获范围和 padding mask；本课假定前向形状已经合法，问的是格子里的数够不够细。 [第 24 课](24_vlm_to_vla.md) 给出 $b_d=\mathrm{clip}(\lfloor(a_d-a^{\min})/\Delta\rfloor,0,B-1)$；本课在这把尺子上叠加第二把尺子：权重量化如何推动 $a_d$。 [第 25 课](25_action_tokenization.md) 比较均匀箱、连续 L1、分块和 DCT；本课不换表示，只在默认 8 箱上量 4 bit。[第 37 课](37_dexterous_humanoid.md) 在固定比特预算下升高动作维数；本课固定 7 维，升高的是每个权重元素的比特。 [第 03 课](03_audio_codec.md) 的向量量化是把连续声音查字典；本课的整数量化是把已有权重压档。两套“量化”英文都叫 quantization，账本必须分开。

阅读顺序建议：先有 24 的箱号公式、13 的“切开不能改语义”、46 的“调度切分不是权重量化”，再读本课。缺 46 也可以：把 stage graph 想成“服务怎么切阶段”，本课四个命题不受影响。缺 13 也可以：把 FSDP 想成“训练时怎么分内存”，本课不调用集合通信。

和第 03 课再钉一次英文撞车。[第 03 课](03_audio_codec.md) 的向量量化（VQ）把一帧连续声音换成码本里的整数编号，损失发生在波形重建和可懂度上。本课的整数量化把已经训好的矩阵压档，损失发生在下一个词、下一组视觉槽、下一组关节箱上。Mimi 的 8 路残差码本再怎么砍层，也改变不了 OpenVLA 那个 256 箱的俯仰角。反过来，把 LLM 收到 4 bit，也不会把 Mimi 的码本变细。笔记里两处都写 quantization 时，必须在旁边标“codec”或“weight”。Talker 若输出的是 codec 编号，那些编号本身是离散的，对权重量化的反应更像文本 token：有间隔就稳，贴边才跳。本课夹具没有音频头，是为了不和 03–04 的 delay schedule 抢题。若你要加第四个头，先把码本 id 的间隔量出来，再谈 4 bit。

和 [第 08 课](08_dynamic_vision.md) 的关系只有一句：动态分辨率改变的是视觉 token 个数，量化改变的是每个权重元素的取值集合。patch 变多不会自动让 4 bit 更稳，也不会自动更脆。本课 $h$ 固定，不讨论 tile。

## 3. 开始前需要准备什么

本课没有 MiniMind-O 训练步骤。开始前把上游事实和本课约定分开写进实验记录。事实来自已打开的 arXiv 页面；约定是本课夹具的权重和门禁。两者混写会导致有人把 pitch 箱 2→1 当成 OpenVLA 的 LIBERO 数字。

CPU 夹具的权重一旦写下就不要改：$h=[1.0,0.5,-0.25,0.125]$，文本四行、视觉四行、动作七行见第 8 节。改权重可以当作自己的练习，但本课标准答案和 `lesson_55.py` 按这组数锁定。浏览器 Lab 用同一组数。手算前先声明用的是按行 absmax，舍入是半格朝正无穷，与 JavaScript `Math.round` 在本题上的行为一致，避免 Python 3 银行家舍入把 $-3.5$ 收成 $-4$。

**上游事实（打开过的页面，不是口口相传）：**

- GPTQ：[arXiv:2210.17323](https://arxiv.org/abs/2210.17323)。一层重建 $\lVert WX-\hat W X\rVert_2^2$；OPT-175B 全精度量化约 4.2 小时（Table 2）；WikiText2 上 OPT-175B 全精度 8.34、RTN-4 10.54、GPTQ-4 8.37（Table 3 与 Table 5）；摘要写端到端相对 FP16 约 3.25×（A100）和 4.5×（A6000）。作者写明当前结果不含激活量化。
- LLM.int8()：[arXiv:2208.07339](https://arxiv.org/abs/2208.07339)。约 6.7B 起离群特征进入全部 Transformer 层；约 150000 个离群值集中在 6 个特征维；把这些维置零会让验证困惑度恶化 600%–1000%，尽管它们只占约 0.1% 的输入特征。99.9% 的乘走 INT8，离群维走 FP16。
- SmoothQuant：[arXiv:2211.10438](https://arxiv.org/abs/2211.10438)。W8A8；离群通道在 token 之间持续出现。Table 1：OPT-175B 平均准确率 FP16 71.6%，INT8 per-tensor 32.3%，INT8 per-channel 71.4%。摘要写最高 1.56× 加速、2× 显存下降。
- AWQ：[arXiv:2306.00978](https://arxiv.org/abs/2306.00978)。保护约 1% 显著通道；OpenFlamingo-9B、INT4-g128、COCO 32-shot CIDEr：FP16 81.70，RTN 77.13（Δ −4.57），AWQ 80.53（Δ −1.17）（Table 6）。VILA-7B VQAv2：80.3 对 AWQ 80.1（Table 7）。TinyChat 相对 Hugging Face FP16 平均 3.2–3.3×。论文还写：Llama-2-70B 可放到一块 64GB 的 Jetson Orin 上；13B 在 8GB 的笔记本 RTX 4070 上约 30 token/s。这些是作者的端侧测量，抄写时带模型和设备。其技术报告未在本课展开逐层内核耗时，本课不把 30 token/s 写成动作控制频率。
- QLoRA：[arXiv:2305.14314](https://arxiv.org/abs/2305.14314)。4 bit NormalFloat；65B 可在单张 48GB 上微调。本课把它留在“存储格式”列，不当作端侧动作验收。
- QVLA：[arXiv:2602.03782](https://arxiv.org/abs/2602.03782)。按通道、按动作空间敏感度分配 $\{0,2,4,8,16\}$ bit。摘要：OpenVLA-OFT 量化版占原 VRAM 的 29.2%，保持原性能的 98.9%，1.49×，相对 SmoothQuant 高 22.6%。引言写 7B 半精度常超过 14GB；Jetson AGX Orin 上“每步数百毫秒”是作者的定性描述，其技术报告未给出可复现的逐步计时表，本课不把它写成自己的延迟数字。

## 5. 原理：边造边讲

八个机制，每个按同一节奏：为什么需要、怎么运转、精确定义、在公开实现里落在哪、怎么证明做对了。本课没有 MiniMind-O 量化运行时可改，代码落点改到论文公式和本课夹具。

### 5.1 端侧量化量的是损伤，不是调度，也不是数据并行

为什么需要。端侧内存按字节收费。7B 半精度权重大约 14GB 量级，QVLA 引言把它写成部署障碍；BitVLA Table I 把 OpenVLA-OFT 记成 15.4GB。压到 4 bit，理论权重大约变成四分之一，具体还要加步长、零点和内核对齐。内存账是动机，不是验收。验收必须回答：压完以后，模型吐出的下一个词、下一组视觉槽、下一组关节箱是否还是原来的身份。

怎么运转。训练并行把一份优化状态切开，推理图把一次前向切成阶段。量化把每个元素的取值集合变小。三者可以叠在同一条部署流水线上，但失败模式不同。FSDP 切错会让梯度对不上；CUDA graph 合错会让 padding 进注意力；量化切错会让箱号换格。本课只训练你看第三种。

数学。记全精度前向为 $f(x;W)$。量化算子 $Q_b$ 产出 $\hat W=Q_b(W)$。权重空间的 $\lVert W-\hat W\rVert$ 只说明网格有多粗。本课拿来验收的是三个判决：

$$
\begin{aligned}
d_{\mathrm{text}}&=\mathbf{1}\bigl[\arg\max z(x;\hat W)\ne \arg\max z(x;W)\bigr],\\
d_{\mathrm{vis}}&=\lVert v(x;\hat W)-v(x;W)\rVert_2,\\
d_{\mathrm{act}}&=\mathbf{1}\bigl[b(a(x;\hat W))\ne b(a(x;W))\bigr].
\end{aligned}
$$

$z$ 是文本 logit，$v$ 是视觉重建，$a$ 是连续动作，$b$ 是逐维分箱。$d_{\mathrm{text}}$ 和 $d_{\mathrm{act}}$ 是 0/1；$d_{\mathrm{vis}}$ 是非负实数。禁止把三个数平均成“量化分数”。

公开实现。GPTQ / AWQ 的默认评测是语言困惑度或视觉-语言基准；QVLA 把目标改写成动作分布的 KL；BitVLA Table II 同时给出离散 VLA 和连续 OFT 的 INT4。本课夹具比这些都小，判决函数同构。

验证。CPU 的 `jumped_dims_4 == ["pitch"]` 且 `text_top1_4 == 0`。任一为假，命题 2 或 3 失败。

### 5.2 对称 absmax：步长、有效档和半格舍入

为什么需要。没有网格就没有“8 bit / 4 bit”这句话。最简单、也最容易手算的网格是对称 absmax：找到最大值的绝对值，把它当成最远端的整数档。

怎么运转。对向量 $x$，比特数 $b$，整数上限 $q_{\max}=2^{b-1}-1$。8 bit 时 $q_{\max}=127$，4 bit 时 $q_{\max}=7$。步长

$$
\Delta_Q=\frac{\max_i|x_i|}{q_{\max}}.
$$

编码 $q_i=\mathrm{clip}(\mathrm{round}_{+0.5}(x_i/\Delta_Q),-q_{\max},q_{\max})$，反量化 $\hat x_i=q_i\Delta_Q$。本课 $\mathrm{round}_{+0.5}$ 定义为 $\lfloor u+0.5\rfloor$，半格朝正无穷。这和 Lab 里的 `Math.floor(x+0.5)` 一致。Python 3 内置 `round(-3.5)` 是银行家舍入，会得到 $-4$，夹具里禁止用它。

数学。单元素误差满足 $|\hat x-x|\le \Delta_Q/2$，前提是没有撞到 $\mathrm{clip}$。按行量化时，每一行自己的 $\Delta_Q$。俯仰角那一行 $[-0.40,-0.10,0.20,0.00]$，峰值为 $0.40$，4 bit 步长 $0.40/7\approx 0.05714286$。整数码是 $[-7,-2,4,0]$，反量化 $[-0.40,-0.1142857,0.2285714,0]$。

公开实现。SmoothQuant 公式 (1) 用 $\max(|X|)/(2^{N-1}-1)$，与这里同族。LLM.int8() 对整张量做 absmax，再按行/列向量加各自的归一化常数。GPTQ 在网格给定之后，用二阶信息调整尚未量化的权重，网格本身仍是非对称或对称的均匀档。

验证。`pitch_codes_4 == [-7,-2,4,0]` 且 `abs(pitch_scale_4 - 0.4/7) < 1e-12`。若有人用银行家舍入，$-0.10/0.05714286=-1.75$，本题未碰到半数；真正的陷阱在别的行。`half_up(-3.5)==-3` 这条检查是为 Lab 对齐准备的。

按行和按张量差在谁的最大值当量程。文本头四行拼成一张 $4\times 4$ 矩阵，全精度最大绝对值是 $2.40$。若整张矩阵共用一个 4 bit 步长，$2.40/7\approx 0.34286$，第一行几乎只剩 $\pm 7$ 和少数邻居，第三行 $0.10$ 一类的小数会被收成 $0$ 或一档。按行量化时，第三行自己的峰值只有 $0.30$，步长 $0.30/7\approx 0.04286$，小系数还能活。本课夹具采用按行，因为 GPTQ / AWQ 的默认也是每行或每组自己的网格。若你把夹具改成按张量，文本间隔会先被削，动作跳箱和文本跳类可能撞在一起，命题 3 的“文本仍稳”就不再免费成立。改网格属于约定变更，必须重写第 10 节，不许偷偷换网格还要求旧门禁。

组量化是按行的邻居。把一行切成每 $g$ 个连续权共享一个步长，$g=128$ 是 AWQ 全文默认。组越小，步长越跟得上局部幅度，额外比特大约是每组一个 FP16 步长：$16/g$ bit/weight。GPTQ Table 5 在 3 bit 上写了分组：OPT-175B 的 WikiText2 从无分组的 8.68 收到 g1024 与 g128 的 8.45；C4 从 10.67 收到 g1024 的 10.47、g128 的 10.36。抄的时候带组大小，不要把 8.45 写成“3 bit 已经无损”。本课夹具每行只有 4 个元素，组大小没有自由度，不必假装自己做了 $g=128$。

### 5.3 离群通道：为什么 8 bit 也会把有效档吃光

为什么需要。若只看权重直方图，许多层看起来很均匀，8 bit 似乎绰绰有余。LLM.int8() 指出：大约从 6.7B 起，隐藏状态里会出现幅度可高出约 20 倍的特征维，并且这些维会扩散到全部层。步长被这几个维撑大，其余维只剩两三个有效整数档。

怎么运转。SmoothQuant Table 1 把这件事写成准确率：OPT-175B 的 INT8 per-tensor 掉到 32.3%，几乎不可用；换成对激活做 per-channel，回到 71.4%，和 FP16 的 71.6% 持平。硬件上的 INT8 GEMM 通常不能按输入通道各自缩放，所以 per-channel 激活在论文里被标成“数值上对、内核上不友好”。SmoothQuant 的回答是把通道缩放挪到权重上：$\hat X=X\,\mathrm{diag}(s)^{-1}$，$\hat W=\mathrm{diag}(s)W$，前向代数不变，激活变平滑，权重仍可量化。

数学。若整张激活的最大值是 $m$，通道 $i$ 的最大值是 $m_i$，则该通道的有效档大约是 $2^b\cdot m_i/m$。$m_i/m$ 到 $1/100$ 时，8 bit 只剩两档左右。LLM.int8() 不平滑，而是把离群维拆到 FP16 矩阵乘，其余 99.9% 走 INT8。SmoothQuant 选一个每通道正数 $s_i$，令

$$
X_{:,i}\leftarrow X_{:,i}/s_i,\qquad W_{i,:}\leftarrow s_i W_{i,:}.
$$

乘积 $XW$ 不变。$s_i$ 取大，激活通道被压平，权重通道变陡。论文 Figure 4 在 OPT-13B 的一层上画过：平滑前激活里有大于 70 的通道，平滑后这些尖刺被挪到权重上，权重仍然相对平坦。$\alpha$ 控制挪多少，太大则权重量化开始坏。本课夹具不实现 $s_i$，因为三个头已经分开量化，没有共享一张被离群撑破的激活。读到这里只要求能指出：离群在激活里时，W8A8 先坏；离群被挪到权重后，W4A16 的显著通道保护（AWQ）才对上号。

把离群故事和贴边故事分家。离群是少数维幅度极大，步长被撑爆，多数维有效档变少。贴边是输出值落在判决面上，任意小的负向扰动都会换箱。本课夹具的 $h$ 各维幅度都在 $1$ 附近，没有 70 那种尖刺；损坏来自贴边。真实 7B 模型两种可以同时在。诊断时先看激活直方图有没有长尾，再看动作值有没有压在 $k\Delta$ 上。只处理一种，另一种仍会在真机接触帧上出现。

公开实现。`bitsandbytes` 的 `Linear8bitLt` 对应 LLM.int8()。SmoothQuant 的官方仓库按 OPT / Llama 插入平滑因子。AWQ 不量化激活，只根据激活幅度放大显著权重通道，属于 W4A16 路线。

验证。本课夹具没有人为塞进 100× 离群，避免和动作边界故事抢戏。读论文时用 Table 1 的 71.6 / 32.3 / 71.4 三格做对照，不要在夹具里重造 175B。若你自己改夹具，把 $h$ 的某一维乘 50 再按张量量化，文本间隔会被压缩；那是合法的扩展实验，不是本课门禁。

### 5.4 权重量化三条路：RTN、GPTQ、AWQ

为什么需要。同一网格，不同的选档策略，损伤差一个数量级。GPTQ Table 5：OPT-175B 的 4 bit，RTN 把 WikiText2 从 8.34 推到 10.54，GPTQ 收到 8.37。3 bit 时 RTN 直接塌到 $7.3\times 10^3$，GPTQ 仍在 8.68。

怎么运转。RTN 就是上一小节的就近入格，每行独立，不用校准前向。GPTQ 把一层写成最小二乘 $\arg\min_{\hat W}\lVert WX-\hat W X\rVert_2^2$，按列块量化，并用 Hessian $H=2XX^\top$ 的逆去补偿尚未量化的权重。校准样本进入 $X$，所以 GPTQ 会“记住”校准域。Table 2 给出单卡 A100 上的全模型量化时间：OPT-13B 20.9 分钟，OPT-30B 44.9 分钟，OPT-66B 1.6 小时，OPT-175B 4.2 小时；BLOOM-176B 3.8 小时。这些小时数是“做成量化权重要多久”，不是推理延迟。AWQ 观察到：按激活幅度选出约 1% 的显著通道，若保持 FP16，OPT-6.7B 的 INT3-g128 困惑度可以从 RTN 的 23.54 收到 11.39（Table 1，1% 按激活选）。按权重大小选 1%，同一表是 22.37，几乎没救。混精度内核不友好，于是改成放大这些通道再全部入格。AWQ 不用回传，校准只统计通道幅度，论文把它写成对指令模型和多模态模型更稳。OpenFlamingo-9B 在 INT3-g128、32-shot 上，GPTQ 的 CIDEr 掉到 64.77（Δ −16.93），AWQ 掉到 74.47（Δ −7.23），RTN 掉到 64.79（Δ −16.91）。视觉-语言上的“校准过拟合”在 Table 6 里看得见。

数学。GPTQ 单步补偿（论文公式 2 的结构）是：量化一个权重 $w_q$ 后，剩余权重加上

$$
\delta_F=-\frac{w_q-\mathrm{quant}(w_q)}{[H_F^{-1}]_{qq}}(H_F^{-1})_{:,q}.
$$

AWQ 的搜索目标（论文 §3.2）是找每通道尺度 $s$，使

$$
\mathcal{L}(s)=\lVert Q(W\,\mathrm{diag}(s))\,(\mathrm{diag}(s)^{-1}X)-WX\rVert
$$

最小。本课夹具走 RTN，因为要手算；论文列走 GPTQ / AWQ 的表。

公开实现。`AutoGPTQ`、`gptqmodel`、Hugging Face `GPTQConfig`；`llm-awq` 与 TinyChat。Qwen 发布过 Qwen2.5-Omni-7B 的 GPTQ-Int4 权重卡片，其技术报告未在本课打开的页面里给出分模态损伤表，本课不编那张表里的分数。

验证。不要在 CPU 里重写 Cholesky。验证本课读懂了差异即可：记录里必须出现“RTN 无校准补偿 / GPTQ 用 $X$ 补偿 / AWQ 用激活幅度缩放”。缺一句，第 10 节第 8 条失败。

### 5.5 文本 token：间隔保护 top-1

为什么需要。人们习惯用 CE 或困惑度当“语言坏了没有”的唯一尺子。夹具里 4 bit 的 CE 从 0.164270 降到 0.153974，若只看 CE，会得出“量化让语言更好”的假故事。真判决是 top-1。

怎么运转。文本头四行与 $h$ 点积，全精度 logit 为 $[3.1375, 0.9625, -0.06875, -0.575]$，间隔 $2.175$。4 bit 后 $[3.214286, 0.985714, -0.091071, -0.598214]$，间隔 $2.228571$。量化噪声大约 $10^{-1}$ 量级，远小于间隔。softmax 之后标签 0 的概率从 0.8485 升到 0.8573，所以 CE 下降。下降来自赢家 logit 被网格推得更远，不是模型变聪明。

数学。若 $z_1-z_2>\varepsilon$，且每个 logit 的扰动不超过 $\varepsilon/2$，则 $\arg\max$ 不变。本课 $\varepsilon\approx 2.18$，4 bit 权重量化引起的 logit 变化约 $0.08$，满足该充分条件。CE 是 $-\log p_{y}$，它可以在不换 $\arg\max$ 时升或降。

公开实现。GPTQ / AWQ 报 WikiText2 困惑度，那是全序列平均 CE 的指数，对“某一个 token 有没有换词”不敏感。部署日志若只打平均 CE，本课视为漏报。

验证。`text_top1_fp == text_top1_8 == text_top1_4 == 0` 且 `text_margin_4 > 2.0`。允许 CE 下降。

### 5.6 视觉 token：L2 先动，粗类后动

为什么需要。视觉编码器输出连续向量。量化后每个分量漂移，L2 几乎一定上升。若把 L2 当成跳类，4 bit 永远“坏了”，无法和动作箱对比。

怎么运转。视觉头四行在全精度下重建 $v=W_{\mathrm{vis}}h=[1.04375,0.43125,-0.2625,0.29375]$。8 bit L2 为 0.002226，4 bit L2 为 0.049148。最大分量始终在第 0 槽。AWQ Table 6 给出同一精神的大规模版本：INT4 后 CIDEr 会掉，但掉多少取决于你是否保护显著通道；Table 7 里 VILA-7B 的 VQAv2 从 80.3 到 80.1，几乎不动。这些数字是视觉-语言基准，不是本课 L2。

数学。粗类 $c=\arg\max_i v_i$。与文本相同，只要分量间隔大于扰动，粗类不变。本课第 0 槽与第 1 槽全精度差约 $0.61$，4 bit 扰动小于该值。

公开实现。OpenFlamingo / VILA 的 AWQ 脚本量化语言模型权重大于量化视觉编码器；具体哪几层保持更高比特，以各仓库配置为准，其技术报告未在本课展开每一层的比特表。BitVLA 则把视觉编码器单独做 Quantize-then-Distill，压到 1.58-bit 权重、INT8 激活，并用全精度教师对齐表征。

验证。`vis_l2_4 > vis_l2_8 > 0`。Lab 另显示粗类是否跳；门禁不要求粗类跳。

### 5.7 动作 token：箱边界比 CE 先坏

为什么需要。这是本课的主命题。[第 24 课](24_vlm_to_vla.md) 已经写出箱号公式。本课要你看见：权重量化推动的是连续值 $a_d$，判决却发生在 $\lfloor(a_d-a^{\min})/\Delta\rfloor$ 的整数面上。值贴在面上，再小的推动也换箱。

怎么运转。动作头七行，俯仰角行 $w=[-0.40,-0.10,0.20,0.00]$，

$$
a_{\mathrm{pitch}}=w\cdot h=-0.40-0.05-0.05+0=-0.50.
$$

区间 $[-1,1]$，$B=8$，$\Delta=0.25$。$(-0.50-(-1))/0.25=2$，箱号 2，格子是 $[-0.50,-0.25)$。8 bit 按行量化后点积仍是 $-0.50$。4 bit 后

$$
a_{\mathrm{pitch}}=-0.40+(-0.1142857)(0.5)+(0.2285714)(-0.25)=-0.5142857,
$$

$(-0.5142857+1)/0.25=1.942857$，箱号 1。其余六维的全精度值离边界更远：例如 $x=0.04$ 在 $[0,0.25)$ 内部，$y=-0.225$ 在 $[-0.25,0)$ 内部。4 bit 把它们挪了一点，仍未过线。

反量化后的命令用格心。箱 2 的格心是 $-0.375$，箱 1 的格心是 $-0.625$。箱号一换，发给控制器的俯仰角跳了 $0.25$，等于整整一个箱宽，不是半个量化步长。半个量化步长只有 $0.0286$。两种“半格”不要兑。

数学。设真值 $a=a^{\min}+k\Delta$，即正好落在箱 $k$ 的左端。任何负向扰动 $\delta<0$ 都满足

$$
\biggl\lfloor\frac{a+\delta-a^{\min}}{\Delta}\biggr\rfloor=k-1.
$$

文本间隔是训练出来的软间隔；箱边界是你写进配置的硬间隔。同一 $\delta$ 在两边的判决不同。BitVLA Table II 提供大规模旁证：把 OpenVLA（离散箱 + CE）做 INT4 PTQ，LIBERO 平均从 76.5 到 72.7，Goal 套件从 79.2 到 72.0；同一表里 OpenVLA-OFT（连续 L1）从 97.1 到 96.9。离散箱对 PTQ 更敏感，和本课夹具同方向。绝对值禁止兑。

公开实现。OpenVLA 用词表尾部 256 个 token 表示每维动作。箱数 256 时 $\Delta$ 更小，贴边概率看起来更低，但接触阶段的微调同样会把值推到面上。教学夹具用 $B=8$ 是为了让半箱 $0.125$ 和 4 bit 步长 $0.057$ 处在同一数量级，肉眼看得见。换成 $B=256$、区间仍是 $[-1,1]$，箱宽变成 $2/256\approx 0.0078$。这时 4 bit 权重引起的 $0.014$ 级漂移可以一次跨过一到两箱。方向不变：硬边界仍然比文本间隔先坏，只是坏的时候跳得更碎。QVLA 不再最小化表征重建，而最小化动作分布的 KL，并按通道敏感度降比特。那是在承认：动作空间的误差比中间层 MSE 更接近任务失败。

贴边不是病理数据，是控制里的常态。夹爪合上、手腕对准杯口、把物体放到桌面，连续值都会在某次控制周期里压到量化网格或动作箱的面上。示教里把俯仰角刚好标成 $-0.5$，和本课夹具同构。评测若只用“走过去拿杯子”这种大行程，平均 $L_1$ 很小，接触那一帧的换箱不会进平均。所以 golden case 必须包含至少一帧贴边动作，否则端侧回归会假绿。

验证。`four_bit_pitch_crosses_bin_boundary` 整条为真：箱号 2/2/1，跳维列表只有 `pitch`。Lab 必须在 4 bit 揭晓后看到 pitch 格子变色。

其余六维建议至少手算两维，确认“没跳”不是因为你没看。$x$ 行 $[0.08,-0.10,0.04,0.16]$，全精度 $0.08-0.05-0.01+0.02=0.04$。4 bit 后该行峰值 $0.16$，步长 $0.16/7\approx 0.022857$，点积约 $0.054286$，仍在 $[0,0.25)$。$y$ 行 $[0.20,-0.80,0.10,0]$，全精度 $0.20-0.40-0.025= -0.225$。4 bit 峰值 $0.80$，步长 $0.80/7\approx 0.114286$，$-0.80$ 仍是最远端，$-0.225$ 被推到 $-0.20$，仍在 $[-0.25,0)$。$z$ 行全零，任何比特都是 $0$，箱 4。零行是对照：量化改变不了本来就是空的命令。夹爪 $0.30$ 在 $[0,1]$ 上箱宽 $0.125$，落在箱 2 的内部，4 bit 后仍是 $0.30$。七维里只有俯仰角既非零、又贴边、又被 4 bit 推向更负。这种“只有一维跳”比“七维全跳”更有教学价值：平均 $L_1$ 可以看起来很小，任务却已经换成另一个俯仰档。

### 5.8 同一序列、三个头、两套比特

为什么需要。若文本、视觉、动作用不同输入，损伤排序会被输入差异污染。端侧真实请求是一张图、一句话、一段要执行的动作，隐藏状态共享。

怎么运转。夹具让三个头读同一个 $h$。量化发生在各自的权重行上，互不借用步长。8 bit 与 4 bit 是两次独立的 $Q_b$，中间不重置 $h$。浏览器滑条只改 $b$，不改 $h$。这才能说“同一序列”。

数学。记三个头的权重为 $W^{(t)},W^{(v)},W^{(a)}$。协议要求

$$
h_{\mathrm{text}}=h_{\mathrm{vis}}=h_{\mathrm{act}},\qquad
b\in\{8,4\}.
$$

报告必须同时列出 $(d_{\mathrm{text}},d_{\mathrm{vis}},d_{\mathrm{act}})$ 在两个 $b$ 上的值。缺一格，协议失败。

公开实现。真实 Omni 里视觉编码器和 LLM 不共享全部线性层，动作专家可能另有一块。QVLA 正是因为通道敏感度跨模块不均匀，才做逐通道比特。本课把“跨模块不均匀”缩成三个头；缩小版保留的是“必须分列”，不是“必须只有一个 $h$”。

验证。Lab 文案写明同一 $h$。CPU 里三个 `evaluate` 调用共用 `HIDDEN`。若有人改成三个 $h$，第 10 节第 1 条失败。

### 5.9 端侧更常走 W4A16，服务端才更常谈 W8A8

为什么需要。比特设置写错，后面所有表都对不上。AWQ 把研究范围写成 weight-only、INT3/INT4、激活仍 FP16，并给出硬件理由：端侧生成是读权重受限，权重大约占总访存的绝大部分，把权重从 16 bit 收到 4 bit，算术强度大约升到 4 FLOP/Byte。SmoothQuant 走另一条：权重和激活都 INT8，才能调用 INT8 GEMM，吞吐接近翻倍，显存约减半。两条路的失败模式不同。W4A16 的损伤主要来自权重网格；W8A8 的损伤主要来自激活离群。本课夹具是 W4A16 的缩小版：只量化权重，隐藏向量 $h$ 保持原样。若有人把 $h$ 也收到 4 bit，pitch 仍会跳，文本间隔会被再削一刀，命题 3 可能被你自己破坏。

怎么运转。解码一步的输入是一个 token 的隐状态，形状接近 $(1,d)$，权重是 $(d,d_{\mathrm{out}})$。读权重的字节数远大于读激活。训练或 prefill 长序列时，激活体积涨上来，W8A8 的算力收益才明显。机器人端侧常见的是低频视觉、逐步动作，更接近 decode。QVLA 仍把激活写成均匀比特（例如 8 bit）以保证无分支路径，权重才按通道分配 $\{0,2,4,8,16\}$。那是“权重细、激活粗且固定”，和本课夹具同方向。

数学。访存主导时，逐步延迟大致随权重字节数下降。论文里的 3.25×、3.2×、1.49× 都是作者在自己内核上量的，单位是壁钟或相对吞吐。本课禁止把“字节变成四分之一”写成“延迟变成四分之一”。没有作者的内核，连比例都不许填。

公开实现。TinyChat 把 4 bit 解量化融进矩阵乘主循环，因为硬件没有 INT4×FP16 指令。GPTQ 原文同样声明：当时主流架构缺少这种混合精度乘法，所以他们的加速来自少读内存，不来自 INT4 算术。LLM.int8() / SmoothQuant 才真正把乘本身改成 INT8。抄加速数字时先问：解量化发生在寄存器里还是写回 DRAM？写回 DRAM 的 4 bit 往往不加速。

验证。实验记录必须出现 `W8A16` 或 `W4A16` 字样。Lab 公式条写 `W{bits}A16`。写成 W4A4 却没量化 $h$，第 10 节第 9 条失败。

端侧还有一条容易漏的账：视觉编码器往往仍是半精度或单独一套内核。AWQ 量化的主要是语言模型线性层。BitVLA 反过来把视觉侧专门蒸馏到 1.58-bit。QVLA 则在视觉、投影、LLM、动作头上按通道混比特。三篇论文的“模型已经 4 bit”不是同一句话。写部署清单时拆四行：视觉、投影、LLM、动作。哪一行没写比特，就当它还是训练时的精度，不要默认它已经跟着 LLM 被压下去。本课夹具把三个头都压，是为了在最小例子上制造分叉；真实脚本里动作头漏压或过压，都比“三个头同一比特”更常见。漏压时文本 CE 好看、内存降不下来；过压时聊天还行、接触帧翻车。两种都要用第 11 节的表定位，不要先重训。

控制频率和 token/s 也不要兑。OpenVLA 原文在 4090 上大约 6 Hz 出动作（第 25 课已引）。AWQ 的 30 token/s 是语言 decode。自回归 VLA 一步动作要吐 7 个箱号，语言意义上的 30 token/s 只对应大约 $30/7\approx 4.3$ Hz 的命令率，还没算视觉编码。OFT 并行头一次吐一段，Hz 可以高很多，量化损伤却走连续误差。本课不测 Hz。笔记里若同时出现 token/s 和 Hz，必须写清分母是词还是控制周期。

把“先坏”说成时间顺序会误导。真实系统里三个头几乎同时算完。本课的“先”是判决敏感度：比特往下走时，哪一个布尔先从 0 变成 1。8 bit 全是 0，4 bit 只有动作是 1，所以动作先坏。若你测 6 bit、5 bit，可能找到更早的跳变点；那是合法的扩展，本课滑条只给 8 与 4，因为验收要的是这一对。不要在报告里写“我们扫了 2 到 16 bit，pitch 在 5 bit 跳”，却仍要求本课 Gate 承认。Gate 只认 8 和 4 两次揭晓。扫中间比特是自己的练习，结果写在附录，标题标明“非本课门禁”。附录里的跳变点若和夹具权重不一致，先承认你改了权重。改权重之后，第 10 节整节要重写布尔，不能只改一个数字。课程网站上的 Lab 不会跟着你的附录走，验收仍以仓库里的 `lesson_55.py` 为准。编排者登记实验之前，用第 8 节那条单命令导入 `run()`；登记之后用仓库脚本跑第 55 课。两种入口必须得到同一份 `checks`。入口不同、箱号不同，先查 `PYTHONPATH` 是不是指到了另一份拷贝。本课文件名是 `lesson_55.py`，不要和 `lesson_25.py` 的分箱函数抄串：第 25 课的示教轨迹和 6 Hz 来回是另一条夹具，箱数、区间可以相同，隐藏向量和权重行不同。两课的箱号对不上，不是量化坏了，是你拿错了输入。第 37 课的固定比特预算也是另一把尺子：它升高动作维数，本课升高每个权重元素的比特。维数实验里的“箱变粗”来自预算切分，量化实验里的“箱号变了”来自权重网格。两句话里都有“箱”，日志里必须写清是哪一种。写不清就先停笔，把第 24 课的 $\Delta$、第 37 课的 $C=Hd$、本课的 $\Delta_Q$ 三个符号抄在页眉。三个符号混用一次，整页数字作废。$\Delta$ 是动作箱宽，$C$ 是动作块预算，$\Delta_Q$ 是权重量化步长。本课门禁用 $\Delta$ 和 $\Delta_Q$ 的相对大小解释 pitch 为什么在 4 bit 过线；不用 $C$，因为 $H$ 与 $d$ 都冻住了。夹具里 $\Delta=0.25$，$\Delta_Q\approx 0.057$，比值大约四。步长一旦涨到箱宽的两成以上，贴边维就会换箱。这句可以当口诀，但不能代替手算点积。口诀只帮你决定先查哪一维，点积才能决定箱号。先查贴边维，再查零行，最后才看离边界最远的那几维。零行必须仍是零。这是对照。

| 动作分箱 | OpenVLA 256 箱；本课 8 箱 | `uniform_bin` |
| 动作敏感度 | QVLA 的通道敏感度与贪婪降比特 | 本课不实现，只对照摘要数字 |
| 离散 vs 连续 | BitVLA Table II 的 OpenVLA / OFT | 夹具只演示离散箱 |

定位时打开论文 HTML，不要凭记忆填表号。GPTQ 的 8.37 在 Table 5，OPT 全家的 4 bit 在 Table 3。AWQ 的 OpenFlamingo 在 Table 6，VILA 在 Table 7。BitVLA 的 INT4 对照在 Table II。QVLA 的 29.2% / 98.9% / 1.49× 写在摘要，正文重复一次；若你引用套件级细表，必须再打开对应表格，本课正文不编细表。

GPTQ Table 3 可以当“模型越大越好压”的阅读练习，但不要写成定律。OPT-175B 的 4 bit GPTQ 只比全精度高 0.03 困惑度；OPT-125M 从 27.65 到 31.12，相对伤口大得多。作者也写了 OPT-66B 是例外。本课夹具没有层数可缩，不能复现“变大就更稳”。能复现的是：同一网格上，间隔大的头稳、贴边的头脆。把 Table 3 的尺度效应和本课的贴边效应写成同一句话，读者会以为只要换 7B 就不用再看箱号。7B 的 OpenVLA 在 Table II 里仍然掉了 Goal。尺度帮得了语言困惑度，帮不了接触面。

Qwen2.5-Omni 技术报告（[arXiv:2503.20215](https://arxiv.org/abs/2503.20215)）讲 Thinker–Talker 与 TMRoPE，不讲 INT4 对各模态的损伤。社区有 GPTQ-Int4 权重卡片。本课把它记成“存在端侧权重、其技术报告未公开分模态损伤表”，到此为止。

读任何一张量化模型卡片，按五问过一遍，答不上就不要把卡片抄进成绩栏。第一问：量化了哪些模块，视觉、Talker、Vocoder、动作头有没有一起压。第二问：W 和 A 各多少比特，有没有组大小。第三问：评测是哪一张表，文本、图文还是操作。第四问：对照基线是 FP16 原模型还是另一个量化方法。第五问：有没有逐步延迟，设备是什么。五问里缺延迟，写“未公开”；缺模块清单，当作只有 LLM 被压。Qwen2.5-Omni 的技术报告过不了第一问和第三问的分模态部分，所以本课只用它当结构对照，不用它当损伤对照。

Talker 若被一起压，损伤尺子要换。Talker 吐的是 codec 编号，判决更像文本 top-1：某一帧 8 路里的某一路换 id，听感不一定立刻坏，但 ASR 词可能已经变。本课不把听感写成箱号。若你的端侧 Omni 同时出字、出声、出动作，验收至少三列：字的 top-1 或 golden token，声的 codec id 或 ASR，动作的箱号。少一列，就回到第 01 课补 golden case，不要在量化节里发明听感分数。

## 7. 数据与测量 recipe

本课数据是一组冻结的权重，不是语料混合物。recipe 的作用是防止有人用自己的随机矩阵替换夹具后，仍要求 pitch 跳箱。

**字段：**

| 字段 | 值 | 用途 |
|---|---|---|
| `HIDDEN` | `[1.0, 0.5, -0.25, 0.125]` | 三个头的唯一输入 |
| `W_TEXT` | 4×4，见源码 | 文本 logit |
| `W_VIS` | 4×4，见源码 | 视觉重建 |
| `W_ACT` | 7×4，俯仰角行 `[-0.4,-0.1,0.2,0]` | 连续动作 |
| `ACTION_BINS` | 8 | 与第 24 课教学 $B$ 一致 |
| 前六维区间 | $[-1,1]$ | 箱宽 0.25 |
| 夹爪区间 | $[0,1]$ | 箱宽 0.125 |
| 舍入 | $\lfloor u+0.5\rfloor$ | 跨语言一致 |
| 比特 | $\{8,4\}$ | Lab 滑条只给这两个 |

**不要混进 recipe 的东西：** 论文困惑度、LIBERO 成功率、任何延迟、任何功耗。那些进对照列。

**测量顺序：** 先全精度，再 8 bit，再 4 bit。每次都写文本 top-1、视觉 L2、七个箱号。最后写跳维列表。8 bit 的跳维列表必须空，4 bit 必须恰好 `pitch`。

**校准样本。** 本课 RTN 不需要校准。若你做改造实验 3（改成 GPTQ 式补偿），校准 $X$ 必须写进 recipe，并声明域。用文本校准去补偿动作头，属于域错误，预期动作箱更不稳。AWQ 的校准只统计通道平均幅度，用 Pile 上的一小段，论文强调这是为了少过拟合到下游。VLA 若只用语言 Pile 统计幅度，动作头的显著通道可能排错。缩小版不要假装自己有 Pile；改造 2 的“动作头留 8 bit”已经表达了同一保护意图。

一份错误 recipe 的典型样子：比特写成“int4”，不写 W 还是 A；箱数写成 256，却用本课的 $[-1,1]$ 区间去解释 OpenVLA 的分位归一化；隐藏向量用随机数，却要求 pitch 跳箱。三处任何一处出现，CPU 的 `checks` 会对不上，这时改的是记录，不是改 `lesson_55.py` 去迁就随机数。OpenVLA 的 1%–99% 分位标定区间，第 25 课已经写过。本课为了手算，把区间冻成 $[-1,1]$ 和 $[0,1]$。两套区间不要在同一张草稿纸上混用。分位标定会把训练集里很少出现的极端关节角挤到两端箱子；贴边仍然会发生，只是边的物理含义变了。

种子与确定性。夹具没有随机数。两次 `run()` 的 `pitch_4` 必须逐 bit 相同。若你看到浮点在 $10^{-15}$ 上晃，先查是不是用了 `round()` 银行家舍入。Lab 与 CPU 对不上，先对 `half_up(-3.5)`，再对步长 $0.4/7$。不要先怀疑浏览器“精度不够”。本题所有中间量都能用分数 $2/35$ 写：步长 $2/35$，$-2\times 2/35=-4/35$，点积 $-0.4-0.05-4/35\times 0.25$，可在纸上通分。

## 8. 按依赖顺序执行实验

不要先打开论文表再回头改夹具。顺序是：手算俯仰角、跑 CPU、再玩 Lab、最后抄论文列。

### Step 0：抄隐藏向量和三个头的形状

$h$ 长度 4。文本头 $4\times 4$，视觉头 $4\times 4$，动作头 $7\times 4$。先确认没有把动作头误写成 $4\times 7$。点积从左边的行取四个系数。形状错了，后面所有箱号都无意义。CPU 源码里 `W_ACT` 的第五行（下标 4）才是俯仰角。

### Step 1：手算俯仰角全精度箱号

$$
a=-0.4\times 1.0+(-0.1)\times 0.5+0.2\times(-0.25)+0\times 0.125=-0.5
$$

$$
b=\biggl\lfloor\frac{-0.5-(-1)}{0.25}\biggr\rfloor=2
$$

写在纸上。不要用计算器的“接近 2 所以箱 2”这种口语，把中间的 $2.0$ 写出来。

### Step 2：手算 4 bit 反量化后再点积

峰值 $0.4$，步长 $0.4/7$。$-0.1/(0.4/7)=-1.75$，朝正无穷半格得 $-2$；$0.2/(0.4/7)=3.5$，得 $4$。点积 $-0.5142857$，箱号 1。这一步不过，不要跑 Lab。

把文本赢家行也手算一遍，避免只信动作。第一行 $[2.40,1.20,-0.40,0.30]$ 与 $h$ 点积

$$
2.40\times 1+1.20\times 0.5+(-0.40)\times(-0.25)+0.30\times 0.125=2.40+0.60+0.10+0.0375=3.1375
$$

第二名 $[0.80,0.40,0.20,0.10]$ 得 $0.80+0.20-0.05+0.0125=0.9625$。间隔 $2.175$。4 bit 按行量化后赢家变成 $3.214286$，间隔 $2.228571$。间隔变大，所以 CE 下降。把“CE 下降”写进失败日志的人，这一步就能拦住。

### Step 3：跑 CPU

编排者登记之前：

```bash
PYTHONPATH=src python -c "from learn_omni_experiments.lessons.lesson_55 import run; r=run(); print(r['checks'])"
```

八条 `checks` 必须全为 True。重点对：`pitch_4` 约 $-0.514286$，`bins_4[4]==1`，`text_top1_4==0`，`jumped_dims_4==['pitch']`。

8 bit 俯仰角为什么一点都没动，也建议对照一次编码，避免只记住“8 bit 比较稳”。该行峰值仍是 $0.40$，$q_{\max}=127$，步长 $0.40/127$。整数码是 $[-127,-32,63,0]$。实数里 $0.20$ 对应 $63.5$，半格朝正无穷本该进 $64$；二进制把比值算成略小于 $63.5$，于是码停在 $63$。$-32$ 与 $63$ 两档的误差在点积里互相抵消，CPU 给出精确的 $-0.5$。不要在纸上坚持 $64$ 然后改夹具。网格比箱宽细两个数量级时，贴边值可以暂时不被推过线。4 bit 步长 $0.057$ 已经和箱宽 $0.25$ 的两成相当，同一贴边就过线。这是“先坏”的定量意思：步长第一次和箱宽处在同一数量级。纸上对 4 bit 时用分数 $2/35$，避开 8 bit 那种 63.5 的浮点边缘。

权重 MSE 三列也写进 Step 3 的笔记，用来核对“误差在涨、判决还没一起跳”。CPU：文本 8 bit $7.8\times 10^{-6}$、4 bit $2.57\times 10^{-3}$；视觉 $2.14\times 10^{-6}$ 对 $8.26\times 10^{-4}$；动作 $3.4\times 10^{-7}$ 对 $8.32\times 10^{-5}$。动作头的权重 MSE 最小，却唯一跳类。MSE 排序和跳类排序相反。有人按 MSE 决定“先保护哪一头”，会先去救文本头。QVLA 改成按动作输出敏感度排序，正是为了挡住这种反序。

### Step 4：Lab 先预测再揭晓

打开 `Lesson55QuantLab`。先选“动作 bin 先跳类，文本 top-1 仍不变”。先揭晓 8 bit：七维原箱，文本未跳。再切到 4 bit 揭晓：pitch 变色，CE 数字允许略降。只揭晓 4 bit、不看 8 bit，门禁不过。预测选成“文本先跳”或“一起跳”，门禁不过。

### Step 5：把论文数字抄进另一列

另开一列，禁止与 Step 3 的 $-0.514286$ 相减。至少抄：GPTQ Table 5 的 8.34 / 10.54 / 8.37；SmoothQuant Table 1 的 71.6 / 32.3 / 71.4；AWQ Table 6 的 81.70 / 77.13 / 80.53；BitVLA Table II 的 76.5→72.7 与 97.1→96.9；QVLA 摘要的 29.2% / 98.9% / 1.49× / 22.6%。抄漏模型名或表号，视为未完成。

### Step 6：写边界声明

用不超过一页对照第 13 课和第 46 课。四行就够：单位、失败模式、本课不测的东西、本课必测的东西。缺这一页，第 10 节第 1 条失败。

## 9. 评测与测量

量化评测容易把“更小”写成“还行”。本课把指标分成三桶，桶之间禁止横着减。

**正确性桶。** 文本 top-1、动作箱号、视觉粗类、视觉 L2。CPU 和 Lab 只填这一桶。L2 没有公开论文对照值。箱号在给定 $B$ 与区间时有闭式解。

**语言建模桶。** WikiText2 / C4 困惑度、零样本准确率。GPTQ Table 3–5、SmoothQuant Table 1 属于这个桶。它们不证明关节命令没换档。

**任务桶。** COCO CIDEr、VQAv2、LIBERO 四套件。AWQ Table 6–7、BitVLA Table I–II、QVLA 摘要属于这个桶。必须写模型、比特、是否 PTQ、套件名。把 LIBERO 平均写成真机能力，是 [第 31 课](31_vla_evaluation.md) 已经禁止的事，本课继续禁止。

**资源桶。** 权重大小、VRAM 百分比、论文自己报的加速倍数。GPTQ 摘要 3.25× / 4.5×，AWQ 的 3.2–3.3×，QVLA 的 1.49×，BitVLA 的 1.4GB 与 11.0× 内存、4.4× 端到端延迟，都只能连着模型名抄。本课不测这一桶。QVLA 引言里的“每步数百毫秒”没有逐步表，本课不抄进资源桶当点估计。

测量协议：

1. 先冻结 $h$ 和三个头，再改比特。
2. 同一 $h$ 上必须同时记 top-1、L2、七个箱号。
3. 8 bit 与 4 bit 各测一次，中间不改权重真值。
4. 论文数字另列，标明表号。
5. 连续动作头若出现在你自己的改造里，额外报每维绝对误差是否超过 $\Delta/2$；本课默认头是分箱。

不确定性。GPTQ 没有给困惑度的误差条。QVLA 摘要的 98.9% 是相对原性能的比例，不是 LIBERO 绝对成功率。缩小版若只跑一次 Lab，不要写置信区间。

OpenVLA 与 OFT 在 INT4 下的差距，是本课在任务桶里最想保住的对照：离散箱更脆。不要把它说成“OFT 已经解决量化”。Table II 仍是仿真套件，N 与随机种子以原文为准；本课不重算区间。把四套件抄全，避免只报平均：

| 模型 | 比特 | Spatial | Object | Goal | Long | 平均 |
|---|---|---|---|---|---|---|
| OpenVLA | 全精度 | 84.7 | 88.4 | 79.2 | 53.7 | 76.5 |
| OpenVLA | INT4 PTQ | 83.0 | 84.0 | 72.0 | 51.6 | 72.7 |
| OpenVLA-OFT | 全精度 | 97.6 | 98.4 | 97.9 | 94.5 | 97.1 |
| OpenVLA-OFT | INT4 PTQ | 98.2 | 98.2 | 97.2 | 93.8 | 96.9 |
| BitVLA | 原生低比特 | 96.6 | 99.0 | 95.4 | 92.8 | 96.0 |

Goal 一行最刺：离散 OpenVLA 掉 7.2 个百分点，OFT 掉 0.7。Long 也掉，但基数本身低，单独看平均会把 Goal 的伤口摊薄。本课夹具的 pitch 相当于 Goal 那种“贴着接触面”的维。Spatial 那种大范围到位，更像 $x=0.04$ 那种离边界还远的维。

内存列同样要带模型名。BitVLA Table I 把 OpenVLA-OFT 写成 15.4GB（相对 BitVLA 1.4GB 的 11.00×），OpenVLA 15.1GB。Table II 的 INT8 / INT4 是 PTQ 之后的占用：OpenVLA INT4 4.4GB，OFT INT4 4.7GB。1.4GB 来自换了 3.0B 的三值骨干，外加视觉侧 Quantize-then-Distill，不是把 15.4GB 的 OpenVLA-OFT 直接做 INT4。规模差和机制差写在同一格，会变成“INT4 可以把 7B 压到 1.4GB”，这句本课禁止。

## 11. 根据症状定位失败环节

按观测到的现象找头，不要先改学习率。本课没有训练。

| 症状 | 先查 | 不是 |
|---|---|---|
| 文本还对，手臂往下栽 | 动作值是否贴箱边界；4 bit 步长 | 视觉编码器“没看懂” |
| 平均 CE 下降，用户说模型傻了 | 看 top-1 和具体哪几个词，不要看平均 | 量化提高了语言 |
| 图还在，L2 很大 | 粗类有没有跳；L2 单独不是跳类 | 必须立刻回 FP16 |
| 8 bit 已经跳箱 | 是否误用按张量步长；是否用了银行家舍入 | “8 bit 本来就不稳” |
| 七维全跳 | $h$ 是否被放大；是否把三个头绑成一个张量做 absmax | 动作表示选错（那是第 25 课） |
| 只有夹爪跳 | 夹爪区间 $[0,1]$ 是否被错当成 $[-1,1]$ | 俯仰角公式 |
| 与论文 72.7% 差很远 | 你测的是夹具箱号，不是 LIBERO | 夹具算错 |
| 打开 4 bit 直接形状错误 | 那是内核或打包问题，属第 46 课邻域 | 本课命题 |
| 解量化后写回一整份 FP16 权重再乘 | 内核没有把 dequant 融进主循环；延迟不会按 4 bit 降 | “4 bit 理论 4×” |
| 同一脚本 W4A16 和 W8A8 混报一个加速 | 分清是少读权重还是 INT8 GEMM | 本课夹具的 pitch |
| GPTQ 比 RTN 更差 | 校准域是否全是文本，动作头被错误补偿 | AWQ 一定更好 |
| 视觉编码器 INT8、LLM INT4、动作头漏写 | 默认常把动作头跟 LLM 绑在一起压 | “混合精度已经保护了身体” |
| golden 文本对、真机打翻 | 接触帧的贴边箱没进 golden | [第 23 课](23_grounding_ocr_spatial.md) 的幻觉探针 |
| 量化前后 hash 不同但箱号相同 | 连续值在变、判决没变；记 L1，不必回 FP16 | “数值漂移就是失败” |
| 量化前后箱号相同但格心命令抖 | 反量化用了箱左端而不是格心 | 第 24 课的格心公式 |

最后两行提醒：本课的布尔判决不是连续值的唯一故事。箱号不变时，格心命令仍可能差半个量化步长。那半步若小于任务允许的接触带，可以接受；若你的反量化误用箱左端，半箱宽 $0.125$ 会直接进控制器。定位时先打印反量化公式，再谈比特。第 24 课已经要求格心；本课不重写那条，只要求量化前后用同一条反量化。前后各用一套，箱号对照作废。
| 视觉粗类跳、动作不跳 | 把视觉间隔做小了；仍要分列报告 | 本课命题被推翻（先查是否还是同一 $h$） |
| 延迟数字出现在 CPU 摘要 | 删掉。CPU 不许报延迟 | 你“顺便测了壁钟” |

定位时打印三张表：三个头的权重峰值、两个比特下的输出、判决结果。三张表能对上，再谈内核。对不上，换 AWQ 是浪费。俯仰角若峰值不是 $0.4$，先假设改了夹具，不要先假设公式坏了。

线上事故的时间顺序也值得记一笔。量化往往先表现为“聊天还行、抓取偶尔探深”，因为文本间隔大、接触阶段的俯仰和夹爪贴边。所以回归负荷必须包含本课这三类输出，不能只用文本基准。 [第 01 课](01_baseline_reproduction.md) 的 golden case 若全是 A2A，加三条：纯文本下一词、一张图的粗类、一个贴边的俯仰角。端侧回归不过这三条，不允许宣称 INT4 完成。

Lab 的四个预测项对应四种常见错觉。选“文本先跳”的人把 CE 当身份。选“一起跳”的人把 L2 上升当成分类。选“都不会跳”的人只做过语言 8 bit。选对“动作先跳”但没揭晓 8 bit 的人，没有对照，门禁仍然卡住。四种错觉都比“不会量化”更危险，因为它们会让错误的部署报告显得很专业。

机制图的六个步骤也可以当口头汇报提纲。第一步只说同一 $h$，第二步只说按行网格，第三步报 top-1，第四步报 L2，第五步报箱号，第六步拒绝合成分数。汇报时若有人在第二步就开始报 LIBERO，打断他，先把夹具三句话说完。三句话是：8 bit 七维原箱；4 bit pitch 换箱；文本 top-1 仍是 0。说不完这三句，后面的论文表没有资格上场。

浏览器 Lab 的验收依赖两次揭晓，是故意的。只看 4 bit 的人会以为“量化就会跳箱”，看不到 8 bit 对照。只看 8 bit 的人会以为“夹具太简单，量化没影响”。两次都看，才能说“先坏”里的“先”是相对于比特下降，不是相对于全精度本身已经坏了。预测必须在揭晓前锁定。揭晓后再改口选对，`ran` 会被清掉，需要重揭。这是为了挡住事后编故事。

## 13. 前沿对照与改造方向

**公开方案。** 2022–2026 年的低比特路线按评测对象分三簇，本课只引用已打开的页面。语言簇：LLM.int8() 用混精度保住离群维；SmoothQuant 把离群从激活挪到权重，做成 W8A8；GPTQ 用二阶补偿把 175B 压到 3–4 bit；AWQ 按激活保护显著通道，并做出 TinyChat。多模态簇：AWQ 第一次把同一套方法报到 OpenFlamingo 与 VILA，Table 6–7 说明视觉-语言基准可以接近无损，前提是方法不是过拟合校准集的重建。身体簇：QVLA 把目标改到动作空间并按通道分配比特；BitVLA 从 1-bit LLM 出发做原生三值 VLA，Table II 给出 INT4 PTQ 在离散箱和连续头上的不对称损伤。Qwen2.5-Omni 的 Thinker–Talker 是本课程主线模型，其技术报告未公开分模态量化表。GPT-4o 级产品的端侧比特策略没有公开技术报告可查，其技术报告未公开该细节。

**差距。** 规模差：你没有 175B，也没有 OpenVLA-OFT 的 LIBERO 评测机，也没有 TinyChat 的 Jetson 实验台。机制差：absmax、箱号、top-1、同一 $h$ 不依赖模型大小。钱能缩小的是 VRAM 绝对值；钱缩不小的是“贴边的俯仰角会换箱”。QVLA 相对 SmoothQuant 的 22.6% 来自动作空间目标加通道比特；缩小版用一行 $[-0.4,-0.1,0.2,0]$ 就能复现“硬边界先坏”。不能复现的是 1.49×，因为没有 7B 和作者的内核。

机制上可以追上的部分写清楚。按行网格、半格舍入、箱号、top-1、三列损伤表，这些在 CPU 和浏览器里就能验收。规模上追不上的部分也写清楚：A100 上的 4.2 小时、OpenFlamingo 5k caption、LIBERO 每套件 500 回合。报告里把能验收的机制和不能验收的规模分成两段。

**动手改造清单。**

1. **把俯仰角挪离边界。** 改动位置：`W_ACT` 第 5 行，改成 $[-0.30,-0.10,0.20,0.00]$，使全精度点积落到箱内部。预算：CPU 数秒，零训练。预期：4 bit 不再跳箱，文本 top-1 仍不变。失败判定：改完仍跳，或你同时改了 $B$。改完之后本课第 10 节第 2 条不再适用，记录里必须写“约定变更：不再要求 pitch 跳箱”。
2. **给动作头单独留 8 bit。** 改动位置：Lab 与 CPU 里只把 `W_TEXT`、`W_VIS` 收到 4 bit，`W_ACT` 留 8 bit。预算：CPU 数秒。预期：跳维列表变空，视觉 L2 仍上升。失败判定：动作仍跳，说明你其实量化了动作行。这是对 QVLA“通道比特不该一刀切”的缩小版。
3. **用文本校准去补偿动作头。** 改动位置：实现一个最小的一行 GPTQ 式补偿，校准 $X$ 只用文本 hidden。预算：CPU 数分钟。预期：文本间隔更大或持平，动作贴边更严重。失败判定：动作箱反而更稳且你无法解释校准域。这条用来理解 GPTQ 会记住所见的 $X$。
4. **连续头对照。** 改动位置：取消分箱，改报 $|a-\hat a|$ 是否超过接触阈值 $0.05$。预算：CPU 数秒。预期：俯仰角 4 bit 误差约 $0.014$，低于 $0.05$，连续判决“未坏”，分箱判决“已坏”。失败判定：两种判决被写成同一个布尔。这是对 BitVLA Table II 的方向复现：连续头比离散箱更能吞下同一点量化噪声。

BitVLA 的训练顺序值得单独记，因为它说明“原生低比特”和“训完再压”不是同一条路。论文 Figure 2：先把 BitNet b1.58 2B4T 配上全精度 SigLIP-L 做图文训练；再用 Quantize-then-Distill 把视觉编码器压到 1.58-bit 权重、INT8 激活，全精度教师对齐表征，且这一阶段只更新视觉编码器；最后在约 100 万条真实轨迹上做机器人训练。连接器和动作头保持全精度，因为参数量可忽略。Table I 的 1.4GB 含这一整套选择。把它写成“把 OpenVLA-OFT 做了 1 bit PTQ”，和原文不符。本课夹具走的是第二条路的极小版本：全精度头 + 推理时 RTN。改造清单不要求你重训 BitNet。

**顺手复现。** 论文结论“RTN 在 4 bit 上显著差于带补偿或带保护的方法”（GPTQ Table 5、AWQ Table 6）在缩小版对应：RTN 已经能制造跳箱，本课不实现 GPTQ 就足以展示损伤，不能展示“补偿能救回箱号”。论文结论“离散 VLA 的 INT4 PTQ 比连续 OFT 掉得多”（BitVLA Table II）对应改造 4，预期同方向。论文结论“按动作敏感度分配比特优于均匀 LLM 量化”（QVLA 摘要 22.6%）对应改造 2，预期同方向。若有人在 Lab 里看到 pitch 跳箱就写“接近 OpenVLA 的 72.7%”，判失败。两个数字的单位分别是箱号和套件成功率，不能兑。

改造实验的失败判定要能被本课夹具触发。实验 1 改一行权重就能失败或成功。实验 2 改量化掩码就能失败。实验 4 比较两个布尔就能失败。实验 3 需要你自己写补偿，允许只写伪代码加手算一个标量，但必须声明未进入 `checks`。

若以后真的拿到 7B VLA 和机载计算机，把改造 2 升级成模块级比特：视觉编码器 8 bit、LLM 4 bit、动作头 8 bit 或按 QVLA 的通道表。失败判定仍不改成“必须达到 98.9%”。改成：同一批 golden 动作箱号在混合比特下比均匀 4 bit 少跳；文本 top-1 不差于均匀 4 bit；VRAM 仍低于半精度。98.9% 是作者机器、作者 LIBERO、作者实现上的点估计，不是本课门禁。门禁用方向和分列记账，不用点估计。

常见错误报告五例，归档前对照删掉：

1. “INT4 之后模型 CE 更低，说明量化有正则作用。”夹具里 CE 确实略降，top-1 未变，动作已经换箱。删掉“正则作用”。
2. “我们测到 4× 加速，因为权重是 4 bit。”没有内核融合测量，只有字节比。改成“权重字节约为四分之一，延迟未测”。
3. “和 QVLA 一样保持了 98.9% 性能。”夹具没有 LIBERO。改成“4 bit 时文本 top-1 保持，pitch 未保持”。
4. “视觉 L2 到了 0.049，视觉坏了。”粗类未跳。改成“L2 上升，粗类未跳，动作已跳”。
5. “第 13 课已经做过数值对账，所以量化后不必再对箱号。”对账的是训练语义，不是推理网格。补测箱号。

五例都来自把一列数字送到另一列去当结论。本课全部门禁都在阻止这件事。若你的摘要里出现“无损”“几乎无损”“可忽略的精度损失”且没有紧跟模型名、比特、判决函数，先把这三个词删掉再写具体布尔。AWQ Table 7 作者自己用了 lossless 来描述 VILA 的 11 个视觉-语言基准；那是他们的表内观察，可以引用，但要连着 VILA 和 INT4-g128。挪到机械臂上，本课视为剪错节。

## 14. 论文与必读材料

按“网格与离群、权重量化、多模态、身体”顺序读。每篇材料对应一个能在箱号表或 Lab 里验证的问题。

### 14.1 网格、离群与 8 bit 乘

- [LLM.int8()](https://arxiv.org/abs/2208.07339)：读 §1 的 6.7B 相变、混精度分解、99.9% / 6 个特征维。带着问题：为什么把离群维置零会让困惑度恶化数百个百分点，而随机置零几乎无事？读完写出：本课夹具为什么故意不塞 100× 离群。HTML：[v2](https://arxiv.org/html/2208.07339)。
- [SmoothQuant](https://arxiv.org/abs/2211.10438)：读公式 (1)、Figure 2 的平滑、Table 1 的 71.6 / 32.3 / 71.4。带着问题：per-channel 激活为什么数值上对、内核上不友好？平滑把谁的量化难度挪走了？HTML：[v7](https://arxiv.org/html/2211.10438)。

### 14.2 4 bit 权重

- [GPTQ](https://arxiv.org/abs/2210.17323)：读公式 (1)(2)、Table 2 的 4.2h、Table 5 的 8.34 / 10.54 / 8.37。带着问题：校准 $X$ 来自哪个域时，动作头会被错误补偿？作者声明了哪些不做（激活量化、混合精度乘法加速）？HTML：[v2](https://arxiv.org/html/2210.17323)。
- [AWQ](https://arxiv.org/abs/2306.00978)：读 Table 1 的 1% 显著通道、§3.2 的尺度搜索、Table 6 的 OpenFlamingo、Table 7 的 VILA。带着问题：为什么按权重大小选出的 1% 救不了困惑度，按激活幅度就可以？TinyChat 的 3.2× 是相对谁？HTML：[v6](https://arxiv.org/html/2306.00978)。
- [QLoRA](https://arxiv.org/abs/2305.14314)：读 NF4 与双重量化。带着问题：4 bit 存储加 16 bit 计算，和本课 W4A16 推理是不是同一件事？答案：微调时反传走 LoRA，不是端侧动作验收。HTML：[v1](https://arxiv.org/html/2305.14314)。

### 14.3 身体上的低比特

- [QVLA](https://arxiv.org/abs/2602.03782)：读摘要与 §3 的动作空间目标、通道敏感度、比特集合 $\{0,2,4,8,16\}$。带着问题：为什么表征 MSE 不是好目标？29.2% / 98.9% / 1.49× / 22.6% 的分母各是谁？贪婪降比特的边际比 $\rho=(s^{(b_{\mathrm{lo}})}-s^{(b_{\mathrm{hi}})})/(b_{\mathrm{hi}}-b_{\mathrm{lo}})$ 在缩小版对应哪一行权重？HTML：[v1](https://arxiv.org/html/2602.03782)。

读 §3 时把敏感度估计算一遍直觉：量化某一通道到更低比特，看动作输出动了多少。动作头和投影层通常排在前面被保护，中间 FFN 的某些通道可以被降到 2 bit 甚至 0 bit（剪掉）。本课夹具只有 7 行动作权重，相当于已经站在“最敏感的那一层”上，所以均匀 4 bit 就会跳箱。若你把同一 4 bit 打在文本头上，间隔 2.17 还扛得住。这正是通道比特要解决的不均匀。

贪婪降比特的四个阶段写成检查清单：全部从 16 起跳；先把 $\rho$ 最小的通道降到 8，检查平均比特是否已经低于预算；不够再降到 4、2、0。0 bit 就是剪掉。激活保持统一比特，避免运行时按通道分支。权重按行存 scale 与 zero-point，取用时反量化。这些工程约束解释了：为什么不能在推理热路径上对每个通道现场选 3 bit 还是 5 bit。本课改造 2 只做模块级 8/4，已经能表达“动作头多留比特”；不要在缩小版里实现 0/2/4/8/16 的求解器，除非你把预算、敏感度定义和失败判定另写一页。

22.6% 这一格特别容易被写成“快了 22.6%”。摘要原文是相对 SmoothQuant 的性能提升，分母是任务性能，不是壁钟。1.49× 才是速度。29.2% 是 VRAM 相对原模型。98.9% 是相对原性能。四个数四个分母。抄漏一个分母，第 10 节第 6 条失败。
- [BitVLA](https://arxiv.org/abs/2506.07530)：读 Table I、Table II、Quantize-then-Distill。带着问题：同一套 INT4 PTQ，为什么 OpenVLA 掉、OFT 几乎不掉？1.4GB 和 15.4GB 比较时，模型大小是否相同？HTML：[v2](https://arxiv.org/html/2506.07530)。

读 Table II 时做一个方向核对：离散箱 + CE 的 OpenVLA，INT4 后 Goal 从 79.2 到 72.0，Long 从 53.7 到 51.6；连续 L1 的 OFT，四个套件都在 1 个百分点附近晃。本课夹具只用一个俯仰角复现“箱比 CE 脆”，不复现套件成功率。读 QVLA 时再带一个边界问题：通道比特分配改变的是损伤分布，还是评测协议？答案必须是前者。LIBERO 怎么拆套件，仍按第 31 课的口径。

读 GPTQ 的 BLOOM 列时不要和 OPT 列混。Table 4：BLOOM-176B 全精度 WikiText2 8.11，GPTQ-4 8.21，RTN-4 8.37；3 bit 时 RTN 塌到 571，GPTQ 仍在 8.64。BLOOM 家族通常比 OPT 好压，作者也写了这一句。把 8.21 和 OPT 的 8.37 平均成“175B 的 4 bit 分数”，本课不用。Zero-shot 列同样要分家：Table 5 里 OPT-175B 的 LAMBADA，GPTQ-4 是 76.80，基线 75.59，RTN-4 是 71.34。语言零样本可以在 4 bit 上几乎不动，同时 3 bit RTN 的 LAMBADA 掉到 0。这再次支持本课的分列：同一张表里，有的指标稳，有的指标死，取决于判决离硬边界有多远。

读 AWQ 的 VILA 表时带着一个“看起来无损”的警告。VQAv2 80.3 对 80.1，GQA 63.1 对 63.0，ScienceQA-IMG 68.0 对 68.0。这些选择题间隔通常很大，和本课文本头同构。VizWiz 从 59.6 到 57.8，掉了 1.8，仍远小于 OpenFlamingo INT3 的 16 点 CIDEr。视觉-语言基准内部已经不匀。把 Table 7 的“lossless”四个字单独剪下来当端侧 VLA 的标题，属于剪错节。

读完材料回头看：权重可以被压成整数，服务可以被切成 stage，训练可以被切到八张卡。三件事都叫“为了能跑起来”，尺子完全不同。你现在应该能拿着任意一份 Omni / VLA 的端侧脚本，在五分钟内指出它量化了哪个头、用哪一种判决、8 bit 对照在哪，并决定能不能只凭文本 CE 给动作签字。下一课问生成质量为什么不能只用重建误差：图像和视频的偏好排序可以和 L2 反向。
