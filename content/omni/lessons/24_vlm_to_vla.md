# 第 24 课：把动作接进视觉语言模型

> 类型：VLA 单元第一课，进阶<br>
> 建议周期：3–5 天读完机制并跑 CPU 实验<br>
> 硬件：主路径无 GPU；复现 RT-2-PaLI-X-55B 需要原文中的多 TPU 云端服务，55B 控制频率写为 1–3 Hz<br>
> 产物：7 维均匀分箱与词表偏移实现、三条输出通路对照、视觉捷径探针记录

## 1. 动作如何成为下一种 token

前一幕把眼睛接进语言模型：图和字可以被拉进同一条因果序列，模型按 next-token（给定已经出现的符号，预测下一个符号）写出答案。这一能力停在文字。你把桌面照片和「抓住杯子」送进视觉语言模型（VLM：吃图像和文本、吐文本的模型），它完全可能输出一句语法正确的「我抓住了杯子」。机械臂读到的是字符串，不是末端位移。夹爪开合、腕部姿态、沿桌面滑过去的那几厘米，都还没有进入同一套条件生成。

本课改的是输出端。输入侧的投影、冻结视觉编码器、动态分辨率，仍然沿用第 [02](02_multimodal_connector.md) 课和第 [08](08_dynamic_vision.md) 课已经讲过的接法；本课不重做三种 connector，也不重做切片。要验证的只有一件事：动作怎样变成和文字同一套 token，或至少进入同一套条件分布。实验用三条通路对照同一张图：只生成文字、生成离散动作 token、文字再映射到技能。切断视觉或切断语言之后，看电机目标还在不在。验收按 2026 年机理研究 [2603.19233](https://arxiv.org/abs/2603.19233) 的定性结论来：场景已经唯一决定任务时，改错指令动作仍不变；多目标同场景时，错指令必须改变动作。

为什么必须先做通路对照，而不是一上来训一个 7B VLA？因为三条通路在演示视频里都可以让胳膊动，失败却发生在完全不同的层。文字通路失败时，日志里全是通顺的中文，电机时间序列是一条平线。技能通路失败时，技能名可能对，低层政策在接触前后抖；也可能技能名就不该在当前场景出现。离散 token 通路失败时，id 可能越出词表切片，或落在正确切片却对应错误物体的坐标。不把三条路接到同一张图上，你无法判断自己在修哪一层。本课的 Lab 因此强制先提交预测：你必须在看见 token 之前，声明视觉捷径会在哪一种场景出现。看过答案再解释，解释总是圆的。

会写 `pick up the cup` 不等于会控臂。把一个强化学习控制器挂在 VLM 外面，可以得到能运动的系统，但那不是本课定义的视觉–语言–动作模型（VLA：同一套骨干既看图、读指令，又出动作）。VLA 的最小承诺是：动作出现在模型自己的输出词表或与文本共享的预测头里，并且能对这条预测算训练损失。

第八幕「动作成为模态」从本课起笔。第 25 课起才会比较分箱、连续回归、分块和压缩；第 26 课才处理异构机器人数据；第 27 课才实现自回归 VLA 的串行延迟。现在若把 OpenVLA 的词表替换或 π0 的流匹配写进作业，超出本课验收。把范围守在「动作如何成为下一种 token」，后面的课才有地方放新机制。依赖写的是 22，建议 23：没有标准 VLM 配方，很难解释「把动作塞进已经预训练的词表」这句话里那个「已经」指什么；没有指代和空间探针，很难设计第 5.10 节那种「看对了格子却不听指令」的对照。没有读 22 也可以完成本课 CPU 实验，因为分箱不依赖投影层；但写三条通路对照时，会缺少「VLM 本来只吐字」这条基线。第 23 课的「答案对、格子错」探针问的是注意力有没有落在正确物体上；本课的捷径探针问的是语言对动作 token 有没有因果作用。两个探针可以在同一张桌上先后做：先确认模型看的是杯子，再改指令看 token 动不动。只做其中一个，解释会含糊。本课 Lab 不显示注意力格子，只显示电机目标和 token；若你已有第 23 课的网格教具，可以把同一场景迁过去对照，但不作为本课 Gate 条件。本课通过条件仍然只看 token 是否随指令改变，不看注意力热图，也不把热图或文字通顺当成功标准，这一点要写进报告的验收栏。

本课术语：

| 术语 | 简要解释 |
|---|---|
| VLM | 视觉语言模型：输入图像和文本，输出文本 |
| VLA | 视觉–语言–动作模型：在 VLM 上让动作成为可预测的符号或连续条件 |
| 动作 token | 把连续动作切成整数编号后，当作词表里的普通符号 |
| 均匀分箱 | 把每个动作维度的取值区间切成 $B$ 段等宽格子，落入第几格就用几号 |
| 词表偏移 | 动作编号加上语言词表长度，避免和文字 id 撞车 |
| 技能 | 短时、有名字的低层政策，例如「拿起海绵」「走到桌子」 |
| 可行性 / 价值函数 | 从当前状态执行该技能，成功概率有多高 |
| 视觉捷径 | 场景已经唯一决定要干什么时，模型可以不读指令、只靠图像出动作 |
| 末端位姿 | 夹爪中心的位置和姿态，常用 6 个自由度加夹爪开合，共 7 维 |

## 2. 本课解决的问题

当前系统（MiniMind-O 以及第 21–23 课铺好的 VLM 配方）可以看图说话。看图说话解决不了控臂。第 [02](02_multimodal_connector.md) 课比较的是图像和声音如何进入 Thinker，那是输入侧。第 [08](08_dynamic_vision.md) 课比较的是分辨率和位置编码，那是看清空间。第 [20](20_unified_understanding_generation.md) 课比较的是同一组参数能不能既理解图像又生成图像，那是另一条输出模态，样本是图像 latent 不是关节。本课的输出模态是动作。从「写出抓住杯子」到「夹爪合上」，中间至少缺三层决策，必须分开验证：

1. **输出是不是动作。** 纯文字通路无论写得多对，电机命令都是空的。
2. **动作如何进入词表。** 连续的 7 维向量不能直接当 softmax 的类别。均匀分箱把它变成整数；词表偏移把它接到语言 id 后面。
3. **条件来自图像、语言，还是二者。** 同一套 next-token 损失并不能保证模型在听指令。场景里只有一个杯子时，改成「抓住苹果」动作可以不动；桌上同时有杯、苹果和碗时，错指令必须改动作。前一种叫视觉捷径，后一种才表明语言进了动作头。

本课用公开论文把这三层钉死，再用缩小版夹具复现机制，不复现 55B 或 13 台真机。对照对象是 2022–2023 年五条路线，外加一条 2026 年的机理测量：

| 路线 | 代表 | 动作在哪 | 本课要学会指出的边界 |
|---|---|---|---|
| 空间动作图 | [CLIPort](https://arxiv.org/abs/2109.12098) | 俯视图上的 pick-place 像素，不是 next-token | 语义走 CLIP，空间走 Transporter；没有语言词表里的关节编号 |
| 语言模型选技能 | [SayCan](https://arxiv.org/abs/2204.01691) | 输出技能名，低层政策执行 | 「会说下一步」和「关节怎么走」是两个系统 |
| 状态进输入、文字出规划 | [PaLM-E](https://arxiv.org/abs/2303.03378) | 输出仍是文本，再条件化低层政策 | 多模态句子解决接地，不把 7 维向量写进词表 |
| 专用动作 token | [RT-1](https://arxiv.org/abs/2212.06817) | 每维 256 bin，Transformer 直接出离散动作 | 高效推理（TokenLearner、3 Hz），词表为机器人专用 |
| 动作塞进 VLM 词表 | [RT-2](https://arxiv.org/abs/2307.15818) | 与 PaLI / PaLM-E 的已有 token 共用 | 第一次把这类模型叫 VLA；和网络图文任务共微调 |
| 多任务扁平序列 | [Gato](https://arxiv.org/abs/2205.06175) | 连续值 μ-law 后 1024 bin，偏移到 `[32000, 33024)` | 同一套权重打 Atari、配图、叠方块；损失只加在文本和动作上 |

失败条件预先写清。出现以下任一情况，不得把作业标记为「已经接上动作」：

- 模型能生成「抓住杯子」，但 7 维动作头从未进入损失；
- 分箱后 bin 0 和 bin $B-1$ 吃掉了整个区间，中间格子是空的；
- 动作 id 和文字 id 重叠，解码时把「的」读成夹爪开度；
- 只训练语言头，却报告动作 token 的梯度非零，或反过来在联合 softmax 下以为动作行没有梯度；
- 多目标同场景时，改错指令动作不变，却把结果写成「模型听懂了语言」。

下一课才比较均匀分箱、连续回归、动作分块和压缩表示。本课把「动作是一种 token」这一件事做完，并且只做这件事。

## 3. 开始前需要准备什么

本课不训练 MiniMind-O，也不要求 GPU。需要的是第 01 课建立的记录习惯，加上一套能手算的 7 维向量。

**上游事实（来自已打开的论文页，不是本课约定）：**

- RT-1 在 17 个月里用 13 台 Everyday Robots 收集约 13 万条回合、700 余条指令；模型 35M 参数，控制频率 3 Hz；每维动作均匀切成 256 个 bin。
- RT-2 在相同机器人数据上共微调 PaLI-X（5B / 55B）和 PaLM-E（12B）；动作写成 8 个整数（terminate 加 6 维位姿位移加夹爪），每维 256 bin；评测约 6 千次真机试验。
- PaLM-E-562B 由 540B PaLM 与 22B ViT 组成；输出是自回归文本；OK-VQA 上该通才模型报 66.1。
- SayCan 用 540B PaLM 在 101 条厨房指令上评测；mock kitchen 规划成功率 84%、执行 74%。
- Gato 约 1.2B 参数、上下文 1024；连续动作先（如需要）μ-law 再均匀 1024 bin，再偏移到文本词表之后。
- CLIPort 在 Ravens 上设 10 个语言条件桌面任务；真机 9 任务的多任务模型用 179 对图像–动作。

**本课约定：**

- 教学分箱取 $B=8$，语言词表占位 $V_{\text{text}}=32$，只为了让边界、偏移和梯度能手算。论文里的 $B=256$ 不改。
- 交互实验是浏览器里的受控模拟，页面已标明「教学模拟，不是模型输出」。
- CPU 实验无网络、无 GPU、无文件副作用。编排者登记之后可用下面命令跑；登记前可直接调用 `lesson_24.run()`。

## 4. 完成后应具备的能力

1. 把 7 维末端动作写成均匀分箱整数，并指出 $a=a^{\min}$、$a=a^{\max}$ 以及左闭右开边界各落在哪一格。
2. 写出词表偏移 $z_d=V_{\text{text}}+dB+b_d$，检查与文本 id 不重叠、维与维不重叠。
3. 写出与文本共享的 next-token 交叉熵，并标出损失掩码里哪些位置是动作。
4. 在三条通路上解释同一张图：文字通路为何电机为空；离散 token 通路如何反分箱；技能通路如何把语言模型分数乘可行性。
5. 指出 PaLM-E、RT-1、RT-2、Gato、SayCan、CLIPort 各自把动作放在哪一层，不把它们说成同一个方法。
6. 设计视觉捷径探针：唯一物体场景改错指令，离散通路动作不变；多目标同场景改错指令，动作必须变。
7. 用独立语言头证明动作 token 行梯度为 0；用联合 softmax 证明语言损失仍会经配分函数漏到动作行。
8. 给定一条带图像、指令、7 维示教的样本，写出 label 序列，并指出通路 A / B / C 各会改哪几格。
9. 在报告里把「上游事实 / 本课约定 / 本次测量」分成三栏，不把 RT-1 的 256 bin 改成教学的 8 bin 再写回论文。

第 8 条是为了防止只记住公式不会填表。第 5.12 节已经给出杯子样本的 10 行 label；换一条苹果样本，你应能独立填出 $z_d$，而不是复制杯子那一行。第 9 条是第 01 课复现纪律在动作词表上的翻版：数字一旦离开它的来源栏，后续课的 $B=256$ 讨论会和本课的 $B=8$ 缠在一起。

## 5. 原理：边造边讲

每个机制按同一节奏：为什么需要、怎么运转、精确定义、公开实现里能对上哪句话、怎么证明做对了。

### 5.1 三条通路，三种「已经接上动作」的假象

把 VLM 接到机器人上，工程上常见三条路。它们都能在演示视频里让胳膊动，训练信号完全不同。

**通路 A：只生成文字。** 模型输出「抓住杯子」。若没有第二套系统把这句话翻译成电机命令，夹爪静止。这是本课的负对照。第 [20](20_unified_understanding_generation.md) 课曾经把图像生成做成模型内部的 head，不允许用外部绘图 API 冒充；这里同样不允许用外部脚本把字幕「执行掉」然后声称 VLM 会控臂。

**通路 B：生成离散动作 token。** 观测和指令进入 Transformer，输出的下一个符号就是 bin 编号。RT-1 把这件事做成机器人专用词表；RT-2 把编号写进已经预训练好的 VLM 词表。训练损失就是普通交叉熵。推理时把整数反量化成连续命令，发给控制器。

**通路 C：文字映射技能。** 模型仍输出或打分自然语言技能名，「pick up the sponge」之类。另一套低层政策（行为克隆或强化学习）真正吐关节。SayCan 是这条路的代表：语言模型负责「这句话接下来该用哪条技能」，价值函数负责「这条技能现在做不做得成」。PaLM-E 的规划输出也落在这条路上：它生成文本决策，再条件化低层政策。

类比：通路 A 像有人在旁边喊操作步骤，自己不动手；通路 B 像把方向盘角度刻成 256 档，用下一个词直接选档；通路 C 像调度员喊「左转」，真正打方向的是已经学会左转的学徒。类比失效处：调度员和学徒之间没有共享梯度，通路 B 的语言知识和动作编号却在同一套 softmax 里互相排挤。RT-2 因此要和网络图文任务共微调，而不是把机器人数据单独再训一遍。

交互实验把三条通路画在同一张桌上。改通路时图像不变。你应看到：文字通路的电机目标永远是 idle；离散通路在唯一物体场景下可以不听错指令；技能通路用「语言分数 × 可行性」选名字，桌上没有苹果时 `pick_apple` 的可行性接近 0。

Lab 的揭晓按钮分成三种，用途不同。「揭晓当前设置」用于自由探索：切断视觉、切断语言、换技能通路，观察中间量。「揭晓唯一场景错指令」和「揭晓多目标错指令」把通路锁成离散、视觉和语言接通、指令锁成「抓住苹果」，只改场景。Gate 要求你先选对预测，再点后两个探针。只点自由探索、不点探针，验收不过。这是故意的：自由探索很容易绕开捷径定义，比如在唯一场景里切断视觉，错指令就会表现为 idle，看起来像「听懂了语言其实失败了」。探针把定义钉死，和 2603.19233 摘要里那句「视觉上下文已经唯一确定任务时语言被忽略；多目标同场景时语言变得必要」对齐。教具里的 94% 和 10% 不会出现，只出现 token 是否相同。把「token 相同」写成「成功率 94%」属于口径错误。

### 5.2 均匀分箱：连续 7 维怎样变成可预测的编号

机械臂一步命令通常写成末端位姿：平移 $(x,y,z)$、旋转 $(\mathrm{roll},\mathrm{pitch},\mathrm{yaw})$、夹爪开合。RT-1 的臂动作就是这 7 个量；另外还有底盘 3 维和离散的 terminate。本课教学向量只保留 7 维，与 COURSE 规格一致。底盘和 terminate 的写法相同，只是再加几段 bin。

设第 $d$ 维的合法区间是 $[a_d^{\min},a_d^{\max}]$，分成 $B$ 个等宽格子，宽度 $\Delta_d=(a_d^{\max}-a_d^{\min})/B$。取值 $a_d$ 的格子编号为

$$
b_d=\operatorname{clip}\left(\left\lfloor\frac{a_d-a_d^{\min}}{\Delta_d}\right\rfloor,0,B-1\right)
$$

$\operatorname{clip}$ 的两端是硬边界：$a_d\le a_d^{\min}$ 记为 0，$a_d\ge a_d^{\max}$ 记为 $B-1$。区间采用左闭右开：格子 $k$ 覆盖 $[a_d^{\min}+k\Delta_d,a_d^{\min}+(k+1)\Delta_d)$，最后一个格子把右端点收进来。RT-1 原文的句子是：每个变量映射到 256 个 bin，这些 bin 在该变量的上下界内均匀分布。RT-2 沿用同一套离散化，把连续维（除 terminate 外）均匀切成 256 bin，于是整步动作变成 8 个整数。教学实验丢掉底盘 3 维和 terminate，只为了让 7 维够演示偏移公式；底盘和终止符在 RT-1 里同样按维分箱或走离散模式。把底盘加回来时，公式变成 $z_d=V_{\text{text}}+dB+b_d$ 的 $d$ 从 0 走到 10，词表长度 $11B$ 或 $8B$（若 terminate 不走均匀 bin 而走 3 类 softmax）。实现前把 $D$ 写进数据卡，和 $B$、$V_{\text{text}}$ 一起哈希。底盘维的物理单位是米与弧度，和臂的末端位移不要共用同一套 $a^{\min},a^{\max}$，否则格子宽度会对一种机体过宽、对另一种过窄。

均匀分箱对「停在某处」和「向左向右」这类多峰动作友好：左峰和右峰可以占用不同格子，softmax 能同时给两峰质量。对「在 0.01 宽度里来回补偿」的高频抖动不友好：格子比抖动还宽时，来回会被压成同一个 id，重建轨迹看起来像被粘滞。下一课用 $B=2$ 会把这件事放大。本课只要承认：上界 $\Delta/2$ 描述的是静态一点的误差，不是动态轨迹的频谱。

反量化用格心：

$$
\hat a_d=a_d^{\min}+\bigl(b_d+\tfrac12\bigr)\Delta_d
$$

对落在开区间内部、未被 clip 的点，重建误差有上界 $|\hat a_d-a_d|\le \Delta_d/2$。$B$ 加倍，上界减半。代价是词表按维线性变长，见下一小节。均匀分箱保不住的东西留给下一课：高频来回抖动、维与维之间的相关、以及动作块的压缩。本课只要求上界公式和边界映射能核对。

教学数值。取 $B=8$，前六维 $[-1,1]$（$\Delta=0.25$），夹爪 $[0,1]$（$\Delta=0.125$），向量

$$
a=(0.4,-0.2,0.0,0.1,-0.5,0.8,0.3)
$$

则

| 维 | $a_d$ | $(a_d-a^{\min})/\Delta$ | $b_d$ |
|---|---|---|---|
| $x$ | 0.4 | 5.6 | 5 |
| $y$ | -0.2 | 3.2 | 3 |
| $z$ | 0.0 | 4.0 | 4 |
| roll | 0.1 | 4.4 | 4 |
| pitch | -0.5 | 2.0 | 2 |
| yaw | 0.8 | 7.2 | 7 |
| gripper | 0.3 | 2.4 | 2 |

核对边界：$(-1,-1,-1,-1,-1,-1,0)$ 应全为 0；$(1,1,1,1,1,1,1)$ 应全为 7。$x=-1+\Delta-10^{-12}$ 仍在格子 0，$x=-1+\Delta$ 进入格子 1。CPU 实验把这三条写成布尔检查。

Gato 的连续值路线不同，但词表偏移的想法相同。文本先用 SentencePiece 进 $[0,32000)$。连续值若还没在 $[-1,1]$，先做 μ-law：

$$
F(x)=\operatorname{sgn}(x)\frac{\log(|x|\mu+1)}{\log(M\mu+1)}
$$

原文取 $\mu=100$、$M=256$，再 clip 到 $[-1,1]$，再均匀切 1024 格，最后把整数平移到 $[32000,33024)$。动作本身已在 $[-1,1]$ 时不再 μ-law。本课 CPU 实验不实现 μ-law，只实现均匀分箱和偏移；Gato 的 1024 与 32000 用来对照「偏移量从哪来」。

### 5.3 词表偏移与共享 next-token 损失

有了 $b_d$，还要把它变成和文字同居的 id。设语言词表大小为 $V_{\text{text}}$，共 $D$ 个动作维，每维 $B$ 格。第 $d$ 维第 $b_d$ 格的 token 为

$$
z_d=V_{\text{text}}+dB+b_d
$$

动作词表长度 $7B$。教学设定 $V_{\text{text}}=32$、$B=8$，上表对应的 id 是 $37,43,52,60,66,79,82$，落在 $[32,88)$。合法文字 id 是 $[0,32)$。维 $d$ 独占 $[V_{\text{text}}+dB,V_{\text{text}}+(d+1)B)$。任意两个维的切片相交应为空。

RT-2 的接法更省事，也更危险。PaLI-X 对不超过 1000 的整数各有独立 token，于是 0–255 直接当 bin。PaLM-E 没有这种整数专座，RT-2 改写词表里最少用到的 256 个 token 充当动作词表。这是在覆盖原有符号。覆盖之后，这些符号在网络文本上的旧含义被冲掉；共微调必须把图文数据留在 batch 里，否则 VQA 会塌。RT-2 原文把「覆盖低频 token」明确写成一种 symbol tuning。

两种塞法对应两种偏移实现。整数专座：bin $b$ 就是文本里的数字 $b$，解码时把生成的十进制字符串解析回整数，再按维切分。低频覆盖：维护一张大小为 256 的旧 id 列表 `rare[b]`，编码时写 `rare[b]`，解码时先把生成 id 查回 $b$。教学公式 $z_d=V_{\text{text}}+dB+b_d$ 属于第三种：在词表尾部追加新符号，不覆盖旧词。追加不会毁掉「的」「cat」之类的高频词，但会改变 `lm_head` 的行数，旧 checkpoint 无法直接加载。覆盖不改行数，旧 checkpoint 能加载，代价是那 256 个旧词变成动作。写实现注释时必须写明用的是追加、覆盖还是整数专座；三种混用，校验集上的动作准确率会看起来像随机。

训练仍是因果语言模型。序列 $x_{1:T}$ 里既有文字也有动作 id。损失掩码 $M$ 标出要算账的位置。第 [01](01_baseline_reproduction.md) 课的规则在这里原样成立：提示、观测、padding 的 label 为 `-100`，只有需要模型吐出来的符号进损失。VLA 的新内容是：$M$ 现在可以包含动作位置。

$$
\mathcal{L}=-\frac{1}{|M|}\sum_{t\in M}\log p_\theta(x_t\mid x_{<t})
$$

$p_\theta(\cdot\mid x_{<t})$ 是在整个联合词表上的 softmax。Gato 把掩码函数写进公式：仅当位置来自文本或智能体动作时 $m(b,l)=1$，图像 patch 和本体感觉观测不预测。RT-1 用标准分类交叉熵加因果掩码。RT-2 在机器人样本上的监督是那串动作整数，在图文样本上的监督仍是自然语言。

两条必须分开测的梯度事实：

**独立语言头。** 语言 logits 来自 $W_{\text{lang}}\in\mathbb{R}^{V_{\text{text}}\times H}$，动作 logits 来自 $W_{\text{act}}\in\mathbb{R}^{7B\times H}$。若本步只对语言 label 做交叉熵，$W_{\text{act}}$ 不在计算图里，动作 token 行梯度为 0。这就是「只训语言头时动作 token 的梯度为 0」。挂一个外部分类器写句子、从不把 $W_{\text{act}}$ 接进损失，属于这种情况。

**联合 softmax。** 一张 $W\in\mathbb{R}^{(V_{\text{text}}+7B)\times H}$ 覆盖全部符号。即使 label 是文字，配分函数 $Z=\sum_j\exp(w_j^\top h)$ 里仍有动作行。动作行的梯度是 $p_j\,h$，一般不是 0。语言训练会把这些很少出现的动作符号往下压。RT-2 要输出约束：机器人任务解码时只从合法动作 token 里采样，图文任务才开放全词表。本课 CPU 实验把「独立头梯度为 0」和「联合 softmax 会漏」做成两条都必须为真的检查，防止只记住其中一句。

### 5.4 CLIPort：空间动作可以不是 token

在 RT-1 把动作编号化之前，桌面操作已经有一条不走 next-token 的路。CLIPort 把问题拆成 what 和 where。CLIP（用图文对比学习出来的双塔模型，第 21 课的主题）提供语义：这句话在找哪类物体、哪种颜色、哪类形状。Transporter 提供空间：在俯视正交图像上预测 pick 像素和 place 像素，动作对平移旋转等变。两条通路合成语言条件下的模仿学习代理。

CLIPort 明确写了自己不依赖的东西：物体位姿、实例分割、记忆模块、符号状态、句法树。桌面重排被写成一系列语言条件的 affordance 预测。仿真里 10 个任务可训一个多任务政策，效果不低于或优于单任务政策；真机 9 个任务的多任务模型只用 179 对图像–动作。

本课把它放在对照位置，原因有三。其一，它证明「语言条件操作」不必经过语言词表里的关节编号。其二，RT-2 在相关工作里把 CLIPort 和 MOO 算作把预训练 VLM 接进视觉运动政策的先例，同时指出它们把政策结构限制在二维动作空间，并且需要标定相机；RT-2 不依赖这两条。其三，第 32 课才会把屏幕点击和机械臂的空间接地放到同一套损失里。现在只需要能指出：CLIPort 的输出是像素上的 pick-place，不是 $z_d=V+dB+b_d$。

若有人把 CLIPort 的成功写成「VLM 已经会控臂」，把口径拉回：CLIP 在这里是冻结的语义先验，动作头是卷积式的空间图，梯度并不流过一个文本 softmax。

Transporter 把抓取写成在俯视像素上找一个 pick 点、再找一个 place 点。对平移和旋转等变这一点，来自把动作表示成与图像对齐的密集图，而不是来自 RoPE。本课的 7 维末端向量没有这层等变：把杯子从画面左侧挪到右侧，bin 编号必须改，模型得自己学。CLIPort 换物体颜色、换未见过的语义属性时，靠 CLIP 的预训练；换桌面几何时，靠 Transporter 的空间头。两条监督都不是 next-token。读 CLIPort 时在纸上画一张两列清单：左列是 CLIP 能转移的词（颜色、形状、开放词汇物体名），右列是 Transporter 负责的厘米级位置。本课的离散动作 token 把这两列压进同一串 id，省了结构，也把「听懂颜色」和「走到正确厘米」缠在一起。视觉捷径探针就是在拆这两列：唯一物体时右列已经足够，左列的词可以被忽略。

### 5.5 SayCan：语言模型选技能，低层政策吐关节

SayCan 的标题把分工写在字面上：Do As I Can, Not As I Say。大语言模型（LLM：只处理文本的生成或打分模型）见过海量「如何收拾洒出来的饮料」的叙述，但没有在这间厨房里失败过。直接问它，可能建议你去找吸尘器；现场没有吸尘器，机器人也不会用。

方法是给机器人一组已学会的短技能 $\Pi$，每个技能 $\pi$ 带一句短描述 $\ell_\pi$，以及从状态 $s$ 执行该技能的成功概率 $p(c_\pi\mid s,\ell_\pi)$。未折扣、稀疏成功奖励为 1 失败为 0 时，这个概率就是价值函数，也就是可行性。LLM 提供 $p(\ell_\pi\mid i)$：在用户指令 $i$ 下，这条技能描述像不像合理的下一步。需要的量是「选这条技能并做成功、从而推进 $i$」的概率。原文的分解是

$$
p(c_i\mid i,s,\ell_\pi)\propto p(c_\pi\mid s,\ell_\pi)\,p(\ell_\pi\mid i)
$$

实现上对技能库打分，而不是自由生成一段可能无法解析的句子。打分把补全限制在可执行集合里。可行性把当前场景接进去：海绵不在视野里，「pick up the sponge」再通顺也乘上一个接近 0 的因子。

评测在真实办公室厨房和与训练环境同构的 mock kitchen，指令 101 条、7 个家族，覆盖单步、名词变化、动词变化、结构化语言、机体状态、众包说法和长程。PaLM-SayCan（540B PaLM）在 mock kitchen 规划 84%、执行 74%；真实厨房规划 81%、执行 60%。去掉价值函数只取语言最高分，规划降到 67%。不用 LLM、把整句指令直接交给语言条件政策，执行接近 0。错误里约 65% 来自 LLM（长程提早结束、否定句、含糊指代），约 35% 来自可行性误判。

本课技能通路按这个乘积实现。桌上只有杯子、指令却是「抓住苹果」时，Lab 把语言模型分数定为 `pick_apple=0.82`、`pick_cup=0.07`、`idle=0.07`，可行性定为 `pick_apple=0.04`、`pick_cup=0.92`、`idle=0.55`。乘积分别约为 $0.033$、$0.064$、$0.039$，argmax 仍是 `pick_cup`。桌上同时有三个物体、指令仍是「抓住苹果」时，`pick_apple` 的可行性升到 0.92，乘积约 $0.75$，argmax 改成苹果。这和离散 VLA 的视觉捷径不是同一机制：前者是「做不到的技能被乘没了」，后者是「场景唯一时指令根本没进动作头」。交互实验把两种分数分开显示，避免把可行性接地误写成视觉捷径。

可行性分数来自价值函数，不是来自 LLM。SayCan 用 TD 学习语言条件 Q 函数；未折扣稀疏成功时，$Q$ 就是成功概率。本课 Lab 用一张写死的表代替 Q 网络：物体在视野里取 0.92，否则取 0.04。改这张表会改变通路 C，不会改变通路 B。若你发现唯一场景下离散通路和技能通路都抓住了杯子，先看它们的中间量：离散通路的 token 与正确指令相同，是视觉捷径；技能通路的乘积表里 `pick_apple` 被可行性压掉，是接地。报告里要写中间量，只写「都抓杯子」等于没做对照。

SayCan 没有把 7 维末端写进 LLM 词表。低层技能当时来自语言条件政策（后续厨房操作里 RT-1 会成为这类低层政策的一种）。本课把它当作通路 C 的完整例子：语言在选菜单，厨房在炒菜，两本账不能合成一条交叉熵。

### 5.6 PaLM-E：连续状态进入句子，输出仍是文本

PaLM-E 要解决的接地问题是：纯文本 LLM 看不见几何，纯 VQA 模型做不了机器人规划。做法是把任意模态编码进语言模型的嵌入空间，和文本插在同一条「多模态句子」里。例子：`Q: What happened between <img_1> and <img_2>?`。连续状态向量 $s\in\mathbb{R}^{S}$（物体位姿、尺寸、颜色等）经 MLP 映到同一空间。输出始终是自回归文本：回答问题，或给出应被低层政策执行的决策序列。

规模写法在原文第 4 节：8B LLM + 4B ViT 称为 PaLM-E-12B，62B + 22B 称为 84B，540B + 22B 称为 562B。562B 在 OK-VQA 上报 66.1，VQAv2 test-dev 报 80.0，COCO caption Karpathy test 报 138.7，且不依赖对 OK-VQA 的专用微调。Tab. 5 把这些数字写在同一张通才模型表里；12B 的 OK-VQA 是 55.5。机器人侧，它在 TAMP、Language-Table、移动操作三个域上做规划与具身问答。Language-Table 上它以 1 Hz 向 Lynch 等人的低层政策发送语言子目标，低层政策以 5 Hz 出动作。移动操作的低层政策来自 RT-1。训练规划用了 SayCan 实验留下的 2912 条序列。

输入编码器有几条变体，原文都当作「多模态句子里的一段连续向量」来用。全局 ViT 把整图压成一组 embedding。物体中心的场景表示（OSRT 一类）把每个物体压成一段，并在提示里写成 `Object j is <obj_j>`，让模型在输出里用 `obj_j` 指代。状态向量 $s$ 走 MLP。实体标注的多模态 token 是他们提出的结构想法之一：模型必须学会在文本里点名它刚刚看见的那一块连续向量。这些都发生在输入侧。输出侧仍然是字。即便输出里出现 `obj_2`，执行时还是低层政策去动那个物体，而不是 7 个 bin。

冻结语言模型、只训编码器，和连语言模型一起微调，原文都做了对比。规模变大时，多模态微调对纯语言能力的遗忘更轻，这是他们列的贡献之一。本课不复现遗忘曲线，只借用这句话来解释 RT-2 为什么不肯丢掉网络图文数据：同一风险在动作微调里会表现为「会控臂、不会看图问答」。

关键边界：PaLM-E 可以把机器人状态当输入，但它的输出约定是文本。原文写，成功的规划必须由技能词表里的技能组成，再由低层政策执行。它不是 RT-2 意义上的 VLA。相关工作里它把自己和 Gato 对比：Gato 是通才多机体动作模型，PaLM-E 强调跨任务正迁移，并在输出端保持语言。

若作业把「把图像 embedding 拼进 LLM」写成 VLA，对照这一节。那是输入侧接地，属于第 02 课已经处理过的 connector 问题。本课要的是输出侧出现动作符号，或至少出现可执行的技能决策并与可行性相乘。

### 5.7 RT-1：专用词表、TokenLearner 与 3 Hz

RT-1 把「指令加图像历史，映射到离散动作」做成序列模型，并在真机规模上把推理延迟压到可跑。输入是 6 帧 $300\times 300$ 图像和一句自然语言。图像经 ImageNet 预训练的 EfficientNet-B3，得到 $9\times 9\times 512$ 特征，展平为 81 个视觉 token。指令经 Universal Sentence Encoder 得到句向量，再通过零初始化的 FiLM 层注入 EfficientNet，使早期特征就已经被任务调制。TokenLearner 把 81 个 token 压成 8 个。6 帧合计 48 个 token，送入 8 层、19M 参数的 decoder-only Transformer。整网 35M 参数。

动作：臂 7 维（$x,y,z,$ roll, pitch, yaw, 夹爪），底盘 3 维（$x,y,$ yaw），外加在「控臂 / 控底盘 / 结束回合」三选一的离散模式。每维 256 bin。损失为分类交叉熵加因果掩码。控制频率 3 Hz，直到输出 terminate 或触及步数上限。TokenLearner 把推理加快约 2.4 倍；重叠窗口上复用视觉 token 再加快约 1.7 倍。自回归地一个维一个维吐动作在他们的消融里没有带来收益，却把推理拖慢一倍以上，所以最终 RT-1 并不按维自回归。

结果（原文）：700 余条训练指令成功率 97%；相对次优基线，新任务、干扰物、背景分别高 25%、36%、18 个百分点。评测约 3000 次真机试验。附录消融把离散动作换成高斯连续输出后，表现明显下降；作者把原因写为：按维离散能表示多峰，高斯只能表示单峰。这一条直接支持本课把均匀分箱当作入门动作表示，而不是过时技术。连续回归、分块、流匹配是后续课的主题，不是对本课公式的否定。

RT-1 的词表是机器人专用的。它不和「猫坐在垫子上」共享 softmax。所以它还不是 RT-2 定义的 VLA。它证明的是：离散动作 token 在多样真机数据上可行，并且能在 3 Hz 下跑。本课教学模型用 $B=8$ 只是把同一公式缩到能手算；验收不要求 97%。

### 5.8 RT-2：把动作写进已经预训练的 VLM

RT-2 的问题是：互联网规模的 VLM 已经会解释物体、关系和指令，怎样让这些知识进入低层控制，而不是只当高层状态机。做法简单：把动作表示成文本 token，造出「多模态句子」，让 VLM 在机器人指令和相机观测之后直接回答动作。作者把这类模型称为 vision-language-action models，并实现为 RT-2。

骨干是现成的 PaLI-X 和 PaLM-E，不新增动作专用层。动作编码沿用 RT-1 的 256 bin。目标字符串形如

```text
terminate dx dy dz droll dpitch dyaw gripper
```

例子：`1 128 91 241 5 101 127`。PaLI-X 用整数专座；PaLM-E 覆盖 256 个低频 token。输入套 VQA 模板：`Q: what action should the robot take to [task instruction]? A:`。

共微调是配方里的关键技术细节。只在机器人轨迹上微调，模型会丢掉网络上学来的抽象视觉概念；batch 里同时保留原图文数据，并提高机器人样本的采样权重。解码时，机器人任务约束输出词表到合法动作 token，图文任务仍用全词表。55B 的 RT-2-PaLI-X 无法装进普通桌面机或机载 GPU，他们部署到多 TPU 云服务再经网络查询，控制频率 1–3 Hz；5B 约 5 Hz。作者写这是当时直接用于控制回路的最大模型，比此前大约一个数量级。

评测约 6 千条轨迹。训练指令上 RT-2 与 RT-1 相近；泛化（新物体、新背景、新环境）平均大约是 RT-1 和 MOO 的 2 倍，大约是其余基线的 6 倍。原文把泛化再分成易、难两档，并在附录表里列出；本课只引用正文那句「约 2 倍 / 约 6 倍」的平均陈述，不从记忆里补表内格子。物理技能仍限制在机器人数据里见过的技能分布，但模型能把这些技能用到网络知识指出的新位置：把物体放到某个数字或图标旁，选最大或最小的物体，选离另一物体最近的物体。加上思维链提示后，可以做多步语义推理，例如选石头当临时锤子，选能量饮料给疲倦的人。这些例子全部来自 RT-2 原文，本课不外推到未展示的技能。

共微调的 batch 里同时有机器人字符串和 VQA 字符串。若某一步采样到 VQA，label 是自然语言，输出约束关闭，模型可以写「the energy drink is red」。若某一步采样到机器人，label 是那 8 个整数，输出约束打开。两种样本的图像都进同一视觉编码器。这解释了为什么「会认图标」能出现在控臂里：图标是网络图文数据里的视觉概念，pick-place 是机器人数据里的运动，共微调让两者在同一套注意力里见面。只训机器人、不留 VQA，图标概念没有监督，难把物体放到某个数字上。本课 Lab 没有 VQA 样本，所以教具不会突然认识数字图标。不要因为 Lab 做不到思维链控臂，就判断 RT-2 原文的例子无效。

RT-2 调查过从零训练、只微调、共微调，以及 5B 对 55B。正文的结论是共微调和更大的骨干有利于泛化。具体格子以附录为准；不确定的数字本课不抄。55B 的 1–3 Hz 来自第 3.3 节的云端服务方案，不是桌面 GPU 的测量。写硬件需求时抄这一句，并写明本课 CPU 实验与该频率无关。

RT-2 第一次把「VLM 的输出符号 = 机器人动作」写成可训练的标准配方。本课的离散动作通路按这个配方缩写：同一套 hidden state，输出是 bin id，损失是交叉熵。规模、共微调配比、思维链提示都不在 CPU 实验里复现。

### 5.9 Gato：多任务扁平序列，损失只加在文本和动作上

Gato 把 Atari 按键、对话、图像说明、真实机械臂关节力矩压成一条 token 序列，同一套 1.2B 权重，24 层，宽 2048，前馈 8196。部署时按上下文决定下一个符号该被解码成字、按键还是力矩。训练 604 个不同任务；超过 450 个任务达到专家分数 50% 以上。上下文 1024。

对动作表示，Gato 给出本课需要的「偏移」教科书定义：文本占 $[0,32000)$，离散控制量占 $[0,1024)$，连续量离散化后占 $[32000,33024)$。智能体时间步的规范顺序是：观测 token、分隔符、动作 token。损失用因果分解

$$
\log p_\theta(s_{1:L})=\sum_{l=1}^{L}\log p_\theta(s_l\mid s_{<l})
$$

再乘掩码 $m(b,l)$，只在文本和动作位置为 1。图像 token 和本体感觉观测当前不预测。

Gato 与 RT-2 的差别对本课很有用。Gato 从多种模态冷启动一个通才序列模型，动作是众多目标里的一类。RT-2 从已经在互联网上花掉巨量计算的 VLM 出发，把动作塞进旧词表。PaLM-E 则强调输出保持语言，以便规划、问答和对话共用一个解码器。三种设计都在「序列模型预测下一个符号」，但符号的语义、词表是否与网络文本共享、哪些位置进损失，三者不同。写报告时这三项要分列，不要写成「都是 Transformer 所以一样」。

Gato 的部署循环值得单独记。提示（例如一段示范）先被 tokenize，形成初始序列。模型逐步采样，直到凑齐当前环境动作规格所要求的那一组动作 token，解码成向量发给环境。环境返回新观测，观测再被 tokenize 接在后面。上下文窗口 1024，更早的观测和动作会被挤出。损失在训练时已经把观测位置掩掉，所以模型从不被要求「画出下一帧」，只被要求「在已经看见的帧之后写出动作或字」。这和本课 Lab 的「切断视觉」探针一致：没有观测 token，动作条件不完整，应输出 idle 或终止，而不是靠语言先验幻觉出一组坐标。Gato 原文还写明真实机械臂叠方块是其任务之一；RT-1 相关工作指出，Gato 的真机操作广度有限，例如主要是单任务叠彩色方块，并且没有按 RT-1 那种规模评估对新任务、新场景的泛化。引用时保持这个边界：Gato 证明扁平序列做得多模态多任务，不证明 13 台厨房机器人上的 700 条指令。

### 5.10 视觉捷径：语言什么时候真正进了动作头

把动作接进词表之后，下一个虚假成功是：模型在桌上只有一个杯子时抓住了杯子，于是宣布它听懂了「抓住杯子」。也许它只是看见了唯一可抓的物体。

[2603.19233](https://arxiv.org/abs/2603.19233) 的标题是 *Not All Features Are Created Equal: A Mechanistic Study of Vision-Language-Action Models*。原文测过的模型名单必须按表写，不外推到未测模型。Table 1 列出：

| 模型 | 参数量 | 动作生成 | 通路 | 评测 |
|---|---|---|---|---|
| $\pi_{0.5}$ | 3B | 流匹配，50 步 | 双通路（PaliGemma + 专家） | LIBERO |
| OpenVLA-OFT | 7B | 连续 L1 回归 | 单通路（Llama-2） | LIBERO |
| X-VLA | 约 1B | 流匹配 | 单通路（Florence-2） | LIBERO、SimplerEnv |
| SmolVLA | 450M | 流匹配 | 双通路（VLM + 专家） | LIBERO、MetaWorld |
| GR00T N1.5 | 3B | 扩散 / 流 | 三通路（DiT + Eagle + VL-SA） | LIBERO |
| ACT | 80M | CVAE | 编解码，无语言 | ALOHA |

实验规模：六个架构、四个基准、超过 394,000 条 rollout。定性结论只采用原文对自己测过的模型写下的句子：

1. **视觉通路主导动作。** 在全部架构上成立。给 $\pi_{0.5}$ 空提示并注入基线视觉激活，动作余弦相似度可回到 0.999，任务成功回到 73–77%。只注入第 0 层已达 0.997。
2. **语言敏感性取决于任务结构，不取决于模型设计。** 视觉上下文已经唯一确定任务时，语言被忽略；同一场景有多个目标时，语言变得必要。X-VLA 在 `libero_goal` 上，错误提示把成功率从 94% 打到 10%；在 `libero_object` 上，无论提示如何都可保持 60–100%。
3. **跨任务注入让目标任务失败，但轨迹被拽向源任务的空间位置。** 五个 VLA 里四个目标成功率为 0；X-VLA 99.8% 的回合与源轨迹对齐。作者称为绑定在场景坐标上的运动程序，而不是抽象任务表征。
4. **多通路架构里，专家通路偏运动程序，VLM 通路偏目标语义。** 在 $\pi_{0.5}$、SmolVLA、GR00T 上，专家通路注入造成的行为位移约为 VLM 通路的两倍。

本课交互实验只压缩第 2 条，因为第 2 条可以直接变成可操作的探针，且不需要 SAE。教学桌上：唯一物体场景对应「视觉已唯一确定任务」；杯、苹果、碗同时出现对应「多目标同场景」。离散动作通路必须复现：错指令在前一场景不改 token，在后一场景改 token。ACT 没有语言，不能拿来讨论错指令；本课不把 ACT 画进三条通路。

这些数字全部来自 2603.19233 对自己实验的描述。不要把「从 94% 降到 10%」写成「所有 VLA 的平均表现」，它是 X-VLA 在 `libero_goal` 上的错提示结果。

### 5.11 代码形态：损失掩码如何把动作头关掉

缩小版前向用不到 PaLI。需要的数据结构与第 01 课的 mask 同源：

1. 观测 token（图像、可选状态）label 为 `-100`。
2. 指令 token label 为 `-100`。
3. 文字回答 token 进入 $M_{\text{text}}$。
4. 动作 token 进入 $M_{\text{act}}$。
5. padding 为 `-100`。

只训语言头：优化器的参数组不含 $W_{\text{act}}$ 和动作 embedding 行，或等价地把 $M_{\text{act}}$ 清空。此时动作行梯度必须是 0。联合词表且 $M$ 只含文字时，动作 embedding 若从未作为输入出现，其输入行梯度可以为 0，但输出行因 softmax 分母一般非 0。写实验报告时这两句话要分开，不能合成「动作参数完全不受语言损失影响」。

公开实现层面，RT-1 的代码在 2022 年随论文开源（`google-research/robotics_transformer`）。RT-2 没有把 55B 训练代码和权重按同样方式公开；能核对的是论文第 3.2 节的字符串格式和「保留 256 个动作 token」这句话。CLIPort 与 SayCan 都有项目页和桌面域示例。本课不要求克隆这些仓库通过测试；要求能指着论文章节说出动作 id 从哪来、损失加在哪。

### 5.12 从一条样本走到标量损失

把前面的公式收成一条可以手算的样本。桌上只有杯子，中心在归一化坐标 $(0.28,0.42)$。教学政策把目标写成 7 维：

$$
a=\bigl((0.28-0.5)\times 2,\ (0.42-0.5)\times 2,\ -0.62,\ 0,\ 0.12,\ 0,\ 0.12\bigr)
$$

即 $a=(-0.44,-0.16,-0.62,0,0.12,0,0.12)$。仍用 $B=8$、前六维 $[-1,1]$、夹爪 $[0,1]$：

| 维 | $a_d$ | $(a_d-a^{\min})/\Delta$ | $b_d$ | $z_d=32+d\cdot 8+b_d$ |
|---|---|---|---|---|
| $x$ | -0.44 | 2.24 | 2 | 34 |
| $y$ | -0.16 | 3.36 | 3 | 43 |
| $z$ | -0.62 | 1.52 | 1 | 49 |
| roll | 0.00 | 4.00 | 4 | 60 |
| pitch | 0.12 | 4.48 | 4 | 68 |
| yaw | 0.00 | 4.00 | 4 | 76 |
| gripper | 0.12 | 0.96 | 0 | 80 |

格心反量化：$\hat x=-1+(2.5)\times 0.25=-0.375$，误差 $0.065$；$\hat z=-1+(1.5)\times 0.25=-0.625$，误差 $0.005$；夹爪格心 $0.0625$，误差 $0.0575$。全部低于半格宽 $0.125$ 或 $0.0625$。CPU 实验用的示例向量 $(0.4,-0.2,\ldots)$ 和这里的桌面政策不是同一条，不要混着对答案。

把这条动作接到语言后面。占位词表里假设「抓住」「杯子」的 id 是 11 和 12，图像占一个特殊 id 3（真正的 VLM 会占几十到几百个视觉 token，这里压成 1 个只为了写 mask）。训练序列与 label 为：

| 位置 | 符号 | id | label | 进 $M$ 吗 |
|---|---|---|---|---|
| 0 | 图像 | 3 | -100 | 否 |
| 1 | 抓住 | 11 | -100 | 否 |
| 2 | 杯子 | 12 | -100 | 否 |
| 3 | $z_x$ | 34 | 34 | 是 |
| 4 | $z_y$ | 43 | 43 | 是 |
| 5 | $z_z$ | 49 | 49 | 是 |
| 6 | $z_r$ | 60 | 60 | 是 |
| 7 | $z_p$ | 68 | 68 | 是 |
| 8 | $z_y$ | 76 | 76 | 是 |
| 9 | $z_g$ | 80 | 80 | 是 |

$|M|=7$。若改成通路 A，序列在「杯子」之后接「了」之类的文本 id，七个动作 label 全部变成 `-100`，动作头即使存在也不会从这条样本得到监督。若改成通路 C，监督是技能名 `pick_cup` 的文本 token，低层 7 维根本不出现在这条序列里。三种通路可以共用视觉编码，不能共用同一行 label。

独立语言头的梯度用四维 hidden $h=(0.5,-0.25,0.75,0.1)$ 就能看清。语言 logits 是 $W_{\text{lang}}h$，动作 logits 是 $W_{\text{act}}h$。交叉熵只拿语言 label=7 时，反向传播停在 $W_{\text{lang}}$ 和 $h$；$W_{\text{act}}$ 的每一行都是全零。把两张表竖着拼成联合 $W$ 再做同一个语言 label 的 softmax，动作行 $j$ 的梯度是 $p_j h$。只要 $p_j>0$，这条梯度就不是零。CPU 实验里联合泄漏的绝对值最大值约为 $0.21$，数量级随随机初始权重变，正负号不重要，重要的是「不是精确 0」。把「精确 0」写进独立头检查、把「大于 0」写进联合检查，两行同时绿，才说明你理解了词表共享的副作用。

教师强制在动作维上同样成立。训练时第 $t$ 维的输入是示教的 $z_{<t}$，不是模型自己刚吐的 bin。推理时没有示教，第一个维若抽到错误格子，后面的维会在错误条件下继续预测。RT-1 的消融表明，按维自回归既慢又没有带来他们关心的收益，于是最终版本并行出所有动作 token。教学实验仍用串行交叉熵，是为了和公式 $\log p(x_t\mid x_{<t})$ 对齐；不要把「串行 CE」自动写成 RT-1 的部署方式。部署方式是论文附录里那句「autoregressively conditioning on actions did not benefit performance and slowed inference by more than 2x」。

到这里，动作成为下一种 token 的最小零件已经齐了：有分箱、有偏移、有 mask、有两种梯度故事、有三条通路的 label 约定。缺的是：这些 token 到底有没有在听指令。那是 5.10 和交互实验的事。

### 5.13 和 MiniMind-O 八路音频编号对照

第 [01](01_baseline_reproduction.md) 课的学生已经见过一种「不是汉字、却占用整数 id」的符号：Mimi 的 8 路音频编号。动作 token 和音频 code 有三处相同、三处不同。相同处帮助迁移直觉，不同处防止把 Talker 的 delay schedule 抄进机械臂。

相同的第一处是：二者都是量化后的整数，模型用分类交叉熵预测它们，解码器再把整数变回连续信号或连续命令。相同的第二处是：损失掩码必须把它们和提示词分开，否则模型会学着模仿用户的「请抓住杯子」而不是输出夹爪。相同的第三处是：词表必须和文本分区，否则一个 id 会同时表示「的」和某一格关节角。

不同的第一处是时间轴。音频 code 按帧排列，第 [04](04_multicodebook_talker.md) 课的 delay schedule 让 8 路在时间上错位，以便同一帧的 8 个编号能被深度解码器重组。动作 token 按维度排列：一步命令是 7 个符号，对应同一时刻的 7 个关节或末端量，没有「第 2 维比第 1 维晚一帧」的物理含义。RT-1 甚至选择不按维自回归。不同的第二处是错误的代价。音频抽错一个 code，听感变差，人可以请模型再说一遍。动作抽错一个 bin，末端可能已经碰到杯子。本课仍用 teacher forcing 训练，并不包含接触力切断；只要求你在报告里写明这一点，不要把验证集交叉熵当成安全指标。不同的第三处是条件。音频 Talker 读 Thinker 的 hidden 和历史 code。动作头读图像和指令。切断视觉时动作应变 idle，切断语言时行为取决于场景是否唯一。音频没有「桌上只有一个杯子」这种视觉捷径。

若把动作接到 MiniMind-O，比较干净的接法是：Thinker 仍出文本 hidden；新增一条动作头，词表追加 $7B$ 个符号，mask 只在动作位置打开。不要复用 Talker 的 8 路深度解码器去解 7 维末端：那 8 路是 RVQ 残差，7 维是并列的物理量。接法写进报告即可，本课不改 MiniMind-O 源码。

### 5.14 推理约束、终止符与一步命令的长度

训练用的是示教里的合法 bin。推理时联合 softmax 可能吐出文字 id、未定义的维组合，或在不该结束时吐出 terminate。RT-2 的解决办法是输出约束：机器人任务解码时，采样分布限制在合法动作 token 上。教学解码器可以写成：第 $d$ 个动作位置只允许 $[V_{\text{text}}+dB,V_{\text{text}}+(d+1)B)$ 内的 id。允许集合之外的 logit 在 softmax 前设为 $-\infty$。这不是训练技巧，是部署契约。若训练从未把非法 id 当作 label，约束不会改变 teacher forcing 的损失，只改变采样。

终止符要单独占一个离散模式或一个额外 bin。RT-1 用三模式开关：控臂、控底盘、结束回合。RT-2 把 terminate 放在动作字符串的第一个整数。教学 7 维向量没有这一位。Lab 用夹爪全开的 idle 向量表示「不动作」，这是教具简化，不是论文接口。写自己的数据时，宁可加第 8 个符号表示 terminate，也不要把「夹爪=1」兼当作结束。夹爪打开在抓取过程中合法，结束回合是另一件事。

一步命令的长度在离散通路上等于维数（或维数加 terminate）。技能通路上等于 1 个技能名，真正的关节序列在低层政策内部展开。文字通路上长度等于句子长度，电机长度为零。评测吞吐时这三条不能用同一个「token 每秒」去比：技能名一个 token 可能对应低层二十步关节；离散 7 个 token 对应一步 3 Hz 命令。第 27 课再讨论串行 7 步和并行 1 步的延迟。本课只要求：报告延迟时写明数的是哪一种符号。

## 7. 数据与训练 recipe

本课不收集 13 万条真机回合。recipe 分两层：论文里实际用过的数据，以及教学缩小版必须自备的数据。

**论文数据（只引用原文，不改数字）。** RT-1 / RT-2 的机器人数据：13 台办公厨房移动操作器，17 个月，约 13 万回合，指令由技能动词加物体名词构成。RT-2 另加 PaLI-X 与 PaLM-E 原来的网络图文数据（VQA、配图、图文交错）。SayCan 的规划训练痕迹来自其 101 条指令实验；PaLM-E 的移动操作规划用了其中 2912 条序列。Gato 混合控制、文本和视觉任务共 604 个。CLIPort 的仿真数据在 Ravens 里按任务程序生成；真机为 179 对。

**教学缩小版。** 一条样本是：俯视桌面的离散物体列表、一句指令、7 维示教动作、可选技能名。物体坐标在 $[0,1]^2$，动作按第 5.2 节分箱。样本分三个桶，桶的定义写进实验记录，不能事后改：

| 桶 | 场景 | 指令 | 用途 |
|---|---|---|---|
| U | 只有杯子 | 「抓住杯子」或「抓住苹果」 | 测视觉捷径：离散通路应对两种指令给出同一串动作 token |
| M | 杯、苹果、碗 | 分别指向三个物体 | 测语言：错指令必须改 $z_{0:6}$ |
| T | 任意 | 任意 | 文字通路：监督是句子，动作 label 全 `-100` |

混合比建议 U:M:T = 1:2:1。U 太少，捷径探针方差大；U 太多，模型学会永远抓杯子。M 里必须包含「指令所指物体在场」和「指令所指物体不在场」。后者是 SayCan 可行性的最小例子，不是视觉捷径。

预处理：动作 clip 到各维 $[a^{\min},a^{\max}]$ 再分箱；不要先分箱再 clip，否则越界会静默掉进错误格子。token 写入 `int32`。记录 $V_{\text{text}}$、$B$、各维上下界的哈希，和 checkpoint 放在一起。换 $B$ 而不换哈希，属于静默改词表。

缩小版样本的 schema 建议固定为一条 JSON 对象，字段名不要中途改：

| 字段 | 类型 | 含义 |
|---|---|---|
| `episode_id` | 字符串 | 稳定主键，不用会移动的行号 |
| `bucket` | `U` / `M` / `T` | 第 7 节的三个桶 |
| `objects` | 物体名到 $(x,y)$ | 俯视坐标，原点在图像左上或桌面中心必须写明 |
| `instruction` | 字符串 | 与评测时逐字相同 |
| `action7` | 长度 7 的浮点数组 | clip 之前的示教动作 |
| `bins` | 长度 7 的整数数组 | 分箱结果，便于不经模型检查编码器 |
| `tokens` | 长度 7 的整数数组 | 加偏移后的 id |
| `skill` | 字符串或空 | 通路 C 的监督；通路 B 可为空 |
| `text_target` | 字符串或空 | 通路 A 的监督 |

一条 U 桶样本的物体表只有 `cup`。它的 `instruction` 可以是「抓住杯子」也可以是「抓住苹果」，`action7` 都应指向杯子，这才造得出捷径探针。一条 M 桶样本必须在 `objects` 里同时出现至少两个名字；`instruction` 改写时 `action7` 必须跟着改，否则第 4 步的打乱对照没有基线。T 桶的 `tokens` 可以留空，但 `text_target` 不能空。

坐标系写进数据卡。若 $(0,0)$ 有时是图像左上、有时是桌面中心，分箱边界检查仍会通过，多目标探针会随机失败。RT-1 的动作上下界按变量各自规定；教学数据把前六维固定在 $[-1,1]$，是为了让 $\Delta=0.25$ 能口算，不是声称真机末端位移落在无量纲的 $[-1,1]$。把真机毫米数直接塞进这个区间而不做仿射变换，属于单位错误，不是分箱错误。

训练预算（缩小版，CPU 可完成机制，不必等到收敛到真机可用）：

| 档 | 样本 | 步数 | 目的 |
|---|---|---|---|
| 过拟合 | 32 条固定 U+M | 直到动作 token 训练准确率 1.0 | 证明分箱和 mask 接对了 |
| 标准 | 2 048 条 | 按验证损失早停 | 跑捷径探针 |
| 负对照 | 标准数据但打乱 M 桶指令 | 同步数 | 多目标准确率应掉到接近随机 |

打乱 U 桶指令时，离散通路准确率不应掉很多：这正是捷径。若 U 和 M 一起掉，说明模型没走视觉捷径，也没学语言，只是崩了。

## 8. 按依赖顺序执行实验

顺序锁死。分箱边界没过，不准看交互实验的「成功率」；交互实验没提交预测，不准写视觉捷径结论；联合 softmax 的漏梯度没看到，不准声称「语言训练不影响动作词表」。

### Step 1：CPU 分箱、偏移、梯度

运行本课实验模块。期望 `checks` 全为真，并记录下列指标：`bins=8`、`text_vocab=32`、`action_vocab=56`、`first_action_token_id=32`、`last_action_token_id=87`、示例向量对应 token `[37, 43, 52, 60, 66, 79, 82]`、独立语言头动作梯度绝对值最大为 0、联合 softmax 动作行梯度绝对值最大大于 0。

任一条失败时停。常见原因：用四舍五入代替 floor；把右端点映射到 $B$ 而不是 $B-1$；偏移写成 $d+b_d$ 漏了乘 $B$；把联合 softmax 误当成独立头。

手算核对可以用实验模块打印的 `example_tokens`。示例向量是 $(0.4,-0.2,0.0,0.1,-0.5,0.8,0.3)$，对应 `[37, 43, 52, 60, 66, 79, 82]`。若你本地改了 `BINS` 或 `TEXT_VOCAB`，这串 id 会变，验收表里的「必须看到」那一行要一起改，并在记录里标注「本课约定已修改」。未改约定却对不上这串 id，优先查 floor 与 clip 的顺序：先 clip 到 $[0,B-1]$ 再 floor 没有意义，必须先 floor 再 clip。$x=-0.5$ 落在格子 2 的左端点，格心重建误差正好是半格 $0.125$，这是上界取到等号的例子，不是实现错误。

### Step 2：三条通路的浏览器教具

打开本课 Lab。先选预测，再揭晓。预测题是：离散动作通路上，把指令从「抓住杯子」改成「抓住苹果」，唯一物体场景和多目标场景各会怎样。正确项是「唯一物体场景动作不变，多目标同场景必须改动作」。

然后必须点两次探针：「揭晓唯一场景错指令」「揭晓多目标错指令」。只揭晓当前随意设置不算通过。文字通路下电机目标应显示「无」。切断视觉后，离散通路应变为 idle，因为没有坐标可接地。切断语言后，多目标场景应变为 idle（语言必要），唯一物体场景仍可抓杯（视觉已足够）。

技能通路显示四项乘积。用它解释 SayCan，不要用它代替离散通路的捷径验收。

### Step 3：手写一条联合损失的 mask

取序列：`[img] 抓住 杯子 z_x z_y z_z z_r z_p z_yaw z_g`。写出每个位置的 label。图像和「抓住杯子」若当作条件，label 为 `-100`；七个 $z$ 为对应 id。再写一条纯 VQA 样本，动作位置不出现。两行 mask 的非 `-100` 计数必须不同。这是第 01 课 mask 纪律在动作维上的延伸。

### Step 4：负对照，禁止事后改桶

在 M 桶打乱指令，保持图像和示教动作不变。离散通路若仍能靠图像挑对物体，说明它在多目标场景也走了捷径，第 2 步的「必须改变」被数据泄漏破坏了。修复办法是：M 桶三个物体的空间布局在样本间要对调，不能让杯子永远在左、苹果永远在右。

不要在本课开始训 OpenVLA 或 π0。那是后续课的预算。

### Step 5：把三条通路的失败写进同一张表

用 Lab 的切断开关填下面这张表，数字来自揭晓后的 token 与电机目标，不要凭记忆填。

| 设置 | 文字通路电机 | 离散通路目标 | 技能通路 argmax |
|---|---|---|---|
| 唯一场景、正确指令、两路接通 | idle | 杯 | pick_cup |
| 唯一场景、错指令、两路接通 | idle | 杯（捷径） | 多为 pick_cup（可行性） |
| 多目标、错指令、两路接通 | idle | 苹 | pick_apple |
| 多目标、切断语言 | idle | idle | idle（本课约定 $n>1$ 且无语言时不选物体） |
| 任意场景、切断视觉 | idle | idle | 可行性全低，idle 或低分技能 |

表中「多为 pick_cup」来自 5.5 节的乘积，不是保证。若你改了 Lab 里的 LLM 分数，把新乘积算一遍再填。离散通路的「杯（捷径）」必须与正确指令的 token 逐个相同，不能只看目标名字。名字相同但 $z$ 不同，说明分箱或坐标在两次揭晓之间被改过。

做完这张表，回头看第 2 节的失败条件。文字通路电机若不是 idle，第 1 条失败。多目标错指令若仍抓杯，第 5 条失败。唯一场景错指令若改了 token，捷径探针没触发：先检查是不是其实切到了多目标场景，再检查视觉是否被切断。

### Step 6：记录，不改论文数字

实验记录里分三栏：上游事实、本课约定、本次测量。上游事实抄第 3 节那组已经打开的论文数字，禁止改 256、97%、84%、66.1、6 千次。本课约定抄 $B=8$、$V_{\text{text}}=32$。本次测量抄 CPU `metrics` 和 Lab token。三栏混写会导致下次换 $B$ 时把论文的 256 一起改掉。

## 9. 评测与测量

主指标是机制指标，不是 LIBERO 平均成功率。

| 指标 | 定义 | 通过 |
|---|---|---|
| 分箱边界命中 | $a^{\min}\to 0$、$a^{\max}\to B-1$、左闭右开 | 7 维全对 |
| 偏移合法性 | 动作 id 落在 $[V,V+7B)$，维切片不相交 | 集合相等 |
| 重建上界 | 格心反量化误差 $\le\Delta_d/2$ | 7 维全满足 |
| 语言头隔离 | 独立语言头时动作行梯度无穷范数为 0 | 精确 0 |
| 联合泄漏 | 语言交叉熵下动作行梯度无穷范数大于 0 | 严格大于 0 |
| 唯一场景捷径 | 离散通路、视觉开、错指令，token 与正确指令相同 | 必须相同 |
| 多目标语言 | 同上设置但三物体，token 与正确指令不同 | 必须不同 |
| 文字无电机 | 通路 A 的电机目标为 idle | 必须 idle |

不要把交互实验里的「与杯程序相同：是」写成真机抓取成功。教具里的杯是一个圆点，token 相同只说明 7 维向量落进同一组格子。

若引用论文数字，带套件或环境名：PaLM-SayCan mock kitchen 规划 84%；RT-1 训练指令 97%；PaLM-E-562B OK-VQA 66.1；X-VLA `libero_goal` 错提示从 94% 降到 10%。横着比这四个数没有意义，它们的成功定义不同。第 31 课再处理评测纪律。

## 11. 根据症状定位失败环节

| 症状 | 先查 | 不要先做 |
|---|---|---|
| $a^{\max}$ 落到不存在的 bin $B$ | clip 是否在 floor 之后 | 加大 $B$ |
| 解码夹爪得到一个汉字 | $V_{\text{text}}$ 是否与训练时一致；是否忘了乘 $B$ | 改学习率 |
| 只训语言、动作 embedding 仍在更新 | 是独立头还是联合 softmax；动作 id 是否出现在输入里 | 断定实现已接上 VLA |
| 联合 softmax 下动作行梯度为 0 | hidden 是否为零向量；动作行权重是否全相同导致数值抵消 | 删掉这条检查 |
| 唯一场景错指令也改了动作 | 通路是否误切到技能或文字；视觉是否被切断 | 宣布没有视觉捷径 |
| 多目标错指令不改动作 | 三个物体的坐标是否实质上重叠；是否仍在唯一场景 | 宣布模型很鲁棒 |
| 文字通路出现非 idle 电机 | Lab 是否把通路 B 的向量复用到通路 A | 把它当 VLA 成功 |
| 技能通路在无苹果时仍选 pick_apple | 可行性是否恒为 1 | 把它当视觉捷径 |
| 与论文 256 bin 对不上 | 是否用了教学 $B=8$ 却去比 RT-1 的重建误差 | 改论文数字 |
| 过拟合 32 条后 M 桶仍随机 | mask 是否把动作位置标成 `-100`；偏移是否训练与推理各写了一遍 | 加层数 |
| 验证损失下降但探针全错 | 训练桶是否几乎没有 M；杯子是否总在画面左侧 | 早停后再训 |
| 独立头梯度不是 0 | 是否把 $W_{\text{act}}$ 和 $W_{\text{lang}}$ 做成同一张表的 view | 调学习率 |
| Lab 里切断视觉仍抓杯 | 物体坐标是否在切断后仍参与 `actionToward` | 改预测选项 |
| 两个探针 token 完全一样 | 多目标场景的苹果坐标是否几乎等于杯子 | 加大 $B$ 掩盖坐标错误 |

调试时只改一个变量。先固定 $B$、$V_{\text{text}}$、场景，再改通路。通路、场景、指令三个旋钮同时转，失败无法归因。第 01 课要求 trace 不改变 logits；本课要求改 Lab 开关不改变未点「揭晓」前的预测单选。预测被重置又没重新提交，Gate 会关掉，这是设计，不是故障。

第 [07](07_full_duplex_routing.md) 课的 CONTINUE / PAUSE / REPLAN 是语音时钟上的状态机。本课的 terminate bin 是动作时钟上的结束符。二者同构，但不要把音频路由代码拷进动作头。动作没有「再听一句」的回放；发错的位移已经作用在接触力上。安全切断是第 40 课的主题，本课只要求 terminate 占用独立的离散模式或独立 bin，不要和夹爪开合同一个 id。

## 13. 前沿对照与改造方向

### 13.1 公开方案

同一问题在 2023 年被 RT-2 写成「动作即文本 token」。之后的开源系统多数继续走「VLM 骨干 + 动作头」，但动作头不再只有 256 bin 这一种。OpenVLA 把动作放进 Llama 词表并做自回归解码，细节在第 27 课。OpenVLA-OFT 被 2603.19233 列为 7B、连续 L1、单通路 Llama-2，说明离散 token 不是唯一出口。π0 / π0.5 用流匹配一次生成一段连续动作，2603.19233 测过 π0.5（3B、双通路、50 步流匹配）。GR00T N1.5 被同一篇论文列为三通路。这些模型的训练配比、真机表和 LIBERO 分套件数字，以它们自己的论文为准，本课不转抄未在本课打开核对过的表。

相对 RT-2，变化集中在三处：动作表示（离散 CE、连续 L1、流匹配）；是否把动作专家从 VLM 里拆出去；评测是否还只用厨房移动操作器。本课的三条通路仍然够用：只要输出还是文本，就属于 A 或 C；只要输出是词表里的动作 id，就属于 B；连续头是 B 的亲戚，损失不再是分类交叉熵，第 25 课再写。

### 13.2 缩小版和前沿的差距

规模差距：教学 $B=8$ 对论文 $B=256$；教学词表 32+56 对 PaLI 整数专座或 55B 词表；教学桌面三个圆点对 13 台机器人、13 万回合。这些差距用钱和数据可以缩，本课公式不用改。

机制差距：教学离散通路在唯一场景是写死的视觉捷径，不是从 394,000 条 rollout 里测出来的。它用于让你看懂 2603.19233 第 2 条结论的操作定义，不能反过来说「我们复现了 X-VLA」。共微调、输出约束、云端 55B 服务、思维链控臂，缩小版都没有。缺它们属于机制未实现，不是 batch 太小。

2603.19233 还做了激活注入、跨任务注入和 SAE。本课不实现 SAE，也不注入隐藏状态。那些方法的验收依赖模拟器 rollout 和按层的激活缓存，已经超出「动作如何成为 token」这个问题。第 29 课才会回到快慢双系统里「专家通路偏动作、VLM 通路偏目标语义」那句 2 倍位移。现在若有人问「为什么错指令在唯一场景无效」，标准答案停在任务结构：视觉已经唯一确定要抓的东西。不要用未实现的 SAE 特征去解释 Lab 里的三个圆点。

### 13.3 动手改造清单

四个实验都在本课的分箱函数和 Lab 政策上改，不新开 7B 训练。

1. **把 $B$ 从 8 改到 2 和 32。** 改 `lesson_24.py` 的 `BINS` 与 Lab 常量，重算示例向量的 token 和重建误差上界。预算：CPU 数秒。预期：$B=2$ 时 $x=0.4$ 和 $x=-0.2$ 可能落入更粗的格子，多目标场景的杯/苹果在 $x$ 维上仍应可分；$B=32$ 时上界缩小 4 倍相对 $B=8$。失败判定：增大 $B$ 后误差上界不变，说明反量化没用格心或宽度公式写反。改 $B$ 之后示例 token 不再是 `[37, 43, 52, 60, 66, 79, 82]`，第 10 节验收第 1 条要改成新串，并在记录里写明约定变更。不要一边改 $B$ 一边继续要求旧串，那是检查写死，不是分箱失败。
2. **给连续值加 Gato 式 μ-law 再分箱。** 只对前六维、$\mu=100$、$M=256$，夹爪仍均匀。预算：CPU 数秒。预期：靠近 0 的小位移占用更多格子，靠近 ±1 的大位移变粗。失败判定：μ-law 后 bin 边界检查仍按线性 $[a^{\min},a^{\max}]$ 去断言，这是测试写错，应改测试而不是改论文里的 μ。
3. **把 Lab 的唯一场景捷径从「写死」改成「可学习的假权重」。** 给图像一个物体计数特征 $n$，给指令一个目标 one-hot $u$，离散头输出 $\mathrm{softmax}(W[n;u])$。令 $n=1$ 时 $W$ 的图像列极大。预算：手算或几十步梯度下降。预期：$n=1$ 时改 $u$ 不改 argmax；$n=3$ 时改 $u$ 必改。失败判定：两种 $n$ 都跟 $u$ 走，说明图像列没起作用。
4. **技能通路加入否定指令。** SayCan 原文承认否定句（「bring me a snack that isn’t an apple」）会失败。在 Lab 的 LLM 分数里把「不要抓杯」写成对 `pick_cup` 的低分，看乘积是否仍被可行性拽回杯子。预算：改一张分数表。预期：唯一场景下可行性仍可能选出杯子，从而展示「接地」和「听懂否定」不是一回事。失败判定：把这一结果写成 VLA 视觉捷径。它是通路 C 的可行性支配，不是通路 B 的视觉支配。

### 13.4 顺手复现

| 论文结论 | 缩小版对应 | 能否看到同方向趋势 |
|---|---|---|
| RT-1：均匀 256 bin 可表示多峰动作 | $B=8$ 的分类头对两个目标各有一个格子 | 能，方向可复现；峰的分辨率差 32 倍 |
| RT-2：动作写入现有词表 | $z_d=V+dB+b_d$ 与整数专座 / 低频覆盖的对照说明 | 机制可复现；共微调配比不能复现 |
| Gato：连续值偏移到文本词表之后 | `[32, 88)` 相对 `[0, 32)` | 能 |
| SayCan：可行性乘语言分数 | Lab 技能乘积 | 能；101 条厨房指令不能复现 |
| 2603.19233：任务结构决定是否听指令 | Lab 两个错指令探针 | 定性可复现；94% 与 10% 不能复现 |

## 14. 论文与必读材料

1. [PaLM-E](https://arxiv.org/abs/2303.03378)（arXiv:2303.03378）。带着什么问题读：多模态句子的输入里可以出现哪些连续量？输出被规定成什么？低层政策在 Language-Table 和移动操作里分别来自哪篇工作？读完应能说明它为什么不是 RT-2 定义的 VLA。
2. [RT-1](https://arxiv.org/abs/2212.06817)（arXiv:2212.06817）。带着什么问题读：81 个视觉 token 怎样变成 8 个？为什么最终不按维自回归？连续高斯输出在消融里掉在哪一类指标上？把 7+3+1 维和本课教学 7 维的关系写清楚。
3. [RT-2](https://arxiv.org/abs/2307.15818)（arXiv:2307.15818）。带着什么问题读：PaLI-X 和 PaLM-E 各自怎样把 256 个 bin 塞进旧词表？共微调和朴素微调差在哪？输出约束在机器人任务和图文任务上是否同一套词表？把「VLA」这个词第一次出现的段落划下来。
4. [Gato](https://arxiv.org/abs/2205.06175)（arXiv:2205.06175）。带着什么问题读：文本、离散控制、连续动作三段 id 范围怎样互不重叠？掩码函数 $m(b,l)$ 排除了哪些模态？604 个任务里「超过 450 个达到 50% 专家分数」不能写成每个任务都超过专家。
5. [SayCan](https://arxiv.org/abs/2204.01691)（arXiv:2204.01691）。带着什么问题读：把 $p(c_i\mid i,s,\ell_\pi)$ 分解成哪两项？Table 2 里 mock kitchen 与真实厨房的规划和执行各是多少？去掉价值函数或去掉 LLM 各掉到哪一格？否定句和提早结束被作者写成哪类错误。
6. [CLIPort](https://arxiv.org/abs/2109.12098)（arXiv:2109.12098）。带着什么问题读：what 通路和 where 通路各依赖哪篇前置工作？输出是像素动作还是关节 token？179 对真机样本支持的是多任务模型还是单任务模型。
7. [A Mechanistic Study of Vision-Language-Action Models](https://arxiv.org/abs/2603.19233)（arXiv:2603.19233）。带着什么问题读：六个被测模型的名单和动作生成方式是什么？语言敏感性那句话里，`libero_goal` 与 `libero_object` 的数字分别是多少？专家通路与 VLM 通路的 2 倍位移写在哪三个多通路模型上。未出现在 Table 1 的模型，不要写进「该文证明」。

读完应能用一句话把本课收住：文字、技能名、动作 bin 都可以当 next-token，但只有后两者会在损失里移动手臂；即便动作 bin 进了词表，场景结构仍可能让语言形同虚设。下一课保持这套词表偏移，比较均匀分箱、连续回归、动作分块和压缩表示各自丢掉什么。

阅读顺序建议：先 RT-1 第 5.1 节（分箱、TokenLearner、3 Hz），再 RT-2 第 3.2 节（文本动作、共微调、输出约束），再 PaLM-E 第 3 节（多模态句子与「输出是文本」），再 SayCan 第 3 节公式和 Table 2，再 Gato 第 2.1 节词表分区，再 CLIPort 摘要和第 3 节，最后 2603.19233 的摘要、Table 1 和 4.2–4.3。这个顺序按「动作在哪一层」从专用机器人词表走到共享 VLM 词表，再退回「其实输出仍是字」和「其实输出是像素」，最后用机理实验问语言有没有被用上。倒着读容易一开始就陷进 SAE 和注入，把本课的分箱公式挤掉。

每篇只交三句笔记：动作进入模型的位置（输入 / 输出词表 / 技能名 / 像素图）；损失加在哪；一条你核对过的数字及其表号或节号。数字没有表号或节号的，不要写入交付物。论文 PDF 很大，允许只精读指定节；指定节之外的附录数字，未打开就不引用。
