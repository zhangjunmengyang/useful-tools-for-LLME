# 第 56 课：用偏好模型给生成打分

> 内容：生成图的像素 L2 与人类偏好奖励何时反向，以及如何用 Kendall τ 拒收单尺验收<br>
> 建议周期：阅读约 80 分钟；浏览器两图对打约 15 分钟；CPU 夹具数分钟<br>
> 硬件：无 GPU 可完成本课阅读、教学模拟与 CPU 机制实验。复现 ImageReward / PickScore / Diffusion-DPO 需要能加载对应公开权重的推理或训练卡<br>
> 产物：两序对打协议、Kendall τ 夹具、过平滑反向对教具

## 1. 生成质量为什么不能只用重建误差

到这一课，课程里已经有两把看起来都能给“图好不好”打分的尺子。[第 20 课](20_unified_understanding_generation.md) 的生成头在 VAE latent 上回归速度场，训练目标是连续量上的欧氏误差；采样结束后，你仍会下意识用像素或 latent 的 $L_2$ 看重建糊不糊。[第 16 课](16_multimodal_preference_optimization.md) 的 mDPO 则要求模型真的看见媒体，但那一课的 chosen / rejected 是**回答文本**，奖励落在 token 概率上，不给生成出来的像素打分。第 49 课的规格把“生成下一帧”和“看懂这一段”拆成两本账，本课接管生成这一侧：帧差 $L_2$ 低，是否等于人更愿意留下这张图。

一张锐利的十字加棋盘当参考。候选 A 做一次 $3\times 3$ 盒滤波，边被抹成坡。候选 B 把整张图平移 1 个像素，边还在，只是格子对不齐。对参考图像素做均方误差，A 更近；用“边还在不在、灰不灰”这种教学偏好分，B 更高。CPU 夹具把这个现象做成四档：过平滑、略糊、半锐、平移锐利。$L_2$ 从低到高恰好是偏好从低到高的反序，Kendall $\tau_a=-1$。浏览器教具默认就是这一对。你必须先预测“两把尺子会不会反向”，揭晓前看不到数字。

这不是教具在作弊。MSE 最优估计是后验均值。一条细边在后验里可能偏左也可能偏右，均值落在中间，看起来就是糊。人不要均值，人要某一个说得通的硬边，哪怕它和某张参考图的像素对不齐。FID 把生成分布和真实分布的 Inception 特征做成 Wasserstein-2 距离，仍然可以和人类排序拧着走。ImageReward 论文 Table 1 在真实用户 prompt 上报告：人类排序与 ImageReward 的 Spearman $\rho=1.00$，与 CLIP 为 $0.60$，与 MS-COCO 上 zero-shot FID 仅为 $0.09$。Pick-a-Pic 论文更写明，即使用 MS-COCO 标题评，PickScore 与人类相关 $0.917$，FID 为 $-0.900$。负号在这里不是排版，是方向反了。

本课不训公开奖励模型，不声称复现 ImageReward 的 65.14% preference accuracy，也不把夹具分数写进模型卡。要改的是验收协议：生成质量必须同时记重建误差和偏好序；两序 Kendall 为负时，禁止把更低 $L_2$ 写成更好。生成账本要记的不是像素更近，而是人会留下哪一张。

再把反向对说成一次实验操作，而不是一句感想。打开 Lab 之前先在纸上写预测：你认为滤波图会在 $L_2$ 上赢还是输，会在偏好上赢还是输。写完再揭晓。揭晓后把四个数抄进笔记：$\mathrm{MSE}_A$、$\mathrm{MSE}_B$、$r_A$、$r_B$。用不等式连接它们。本课默认预置下应看到 $\mathrm{MSE}_A<\mathrm{MSE}_B$ 且 $r_A<r_B$。若你看到的符号不同，先记录滑条位置，不要立刻改教学公式。CPU 夹具的符号是锁死的，Lab 滑条可以走到同序区。两种结果都合法，合法的前提是预测发生在揭晓前。预测发生在揭晓后，Gate 不计。这条纪律和第 20 课“看 test 前锁定主指标”同源：人会事后编故事。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 重建误差 | 生成图与参考图在像素或 latent 上的距离，本课主用均方误差 $L_2$ |
| MMSE | 最小均方误差估计：后验分布的均值；多峰时均值发糊 |
| 过平滑 | 高频边被抹掉的重建，看起来像雾，常赢 $L_2$、输偏好 |
| 偏好对 | 同一 prompt 下两张图，人标哪张更好，或标平局 |
| 奖励模型（RM） | 输入 prompt 与图，输出标量 $r$，用来近似“人会选谁” |
| Bradley–Terry | 把“i 赢 j”的概率写成 $\sigma(r_i-r_j)$ 的配对模型 |
| Kendall $\tau$ | 两组排序有多少对同序、多少对反序的相关系数，完全反序为 $-1$ |
| FID | Fréchet Inception Distance：两分布在 Inception 特征上的距离，越低越像真实集 |
| ImageReward | 在 137k 专家比较上训的文生图偏好 RM |
| PickScore | 在 Pick-a-Pic 用户选择上微调 CLIP-H 得到的打分器 |
| HPS / HPSv2 | Human Preference Score：用人类选择微调 CLIP，作偏好代理 |
| ReFL | 在扩散后段把 RM 分数回传到去噪网络的微调法 |
| Diffusion-DPO | 把 DPO 写到扩散似然上，直接吃 pairwise 偏好 |

前面课已经解释过的词直接链回去：loss mask、golden case 见[第 01 课](01_baseline_reproduction.md)；偏好对、reference、隐式奖励见[第 16 课](16_multimodal_preference_optimization.md)；flow matching、VAE latent 见[第 20 课](20_unified_understanding_generation.md)；CLIP 余弦见[第 21 课](21_clip_siglip_contrastive.md)；评测数字不能横着比见[第 47 课](47_eval_taxonomy.md)。本课若再把 DPO 推导或 Euler 积分重写一遍，会和 16、20 课抢篇幅。

把同一件事说成验收口令。你手里有 $n$ 张同一 prompt 的生成图。重建尺给出一个从近到远的排列 $\pi_{L_2}$。偏好尺给出一个从高到低的排列 $\pi_{r}$。本课要你先会造出 $\pi_{L_2}$ 与 $\pi_{r}$ 完全相反的一组图，再规定：相反一旦出现，发布说明里禁止只印重建尺。口令的反面同样成立：两把尺子同序时，你仍须把两列都印出来，因为下一批 prompt 可能翻面。ImageReward Table 1 已经在真实模型名次上翻过一次：Openjourney 人类第一、COCO FID 第五。夹具只是把翻面缩到 8×8，让你不用下载权重也能复核符号。

和“图好看”这种口语也要划清。好看可能指饱和度、清晰度、像不像某张名画、像不像用户脑子里的那只猫。公开 RM 各自吃了一部分：ImageReward 的标注文档把对齐、保真、无害拆开再合成总序；HPSv2 让普通标注者在同一 prompt 的若干张里选更想留下的；PickScore 记录的是真实用户在产品里点哪张。三套标注都不是 PSNR。你若在业务里另有“必须认得出车牌”这类硬规则，那是可验证奖励，走[第 17 课](17_grpo_rlvr.md) 的 verifier，不要塞进本课的标量 $r$ 里充数。本课的 $r$ 只回答 pairwise 偏好，不回答“客观上对不对”。

## 2. 本课解决的问题

当前系统（以及你在文生图、文生视频报告里看到的数字）默认验收常常是“PSNR 高一点、FID 低一点、flow 的速度 $L_2$ 降了”。它解决不了四类失败，而且这四类会在总平均里被兑掉：

1. 把过平滑重建的低 $L_2$ 写成“生成更好了”。
2. 把 COCO 上的 FID 写成“用户会更喜欢这些图”。
3. 用 CLIP 余弦代替人类 pairwise 选择，漏掉肢体崩坏和审美。
4. 视频侧只报帧间 $L_2$，不报运动是否顺、是否还对准 prompt。

本课的改造范围只包括打分协议、排序相关和一小段可手算的 Kendall 夹具。不重做第 20 课的 flow head，不重做第 16 课的 CoPO 裁剪图，不比较离散视觉 token 与连续 latent 谁更适合统一模型（那是第 20 课的三臂），不把视频理解的 Video-MME 准确率填进生成账（那是第 47 课的 C2）。

以下结果不能支持“生成已经对齐人类”或“重建误差已经够用”：

- 只报 test 集 $L_2$ / PSNR，没有人类或 RM 排序；
- 用 FID 单独给模型排名，不报告它与人类排序的 Spearman / Kendall；
- 把 CLIP 图文相似度当作偏好胜率；
- 把第 16 课文本 DPO 的 pair accuracy 写成生成图变好了；
- 视频只报帧差，不拆视觉质量、运动、文本对齐。

执行顺序固定：先在 CPU 夹具上证明 $L_2$ 序与偏好序可以完全相反，再在浏览器里亲眼看到过平滑赢误差、输偏好，最后如果有 GPU，才把同一套两序协议接到公开 RM 的推理脚本上。没有 GPU 时，前两步已经构成完整交付。

和第 16、20 课以及第 49 课规格的边界再钉死一次。第 16 课问的是：回答文本有没有看见图；chosen 是句子。本课问的是：生成出来的图有没有被人喜欢；chosen 是像素。第 20 课问的是理解和生成能否共享骨干，生成目标仍是速度 $L_2$；本课不改那条损失，只规定它不能单独当验收。第 49 课问生成帧差和理解 CE 的有效位置是否相交；本课假定它们已经分账，再问生成账里该用 $L_2$ 还是偏好 RM。三课的检查票要一起用：先问这格是生成还是理解，再问生成格用的是误差还是偏好，再问两序相关。

本课固定四个可证伪命题：

1. 存在一组固定像素图，使得 $L_2$ 排序与教学偏好排序的 Kendall $\tau_a<0$。
2. 过平滑候选在这组图里 $L_2$ 最低，偏好也最低。
3. 平移锐利候选 $L_2$ 高于过平滑，Bradley–Terry 下 $P(\text{shift}\succ\text{blur})>1/2$。
4. 把“更低 $L_2$”直接写成“更好生成”的报告必须被拒绝。

四条都通过，只能说明打分协议可复核。它们不能说明 ImageReward 在你的业务图上仍是 65.14%，也不能说明 Diffusion-DPO 微调后的 69% 人类胜率可以搬到 MiniMind-O 的 256×256 缩小实验。

把“验收改什么、模型不改什么”列成一张职责表，防止本课膨胀成第二门生成课。

| 模块 | 本课动不动 | 理由 |
|---|---|---|
| MiniMind-O 骨干 / Talker | 不动 | 生成偏好与语音双工无关 |
| 第 20 课 flow head 与速度 $L_2$ | 训练目标不动，验收加列 | 欧氏损失仍合法，只是不够 |
| 第 16 课 mDPO pair | 不混用 | chosen 是句子，不是像素 |
| 第 21 课 CLIP 权重 | 可当对照列，不当主验收 | Table 6 已显示零样本不够 |
| 评测脚本的列集合 | 动 | 必须同时写出 $L_2$ 序和 $r$ 序 |
| 发布说明的主句 | 动 | $\tau<0$ 时禁止只报更低误差 |
| 公开 RM 权重 | 可选加载 | 无 GPU 时用教学 $r$ 完成协议 |

职责表也挡住另一种膨胀：有人想在本课重做 Show-o / Janus 的共享骨干。那是第 20 课的三臂。本课只问三臂输出的图用哪把尺子验收。Janus 的离散视觉 token 交叉熵仍然是一种重建或似然，不是人类 pairwise。Show-o 的离散扩散同理。它们的论文若没报 pairwise 人类胜率，本课引用时写未公开，不拿 FID 顶替。

## 4. 完成后应具备的能力

完成后，拿到任意一组生成图，你应能完成以下检查：

1. 写出像素 $L_2$、LPIPS 和 Bradley–Terry 奖励各自比较的是什么。
2. 解释为什么 MMSE 会把多峰后验平均成糊图。
3. 在过平滑与 1 像素平移之间指出哪张赢 $L_2$、哪张赢偏好。
4. 手算两组全序的 Kendall $\tau_a$，并判断符号。
5. 说明 ImageReward Table 1 里 FID 的 $\rho=0.09$ 和 PickScore 的 FID $-0.900$ 各说明什么。
6. 把第 16 课的文本 pair 和第 20 课的速度 $L_2$ 从本课的生成偏好账里剔除。
7. 列出用 RM 改生成器的三条路：过滤、ReFL 类回传、Diffusion-DPO，并写清各自吃的数据。
8. 视频侧拒绝只用帧差，至少拆视觉、运动、文本对齐三列。
9. 写出过滤、ReFL、Diffusion-DPO 各需要什么数据，并把“只升 $r$”和“生成更好”分成两个状态。
10. 在标注说明里写出对齐、保真、无害冲突时的优先级，而不是让标注者临场发挥。

## 5. 原理：边造边讲

六个机制，每个按同一节奏：为什么需要、怎么运转、精确定义、代码落点、怎么证明做对了。

### 5.1 $L_2$ 最优是均值，均值会糊

生成模型在训练时最常最小化某种平方误差。扩散模型回归噪声，flow matching 回归速度，超分辨率网络回归像素，写法不同，几何一样：独立地对每个坐标做欧氏惩罚。独立是关键。两个相邻像素在真实图像里几乎从不独立，边、纹理、文字笔画都是结构化的。平方损失不看结构，只看每个坐标离目标多远。

设参考图为 $x^\star$，生成图为 $\hat x$。像素均方误差

$$
\mathrm{MSE}(\hat x,x^\star)=\frac{1}{HW}\sum_{i=1}^{HW}(\hat x_i-x^\star_i)^2
$$

在固定 $x^\star$ 时，最优 $\hat x$ 就是 $x^\star$ 自己。训练时你没有单张 $x^\star$，只有条件分布 $p(x\mid c)$。对条件平方损失取期望，最优预测是后验均值：

$$
\hat x_{\mathrm{MMSE}}(c)=\mathbb{E}[x\mid c]
$$

若 $p(x\mid c)$ 在“边偏左”和“边偏右”两个峰上，均值落在两峰中间，像素值变成过渡灰，边消失。这就是过平滑。类比：问十个人“硬币正面朝哪”，五人说左、五人说右，均值是“朝中间”。类比失效处：人可以回答“我不知道”；像素均值没有“不知道”，它会画出一张谁都不承认的图。

1 像素平移几乎不改变人看到的结构，却让边和参考图的边错开。错开的每个边像素贡献接近 $1$ 的平方误差。盒滤波把边摊成几个像素宽的坡，每个像素只偏 $0.1$ 到 $0.5$，总和往往更小。本课 CPU 夹具里，一次盒滤波相对 8×8 参考图的 MSE 约为 $0.073$，1 像素平移约为 $0.216$。滤波更近，看起来更糊。

验证：打印四张候选相对同一参考图的 MSE。若平移图的 MSE 低于滤波图，先检查是不是把参考图也滤了，或平移用了循环移位把棋盘映成自己。棋盘周期为 2 时循环移 1 等于取反，误差会到极值，但仍应高于适度滤波。本课实现用零填充平移，避免周期巧合。

把 8×8 夹具里的四个数摊开，避免只记“滤波更近”这一句。一次 $3\times 3$ 盒滤波后 MSE 约为 $0.0726$，教学偏好约为 $0.1214$。把滤波图与 1 像素平移按 $0.15$ 和 $0.40$ 线性混合，MSE 依次升到约 $0.0777$ 和 $0.0992$，偏好升到约 $0.1336$ 和 $0.2080$。纯平移 MSE 约 $0.2163$，偏好约 $0.6625$。四档在两把尺子上都是严格单调，方向相反。全 $0.5$ 的灰图 MSE 约 $0.1860$，比平移更近，偏好为 $0$。恒等图 MSE 为 $0$，偏好约 $0.6562$，和纯平移接近：教学 $r$ 奖励的是边，不奖励“和参考图重合”。这正是它和 $L_2$ 分家的地方。换一套系数可以让恒等图赢偏好，但只要滤波仍赢 $L_2$、输边，符号结论不变。写报告时把系数和参考图哈希一起存档，防止有人用另一套 $r$ 把夹具改成同序再声称“本课失败”。

和第 20 课的衔接要具体到张量。flow matching 的训练损失是速度场上的 $L_2$，采样结束后你还会拿解码图像相对训练图再算一次像素 $L_2$。两步都是欧氏。第一步决定网络学均值速度，第二步决定你用均值图像当验收。本课不改第一步：速度 $L_2$ 仍是合法训练目标。本课改第二步：解码之后必须另排一列 $r$。若有人把速度损失下降写成“人类更喜欢这些图”，按本课第 9 节拒收。VAE latent 上的 $L_2$ 也一样。latent 比像素平滑，过平滑更难用肉眼发现，更需要独立的偏好列。

两把尺子何时同序，也要能造出来。把 A、B 都做成恒等图，MSE 同为 0，偏好同分，Kendall 无定义或全并列。把 A 做成 3 次滤波、B 做成 2 次滤波，两边都糊，通常 $L_2$ 与偏好同序：糊得轻的两边都更好。Lab 的“预置同序对”就是这一支。协议必须同时覆盖反向和同序。只会演示反向、把滑条焊死，验收不算过。同序出现时，正确说法是“这一批候选上两尺同向”，不是“重建误差已经等于人类偏好”。

### 5.2 感知距离能跟上局部判断，仍不是偏好

LPIPS 论文（Zhang 等，CVPR 2018，[arXiv:1801.03924](https://arxiv.org/abs/1801.03924)）的 Figure 1 直接摆出反例：哪一块更像中间的参考块，传统 $L_2$/PSNR、SSIM、FSIM 和人类判断拧着。作者在 BAPPS 上收集 2AFC（二选一强迫选择：两张畸变里哪张更接近参考）。深度网络内部激活做成的距离比经典指标更接近这些判断。正文还写了一句本课要用的话：模糊会造成很大的感知差别、很小的 $\ell_2$ 差别。

LPIPS 比较的是“像不像参考”，仍需要一张参考图。文生图用户常常没有参考照片，只有一句 prompt。像不像 COCO 里某张真实图，和“这句 prompt 我更想留下哪张生成图”，不是同一个问题。FID 更远一步：它比较的是整集分布，不给单张图打分。ImageReward 论文 2.3 节列了 FID 的两个缺口：现在的模型多是零样本使用，微调 FID 不能代表真实用法；FID 依赖整集平均，不能当单张选择器。Pick-a-Pic 把第二个缺口做成数字：在 MS-COCO 标题上，用 FID 给模型排序，与人类排序相关 $-0.900$。

所以感知度量是中间层，不是终点。本课允许把 LPIPS 记为“有参考时的感知重建”，单独一列；禁止用它代替 pairwise 偏好。验证：同一对图，同时写 $L_2$、（若有参考）LPIPS、（若有 RM）$r$。三列符号不一致时，报告必须写清你采纳哪一列作验收，以及另外两列被降级的理由。

BAPPS 的规模帮助你判断 LPIPS 能管到哪。训练集含 15 万级畸变 2AFC，验证还包含超分、插帧、去模糊、上色等真实算法输出。它比 TID2013 更宽的地方是畸变种类和算法输出，不是“人更喜欢哪张文生图”。文生图的失败（六指、乱字、数错物体）很少出现在传统畸变列表里。所以 LPIPS 下降可以支持“更像参考块”，不能支持“更像用户想要的那张猫”。本课夹具里甚至没有实现 LPIPS：8×8 太小，深度特征没有意义。教学 $r$ 用边能量代替“人要硬边”这一条，范围更窄，也更诚实。

把三列的输入条件写成表，免得实验记录里混用。

| 列 | 必须提供 | 比较的是 | 单张可算 | 能当人类偏好代理 |
|---|---|---|---|---|
| 像素 $L_2$ / PSNR | 参考图 | 坐标独立的欧氏差 | 能 | 不能，见夹具 |
| SSIM | 参考图 | 局部均值、方差、协方差 | 能 | 不能默认，LPIPS Figure 1 已给反例 |
| LPIPS | 参考图 | 深度特征差 | 能 | 更接近 2AFC“像不像参考”，仍不是 prompt 偏好 |
| FID / IS | 一整集真实图 | 分布距离 | 不能 | ImageReward Table 1、Pick-a-Pic 均显示可与人类拧着 |
| CLIP 余弦 | prompt | 图文是否像一对 | 能 | HPSv2 Table 6：零样本 CLIP-H 在 HPD v2 上 65.1，低于专用 RM |
| 偏好 RM | prompt + 图 | 人会选谁 | 能 | 只在其训练集分布内可讨论 |
| 人类 pairwise | 标注说明 | 该批标注者的选择 | 能（贵） | 上限，HPSv2 单人 vs 单人 78.1% |

IS 和 FID 还共享一个本课要避开的陷阱：它们的特征来自 ImageNet 分类网。HPS 论文引言写过，这类特征偏纹理、不看用户意图，而且是单模态的。你若只有 COCO FID，最多能说“生成分布在 Inception 空间里更接近 COCO 照片”。把这句话翻译成“用户更满意”，就是单位错误。第 47 课管跨基准不能横着减；本课管生成内部这七列不能合成一个“质量分”。需要一个发布数字时，预先指定人类抽检胜率或某个点名的 RM 胜率，其它列进附录。

### 5.3 Bradley–Terry：把“谁赢”写成两个分数之差

人类标注给的是比较，不是绝对分。同一 prompt $c$ 下，图 $x^w$ 优于 $x^l$，记作 $x^w \succ x^l \mid c$。Bradley–Terry 模型假设存在标量奖励 $r(c,x)$，使得

$$
P(x^w \succ x^l \mid c)=\sigma\bigl(r(c,x^w)-r(c,x^l)\bigr)
$$

其中 $\sigma(z)=1/(1+e^{-z})$。最大似然就是 ImageReward 式 (1) 和 Diffusion-DPO 式 (4) 共用的损失：

$$
\mathcal L_{\mathrm{BT}}=-\mathbb{E}\bigl[\log\sigma\bigl(r_\phi(c,x^w)-r_\phi(c,x^l)\bigr)\bigr]
$$

[第 16 课](16_multimodal_preference_optimization.md) 已经从同一个模型推出 DPO：最优策略的隐式奖励等于 $\beta\log(\pi/\pi_{\mathrm{ref}})$。本课停在奖励模型本身。生成器还不会写似然时（扩散在像素上没有归一化的 $p(x_0\mid c)$），你不能直接套文本 DPO，必须先有 $r$，或把扩散的 ELBO 当成似然代理（Diffusion-DPO 的做法）。

教学夹具里的 $r$ 不是神经网络。对一张图计算离散梯度能量、方差和发灰惩罚：

$$
r_{\mathrm{toy}}(x)=2.4\,E_{\mathrm{edge}}(x)+0.9\,\mathrm{Var}(x)-0.35\bigl(1-4\mu(1-\mu)\bigr)
$$

$E_{\mathrm{edge}}$ 是相邻像素差的均方。过平滑把它压下去；平移几乎不伤它。这只是为了在无 GPU 时让“人更喜欢硬边”可手算。正式 RM 用 BLIP 或 CLIP 骨干，见下一小节。

验证：对夹具里的过平滑与平移图，算 $P(\text{shift}\succ\text{blur})=\sigma(r_{\mathrm{shift}}-r_{\mathrm{blur}})$。该值必须大于 $1/2$，且把这对标签对调后损失上升。CPU 实验把这两条写成 checks。

把夹具里的两个标量代进去。CPU 实验打印的过平滑 $r\approx 0.1214$，平移 $r\approx 0.6625$，差约 $0.541$。Bradley–Terry 概率 $\sigma(0.541)\approx 0.632$，正确标签损失 $-\log\sigma\approx 0.459$，标签对调后损失 $\approx 1.000$。手算与脚本差应小于 $0.01$。符号错了就不能用“舍入”开脱。教学 $r$ 的绝对数值没有单位，只有差有意义。换一套边能量系数，差会变，只要过平滑仍低于平移，BT 概率就仍大于一半。公开 RM 的输出同样不要当绝对分用：ImageReward 在 Table 1 给六个模型的是均值分数，排序才和人类比，绝对值跨论文不可比。

图像偏好还有几类不看内容也能猜对的捷径，对应第 16 课的长度偏差、文风偏差。常见的有：分辨率更大的赢、更饱和的赢、中心构图的赢、带水印或 UI 边框的输。训练 RM 前要在验证集上做切片：只比较同分辨率、同 guidance 的对，准确率还在不在。若只有“大图赢小图”，RM 没有学会 prompt 对齐。PickScore 的训练数据来自真实用户点选，用户会偏爱更锐、更饱和的样本，这是数据事实，不是 bug；你若业务要的是“更像证件照”，必须另标，不能指望 PickScore 自动改口味。

平局要进损失。经典 BT 没有 tie。Pick-a-Pic 和 VideoReward 都发现允许平局能提高一致率和稳健性。实现上常见两种：平局样本的目标改成 $0.5$，损失用 $|r_i-r_j|$ 的惩罚；或改用带平局的 Bradley–Terry–Luce。本课夹具没有平局，四档分数严格不等。你自己的 20 对抽检若出现平局，计算 $\tau$ 时把该对从 $C$ 和 $D$ 里剔除，并在分母注明有效对数。不要把平局算成 Concordant 来抬 $\tau$。

### 5.4 公开偏好模型吃什么数据、报什么数

四条公开线，数字只引用已打开的表。

**ImageReward**（Xu 等，NeurIPS 2023）。骨干是 BLIP（ViT-L 图像编码器 + 12 层文本编码器），图文特征交叉注意力后接 MLP 出标量。数据来自 DiffusionDB 的真实用户 prompt，专家按对齐、保真、无害打分再排序，有效标注 8,878 个 prompt、136,892 对，摘要写成 137k。测试集 466 个 prompt、6,399 对。Table 3：preference accuracy 为 CLIP 54.82%、Aesthetic 57.35%、BLIP 57.76%、ImageReward 65.14%。摘要把相对 CLIP / Aesthetic / BLIP 的提升写成 38.6% / 39.6% / 31.6%；与 Table 3 并列引用，不要把 38.6% 写成准确率本身。Table 1 用真实用户 prompt 的人类胜场给六个模型排序：Openjourney、SD 2.1-base、DALL-E 2、SD 1.4、Versatile Diffusion、CogView 2。ImageReward 的排序与人类一致，$\rho=1.00$；CLIP 为 $0.60$；同一批模型在 MS-COCO 2014 上的 zero-shot FID 排序与人类 $\rho=0.09$。Openjourney 人类第 1、FID 第 5（20.7）；DALL-E 2 人类第 3、FID 第 1（10.9）。这就是“FID 低不等于人喜欢”的表内证据。

把 Table 1 六行全抄进实验记录当对照，避免只记两头。真实用户 prompt 上人类胜场：Openjourney 507、SD 2.1-base 463、DALL-E 2 390、SD 1.4 362、Versatile Diffusion 340、CogView 2 74。ImageReward 均值：0.2614、0.2458、0.2114、0.1344、$-0.2470$、$-1.2376$，名次与人类相同。CLIP 均值挤在 0.20 到 0.28：SD 1.4 反而最高（0.2763），Openjourney 第二（0.2726），区分度差。COCO 上 ImageReward 把 DALL-E 2 排第一（0.5387），与人类在用户 prompt 上的第三不一致，作者把这一列的 $\rho$ 写成 0.77。FID：DALL-E 2 的 10.9 带星号，来自原论文 30k 设置；其余在 256×256 的 COCO 2014 val 上测。CogView 2 两边都垫底，说明“有的模型两把尺子会一起骂”，不能反过来推出“两把尺子等价”。只有六行里名次交叉的那几对，才构成反向证据。写报告时把交叉对单独圈出来：Openjourney 对 DALL-E 2，人类与 FID 相反。圈不出来，就还在用总相关讲故事。

六个模型的交叉还可以当反例库。有人说“只要换更新的生成器，FID 和人类就会一起好”。Table 1 里 SD 2.1-base 人类第二、FID 第四（18.8），SD 1.4 人类第四、FID 第二（17.9）。同一家配方的两个版本，两把尺子交叉。更新不是充分条件。本课夹具不包含“更新的滤波”，它包含“更糊的滤波”和“错位的锐利”。锐利可以更新，也可以只是把边挪开。验收脚本必须能骂挪开的边：若 $L_2$ 单独当家，挪开的边会被判死刑，人却可能留下它。这就是为什么主句要看 $r$。

名次交叉还有一个用法：当负对照。你在自己的 20 个 prompt 上若从未看到 $L_2$ 与 $r$ 交叉，先别庆祝“两尺已经一致”。检查候选是不是太近：四张图都是同一次采样的相邻 seed，糊的程度差不多，Kendall 会在 0 附近抖动。夹具故意把糊和错位拉到两端，交叉才稳定出现。真实模型评测也要保证候选之间有足够差异：混进一张明显坏图、一张明显好图，再看中间两张能不能把两尺拉开。ImageReward Figure 3 用箱线说明它比 CLIP 更能拉开同模型内的样本。本课没有箱线，只有四档。四档的意义是：差异不够时 $\tau$ 没有解释权。

把“差异不够”写成拒绝理由，和 $\tau>0$ 写成“本批同向”要分开。前者是实验无效，后者是有效的同向结果。无效时加候选或换 prompt，不要改 $r$ 的系数去制造交叉。制造出来的交叉和夹具一样可以算 $\tau=-1$，但不能写进域内结论。夹具的 $-1$ 只证明协议能抓住反向，不证明你的生成器正在反向。

再补一条和采样有关的反向。分类器自由引导（CFG）把有条件预测和无条件预测做差再放大，常能让图更听 prompt，也会让过饱和、过锐化一起上来。Pick-a-Pic 观察到 guidance 9 通常赢 guidance 3。若你用像素 $L_2$ 去对一张较干净的参考图，guidance 9 的图可能更远，因为多出来的高频并不等于参考图的高频。于是同一生成器、同一 prompt、只改 guidance，就可以造出 $L_2$ 与用户选择反向的一对。这对比滤波–平移更接近真实训练。本课 Lab 没有 CFG 滑条，是为了让 16×16 像素保持可解释。你若做 Step 3，把 guidance 3 对 9 收进 20 个 prompt 里的 5 个，作为真实采样反向的探针。探针失败（两尺同向）同样有效：说明在你的 RM 和域上，听 prompt 的高频碰巧也更接近参考。有效的同向仍要两列都印。

CFG 探针的记录格式与夹具相同，只是候选从滤波/平移换成 `guidance=3` / `guidance=9`。表头照旧：`id, mse, r, rank_l2, rank_pref`。若没有参考图，mse 列留空，只报 $r$ 序和人类序的 $\tau$，不再声称与 $L_2$ 反向。空列必须看得见，不能删掉整列假装“我们只用偏好”。删列等于换协议。换协议要改预注册，不能在看完 5 个 prompt 之后改。

把预注册理解成一张不能事后改的卡片，字段只有六个：主验收列、对照列、n、划分、$\tau$ 的定义、过优化越线阈值。六个字段在看任何测试图之前签字。签字后只能新增附录列，不能改主列。第 20 课用同样纪律锁 $U_{\mathrm{primary}}$ 和 $G_{\mathrm{primary}}$。本课锁的是“偏好序相对 $L_2$ 序的符号”。符号是主结果，准确率是附录。有人把 65.14% 印在第一页、把 $\tau$ 符号藏在脚注，按本课第 9 节算未通过。第一页必须能回答：这一批生成图，重建尺和偏好尺有没有反向。

卡片签字的人必须是写报告的人，不能是“组里另一个看过 RM 名字的人”。预注册不是仪式。它防止的是：先看见 Openjourney 的 FID 难看，再决定主指标改成 ImageReward。Table 1 已经把这种事后挑选写在明面上：六行里总能挑出一把对自己有利的尺。本课把挑选的时间提前到看行之前。看行之后只能解释，不能换尺。签字可以用实验记录首页的一行日期和姓名代替正式法律文本。缺这一行，等于没有预注册。日期必须早于任何测试图的生成时间戳。时间戳倒挂时，把该次评测整页作废，不要只改日期。作废不是惩罚，是防止事后挑选留下痕迹。下一轮重新签字、重新出图。旧图可以进附录当失败案例，不能进主表。附录要标明“签字后才生成”或“签字前旧图”，两类不得合并算 $\tau$。合并会把看过的图和没看过的图兑在一起，符号不再可解释。若旧图必须展示，单独开表，标题写成“探索集”，并声明不参与第 9 节验收。探索集上的反向只能当假说，不能当通过证据。假说要进下一轮预注册，才能变成主表。探索集的文件名也要带 `explore-` 前缀，避免汇总脚本把它算进主表。前缀是协议的一部分，不是文件名审美。

**PickScore**（Kirstain 等）。数据来自真实用户在 web app 上的选择，不是众包工人。论文实验版本：训练 583,747 条，验证/测试各 500 条；全文还写数据集超过五十万例、后有超过一百万例的更新。每个例子是 prompt、两张图、偏好或平局。PickScore 微调 CLIP-H，目标与 InstructGPT 的 RM 同类。测试：PickScore 70.5%，人类 68.0%，零样本 CLIP-H 60.8%，美学预测器 56.8%。作者把 70.5%>68.0% 写成 superhuman。本课引用时必须写清：这是“预测该数据集用户选择”的准确率，不是美学真理。FID 在 MS-COCO 标题上与人类相关 $-0.900$，PickScore 为 $0.917$。

**HPS 与 HPSv2**。HPS v1 从 Discord 收集 98,807 张图、25,205 次选择，结论是 IS、FID、CLIP 都不能完整预测这些选择。HPSv2 换更宽的图源：9 个生成模型加 COCO 真图，798,090 次选择。训练时微调 OpenCLIP ViT-H/14。Table 6 准确率：

| 模型 | ImageReward 测试集 | HPD v2 测试集 |
|---|---|---|
| CLIP ViT-H/14 | 57.1 | 65.1 |
| ImageReward | 65.1 | 74.0 |
| Aesthetic | 57.4 | 76.8 |
| HPS v1 | 61.2 | 77.6 |
| PickScore | 62.9 | 79.8 |
| 单人 vs 单人 | 65.3 | 78.1 |
| HPSv2 | 65.7 | 83.3 |

HPD v2 测试集比 ImageReward 测试集更宽，HPSv2 在两列都最高。单人 vs 单人 78.1 说明偏好有噪声：RM 不准到 100% 不一定是模型坏了。

**多维与局部反馈**。MPS（Zhang 等，[arXiv:2405.14705](https://arxiv.org/abs/2405.14705)）用一个 CLIP 加条件模块打多个偏好维度。RichHF-18K（Liang 等，[arXiv:2312.10240](https://arxiv.org/abs/2312.10240)）在 18K 张生成图上收集更富的反馈：哪里错、错什么，再训 RAHF 去预测。标量 RM 把肢体崩坏、文字拼错、构图平庸压成一个数，定位失败时不够用。本课主线仍用标量，因为 Kendall 对打只需要一个序；多维是诊断列，不是第二把总尺子。

验证：引用上述任一准确率时，必须写数据集名、划分、n。把 HPSv2 的 83.3% 写到 ImageReward 测试集上，或把 65.14% 写成“人类一致率”，报告作废。

把 ImageReward 的标注流水线按论文 2.1 节拆开，避免把它写成“找人打了个分”。prompt 来自 DiffusionDB，用基于语言模型相似度的图算法挑 10,000 条，每条配 4 到 9 张图，共 177,304 个待标候选。标注分三截：先给 prompt 分类并标出有问题的句子；再按对齐、保真、无害给每张图打分；最后把图排序，文档里写明三项冲突时怎么取舍。标注者多数至少大学学历，质检员复检，不合格打回。两个月后有效 prompt 8,878 条，比较对 136,892。测试用 466 条来自与研究员更一致的标注者。这些数字说明两件事。第一，偏好数据的成本在流程，不在“多画几张图”。第二，测试集不是随机切片，是高一致子集，65.14% 是在这个子集上的准确率。你自己的 100 对探针若没有质检和冲突规则，准确率不能和这张表横比。

Table 2(a) 还报了标注一致率，用另外 40 个 prompt、778 对来量研究员、标注者、标注者集成和模型之间有多常选同一张。本课不把那些格子里未在 HTML 中完整抄下的百分数写进正文。你需要记住的只有方法：上 RM 准确率之前，先量人与人的一致率，它是天花板。HPSv2 Table 6 把天花板写成单人 vs 单人 78.1%、单人 vs 平均人类 85.0%。RM 到 83.3% 已经贴近后一个数。再往上刷训练准确率，多半在拟合某几个标注者的癖好。缩小探针里若两名标注者一致率低于 0.65，先改说明，不要加网络层。

ImageReward 对训练超参很敏感。作者写快速收敛随后过拟合，于是冻一部分 transformer 层。最终选用冻 70%、学习率 1e-5、batch 64。消融 Table 2(b) 显示数据从 2k、4k 到 8k prompt 时 preference accuracy 从 63.18、64.71 到 65.14。本课引用这三格，是为了挡住“再标 200 对就能复现 Table 3”的计划。200 对连 2k 的边都不到。缩小协议的诚实写法是：200 对只够量公开 RM 的域内 $\tau$，不够训一只新的 BLIP-RM。

Pick-a-Pic 走另一条：产品里的真实用户。用户每次看两张，点一张或平局，被拒绝的那张换成新图。论文写明用 Gmail 或 Discord 登录、禁 NSFW 短语、禁过快点击、每用户交互上限。实验用的训练集 37,523 个 prompt、4,375 个用户。质量控制和 ImageReward 的专家质检不是同一套，偏差类型也不同：专家说明会把审美写成规则，用户点击会把个人口味和界面位置混进来。报告必须写数据来自哪一条，不能写成“人类偏好”四个字完事。

CLIP 余弦为什么不够，用 HPSv2 Table 6 的两列一起读。零样本 CLIP-H 在 ImageReward 测试集 57.1、HPD v2 65.1。Aesthetic 在 HPD v2 到了 76.8，却在 ImageReward 测试集只有 57.4：它会看图漂不漂亮，不太管是不是这句 prompt。专用 RM 要同时吃图和句。ImageReward 用交叉注意力，PickScore / HPSv2 用 CLIP 双塔再微调。本课教学 $r$ 故意不看 prompt，因为它的候选已经共享同一张参考图、同一句“十字加棋盘”。域外 prompt 上禁止使用 $r_{\mathrm{toy}}$。这是教学模拟的边界，Lab 标题里已经写了。

### 5.5 两序对打：Kendall $\tau$ 为负就停

有了每张图的 $L_2$ 和 $r$，得到两个全序。Kendall $\tau_a$ 只看两两对：

$$
\tau_a=\frac{C-D}{\binom{n}{2}}
$$

$C$ 是两把尺子同序的无序对，$D$ 是反序对。没有并列时 $\tau_a\in[-1,1]$。完全相同为 $+1$，完全相反为 $-1$。本课夹具 $n=4$，$\binom{4}{2}=6$，六对全反，$C=0,D=6,\tau_a=-1$。

为什么不用 Spearman。Spearman 是秩的 Pearson 相关，对差距大小敏感一些；Kendall 直接数反序对，和“有多少对图 $L_2$ 与人拧着”这句话同构。报告两种都可以，本课验收只锁 Kendall 的符号。

协议：

1. 固定候选集合，禁止看完结果再删图。
2. $L_2$ 低者秩为 1（更好重建），$r$ 高者秩为 1（更被偏好）。两列“1”的含义相反，写进表头。
3. $\tau<0$ 时，主验收不得使用 $L_2$ 单列。
4. $\tau$ 接近 0 时，两把尺子几乎独立，仍不得用 $L_2$ 代替偏好；只能说它们没信息互相替代。
5. 并列单独计数。本课夹具用严格不等，避开 $\tau_b$ 的修正项。

验证：对同一组秩，自比较 $\tau=+1$；把偏好秩左右翻转后再比 $L_2$，应得 $+1$。这两条保证你没把升降序写反。CPU 实验包含它们。

### 5.6 有了 $r$ 之后怎样改生成器

打分不是终点。公开文献里至少三条路，本课只要求你能分开，不要求你训。

**过滤。** 同一 prompt 采 $K$ 张，留 $r$ 最高的一张。ImageReward Figure 1 上半是 64 张里按不同打分器选 Top-1。PickScore 论文用它比 CLIP-H 赢 71.3%、比美学预测器赢 85.1%、比不做选择的原模型赢 71.4%（均为人类评估胜率）。代价是算力乘 $K$，模型本身没变。

**把 $r$ 回传到去噪过程。** 扩散没有归一化似然，不能直接对 $x_0$ 做策略梯度。ReFL（ImageReward §3）的观察是：在约 40 步去噪里，$t\le 15$ 时 $r$ 全体偏低；$t\ge 30$ 时不同样本的 $r$ 已经可分。于是在后段随机步 $t\in[30,40]$ 预测 $x_0'$，对 $r(c,x_0')$ 求梯度，再加预训练噪声损失正则。Table 4 人类评估相对 SD v1.4：ReFL 胜率 58.79%（真实用户 prompt）和 58.49%（MT Bench）；同一表里 RAFT 多轮迭代胜率掉到 20.97%。DRaFT（Clark 等，[arXiv:2309.17400](https://arxiv.org/abs/2309.17400)）和 AlignProp（Prabhudesai 等，[arXiv:2310.03739](https://arxiv.org/abs/2310.03739)）把奖励梯度穿过整条采样链。Diffusion-DPO 论文 Table 1 把这两类标成开词表、推理成本不变、但缺少散度控制，容易 mode collapse。本课不编它们的准确率表；只记下：直接最大化可微 $r$ 时，必须看多样性，不能只看 $r$ 上升。

**Diffusion-DPO。** Wallace 等把 DPO 写到扩散 ELBO 上，直接吃 pairwise，不必先训 RM。数据是 Pick-a-Pic 851K。人类评估：PartiPrompts 上 DPO-SDXL 相对 SDXL base+refiner 约 69% 被偏好；文中另一处写 General Preference 70.0%、HPS 基准 64.7%。它吃的是比较数据，不是标量 $r$ 的梯度，因此和 ReFL 不是同一条实现。和第 16 课文本 DPO 的差别：这里的“似然”是逐步去噪的 ELBO 项，不是自回归 token log-prob。

奖励过优化（reward overoptimization）在三条路上都会出现：过滤会选 RM 没见过的怪异高分；回传会在 $r$ 的漏洞上刷饱和度或假细节；DPO 会把某种风格推到标注分布外。本课验收要求：微调后除了 $r$ 上升，还要报未用于训练的人类抽检或第二套 RM，以及重复图 / 过饱和的计数。只有 $r$ 上升，记为“刷分成功”，不记为“生成更好”。

三条路的输入输出写成一张决策表，避免实验记录里把过滤写成微调。

| 方法 | 训练生成器 | 需要可微 $r$ | 需要 pairwise | 推理成本 | 本课缩小版能复现的方向 |
|---|---|---|---|---|---|
| Top-$K$ 过滤 | 否 | 否，能打分即可 | 否 | $\times K$ | $r$ 更高的子集，多样性可能下降 |
| ReFL | 是，后段步 | 是 | 否 | 不变 | $r$ 上升；Table 4 相对 SD v1.4 人类胜率 58.79% 不能在 8×8 上复现 |
| DRaFT / AlignProp | 是，采样链 | 是 | 否 | 不变 | $r$ 上升；稳定性与多样性见原论文，本课不编表内百分数 |
| Diffusion-DPO | 是 | 否 | 是 | 不变 | 需要真实 pairwise，MiniMind-O 缩小实验预期不能复现 69% |

ReFL 的伪代码在 ImageReward Algorithm 1：随机抽后段 $t$，从 $x_t$ 预测 $x_0'$，解码成图，算 $\lambda\phi(r(y,z))$，再与预训练噪声 $L_2$ 加权。$\phi$ 是把奖励变成损失的单调变换，论文用它避免分数爆炸。你若实现缩小版，把 $t$ 的合法区间写进配置；只用最后一步回传，原文已写不稳定。Diffusion-DPO 不走这条路。它把“$x_0$ 的偏好”展开成逐步去噪的 ELBO 项，对赢图和输图的噪声预测误差做差，再套 $\sigma$。实现时赢图、输图要在同一 $t$、同一噪声实现上比较，否则差里会混进采样噪声。这些细节本课不要求你写进 MiniMind-O；要求你在实验记录里写清走的是过滤、回传还是 DPO，三选一，禁止写成“我们做了 RLHF”这种伞词。

选路的判据只有三条。没有训练卡：过滤。有训练卡、有可微 RM、没有大规模 pairwise：ReFL 或 DRaFT。有 Pick-a-Pic 这类比较数据、想少碰 RM 漏洞：Diffusion-DPO。判据不包含“哪篇更新”。更新的论文仍可能只做过滤。

### 5.7 视频：帧差更不能当总账

第 49 课规格要求生成帧差和理解 CE 的有效位置不相交。本课在生成侧再加一把偏好尺。视频比图多一个运动轴。只对相邻帧做 $L_2$，最优仍是均值：物体可能向左也可能向右，均值是残影。人要的是一条说得通的轨迹，哪怕和某条参考轨迹的像素对不齐。

VideoScore（He 等，[arXiv:2406.15252](https://arxiv.org/abs/2406.15252)）发布 VideoFeedback：11 个生成模型上 37.6K 条人类多维打分，再训 VideoScore。作者报告 VideoFeedback-test 上与人类的 Spearman 为 77.1，并称比此前最好指标高出约 50 个点。它是有参考或有人类分数时的代理，不是帧差。

VideoReward（Liu 等，[arXiv:2501.13918](https://arxiv.org/abs/2501.13918)）针对更现代的视频模型，收集约 182k 三元组，三维是视觉质量 VQ、运动质量 MQ、文本对齐 TA。奖励模型用带平局的 Bradley–Terry。对齐算法改写到整流流：Flow-DPO、Flow-RWR、推理期 Flow-NRG。作者写明：按时间步缩放的 $\beta$ 会让 Flow-DPO 在部分任务上变差，固定 $\beta$ 后它成为他们比较里最有效的训练期方法。本课引用这条机制，不引用未在摘要和引言里核对过的百分表。

协议：视频生成至少三列。帧 $L_2$ 或 flow 速度损失是训练目标，可以记；验收必须另有 VQ / MQ / TA，或一个明确写出如何加权的标量 RM。缺运动列的报告，按第 47 课的精神标为类错误。

把残影例子写成和图像过平滑对称的一句话。两帧里一个圆点分别在左和右，帧平均是中间一道杠。杠相对“随机抽一帧真值”的期望 $L_2$ 往往更低，人却说点消失了。第 49 课规格要你检查理解 CE 的 mask 和生成帧差的有效位置不相交；本课要你在生成有效位置上再问：帧差最低的那条轨迹，运动偏好是不是也最低。CPU 里用平移圆点对上残影杠即可，不必上视频 RM。VideoReward 的 MQ 列是给真模型用的；你的 8 帧夹具用“质心是否仍是单峰”当 MQ 代理，并在报告里写 `mq-proxy-centroid`，不要写成 VideoReward。

时间维还有第二类 $L_2$ 陷阱：对整段视频向参考视频逐帧对齐后再平均。摄像机允许轻微抖动时，逐帧最优是把每一帧都滤成参考的均值，闪烁消失，电影感也消失。人类偏好里的“稳”和“死”要拆开记。VQ 可以给稳加分，MQ 必须给“还有运动”加分，两列冲突时按预注册权重合成，禁止事后看哪列好看用哪列。

VideoScore 的 77.1 Spearman 只绑在 VideoFeedback-test 上。作者还写它在 EvalCrafter、GenAI-Bench、VBench 上与人类相关高于其它指标。本课不抄那些表里未打开核对的格子。你若用 VideoScore 当 RM，报告必须写版本（官方仓库另有 v1.1）和抽帧数。抽 4 帧和抽 16 帧不是同一个函数。VideoReward 论文指出 VideoScore 在更现代的 VideoGen-RewardBench 上会接近随机，因为它主要吃早期生成器的标注。域外失败是预期，不是侮辱。本课夹具用残影对平移，不碰这些权重，所以也不借用 77.1。

### 5.8 奖励漏洞：分高了图却坏了

$r$ 是拟合出来的曲面，有洞。生成器若能在洞里走，分数会涨、图会坏。本课把这类失败叫奖励漏洞，不叫“模型变聪明”。常见洞有四类。

饱和度洞。许多美学数据和用户点击偏爱更艳的颜色。RM 学会“更饱和更高分”。回传或过滤会把皮肤推成塑料橙。检测：在验证图上测平均饱和度，$\Delta$ 超过预注册阈值就标红。第二套 RM 若是 ImageReward 这类含保真标注的，往往能拦住；纯美学预测器会一起被骗。

文字洞。prompt 含可读文字时，CLIP 系 RM 可能因为“图里有像字的纹理”给高分，人却读出乱码。检测：对含文字的 prompt 单独切片，人类抽检只问“字对不对”，不与总 $r$ 平均。

肢体洞。HPS v1 收集 Discord 选择的动机之一，就是awkward limbs。RM 若训练数据里崩坏样本不够，会把“像人”的统计纹理打高分。检测：人像 prompt 单独算人类胜率；不能用风景上的 $r$ 代替。

过平滑洞。反过来，若 RM 在某种风格数据上把“柔光”学成高分，它会和 $L_2$ 站到同一边，夹具的反向消失。这不是好消息。说明这只 RM 在你的候选集合上没有提供新信息。换候选或换 RM，不要宣布 $L_2$ 已经足够。

防护只有记录，没有神话。预注册第二套 RM 或人类抽检；预注册饱和度、重复哈希、人脸关键点失败率；其中一项越线，微调停止。第 16 课用 AncPO 防止 chosen 概率一起沉；本课没有等价的解析锚，只能靠第二尺子。写“我们监视了 $r$”而不写监视了哪几条越线规则，等于没监视。

### 5.9 把两序写进同一份评测记录

机制要落到一行记录上，否则课上讲完，脚本里仍只 dump PSNR。一条生成评测记录的最低字段：

`prompt_id, image_id, seed, mse_to_ref_or_empty, r_name, r_value, rank_l2, rank_r, split, license`

`mse_to_ref_or_empty` 允许空：文生图常常没有参考图。没有参考图时 $L_2$ 列整列空，Kendall 只在有参考的子集上算，并在脚注写 n。禁止用“和另一张生成图的 $L_2$”冒充重建误差，那是样本间距离，不是对真值的误差。FID 不进这一行，进另一张表：`model_id, fid_coco, n_images, resolution`。两张表不能 union 成一个平均数。

FID 本身怎么来的，写到能手算符号为止。Inception 网络把每张图编成特征向量。真实集特征的均值 $\mu_r$、协方差 $\Sigma_r$ 和生成集的 $\mu_g$、$\Sigma_g$ 之间，Fréchet 距离是

$$
\|\mu_r-\mu_g\|_2^2+\mathrm{Tr}\bigl(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2}\bigr)
$$

它比较的是两个高斯之间的距离，不是单张图好不好。生成器把图推向 COCO 照片的特征均值，FID 会降；用户要的如果是插画、图标、文字海报，这个均值可能是错的靶。Pick-a-Pic 用 COCO 标题评仍得到 FID 与人类 $-0.900$，说明靶错了会连符号一起错。本课不要求你实现矩阵平方根；要求你在报告里写清 FID 的真实集是哪一个。真实集从 COCO 换成内部海报，名次可以翻面，这不是随机噪声，是尺子换了。

排序在每个 `prompt_id` 内部做。跨 prompt 把所有图按 $r$ 全局排序没有意义：一句“红苹果”的高分图不该压过一句“夜景城市”的低分图。ImageReward 和 HPSv2 的 preference accuracy 都是 prompt 内 pairwise。你的脚本若先把全测试集按 $r$ 排序再切 Top-1，报告里必须改名为 `global-r-filter`，那是另一种产品策略，不是论文里的偏好准确率。

伪代码用 Python 围栏，便于对照 CPU 实验，不是要你在课上训练 RM。

```python
def prompt_tau(l2_list, r_list):
    l2_rank = ranks_from_scores(l2_list, higher_is_better=False)
    r_rank = ranks_from_scores(r_list, higher_is_better=True)
    return kendall_tau(l2_rank, r_rank)["tau"]
```

每个 prompt 一个 $\tau$，再对 prompt 取中位数。不要先把所有图摊平成一个大排序。n=2 的 prompt 只有一对，任 $\tau\in\{-1,+1\}$，方差大，单独报没有信息。本课夹具是 n=4 的一个 prompt，信息在“完全反序”这件事，不在中位数。真实测试集要写清有多少 prompt 的 n≥4，只用这些算中位数 $\tau$。

和 golden case 的关系见[第 01 课](01_baseline_reproduction.md)。生成偏好的 golden case 记录 pairwise 标签：这两张里人类选了 w 赢 l。它不要求生成图长成某一张固定照片。复放时 RM 的符号必须仍是 w 分更高，否则权重或预处理变了。$L_2$ 列可以变（换参考图就会变），人类标签列不能变。这和第 01 课的 hash 纪律同一精神：变的是计算，不变的是判定。

MiniMind-O 当前主路径不生成图像。第 20 课的选修实验才会出 256×256。本课协议在第 20 课的评测脚本上加列即可，不必改 Thinker。没有做第 20 课的人，用本课 Lab 和 CPU 夹具交付。不要为了“接上主线”去改 Talker 或 codec。那是抢题。

$L_2$ 仍是对的尺子，发生在你真的有一张必须逼近的参考、而且任务定义就是逼近。无损附近的压缩、医学图像的可逆重建、第 20 课训练速度场时的回归目标，都属于这一类。本课否定的是把这类尺子拿去代理“人想留下哪张生成图”。两件事可以共用同一个网络头，不能共用同一句验收。写配置时把训练目标键和验收键拆开：`train.loss = flow_mse`，`eval.primary = preference_rm`。键名写在同一份 yaml 里，比写在论文引言里更难被事后改口。

音频侧有过类似的分家。[第 03 课](03_audio_codec.md) 的码率–失真曲线用重建误差和可懂度一起看，Mimi 不能只用波形 $L_2$ 当听感。图像生成把这件事又做了一遍，只是参考图常常不存在。没有参考图时 $L_2$ 列为空，偏好列仍在。空列不是缺数据事故，是任务定义。硬填一张 COCO 图当参考，等于换题。

把第 16 课和本课的 pair 格式并排，避免数据加载器抄错。

| 字段 | 第 16 课文本 mDPO | 本课生成偏好 |
|---|---|---|
| 条件 | 问题 + 图像 | prompt |
| chosen | 更好的回答句子 | 更好的生成图 |
| rejected | 更差的回答句子 | 更差的生成图 |
| 必须看见的媒体 | 原图 vs 裁剪图（CoPO） | 生成图像素本身 |
| 损失落点 | token log-prob | RM 标量或扩散 ELBO |
| 无条件作弊 | 不看图只看文风 | 不看 prompt 只看饱和度 |

抄第 16 课的 `chosen` 列到本课，会把“一句好看的话”当成“一张好看的图”。加载器里用不同的 schema 名：`mdpo_pair` 与 `gen_pref_pair`。混用直接当非法行。

## 6. 数据与训练 recipe

本课主路径不训公开 RM。若你有 GPU，想把协议接到真实权重上，数据配方如下。没有 GPU 时读完本节即可，不要根据缺卡判断自己没学完。

**离线偏好数据。** 一条记录最少字段：`prompt`、`image_w`、`image_l`、`label`（win / lose / tie）、`annotator_id`、`model_id`、`seed`、`guidance`、`resolution`、`license`。缺 `prompt` 或两张图之一，不得进训练集。平局要保留：Pick-a-Pic 发现“两张图允许平局”比强迫二选一更稳。VideoReward 也强调 ties 能提高 RM 稳健性。

**正负图必须同 prompt。** 跨 prompt 的“好看图 vs 难看图”会让 RM 学成美学分类器，忽略文本对齐。ImageReward 和 HPD v2 都是同一 prompt 下的排序。第 16 课的 CoPO 是“同一回答换图”；本课是“同一 prompt 换图”。不要把两种 pair 混进一个 batch 还写成同一实验。

**图源偏差。** HPSv2 批评早期数据几乎全来自 Stable Diffusion 家族，RM 换到其他生成器会塌。HPD v2 因此纳入 9 个模型和 COCO 真图，测试集含训练未见的 5 个模型。你的缩小实验若只有一种生成器，报告必须写 `single-generator-rm`，不得写成通用偏好模型。

**prompt 偏差。** 用户 prompt 常堆风格词，甚至自相矛盾。HPSv2 用 ChatGPT 清成一句完整描述，并按 Animation / Concept-art / Painting / Photo 四类评。Pick-a-Pic 指出 34.9% 的样本来自只占 4.7% 唯一 prompt 的重复句。去重规则要预注册：按 prompt 哈希分训练/验证，验证集每个 prompt 只留一条。

**训练。** 标量 RM：冻结大部分骨干，只训上层和 MLP，学习率约 $1\times 10^{-5}$ 量级（ImageReward 选 1e-5、batch 64、冻 70% transformer）。HPSv2 冻图像塔前若干层，训 4000 step，lr $3.3\times 10^{-6}$。过拟合来得很快。验证指标用 preference accuracy 和与人类的 Kendall，不要用训练损失单独早停。

**负对照。** 必须跑三条：打乱 pair 标签，准确率应回落到 $0.5$ 附近；把图换成纯噪声，RM 不得稳定偏爱某一侧；把 prompt 换成无关句，$r$ 差应收缩。三条里任一条失败，RM 不能上线当验收。

**与第 20 课数据的关系。** 第 20 课生成臂用配对的 caption 和 VAE latent 训速度场。本课若要 ReFL / DPO，需要额外的 pairwise。不要把第 20 课的重建集直接标成 chosen，那会把 $L_2$ 最优重新标成“人类喜欢”。

**一百对的最小标注配方。** 没有 137k 时，仍可做一个域内探针，不能叫 ImageReward 复现。选 25 个业务 prompt，每个用同一生成器出 4 张，两两组成最多 6 对，去重后留 100 对。两名标注者独立选，允许平局。一致率写进报告；低于 0.65 先改标注说明，再训 RM。用这 100 对只能做一件事：量公开 RM 或 $r_{\mathrm{toy}}$ 在你域内的 $\tau$。禁止用它微调 SDXL 再报人类胜率。样本量只够探针，不够训练。

**标注说明最低字段。** 对齐：图里是不是 prompt 点名的物体、数量、关系。保真：肢体、文字、几何是否崩。无害：是否含标注规范禁止的内容。总体：三者冲突时按说明里的优先级合成一票。ImageReward 的附录 B 是完整说明，本课不抄；你必须有自己的一页，并写明优先级。没有优先级时，一名标注者重对齐、一名重保真，一致率会假低，RM 会学成噪声。

**采样参数要进 pair。** guidance、步数、分辨率、负面 prompt 都要记。Pick-a-Pic 用不同 guidance 比较过用户选择，guidance 9 通常赢 guidance 3。你若把不同 guidance 的图组成 pair 又不记录，RM 可能只在学“更听 prompt 的采样配置”，不是学生成器权重。缩小实验里把这些字段写进 `pair.jsonl` 的同一行，缺字段的行按第 57 课规格的精神拒收。本课不实现出处清单，只要求 pair 能复放。

**batch 构造。** 同一 prompt 的多对不要全部挤进同一个优化步，否则梯度被少数句主导。按 prompt 哈希分桶，每步从一个桶抽一对。验证集按 prompt 划分，不要按行随机切：同一句的两对分别进训练和验证，准确率会虚高。HPSv2 和 Pick-a-Pic 都强调 prompt 级划分。你的 100 对探针按 20 个 prompt 留作验证，一刀切。

## 7. 按依赖顺序执行实验

没有 GPU 时，只做 Step 0 到 Step 2。有公开 RM 权重时再做 Step 3。有训练卡时才做 Step 4。顺序不能倒：先看到反向对，再谈微调。

### Step 0：手算四档夹具

使用本课 CPU 实验里的 8×8 参考图：棋盘灰度 0.35，中央十字为 1。四张候选：一次盒滤波；滤波与 1 像素平移的 $0.15$ 混合；$0.40$ 混合；纯平移。对参考图算 MSE，对教学 $r_{\mathrm{toy}}$ 算偏好。确认：

- MSE 升序等于过平滑到平移；
- $r$ 升序等于过平滑到平移；
- 两序秩互为翻转，$\tau_a=-1$。

运行（仓库未注册本课时，直接调模块）：

```bash
PYTHONPATH=src python -c "from learn_omni_experiments.lessons.lesson_56 import run; print(run()['metrics']['kendall_tau'])"
```

输出必须是 `-1.0`。任何非负值先查候选是不是被循环移位折回棋盘。

手算 Kendall，不要只信脚本。四张图编号 1=过平滑、2=略糊、3=半锐、4=平移。$L_2$ 秩 $(1,2,3,4)$，偏好秩 $(4,3,2,1)$。六对是 $(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)$。每一对在 $L_2$ 上小号赢，在偏好上大号赢，六对全是 $D$。$C-D=-6$，$\binom{4}{2}=6$，$\tau_a=-1$。若有人把偏好秩也写成 $(1,2,3,4)$，那是把“秩 1”的含义弄反了：本课约定 $L_2$ 低为 1、$r$ 高为 1。写进表头比写进脚注更不容易错。自检：把偏好秩左右翻转应得 $(1,2,3,4)$，与 $L_2$ 秩相同，$\tau=+1$。CPU 实验的 `identity_l2_is_zero_and_self_tau_is_one` 覆盖这条自检。

### Step 1：浏览器先预测再揭晓

打开本课 Lab。默认 A 为 1 次盒滤波，B 为 1 像素平移。先在三个预测里选一项，再点揭晓。关键数字（两张图的 $L_2$、偏好、是否反向、四档 Kendall）在揭晓前必须是占位符。验收条件：预测选“L2 更低的那张过平滑，人更不喜欢”，并且当前参数下确实反向。把 A、B 都设成锐利或都设成很糊，反向会消失，Gate 应变回未通过。这是故意的：协议必须能造出反向，也必须能造出同序，避免教具写死答案。

Lab 里两张图是 16×16 像素块，着色只表示亮度，不是真实照片。教学模拟四个字写在框上。揭晓前，$L_2$、偏好、是否反向、四档 Kendall 全部是占位符。预测选项有三个：同序、反向、同分。只有选反向且当前滑条确实反向，Gate 才通过。默认滑条（A 滤波 1 次、B 平移 1 像素）是反向对；预置同序对把 A 设成 2 次滤波、B 设成不平移。改滑条会清掉揭晓状态，防止拿旧数字套新图。四档 Kendall 始终按滤波、0.15 混合、0.40 混合、平移这组固定像素算，不随滑条变，用来对照 CPU 夹具的 $-1$。滑条只决定你眼前这对本对是否反向。这样拆开，是怕有人把“四档 $\tau$”和“当前两张”混成一个数。

### Step 2：写两列表

把四张候选抄进实验记录，表头固定为 `id, mse, r_toy, rank_l2, rank_pref`。附加一行灰均值图（全 0.5）：它相对参考图的 MSE 可以低于平移图，偏好却最低。这一行证明“更近的像素”甚至不必是滤波，均值本身就会赢 $L_2$、输偏好。

### Step 3：公开 RM 推理（可选）

加载 ImageReward 或 PickScore 或 HPSv2 的公开权重，在你自己的 20 个 prompt×4 张图上打分。预注册：主序用哪个 RM、是否允许把 CLIP 当对照。报告 $\tau(L_2, r)$ 和 $\tau(r, \text{你自己的 5 人抽检})$。抽检 $n<20$ 时只报原始胜负，不报百分比。此步失败的合法结论是“该 RM 在我的域上与 $L_2$ 同序”或“与人类抽检不一致”；不要改 Step 0 的夹具来迁就。

### Step 4：用 $r$ 改采样或微调（可选）

只允许三种预注册臂：Top-$K$ 过滤；$K\in\{4,16,64\}$ 必须写死。ReFL 类后段回传，步数范围写进配置。Diffusion-DPO 或文本侧 DPO 不在本课主表。每臂报：$r$ 均值、抽检胜率、唯一图哈希数、过饱和计数。$r$ 升而唯一哈希数掉超过预注册阈值，记为过优化，不算通过。

## 8. 评测与测量

主指标在看测试结果前锁定。

**协议卡。** 每一列数字必须能填：比较对象（像素 / Inception 特征 / 人类 pairwise / RM 标量）、是否需要参考图、单位、n、划分。FID 的单位是分布距离，不能和 preference accuracy 减。第 47 课的互斥标签在这里变成：C-gen-l2、C-gen-fid、C-gen-pref、C-gen-human。四类不得平均成“生成分”。

**人类抽检。** 同一 prompt 两张图，允许平局。至少两名标注者。报告一致率和相对 $L_2$ 的 $\tau$。ImageReward 用研究员与标注者的一致率当上限（Table 2）；HPSv2 Table 6 的单人 vs 单人是 78.1%。你的抽检若高于这个数，先怀疑题目太容易或标注者看到了模型名。

**自动偏好。** 写清 RM 名称、权重哈希、预处理分辨率。ImageReward 与 PickScore 对同一对图符号相反时，两列都留，主验收预先指定一列。禁止 test 后改主列。

**重建列。** $L_2$、PSNR、SSIM、LPIPS 可以报，标题必须含“重建/感知重建”。它们通过的条件是：你声称的是“更接近某张参考图”，不是“人更喜欢”。

**视频列。** VQ、MQ、TA 分列。若只有帧 $L_2$，状态为 `incomplete`，不能写“视频生成已评估”。

**相关。** 主相关用 Kendall $\tau_a$。n=4 的夹具 $\tau$ 不得写进模型卡。n≥20 的真实抽检可以报 $\tau$ 和 95% 置信区间；区间算法预注册，本课不发明一种。

**和 CLIP 分数并排时怎么读。** [第 21 课](21_clip_siglip_contrastive.md) 的余弦量的是“图和这句话像不像一对”。偏好 RM 量的是“两张都像这句话时，人留哪张”。前者可以两张都高、人仍然讨厌其中一张的六指。HPSv2 Table 6 把零样本 CLIP-H 放在最上面：ImageReward 测试集 57.1，HPD v2 65.1，只比乱猜好一截。实验记录里 CLIP 列的标题必须是 `clip_alignment`，禁止写成 `preference`。若你用 CLIP 做过滤，单独开一臂，主验收仍是人类或专用 RM。

**fresh generation。** 第 16 课要求不要只在旧 pair 上算概率。本课同样：RM 微调或过滤之后，必须用新 seed 出图再打分。旧图上的 $r$ 上升只证明打分器记住了训练集。新图上 $r$ 上升且人类抽检同向，才能写“生成变了”。步数、guidance、分辨率与训练时不一致，记为实验无效，不是负结果。

## 9. 验收条件

本课通过，当且仅当下列全部成立：

1. CPU 实验全部 checks 为真，其中 $\tau_a=-1$，过平滑 $L_2$ 最低且偏好最低。
2. 浏览器 Lab 在揭晓前不显示 $L_2$ 与偏好；用户先提交预测；存在一组滑条使反向成立。
3. 实验记录含两列表，表头含义不混。
4. 正文引用的准确率、相关、胜率都能指到论文表号或原句。
5. 没有把第 16 课文本 pair accuracy 或第 20 课速度 $L_2$ 当作本课生成偏好结果。
6. 若做了 Step 3 或 4，过优化计数和抽检列齐全；否则明确标记未做。

任一条失败，状态是“协议未完成”，不是“生成模型差”。夹具本来就不是生成模型。

## 10. 根据症状定位失败环节

| 症状 | 先查 | 不该做 |
|---|---|---|
| 夹具 $\tau\ge 0$ | 参考图是否被一起滤波；平移是否循环；教学 $r$ 是否误用了 MSE | 改系数硬凑 $-1$ 却不解释边能量 |
| 滤波 $L_2$ 高于平移 | 滤波次数是否过大，图已经糊到不像参考 | 换成更大平移来“制造反向”而不写条件 |
| Lab 揭晓前能看见分数 | 是否跳过预测；是否用了旧状态恢复 | 把默认反向写死在文案里当答案 |
| 公开 RM 与夹具同序 | 域外图、分辨率、是否把糊图也当成“真实风格” | 宣布 $L_2$ 已经等于偏好 |
| RM 准确率逼近 100% | 验证集是否泄漏；prompt 是否重复 | 当成已解决人类偏好 |
| $r$ 上升、图过饱和 | 第二套 RM、唯一哈希、人类抽检 | 加大学习率继续刷 $r$ |
| 视频帧 $L_2$ 下降、运动残影 | 是否在平均轨迹 | 用更长的时间平滑 |
| 报告把 FID 和胜率减出“高 20 点” | 第 47 课单位 | 用 z-score 强行同列 |
| 教学 $r$ 与公开 RM 符号相反 | 域、分辨率、是否人像切片 | 改教学系数去追公开 RM |
| Kendall 分母含平局对 | 有效对数是否扣除 tie | 把平局算成 Concordant |
| 只在旧图上 $r$ 上升 | 是否用新 seed 重采样 | 把记忆当成生成改进 |
| 四档不严格单调 | 混合系数是否写反、是否用了循环移位 | 手工改像素凑 $\tau=-1$ |
| Lab 预置同序对仍显示反向 | 滑条是否被旧状态恢复成 1 和 1 | 把 Gate 改成永远通过 |

诊断时保持一条：先固定尺子，再解释模型。尺子写反时，模型怎么改都是噪声。

把一次真实周报里可能出现的句子改写成可验收的句子，当作对照练习。

原句：“我们把 FID 从 20 降到 15，生成质量明显提升。”
改写：“COCO 256 上 FID 从 20.7 降到 15.x（n=3 万张，协议与 ImageReward Table 1 相同）。同期 50 个用户 prompt 上 ImageReward 均值未报，人类 5 人抽检未做。因此只允许写分布更接近 COCO，不允许写用户更满意。”

原句：“偏好模型分数提高了 0.2，对齐成功。”
改写：“指定 RM（权重哈希 xxx）在 20 个 prompt、每 prompt 4 张新 seed 图上均值从 a 到 a+0.2。第二 RM 符号相同。饱和度中位数上升 0.04，未超预注册 0.08。人类 40 对抽检胜率 24/40，未计算百分比置信区间。状态记为 RM 上升且未触发过优化规则，人类证据不足。”

原句：“视频更流畅了，帧差降低。”
改写：“8 帧夹具上残影杠的帧 $L_2$ 低于平移圆点，质心单峰代理（MQ）更低。主验收用 MQ 代理。帧差下降不得写入标题。”

三句改写都故意写得难看。难看是因为把条件写全了。好看的原句通常缺条件。本课的交付物宁可难看。

## 11. 交付物

最低交付（无 GPU）：

- 两列表：四张候选的 MSE、$r_{\mathrm{toy}}$、两列秩、$\tau_a$；
- Lab 截图或状态：预测为 invert，当前对反向为真；
- CPU `checks` 全 True 的运行记录（含源码摘要，若编排者已接入实验框架）；
- 一页边界说明：本课不覆盖文本 mDPO、不覆盖 flow 训练、不覆盖视频理解准确率。

加分交付（有权重）：

- 20 prompt 上 $L_2$ 与公开 RM 的 $\tau$，以及 5 人抽检原始表；
- Top-$K$ 过滤前后的人类或 RM 胜负，K 预注册。

禁止交付：把夹具 $r_{\mathrm{toy}}$ 写成 ImageReward；把 $\tau=-1$ 写成“我们的生成模型与人类完全反向”；把 FID 单列当成发布指标。

交付检查用文件名而不是感觉。`ranks.csv` 必须能用表格软件打开，四行四张候选，列名与第 7 节表头一致。`prediction.json` 或 Lab 进度里能读到 `prediction=invert` 且 `inverted=true`。`citations.md` 列出本课引用过的表号。缺任一文件，状态停在“未交卷”，不要用长周报代替。夹具 $\tau=-1$ 可以进 `ranks.csv` 的脚注，不能进对外幻灯片的大字标题。对外标题若需要一句话，用“重建误差与人类偏好可以反向，生成验收必须两列”，不要用夹具里的 $-1$ 冒充模型指标。

## 12. 前沿对照与改造方向

**公开方案。** 文生图打分：ImageReward、PickScore、HPSv2 把人类 pairwise 做成可查询标量，已经能在各自测试集上超过零样本 CLIP 和美学预测器。用 $r$ 改模型：过滤（ImageReward / PickScore 都做了）、ReFL 后段回传、DRaFT / AlignProp 全链回传、Diffusion-DPO 直接吃比较。视频：VideoScore 在早期模型的多维分数上 Spearman 77.1；VideoReward 把 VQ/MQ/TA 做成带平局的 BT，并改整流流上的 Flow-DPO。统一生成模型（Show-o、Janus，见课程文献表 [2408.12528](https://arxiv.org/abs/2408.12528)、[2410.13848](https://arxiv.org/abs/2410.13848)）仍在像素或离散视觉 token 上做生成损失；它们的论文主表不是本课的人类偏好表。若某篇统一模型技术报告没报 pairwise 人类胜率，写“其技术报告未公开该细节”，不要用 FID 填。

**差距。** 规模差：137k 到 80 万级 pairwise、SDXL 3.5B 微调，钱能缩小。机制差：本课教的是两序何时反向、反向时哪一列能当验收。缩小到 8×8 仍能复现方向：滤波赢 $L_2$、输硬边偏好。不能复现的是 ImageReward 65.14% 这类准确率，那是骨干和标注规模。

**改造实验。**

1. 把第 20 课缩小 flow 的 32 步 Euler 输出接到本课两列表。改动位置：生成评测脚本里并行写 MSE 与 $r_{\mathrm{toy}}$（或公开 RM）。预算：已有 checkpoint 上 50 个 prompt，CPU 数分钟或单卡半小时。预期：过平滑提示词（“blurry, smooth lighting”）上 $L_2$ 更好、偏好更差，$\tau$ 为负。失败：所有提示词上两序同号，且人工抽检也同号。那时要查是不是候选多样性不够，而不是改 $\tau$ 公式。
2. 在过滤臂上扫 $K=1,4,16$。改动：采样循环后按 $r$ 取 Top-1。预算：单卡、20 prompt。预期：人类或第二 RM 胜率随 $K$ 上升，但唯一构图数下降。失败：$K=16$ 的图在饱和度上崩溃，或 $r$ 与人类抽检 $\tau\le 0$。
3. 视频短序列（8 帧）同时报帧 $L_2$ 和运动边能量。改动：在第 49 课规格的生成损失旁加一列 MQ 代理。预算：CPU 合成平移 vs 残影两条轨迹即可。预期：残影赢帧 $L_2$、输 MQ。失败：两条轨迹同序，说明 MQ 代理写成了帧差本身。
4. 负对照：RM 输入的 prompt 换成无关句。预算：Step 3 的同一批图。预期：$|r_w-r_l|$ 收缩。失败：无关 prompt 下 RM 仍以 70% 准确率复现原序，说明它在做无条件美学，第 16 课那种 unconditional preference 在生成侧复发。

**缩小复现映射。** ImageReward Table 1 的结论是 FID 与人类排序几乎不相关。缩小版：四张夹具图的 $L_2$ 与 $r_{\mathrm{toy}}$ 的 $\tau=-1$，方向一致（误差尺与偏好尺可反向），不能复现 0.09 这个具体相关。PickScore 的 FID $-0.900$ 同理：只复现“可负”，不复现数值。Diffusion-DPO 的 69% 人类胜率在本课缩小设置里预期不能复现，因为没有 SDXL 也没有 851K pair。

公开系统和本课缩小版的差距再拆一次，避免“我们做了偏好优化”这种空话进周报。

规模差：标注对数从本课的四张图到 13.7 万至 80 万；骨干从 8×8 边能量到 BLIP-ViT-L 或 CLIP-H；生成器从十字棋盘到 SDXL 3.5B。这些用钱和卡能堆。机制差：MSE 均值发糊、BT 用分差、Kendall 数反序对、$\tau<0$ 时拒收单尺。这些在 CPU 上就能假。假失败也有价值：若有人改教学 $r$ 变成“惩罚边”，夹具会变成同序，于是你知道：反向不是像素的物理定律，是“人要硬边”这条偏好假设。换一群标注者，假设可以变。协议不变的是：假设必须写成可对打的两列，不许藏在 PSNR 里。

顺手复现的方向表：

| 论文结论 | 缩小版动作 | 预期能看到 | 不能声称 |
|---|---|---|---|
| FID 与人类排序可接近 0 或为负 | 夹具 $\tau(L_2,r)=-1$ | 符号可负 | $\rho=0.09$ 或 $-0.900$ |
| 专用 RM 超过零样本 CLIP | 对照列写 CLIP 余弦 | 教学 $r$ 与 CLIP 不必同序 | 65.14% 或 70.5% |
| 过滤能抬人类胜率 | Top-$K$ 臂 | $r$ 更高的子集 | PickScore 的 71.3% 胜率 |
| ReFL 相对 SD v1.4 人类胜率 58.79% | 不在缩小版做 | 无 | 任何 ReFL 百分数 |
| 视频要分 VQ/MQ/TA | 8 帧残影对平移 | 帧 $L_2$ 与 MQ 代理反向 | VideoScore 77.1 |

第四行故意写“不在缩小版做”。没有扩散采样链，回传梯度没有着落。把盒滤波的梯度叫做 ReFL，属于伪造方法名。

## 13. 论文与必读材料

每篇只带一个阅读问题。打开摘要或 HTML 后再把数字抄进报告。

1. [ImageReward](https://arxiv.org/abs/2304.05977)（Xu 等，2304.05977）。带着问题读：Table 1 里 FID 与人类排序的 Spearman 是多少，Openjourney 的人类名次和 FID 名次差几位？Table 3 的 65.14% 对应多少对比较？ReFL 相对 SD v1.4 的人类胜率写在哪张表？
2. [Pick-a-Pic / PickScore](https://arxiv.org/abs/2305.01569)（Kirstain 等，2305.01569）。带着问题读：PickScore、人类、CLIP-H 预测用户选择的准确率各是多少？FID 在 MS-COCO 标题上与人类的相关为什么是负的？
3. [Human Preference Score](https://arxiv.org/abs/2303.14420)（Wu 等，2303.14420）。带着问题读：Discord 数据里有多少张图、多少次选择？作者认为 IS / FID / CLIP 漏掉的是哪一类失败（肢体、表情）？
4. [HPSv2](https://arxiv.org/abs/2306.09341)（Wu 等，2306.09341）。带着问题读：HPD v2 的选择次数和图像对数？Table 6 为什么要同时报 ImageReward 测试集和 HPD v2 测试集？单人 vs 单人 78.1% 对 RM 上限意味着什么？
5. [LPIPS](https://arxiv.org/abs/1801.03924)（Zhang 等，1801.03924）。带着问题读：Figure 1 的传统指标和人类 2AFC 如何冲突？模糊与 $\ell_2$ 那句话在引言哪一段？LPIPS 仍然需要参考图，它替代不了什么？
6. [Diffusion-DPO](https://arxiv.org/abs/2311.12908)（Wallace 等，2311.12908）。带着问题读：扩散似然如何被 ELBO 代替？PartiPrompts 上相对 SDXL base+refiner 的人类偏好大约是多少？它和 ReFL 吃的数据有何不同？
7. [DRaFT](https://arxiv.org/abs/2309.17400)（Clark 等，2309.17400）与 [AlignProp](https://arxiv.org/abs/2310.03739)（Prabhudesai 等，2310.03739）。带着问题读：奖励梯度穿过采样链时，论文自己如何讨论稳定性与多样性？技术报告未公开的细节不要补。
8. [VideoScore](https://arxiv.org/abs/2406.15252)（He 等，2406.15252）。带着问题读：VideoFeedback 的规模和 77.1 这个 Spearman 是在哪个测试集上？它能不能代替帧 $L_2$ 当训练损失？
9. [Improving Video Generation with Human Feedback](https://arxiv.org/abs/2501.13918)（Liu 等，2501.13918）。带着问题读：VQ / MQ / TA 为什么要分列？Flow-DPO 的 $\beta$ 随时间步变化会怎样？
10. [RichHF-18K](https://arxiv.org/abs/2312.10240)（Liang 等，2312.10240）与 [MPS](https://arxiv.org/abs/2405.14705)（Zhang 等，2405.14705）。带着问题读：标量 $r$ 定位不了的局部错误，这两篇各用什么结构补？本课 Kendall 对打为什么仍用一个序？

课程内对照：[第 16 课](16_multimodal_preference_optimization.md) 读 CoPO 时问“看不见图能否做对文本偏好”；本课问“不看人能否做对生成偏好”。[第 20 课](20_unified_understanding_generation.md) 读速度 $L_2$ 时问它能不能当验收；答案在本课的 $\tau$ 符号里。第 49 课规格读生成与理解分账；本课是生成账内部的第二列。

读完材料之后，实验记录的第一页只准出现这五句，多一句就说明你还在用排行榜口吻：

1. 本批候选的 $L_2$ 序是什么。
2. 本批候选的偏好序是什么，偏好来自人类还是哪个 RM。
3. 两序 Kendall $\tau_a$ 是多少，n 是多少，平局怎么处理。
4. $\tau<0$ 时主句有没有仍在用“更低误差”。
5. 若做了过滤或微调，第二尺子和过优化计数写在哪一列。

五句都能指到文件行，本课才算交卷。指不到就还在口头上“用了偏好模型”。偏好模型是一个函数。函数会错，错的时候要靠第二列发现，不能靠把函数名字印大。

若只读一篇，读 ImageReward 的 Table 1 和 Table 3。Table 3 告诉你专用 RM 比 CLIP / Aesthetic / BLIP 余弦更会猜人类 pairwise。Table 1 告诉你即使用上了这只 RM，FID 仍然可以和人类名次几乎不相干。两张表一起才构成本课的论点。只读 Table 3 会变成“我们换了更好的自动指标”；只读 Table 1 会变成“FID 无用”。论点是：自动指标必须和人类序对打，打输的那一列不得当主句。Pick-a-Pic 的 $-0.900$ 是同一论点在另一数据集上的重复测量。HPSv2 Table 6 是同一论点在更宽图源上的重复测量。本课 8×8 夹具是同一论点在可手算像素上的重复测量。重复是为了让你在自己的脚本里也做一次，而不是为了堆参考文献。

交卷前用下面这段自检对着文件勾，勾不上的行不要用形容词补。

- 第一个标题是指定的整句，第一个二级标题去掉编号后等于“生成质量为什么不能只用重建误差”。
- 文中出现的 65.14、70.5、83.3、0.09、$-0.900$、69%、58.79%、77.1、137k、798,090 都能指到打开过的表或句。
- 夹具 $\tau=-1$ 只出现在 ranks 脚注和 CPU 输出，不出现在对外标题。
- Lab 状态里预测先于揭晓。
- 没有把第 16 课 pair accuracy、第 20 课速度 $L_2$、第 47 课六类准确率写进本课主句。
- 视频若只报帧差，状态是 `incomplete`。
- 对外句子里不要反复制造对立排比。本课只钉死一次：$L_2$ 更近和人会留下谁可以反向。口号不能跑 CPU。
