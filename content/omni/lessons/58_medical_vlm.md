# 第 58 课：把医学图文从自然图像配方里拆出来

> 内容：医学图文训练协议、报告字段 mask 与无框断言评测<br>
> 建议周期：阅读约 80 分钟；浏览器胸片门控与 CPU 夹具可在同日完成<br>
> 硬件：无 GPU 可完成全文、教学模拟与 CPU 实验；复现 LLaVA-Med 公开配方需 8×A100<br>
> 产物：医学配方卡、字段 mask 表、无框肯定计数器、空图探针记录

## 1. 医学图文为什么不能沿用自然图像配方

[第 22 课](22_standard_vlm_recipe.md)把自然图像视觉语言模型（vision-language model, VLM：同时吃图像和文字、用 next-token 吐文字的模型）写成一张冻结时间表：冻视觉编码器，只训投影 $W$，再打开语言模型。数据是过滤后的网络图文对和视觉指令。那张表在 CC3M、COCO、VQAv2 这一类自然图像上成立，因为它默认三件事同时为真：一张图对应一句描述；描述里的名词大多能在像素里找到；编造一个“沙发上的狗”最多是配文风格问题，不会被当成病灶记录。

医学图文把这三件事同时拆掉。一张胸片检查经常有后前位和侧位两张图，还可能有历史片。文字不是一句 caption（配文：用一两句话概括图里有什么），而是半结构化报告：检查原因、对比旧片、逐器官所见、最后一段印象。阳性发现如果没有位置，不能当作“模型会看图”。空图（示意胸片上没有任何斑片，教学里用来模拟“没有可框出的病灶”）若仍写出“肺炎”，失败来自语言先验，不是来自像素。

LLaVA-Med（[arXiv:2306.00890](https://arxiv.org/abs/2306.00890)）把第 22 课的网络骨架借过来：线性投影连接冻结的视觉编码器和因果语言模型，初始化来自通用域 LLaVA。它改的是数据和课程。第一阶段从 PMC-15M 抽 600K 生物医学图注，只更新投影，把新词表对齐进已经训好的语言模型。第二阶段用 GPT-4 根据图注和文内引用写成约 60K 多轮对话，仍冻视觉编码器，更新投影和语言模型。论文摘要写明：八张 A100 上不到 15 小时。表 5 给出更细的账：batch 128 时，第一阶段 1 个 epoch 6.8 小时，60K 指令 3 个 epoch 8.0 小时。

借用骨架不等于借用验收。LLaVA 用 CIDEr、ScienceQA、LLaVA-Bench 衡量“会不会按人的要求描述自然图”。LLaVA-Med 在聊天集上用语言 GPT-4 打相对分，在 VQA-RAD、SLAKE、PathVQA 上把封闭题记准确率、开放题记 recall（召回：真值 token 出现在生成序列里的比例）。本课再加一条第 22 课和[第 23 课](23_grounding_ocr_spatial.md)都没有单独建账的协议：无框肯定（unboxed positive assertion：生成了阳性病灶名，却没有绑定框）。浏览器实验是示意胸片，不是放射影像。关掉“禁止无框断言”后，空图仍会写出肺炎。验收是抓住这一条，不是学会读片。

本课只讲训练与评测协议，不构成临床建议，也不评估任何真实患者影像。教学模拟里的“肺炎”是一个可计数的阳性词，用来暴露语言先验，不是诊断结论。若你在报告、幻灯片或代码注释里写出“可用于辅助诊断”“达到医师水平”“可以替代读片”任何一句，本课记为超范围，即使实验数字全部正确。协议课的完成标准是能拒绝错误配方，不是获得医疗许可。

做完这课你手里会有：一张对照第 22 课填写的医学配方卡；一张把 INDICATION / COMPARISON / FINDINGS / IMPRESSION 拆开的 mask 表；一个无框肯定计数器 $U$；一组空图探针。下一课处理的是音乐和环境声，不再占用医学协议。若你还要继续做医学方向，应带着本课的配方卡去读新论文，而不是重新从第 22 课的自然 caption 出发。卡上缺的格子先标 `unknown`，再用新论文的表去填；不要因为新模型名字更响就把 $U$ 和字段 mask 删掉。领域会变，协议字段不应变。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 图注对（figure-caption pair） | 论文插图和对应 caption；PMC-15M 的基本样本 |
| 概念对齐（concept alignment） | LLaVA-Med 第一阶段：用图注把生物医学视觉概念映到词嵌入 |
| 文内引用（inline mention / citance） | 正文里提到该图的句子，给 GPT-4 当额外上下文 |
| 60K-IM | 带 inline mention 的约 60K 指令数据 |
| 报告字段 | INDICATION、COMPARISON、FINDINGS、IMPRESSION 等功能段 |
| 无框肯定 $U$ | 阳性且未绑框的句子计数或比例 |
| 空图探针 | 没有可框区域的输入；用于抓语言先验 |
| 封闭 / 开放 VQA | 封闭题记准确率，开放题记 token recall |
| 课程学习（curriculum） | 先对齐词汇，再学开放对话，两段数据与冻结集合都不同 |

## 2. 本课解决的问题

把第 22 课的脚本改个数据路径，指向一批胸片和报告，loss 会降。降 loss 证明不了四件事：

- 模型有没有把“ground-glass”“H&E”“CXR”这些词和对应像素对齐，还是在用通用域 LLaVA 的常识瞎猜；
- 报告里哪些字段真的该由当前图像生成，哪些是检查原因或旧片对比；
- 一次检查多张图时，模型有没有把侧位和正位当成两张无关的自然图；
- 空图或正常示意胸片上，阳性词是不是被语言先验写出来的。

本课的研究问题可以写成一句：从已经按第 22 课训好的通用 VLM 出发，若仍用自然图像的 caption 损失、单图假设和“描述得像不像”的指标，医学图文的概念对齐、字段监督和无框肯定会一起坏掉。

和第 22 课的边界如下。第 22 课允许的变量是冻结集合和阶段顺序，数据是自然图文对与视觉指令。本课允许的变量是领域数据、报告字段 mask、多图检查协议和无框断言门控。冻结顺序可以沿用“先投影、后语言模型、视觉编码器默认仍冻”，但不得把 595K CC3M 和 600K PMC 写成同一个 stage。和第 23 课的边界：第 23 课用自然物体网格测“答对但看错格子”；本课用病灶名与框的绑定测“空图仍报肺炎”。POPE 的分母是“物体不在图中”的是非题；本课的分母是阳性句子。两课都抓幻觉，度量不同，必须两个实验 ID。

出现以下任一情况，不得把一次医学 VLM 训练标成合格配方：

- 只报 VQA 均分或聊天相对分，没有空图探针，也没有无框肯定计数；
- 把整份报告当 caption，INDICATION 和 COMPARISON 与 FINDINGS 进同一段 $M$；
- 用第 22 课浏览器里的图文对齐 80 分解释本课的胸片门控；
- 把 LLaVA-Med 表 4 的封闭准确率写成开放生成质量，或把开放 recall 写成“没有幻觉”；
- 把教学示意胸片的 $U=1$ 写成真实肺炎检出率；
- 声称完成了临床验证。本课没有临床验证这项交付。

合格配方的最小证据链是：领域数据来源与过滤规则、冻结表、字段 mask 打印、空图上的 $U$、封闭准确率与开放 recall 分列。缺证据链的漂亮曲线，本课记为未完成。证据链还要能追到样本：哪一条空图触发了 $U=1$，哪一条报告把 `cough` 放进了损失。[第 01 课](01_baseline_reproduction.md)的 trace 纪律在这里仍然有效，只是追的对象从 8 路音频编号换成了字段角色和无框计数。没有样本 id 的 $U_{\mathrm{rate}}$，和没有 hash 的 loss 曲线同类，都不能当作本课的完成信号。把样本 id 写成 `empty-0`、`report-naive-3` 这种教学名字即可，不必等到有真实影像库。

## 3. 开始前需要准备什么

本课可独立阅读。若已读第 22 课，冻结顺序不必重推；没读过也可以把“通用 VLM 已经会跟自然图像指令”当作上游事实。[第 21 课](21_clip_siglip_contrastive.md)的对比学习解释了冻结视觉编码器为什么能当眼睛；医学里这双眼睛看的是网页照片，不是胸片，所以第一阶段必须改数据。第 23 课的 IoU 和幻觉率本课会引用定义，不重做 8×8 网格。

**上游事实（来自已打开的论文，本课不改）：**

- LLaVA 第一阶段 595K 过滤图文对，第二阶段 158K 指令，视觉编码器始终冻结。数字见第 22 课对 [LLaVA](https://arxiv.org/abs/2304.08485) 表 7、表 8 的抄写。
- LLaVA-Med 第一阶段 600K PMC 图注，冻视觉编码器和语言模型，只更新投影；第二阶段约 60K 指令，仍冻视觉编码器，更新投影和语言模型。聊天评测 193 题、50 张未见过的图。60K-IM 总体相对分 50.2，通用 LLaVA 为 36.1，只做第一阶段为 23.3（表 1）。
- PMC-15M 由 BiomedCLIP 论文给出：15,282,336 对图注，来自 PMC 截至 2022-06-15 的 440 万篇全文；比 MIMIC-CXR 大约两个数量级。BiomedCLIP 把 MIMIC-CXR 记为 377,110 对。
- LLaVA-Med 指令数据覆盖五种常见成像：胸片（CXR）、CT、MRI、组织病理、大体病理。图注短于 30 词的约占 PMC-15M 的 25%，因此 30 词被用作“简要描述 / 详细描述”问题列表的分界。
- 下游微调表 3：VQA-RAD 训练图像 313、测试 203，问答 1797 / 451；SLAKE 英语子集训练图像 450、验证 96、测试 96；PathVQA 训练图像 2599、验证 858、测试 858。
- 表 4 从 LLaVA 初始化再微调：VQA-RAD 开放 61.52、封闭 84.19；SLAKE 开放 83.08、封闭 85.34；PathVQA 开放 37.95、封闭 91.21。开放列是 recall，封闭列是准确率。

**本课约定：**

- 教学字段只使用四段：INDICATION、COMPARISON、FINDINGS、IMPRESSION。真实 MIMIC-CXR 报告还有页眉、电子病历导入段和可选 addendum；本课不把那些段写进 CPU 夹具，避免假装复现了 Johnson 2019 的全部版式。
- 无框肯定的判定：句子小写分词后含 `pneumonia` / `effusion` / `consolidation` 之一，且不含 `no` / `without` / `absent` / `clear`，同时 `box is None`。
- 浏览器实验是示意胸片查找表，分数不可写入真实模型报告，也不可称为读片结果。
- CPU 实验的 token 序列写死在源文件里，无随机数、无网络、无 GPU、无文件副作用。

无 GPU 时的完成标准：读完全文、通过本页胸片门控、跑通 `lesson_58.py` 的全部 `checks`。有 8×A100 时，可以按论文表 5 估计卡时，不必在本课追 VQA-RAD 的 84.19。有卡却没有空图探针的 run，本课仍然记为未完成，因为缺的是协议而不是算力。

实验记录里要分开写事实和约定。事实例子：LLaVA-Med 表 1 的 50.2。约定例子：本课阳性词表只有三个英文词。混着写会导致别人按 50.2 去核对你的 $U=1$。事实来自论文表号，约定来自本课夹具，两者的单位、样本量和失败含义都不同。建议在笔记页顶上放两行：

```text
upstream: LLaVA-Med 2306.00890 tables 1,3,4,5; BiomedCLIP PMC-15M 15282336 pairs
course: toy report fields, U on schematic CXR, not a diagnostic score
```

第二行禁止出现可执行命令。若要把公开超参抄进同一页，另加 `paper_stage1_pairs: 600000` 并注明来源节号。没有节号或表号的学习率、准确率、卡时不要抄。抄了又写不出出处的数字，本课按编造处理，即使碰巧和某篇博客一致。笔记页的作用是让半年后的你还能分开哪些是 LLaVA-Med 表内事实，哪些是玩具夹具。分不开的笔记，等于没有笔记。本课宁可少抄一张表，也不要把玩具 $U$ 写进原文数字旁边而不加来源。来源写表号，约定写 `course:`，两行并排，不要合并成一句摘要。合并以后出处就丢了。

## 4. 完成后应具备的能力

1. 对照第 22 课写出 LLaVA-Med 两阶段的可训练模块，并指出数据来源从 CC3M 换成了 PMC 图注。
2. 解释为什么只做第一阶段会把聊天相对分从通用 LLaVA 的 36.1 降到 23.3：概念覆盖增加，指令跟随丢掉。
3. 画出 GPT-4 写指令时看不见图像这一条数据生成路径，并说明 60K-IM 相对 60K 多了什么。
4. 给出医学报告与自然 caption 的 mask 集合，手算能对上 CPU 实验。
5. 定义 $U$，并在空图上触发 $U=1$。
6. 把封闭准确率和开放 recall 写成两个公式，指出 recall 为 1 时 $U$ 仍可为 1。
7. 说明多图检查不能拆成两张独立自然图：对比段需要另一张图作为条件，不能当当前图的生成目标。
8. 读一篇医学 VLM 论文时，能抽出数据过滤、冻结集合、字段监督和幻觉探针；缺一格就标 `unknown`。
9. 向同事解释：本课交付的是协议，不是可以上线的读片系统。
10. 面对“我们把 LLaVA-1.5 在 MIMIC-CXR 上再训一晚”这种建议，能指出至少两个可测风险：indication 泄漏进损失、空图无框肯定。

这些能力不要求你在消费级显卡上复现 LLaVA-Med 表 4。它们要求你在没有大卡时仍然能拒绝一份没有 $U$、没有字段 mask 的医学训练报告。课程故意把 GPU 当作可选项：字段集合和空图计数一旦能在 CPU 上核对，上卡只是把同一协议乘上数据和时间。没有卡的人同样要会说“这份报告把 indication 算进了损失，所以不算医学配方”。会说这句话，比会复述 50.2 更接近本课目标。

## 5. 原理：边造边讲

十二个机制。每个仍走直觉、机制、数学、代码、验证。代码落点写公开实现里会反复出现的写法，不是 MiniMind-O 的 connector 注册表。

### 5.1 自然图像配方默认了错误的数据几何

第 22 课的投影

$$
H_v = W Z_v
$$

在医学里仍然成立：CLIP 或 SigLIP 给出网格特征 $Z_v$，线性层把它送到词嵌入维。失效的是 $Z_v$ 的来源分布。CLIP 在网络照片上对比训练，见过“狗、沙发、胸片照片”，很少见过“右下肺实变与心影重叠”。LLaVA-Med 第 1 节写得很直接：通用视觉助手会像外行人一样回避生物医学问题，或者给出错误回答和完全幻觉。

机制上，领域偏移发生在两处。视觉塔把胸片编成接近“灰度人体照片”的向量；语言模型把报告编成接近“说明文”的向量。投影 $W$ 若只在 CC3M 上训过，两边的新词都没有锚点。第一阶段用 600K 生物医学图注，只更新 $W$，就是在不打乱已经成型的语言方向的前提下，把新的视觉概念推进词嵌入邻域。这和第 22 课阶段 1 的数学相同，样本不同。

验证：同一套冻结表，把数据从 COCO caption 换成 PMC 图注，必须新开实验 ID。若有人用第 22 课的 595K 数字填写本课的 600K 格子，配方卡判不合格。

### 5.2 课程学习：先对齐词汇，再学对话

LLaVA-Med 把适配写成两段课程，论文第 4 节和图 3。第一阶段把图注扩成单轮“请描述这张生物医学图像”，监督是原 caption。图注短于 30 词时从简要问题列表抽样，否则从详细列表抽样。视觉编码器和语言模型冻结，只更新投影。作者把这一段解释成：扩展已经对齐的图文词表，覆盖生物医学概念。

第二阶段才使用 GPT-4 生成的多轮对话。视觉编码器仍冻，投影和语言模型继续更新。目标从“会用领域词描述”变成“会按开放指令交谈”。表 1 是这条课程的数量证据。只做第一阶段，总体相对分 23.3，低于未适配的 LLaVA 36.1：模型更会堆术语，却不会跟多样指令。10K 指令升到 39.9，60K 到 49.4，60K-IM 到 50.2。数据量从 10K 到 60K 的增益，比再堆第一阶段 epoch 更直接地抬聊天能力。

记两段可训练集合，沿用第 22 课符号：

$$
\begin{aligned}
\Theta_1^{\mathrm{med}} &= \theta_W \\
\Theta_2^{\mathrm{med}} &= \theta_W \cup \theta_{\ell}
\end{aligned}
$$

LLaVA-Med 原文第二阶段更新整颗语言模型，不是 LoRA。本课 CPU 实验不数 7B 参数，只核对其数据与 mask 协议。若你在缩小版上改用 LoRA，必须在配方卡上写“教学简化”，不得写成论文默认。

验证：聊天评测必须同时报 Stage 1 和 Stage 2。只报 Stage 2 终值，会把“指令数据有效”和“概念对齐有效”兑在一起。

### 5.3 GPT-4 写指令时看不见图像

LLaVA-Med 第 3 节：给定 caption，提示语言 GPT-4 生成多轮问答，语气像它能看见图像，尽管它只有文本。图注太短时，再把正文里提到该图的句子（inline mention）拼进提示。图像本身不进入 GPT-4。图 1 的例子把插图画出来给读者看，提示里并没有这张图。

这条路径有一个直接后果：指令数据的上界是图注加 citance 的信息量，不是像素的信息量。图注写错、写得太泛、或把组合图的多个子图混成一句，GPT-4 会把错误写成流畅对话。LLaVA-Med 用“只保留单图”的过滤降低组合图风险，并在五种模态上各采样。HuatuoGPT-Vision（[arXiv:2406.19280](https://arxiv.org/abs/2406.19280)）后来把这种做法叫作 blinded reformatting，并对比了让 GPT-4V 同时看图和上下文的 unblinded 路径。他们的表 1 把 LLaVA-Med VQA 记为 56,702 条，把 PubMedVision 记为 1,294,062 条。本课主路径仍以 LLaVA-Med 的盲生成协议为对照，不要求复现 GPT-4V 蒸馏。

验证：数据卡必须有一列“指令生成时是否看见图像”。填 `text-only GPT-4` 或 `MLLM` 或 `human`。空着则本课未完成。

### 5.4 60K、60K-IM 和 10K 不是同一份指令

LLaVA-Med 迭代过三个指令集：10K 不带 IM、60K 不带 IM、60K-IM 带 IM。表 1 显示 60K-IM 总体 50.2，略高于 60K 的 49.4；对话题 55.1 对 53.7，描述题 36.4 对 36.9。IM 的增益主要落在对话，不落在“再写得更长”。表 4b 的零样本平均分：10K 约 39，60K 约 40.7，60K-IM 约 41.2。微调 9 个 epoch 之后，60K-IM 平均 73.90，明显高于同表里 60K 微调 3 epoch 的 58.60。

本课不把 0.8 个点的聊天差写成“必须有 IM”。本课要求：三份数据若都训了，必须分列；没训的写未做。把 10K 的结果贴到 60K-IM 的格子，属于协议错误。

采样规则也要登记。五种模态：CXR、CT、MRI、组织病理、大体病理。图 2c 给出各域的图像数和问答数分布。评测若只报胸片，不得写成“生物医学全覆盖”。

### 5.5 报告字段与自然 caption 的 mask 不同

自然图像样本展开后大致是：图像占位、一句“描述这张图”、一句 caption。第 01 课和第 22 课已经规定，损失只在助手回答上算。医学报告如果仍按“助手说的每一句都算”，会把不该由当前图像负责的字段一并写进损失。

本课把一条胸片报告拆成四段功能：

| 字段 | 谁提供信息 | 能否由当前图像生成 | 本课是否进 $M$ |
|---|---|---|---|
| INDICATION | 申请单、主诉、检查原因 | 不能。它是拍这张片之前就有的文本 | 否 |
| COMPARISON | 旧检查 | 不能。需要另一张图或“无旧片”的元数据 | 否 |
| FINDINGS | 当前图像上的所见 | 能，且应当可被框或区域约束 | 是 |
| IMPRESSION | 对 FINDINGS 的汇总 | 能，但是 FINDINGS 的函数，不是第二份独立观察 | 是 |

自然 caption 的监督集合

$$
M_{\mathrm{nat}}=\{t:\mathrm{role}(t)=\mathrm{caption}\}
$$

医学报告的监督集合

$$
M_{\mathrm{med}}=\{t:\mathrm{role}(t)\in\{\mathrm{findings},\mathrm{impression}\}\}
$$

若把第 22 课的“除图像占位外凡助手文本都算”抄过来，得到

$$
M_{\mathrm{naive}}=\{t:\mathrm{role}(t)\neq\mathrm{condition}\}
$$

$M_{\mathrm{naive}}$ 会包含 indication 和 comparison。模型于是学会：看见胸片轮廓就复读“咳嗽待排”，或凭空写“对比旧片有吸收”。loss 照样降，因为这些词在训练里高频出现。CPU 实验里自然监督 7 个 token（`A dog sits on a sofa .`），医学监督 8 个 token（findings 三词加句号，impression 三词加句号），naive 监督更多，且包含 `cough`。三条集合必须互不相等。

CheXagent（[arXiv:2401.12208](https://arxiv.org/abs/2401.12208)）把 FINDINGS 生成和 IMPRESSION 汇总写成两个任务：前者以图像为条件，后者可以是纯文本汇总。本课不复现他们的 CheXbert-F1 数字，只借用“字段即任务”这一纪律。MIMIC-CXR 原文把报告写成半结构化自由文本，页眉和电子病历导入段不是放射科医师写的；那些段更不能当视觉生成目标。Johnson 2019 的精确版式本课不抄进夹具，避免把教学四段伪装成完整 MIMIC 解析器。

验证：打印每条样本的 `role` 和 mask。`cough` 在医学 mask 里必须是 0，在 naive mask 里必须是 1。`lungs` 在医学 mask 里必须是 1。图像占位在两种配方里都必须是 0。

### 5.6 多图检查不能拆成两张自然图

自然图像 VLM 默认一张图一个样本。胸片检查常有后前位和侧位；CT、MRI 是一层层切片；病理是多倍镜视野。LLaVA-Med 在指令数据里过滤到“只含单个 plot 的图”，这是为了降低组合图噪声，不是说真实检查都是单图。CheXagent 单独设了 view matching（判断两张胸片是不是同一次检查）和 temporal classification（同一患者两张片之间病变是好转、稳定还是加重，MS-CXR-T 上准确率 0.694，95%CI 0.565–0.790）。这些任务的条件是两张图，目标是关系，不是第二张图的 caption。

机制上，第 $k$ 张图的视觉 token 记为 $H_v^{(k)}$。对比段的正确条件是

$$
p(x_{\mathrm{comp}}\mid H_v^{(1)},H_v^{(0)},x_{\mathrm{ind}})
$$

其中 $H_v^{(0)}$ 来自旧片。若训练时只喂 $H_v^{(1)}$，却把 comparison 文本放进 $M$，模型会用当前图去拟合“较前片吸收”这种不可见事实。多图协议至少要登记：本样本绑定了几张图、它们的 view、有没有旧片。缺登记的多图训练，本课视为单图配方的偷换。

验证：CPU 夹具是单图，所以 comparison 直接从 $M_{\mathrm{med}}$ 剔除。GPU 微型实验若引入第二张图，必须新增一个实验 ID，不得覆盖本课单图 mask 的结论。

### 5.7 无框肯定：阳性发现没有位置

第 23 课把幻觉写成“图里有没有椅子”。医学里更危险的失败是：模型写出一个病灶名，却指不出区域。报告读起来像那么回事，框是空的。本课把这种输出叫无框肯定。

对一条生成句 $s$，定义阳性

$$
\mathrm{pos}(s)=\mathbf{1}[s\text{ 含病灶词}]\cdot\mathbf{1}[s\text{ 不含否定线索}]
$$

无框肯定计数

$$
U_{\mathrm{count}}=\sum_{i}\mathbf{1}[\mathrm{pos}(s_i)=1 \land b_i=\varnothing]
$$

无框率（只在阳性句上平均，避免把大量正确阴性兑掉）

$$
U_{\mathrm{rate}}=\frac{U_{\mathrm{count}}}{\max(1,P)},\quad P=\sum_{i}\mathrm{pos}(s_i)
$$

空图探针要求：输入没有可框区域时，$U_{\mathrm{count}}$ 应为 0。若门控关闭、语言模型先验很强，教学查找表会给出 `there is pneumonia` 且 `box=None`，于是 $U_{\mathrm{count}}=1$。这就是浏览器验收要抓的事件。

CheXagent 的 phrase grounding 在 MS-CXR 上报告 mIoU 0.627、mAP 0.810，说明胸片领域可以把句子落到框上。LLaVA-Med 的主评测没有这条门控。本课不把 0.627 抄成自己的分数，只把“阳性必须能落地”写成协议。IoU 阈值若用 0.5，与第 23 课一致；改阈值必须单列。

验证：CPU 实验四组句子：空图门控关 $U=1$；空图门控开（`no pneumonia`）$U=0$；有框阳性 $U=0$；混合四句 $P=2$、$U_{\mathrm{count}}=1$、$U_{\mathrm{rate}}=0.5$。改病灶词表而不改断言，检查应失败。

### 5.8 空图上的语言先验

为什么空图会写出肺炎？因为训练分布里“胸片”和“肺炎”共现极高，提示词又是开放描述。模型不必看见斑片，只要看见胸片轮廓，就值得把高频阳性词写出来。第 21 课的对比学习会把这种共现写进共享空间；第 22 课的指令微调会把它写成流畅句子。医学评测若只用含病样本，这条捷径不会被惩罚。

门控是推理期规则，也可以做成训练期约束。推理期：解码器若要输出阳性词，必须先输出框 token 或拒绝。训练期：阳性 FINDINGS 句子若没有框标注，该句不进 $M$，或进一个单独的“需要框但缺失”桶，不得混进普通 caption 损失。本课浏览器实现的是推理期查找表：门控开且空图，输出“未见局灶实变”；门控关且空图，输出无框“肺炎”。

类比：写病理切片报告时，如果玻片是空白的，不能因为申请单写了“怀疑肿瘤”就填写肿瘤名。类比失效处：真实空白玻片是事故，教学空图是探针。不要把空图探针理解成“医院会拿空白片来考模型”。

验证：同一套权重，必须跑含病灶图和空图。只报含病灶图的准确率，本课记为未完成。浏览器里先预测“空图仍会无框报肺炎”，再关门控、选空图、运行，看到 $U=1$。

### 5.9 开放 recall 掩盖不了无框肯定

LLaVA-Med 第 5.2 节把封闭题记准确率，开放题记 recall：真值 token 出现在生成序列中的比例。作者明确说，前人常把训练集里出现过的答案当成分类候选，会高估泛化。他们的生成设定更接近开放，也更难。

recall 的公式是

$$
\mathrm{Recall}=\frac{|G\cap Y|}{|G|}
$$

其中 $G$ 是真值 token 集合，$Y$ 是生成 token 集合。若 $G=\{\texttt{pneumonia}\}$，$Y=\{\texttt{patchy},\texttt{infiltrates},\texttt{pneumonia},\texttt{wires}\}$，recall 为 1。同一段生成可以没有任何框。CPU 实验把这条做成检查：`open_recall_can_be_one_with_unboxed_positive`。封闭准确率用逐题精确匹配，三条里对两条就是 $2/3$，和 recall 不是同一个数。

表 4a 从 LLaVA 初始化的 LLaVA-Med：PathVQA 开放 37.95、封闭 91.21。同一 checkpoint 上两个数可以差很远。把 91.21 写成“病理 VQA 已经 91 分”而不标封闭/开放，属于记错。通用 LLaVA 在 PathVQA 开放只有 7.74，封闭 63.20；领域适配主要抬的是会不会用领域词，不是“已经会定位”。

验证：报告模板强制三列：封闭准确率、开放 recall、$U$。缺 $U$ 不得用前两列宣称没有幻觉。

### 5.10 换眼睛：BiomedCLIP 与通用 CLIP

LLaVA-Med 默认视觉塔仍是通用 CLIP。表 4a 另报了 BioMed CLIP 初始化：VQA-RAD 开放 64.75、封闭 83.09；SLAKE 开放 87.11、封闭 86.78；PathVQA 开放 39.60、封闭 91.09。作者写：从 LLaVA 或 Vicuna 初始化语言模型差别不大，从 BiomedCLIP 初始化视觉塔略好。表 4b 零样本平均，BioMed CLIP 60K-IM 为 42.21，CLIP 7B 为 41.22。

BiomedCLIP 自己的理由更长。PMC-15M 覆盖约三十类生物医学图像，图比 224×224 大、caption 比 CLIP 默认 77 token 长，所以他们换 PubMedBERT、加长文本上下文、提高分辨率。通用 CLIP 在 PMC 检索上差，是因为“胸片”这种粗词能匹配，而“右侧大量胸腔积液”这种细词匹配不上。

对本课：换眼睛是可选改造，不是主路径验收。主路径是：即使眼睛仍是通用 CLIP，数据和 mask、$U$ 也必须按医学协议改。若第一阶段就解冻通用 CLIP 去迎合 600K 图注，第 22 课的旧文本探针和第 23 课的定位都可能被改写。LLaVA-Med 没有在第一阶段解冻视觉塔。

验证：配方卡上视觉塔名字、是否冻结、是否 BiomedCLIP，三格都要填。填“跟 LLaVA 一样”而不写 CLIP，不合格。

### 5.11 下游 VQA 微调不是聊天助手的替代

论文第 4 节另有一段：在两阶段之后，再把 LLaVA-Med 微调到 VQA-RAD、SLAKE、PathVQA。封闭题把候选答案写进提示，开放题仍自由生成。表 4b 显示微调 epoch 从 1 到 9 会明显抬平均分，15 和 18 epoch 不再涨。这是数据集特异模型，用来提高该基准上的专用分数，不是把聊天助手直接当成该基准的零样本上界。

LLaVA-Med 在封闭题上超过若干先前监督方法，开放题在 SLAKE 上到 83.08 / 84.71 / 87.11（三种初始化），在 PathVQA 开放仍明显低于把开放题当成分类的方法。作者解释：不限制答案集合时更难。本课把这条写成评测纪律：若你的方法是生成，就不要和分类设定的开放准确率横比。第 47 课的分桶思想在这里同样适用，本课不重做六类标签，只要求医学 VQA 的封闭/开放分列。

验证：零样本和微调必须两行。用微调 9 epoch 的 73.90 平均分宣传“聊天助手零样本”，本课记为协议错误。

### 5.12 卡时、batch 与“一天训完”的边界

摘要写“不到 15 小时（八张 A100）”。讨论写 Stage 1 和 Stage 2 大约 7 小时和 8 小时，显存 40G。表 5 在 batch 128、八卡上给出：第一阶段 1 epoch 6.8 小时、3 epoch 19.4 小时；第二阶段 10K 为 0.6 / 1.8 小时，60K 为 2.6 / 8.0 小时。把 6.8 加 8.0 得到 14.8 小时，和摘要的“不到 15 小时”一致，对应“第一阶段 1 epoch + 60K 指令 3 epoch”这条主路径。3 epoch 的第一阶段 19.4 小时已经超过“一天内的 15 小时”叙事，必须单独登记。

这些数字属于原论文硬件。本课 CPU 实验是秒级。禁止把表 5 的小时数写进 `lesson_58.py` 的 `metrics` 假装测到了。缩小版若用 128 条图注，只许报告方向：第一阶段投影梯度非零、视觉塔参数不变。

学习率本课不编。LLaVA-Med 技术报告未在摘要和表 5 里公开与 LLaVA 不同的新学习率表。不确定的格子写 `unknown`，默认沿用 LLaVA“投影阶段高于指令阶段两个数量级”的数量级，并在报告里标明“沿用 LLaVA，非 LLaVA-Med 表内数字”。

### 5.13 本课玩具序列在算什么

CPU 实验把自然样本写成 12 个标记，医学样本写成 15 个标记。自然序列是图像占位、四个用户词、七个 caption 词：`A dog sits on a sofa .`。医学序列是图像占位、两个字段标题、indication 的 `cough`、comparison 的 `none`、findings 的 `lungs are clear .`、impression 的 `no acute process .`。字段标题本身不进 $M_{\mathrm{med}}$，它们只是结构，不是观察。

于是可手算：

| 配方 | 进损失的标记 | 个数 |
|---|---|---|
| 自然 caption | `A dog sits on a sofa .` | 7 |
| 医学字段 | `lungs are clear .` 与 `no acute process .` | 8 |
| 把自然配方抄到报告 | 除 `<image>` 外全部 | 14 |

`cough` 只出现在 naive 集合里。`none` 同理。图像占位两种配方都不进损失。impression 金标准里的 `no` 是该字段的合法词，不算无框肯定：无框肯定只在模型生成句上、按病灶词和否定线索判定。金标准 mask 和生成期 $U$ 是两张表。

空图门控关的生成句写死为 `there is pneumonia` 且 `box=None`，故 $U_{\mathrm{count}}=1$。门控开写成 `no pneumonia`，含否定线索，阳性为 0，$U_{\mathrm{count}}=0$。有框句 `pneumonia in the right base` 的 `box` 非空，$U_{\mathrm{count}}=0$。混合四句里阳性句两条、无框阳性一条，故 $U_{\mathrm{rate}}=1/2$。

开放 recall 的玩具：$G=\{\texttt{pneumonia}\}$，$Y$ 含该词以及 `patchy`、`infiltrates`、`wires`，recall 为 1，同时空图 $U_{\mathrm{count}}$ 仍为 1。封闭准确率三条对两条，等于 $2/3$。这两个数不得填进同一格。

验证：`lesson_58.py` 的 `metrics` 必须打出 `natural_supervised_tokens=7`、`medical_supervised_tokens=8`、`naive_supervised_tokens=14`、`unboxed_empty_gate_off=1`、`unboxed_mixed_rate=0.5`。改序列却不改断言，检查应失败。

### 5.14 哪些可以从第 22 课原样搬走

可以搬走的：投影公式 $H_v=WZ_v$；第一阶段只训 $W$、视觉塔与语言模型冻结；第二阶段仍冻视觉塔；损失只覆盖助手目标；学习率按可训练集合分组；旧能力要有回归探针。LLaVA-Med 自己的架构描述与 LLaVA 相同，线性投影，7B 级语言模型。

不能搬走的：595K 与 158K 的数据身份；CIDEr 或 LLaVA-Bench 作为主验收；“描述得像不像”当作病灶是否存在；单图假设；整段助手文本都进 $M$。LLaVA 在 ScienceQA 上跳过第一阶段掉 5.11 个百分点，那是自然图像任务上的投影对齐证据，不能写成医学 VQA 也会掉 5.11 分。本课对应的负对照是：跳过 600K 概念对齐、直接在 60K 指令上更新语言模型。方向可能相同，幅度必须另测，未测就标 `unknown`。

MiniMind-O 的 SigLIP2 默认冻结，和 LLaVA-Med 第一阶段的眼睛同类。若有人把 PMC 图注倒进 MiniMind-O 却不改 mask，本课的 $M_{\mathrm{naive}}$ 就会在 omni 系统里重演。第 15 课管多任务配比，本课管字段身份。一个 batch 可以同时违反两课：indication 进了损失，同时胸片 token 被长音频挤掉。报告里要分两行写。

### 5.15 一条假报告从进到出

把协议走成一条样本，避免只记住表。输入是一张示意胸片和下面这段已经切好字段的文本。它不是真实病历，只用来对 mask 和 $U$。

INDICATION: cough

COMPARISON: none

FINDINGS: lungs are clear.

IMPRESSION: no acute process.

collator 先写成角色序列，再按 $M_{\mathrm{med}}$ 打 label。用户可见的提示可以包含检查原因，那是条件，不是目标。模型若在 FINDINGS 位置输出 `there is pneumonia` 且解析不到框，这一句的 $\mathrm{pos}=1$、$b=\varnothing$，对空图探针贡献 $U_{\mathrm{count}}+=1$。模型若输出 `no pneumonia`，否定线索把阳性打成 0，$U$ 不加。模型若在有斑片的对照图上输出 `pneumonia in the right base` 并带上 `(0.58, 0.52, 0.82, 0.78)`，阳性成立但有框，$U$ 不加。

同一条样本若误用 $M_{\mathrm{naive}}$，`cough` 和 `none` 会进入损失。几个 epoch 之后，空图条件加上“请写报告”，模型会先复读咳嗽，再写肺炎。BLEU 可能还升，因为训练里很多报告都以主诉开头。这就是“指标在涨、协议在烂”的最小例子。CPU 实验不训练，只核对集合是否包含 `cough`；浏览器实验不训练，只核对门控开关是否改变 $U$。

把这条样本的监督 token 写进笔记：医学配方八个，`lungs are clear . no acute process .`；naive 十四个，多出标题、`cough`、`none`。交作业时这两行必须和 `lesson_58.py` 打印一致。若你改了夹具词表，先改正文表格再改正文叙述，不要只改一处。

### 5.16 语言先验走哪两条路

空图写肺炎，至少有两条互不替代的路。第一条是视觉捷径：编码器把“胸片轮廓”编成接近训练里大量阳性胸片的向量，投影后再被语言模型读成“这是一张该写肺炎的图”。第二条是文本捷径：提示词含 `chest`、`x-ray`、`findings`，语言模型在看不见图时也会把高频共现续出来。两条路可以同时开。

拆路的最小对照是打乱图像或换成全黑，保持提示不变。若阳性词频率几乎不掉，文本捷径为主。若全黑就掉、空的示意胸片仍不掉，视觉捷径为主：模型在用“这看起来像胸片”而不是“这里有斑片”。本课浏览器查找表把两条路合成一个开关，用来教 $U$，不用来归因。GPU 微型实验若要归因，必须同时跑空图、全黑、含斑片三组，三行分列。缺全黑行，不得写“已经证明是视觉捷径”。

第 23 课的 POPE 走的是“物体不在图中仍答有”。本课空图探针更窄：输入是医学图像域的负例，输出是病灶名，并且要求没有框。POPE 的分母是负例题数；$U_{\mathrm{rate}}$ 的分母是阳性句数。一个模型可以 POPE 很低（它会说“没有杯子”）但 $U$ 很高（它一看见胸片就写肺炎）。两课的探针都要跑，不能互相顶替。

### 5.17 框 token 与 FINDINGS 的对齐方式

阳性落地不一定要走检测头。常见三种接口，本课都允许，但同一份报告只能选一种并写进卡：

1. 连续坐标。生成 `[x1, y1, x2, y2]` 再解析。失败就是 `box=None`。
2. 离散位置 token。把网格编进词表，和第 23 课的 location token 同类。解析不到合法格点即无框。
3. 编号标记。先在图上叠编号，模型说编号，再把编号映回区域。没有编号却写了病灶名，算无框。

LLaVA-Med 主路径是自由文本，没有这三种接口。所以用 LLaVA-Med 官方评测脚本得不出 $U$，不是脚本少打了一行百分数，是生成协议里根本没有框。CheXagent 在短语接地任务里要求模型输出框，mIoU 0.627 是该任务的分数，只有在你真的让模型吐框时才能对照。若你的助手只出文字，应报 $U$，不应报 mIoU。

训练期若有框，FINDINGS 句子和框要共享样本 id。没有框的阳性金标准进 `unboxed_gold` 桶：可以剔除、可以降权、可以只当负对照，不能静默混进普通 caption。混进去的后果是：模型学会写病灶名，同时学会不写框，因为金标准里本来就没有框，next-token 损失不会惩罚缺框。这是 $U$ 在训练里长出来的最常见原因。

## 6. 在公开实现中定位这些机制

读公开仓库时，按“数据是哪一阶段、冻谁、mask 盖哪些字段、评测有没有空图”四条线找。不要先陷进 connector 类型，那是[第 02 课](02_multimodal_connector.md)的接口。

**数据阶段。** LLaVA-Med 把第一阶段叫 biomedical concept feature alignment，第二阶段叫 end-to-end instruction-tuning。图注被扩成单轮描述指令，监督是原 caption。指令数据来自 GPT-4 的 JSON 对话。读脚本时先确认当前 DataLoader 读的是 600K 图注还是 60K 对话。把两份数据 concat 成一个 stage，事后无法拆开表 1 的 Stage 1 / 10K / 60K / 60K-IM。

**冻结。** 第一阶段 optimizer 只能收到投影参数。第二阶段可以收到投影和语言模型，仍排除视觉塔。Hugging Face 的 `LlavaForConditionalGeneration` 把投影叫 `multi_modal_projector`，视觉塔叫 `vision_tower`。教学最小实现是按名字开关 `requires_grad`：

```python
def medical_trainable(model, stage: str):
    groups = []
    for name, param in model.named_parameters():
        train = "projector" in name or name.endswith("W")
        if stage == "instruct" and (
            name.startswith("language_model") or name.startswith("llm")
        ):
            train = True
        if name.startswith("vision") or "vision_tower" in name:
            train = False
        param.requires_grad = train
        if train:
            groups.append(param)
    return groups
```

阶段名 `align` / `instruct` 对应 $\Theta_1^{\mathrm{med}}$ 与 $\Theta_2^{\mathrm{med}}$。不要在这里注册第三种 connector。第一阶段结束后，视觉塔与语言模型的参数绝对差分必须为 0，投影差分必须非 0。只打印布尔值不够：布尔值说明意图，差分说明优化器有没有改到冻结塔。

**字段 mask。** 公开医学报告生成代码常把整份报告当 `labels`。本课要求在 collator 里按字段切。伪代码只表达协议，不指向某一仓库的函数名：

```python
def report_labels(tokens, roles, ignore_index=-100):
    labels = []
    for token, role in zip(tokens, roles):
        if role in {"findings", "impression"}:
            labels.append(token)
        else:
            labels.append(ignore_index)
    return labels
```

若框架先把 `<image>` 一个占位展开成几十到几百个视觉位置，必须按真实视觉长度记账，否则 FINDINGS 的起点会错位。这和第 22 课“图像占位不进 $M$”是同一纪律，只是医学多了字段身份。

**无框门控。** LLaVA-Med 官方评测脚本数的是聊天相对分和 VQA 的 recall / 准确率，不数 $U$。若要在生成循环里加门控，需要一个病灶词表、一套否定线索、以及框 token 的解析器。框可以用连续坐标、离散位置 token，或第 23 课的编号标记。本课 CPU 夹具用 `box is None` 表示解析失败或根本没输出框。教学查找表把门控做成开关，不是梯度规则。

**评测入口。** 聊天 193 题的 GPT-4 打分需要图注和 citance 作为裁判上下文；裁判模型看不见像素。VQA 三条基准要分开放和封闭。空图探针需要你自己造：从测试集里选“无阳性标签、无框”的样本，或使用本课示意胸片。不要把示意胸片的 $U$ 和 VQA-RAD 的 84.19 写在同一张对比表。

读别人的医学 VLM 仓库时，强制填八格，缺格就标 `unknown`：

1. 视觉塔是通用 CLIP 还是 BiomedCLIP 一类领域塔，是否冻结；
2. 第一阶段数据是 PMC 图注、胸片报告，还是自然 caption 混进医学；
3. 指令是盲 LLM 写的、多模态 LLM 写的，还是医师写的；
4. 报告字段如何切，哪些进 $M$；
5. 一次检查绑几张图；
6. 封闭 / 开放指标是否分列；
7. 有没有空图或“无发现”负例；
8. 阳性发现有没有框、点或分割。

这八格能填满，才允许说“我们也是 LLaVA-Med 两阶段”。填不满时，只引用你确实看见的格。

## 7. 数据与训练 recipe

配方是数据和冻结绑在一起的。只抄阶段名、不抄数据身份，阶段会失去原论文里的含义。

### 7.1 对照表：自然图像 LLaVA 与 LLaVA-Med

| 初始化 | 随机投影 + 冻结 CLIP + Vicuna | 通用 LLaVA 权重，再继续训 |

| 第二阶段数据 | 158K 视觉指令（对话 58K、详述 23K、推理 77K） | 10K / 60K / 60K-IM GPT-4 对话，五模态 |

两行不得合成“600K 医学 CC3M”。单位都是图文对数，不是 token 数。Qwen2.5-VL 的 4.1T token 不能横着和 600K 比“谁数据更多”。

### 7.2 概念对齐数据怎么扩

对图 $\mathbf{X}_v$ 和图注 $\mathbf{X}_c$，抽一个描述问题 $\mathbf{X}_q$，做成单轮：

Human: $\mathbf{X}_q$ $\mathbf{X}_v$ STOP

Assistant: $\mathbf{X}_c$ STOP

问题列表分简要和详细两套，见论文附录 A。25% 的 PMC-15M 图注短于 30 词，所以 30 词是分界，不是医学上的“简要”定义。本课不把 30 词抄进临床文书规范，它只是抽样规则。

过滤很粗：从 1500 万对里抽 600K，优先覆盖概念，而不是覆盖某家医院的报告版式。组合图、统计图、非医学示意图会混进来。LLaVA-Med 在指令阶段才收紧到单 plot、五模态。第一阶段更吵，正是因为它要先把词表铺开。

### 7.3 指令数据怎么写，IM 怎么加

从 PMC-15M 滤到单 plot，再在五模态上采样约 60K。每条给 GPT-4 的上下文是 caption，可选加 citance。人工写了 few-shot，示范如何根据文本假装看见图像。产出是多轮问答，不是一句 caption。图 2 用动词-名词根统计说明指令和回复的多样性；本课不把那张图的扇区百分比写成必须复现的指标，因为论文没有在表里给出可抄的精确扇区数字。

60K-IM 相对 60K，多的是文内引用。表 1 总体 50.2 对 49.4。不要为 0.8 个点单独再开一个“必须有 IM”的实验叙事。要开就预注册：同一冻结表、同一 60K 图像集合、唯一变量是提示里有没有 citance。失败判定写在训练前：若聊天相对分差小于你预注册的噪声（教学建议先写 2 个点），结论是“此规模下 IM 效应小于噪声”，而不是改表 1。

HuatuoGPT-Vision 的对照值得登记，不当成本课主数据。他们从 LLaVA-Med PMC 514K、PMC-Inline 11M、PMC-OA 1M 合并后再滤，得到 914,960 张医学图，再用 GPT-4V 同时看图和上下文写成 647,031 条对齐 VQA 与 647,031 条指令 VQA，合计约 129 万。表 6 在 LLaVA-v1.5-LLaMA3-8B 上：加 PubMedVision 后 VQA-RAD 54.2 到 63.8，SLAKE 59.4 到 74.5，PathVQA 54.1 到 59.9，PMC-VQA 36.4 到 52.7。这些是他们的零样本生成设定，不是 LLaVA-Med 表 4 的微调设定，不能横减。

### 7.4 报告数据怎么切

若你的任务从聊天助手换成胸片报告生成，数据源往往是 MIMIC-CXR 一类带自由文本报告的胸片库，而不是 PMC 图注。BiomedCLIP 把 MIMIC-CXR 记为 377,110 对，并强调 PMC-15M 大约大两个数量级、且模态更杂。数量级只能说明“PMC 更宽，MIMIC 更像临床报告”，不能说明谁更该当第一阶段。

切字段时至少做四件事：

1. 用规则或模型标出 INDICATION / COMPARISON / FINDINGS / IMPRESSION；标不上的样本进 `parse_fail` 桶，不得静默当 caption。
2. INDICATION、COMPARISON 放进条件侧或直接丢弃，不进 $M_{\mathrm{med}}$。
3. FINDINGS 若有框或分割，阳性句必须能关联到区域；关联不上的阳性句进 `unboxed_gold` 桶，训练时可降权或剔除。
4. IMPRESSION 可以当 FINDINGS 的汇总任务单独训，CheXagent 就是这样做的；也可以和 FINDINGS 一起进 $M_{\mathrm{med}}$，但要在卡上写明。

CheXagent 的 CheXinstruct 有 8,466,352 条三元组、35 项任务、32 个公开源、1,077,494 张不重复图。其中部分任务是纯文本，例如从 FINDINGS 汇总 IMPRESSION，三元组里没有图。本课不要求你拼出 850 万条。本课要求：任务身份写在每一行，纯文本汇总不得冒充“看了图才写出印象”。

### 7.5 推荐的教学配比

无 GPU：不训模型。用本课 CPU 序列和浏览器查找表完成协议。

1×24GB：不要下载 7B。用很小的因果 LM 加冻结小视觉塔，图注 2 千到 1 万条做阶段 A，指令 500 到 2 千条做阶段 B。必须打印字段 mask 和空图 $U$。不要追表 4。

8×A100：若真复现 LLaVA-Med，按表 5 登记 batch 128、第一阶段 1 epoch、60K 指令 3 epoch。数据 hash、冻结差分、193 题聊天、三条 VQA 的封闭/开放、以及你自己加的空图 $U$，五类一起交。缺 $U$ 仍算本课未完成，即使 VQA 数字接近原文。

学习率：LLaVA-Med 未在已打开的正文表里给出独立学习率表。缩小版沿用第 22 课数量级：投影阶段 $10^{-3}$，指令阶段 $10^{-5}$，并在卡上写 `lr_source: LLaVA-default`。若你从某份训练脚本读到具体数字，把脚本 commit 和超参文件列入事实栏，不要写进本课课文冒充论文表。

### 7.6 空图与无发现负例怎么造

$U$ 的分母若被阳性图污染，计数就失去意义。造负例时按这个顺序，写进实验记录。

教学路径不使用真实患者影像。浏览器 Lab 的空图是示意肋骨和肺野，斑片用椭圆表示，页面上写明“教学示意图，不是放射影像”。CPU 夹具甚至没有图，只有句子和可选框。这两条已经够完成本课主路径。

若有公开、已去标识、许可允许的“无发现”标签可用，另开 `negatives-v1` 清单，每行至少含：image_id、许可字段、标签来源、是否含框、是否被本课当作空图探针。缺许可的行不得进清单。第 57 课若已写出处协议，按其必填字段补；若该课尚未写入你的仓库，至少保留许可和哈希两列，不要用“网上找的正常胸片”这种句子代替。

规则审核：标签为无发现、无框、且报告 FINDINGS 不含本课病灶词表。任一条失败，样本进 `review` 桶，不进 $U$ 分母。审核是人做的，模型不能自己给自己发负例证书。20 条起步，不够 20 就写 `N=实际条数`，并把阈值改成条数。

反事实负例可以补，但不能替代无发现图。全黑、随机噪声、自然图像里的风景，用来拆 5.16 的文本捷径。风景图上写出肺炎，说明提示词比像素强；它不能说明模型在胸片轮廓上会不会写肺炎。三类负例三行记账：示意空图、标签无发现、反事实非胸片。

### 8.1 CPU 夹具（必做）

检查项如下：

5. 图像占位两种配方都不进损失；
6. 空图门控关 $U_{\mathrm{count}}=1$，门控开为 0；
7. 有框阳性 $U_{\mathrm{count}}=0$；
8. 混合批 $P=2$、$U_{\mathrm{count}}=1$、$U_{\mathrm{rate}}=0.5$；
9. 开放 recall 为 1 时，空图无框计数仍为 1；
10. 封闭准确率按精确匹配得 $2/3$，不得写成 recall。

全部为 True 才算本课机制验收通过。

### 8.2 浏览器胸片门控（必做）

打开本课页面的“胸片无框断言门控”。必须先在三个选项里选出“空图仍会无框报肺炎”，再运行。默认门控是开、默认图是空图，此时 $U=0$，不能通过验收。把“禁止无框断言”关掉，保持空图，运行后 $U=1$，验收才亮。这是教学模拟，示意图不是放射影像。

有斑片的示意胸片用来对照：门控开时应出现框；门控关时即使有斑片也可能漏绑框。验收指定的失败臂是空图加门控关，不要用有斑片图去凑 $U=1$ 再宣称“抓到了空图先验”。

### 8.3 可选 GPU 微型实验

仅在有卡、并且已经有一份冻结好的 CLIP 与小 LLM 时做。顺序固定：

1. 过拟合 128 条 PMC 风格图注，只训 $W$，确认视觉塔与语言模型差分小于预注册 $\varepsilon$；
2. 同一起点上用 128 条带字段的假报告，比较 $M_{\mathrm{med}}$ 与 $M_{\mathrm{naive}}$：naive 臂若更容易复读 indication，记为符合本课失败臂；
3. 造 20 张空图或“无发现”图，生成后算 $U$；
4. 禁止在第 2 步改善了报告 BLEU 之后，回写第 3 步的 $U$。

### Step 0: 登记起点

写下视觉塔名字与是否冻结、LLM 名字、投影形状、数据是 PMC 图注还是胸片报告、字段切分规则、$U$ 的词表。CPU 实验填“toy 12/15 tokens, findings={pneumonia,effusion,consolidation}”。

### Step 1: 字段 mask 与自然 mask

跑 CPU 实验。记录三套监督 token 数 7 / 8 / 14。失败则先查 `role` 字符串有没有把 header 误标成 findings。

### Step 2: 空图 $U$

跑 CPU 四组句子和浏览器空图。失败则先查否定线索有没有把 `no pneumonia` 误判为阳性。

### Step 3: 开放 recall 负对照

确认 recall=1 与 $U=1$ 可以共存。不要在这一步比较 MLP 和 Q-Former。

### Step 4: 写医学配方卡

一张表，两行阶段，列包括：数据身份、可训练模块、字段 mask、多图绑定、$U$、封闭/开放、卡时来源。缺列则本课未完成。

### Step 5: 不要在本课引入新骨干

有人会想顺便换成动态分辨率或 MoE。停。那是第 08 课和第 11 课。本课只允许数据身份、mask 和 $U$ 变化。骨干一变，你又说不清是领域协议的功劳。

浏览器操作顺序写成六步，和 CPU 夹具对齐，避免只记得“拨开关”。进入页面时门控默认开、图像默认空图，此时还看不见报告。先在预测栏选出“空图仍会无框报肺炎”，运行按钮才会亮。若你现在运行，得到的是门控开的空图，$U=0$，验收不亮，这是对照臂。把禁止无框断言关掉，保持空图，再运行，报告应出现无框“肺炎”，$U=1$，示意胸片上出现“无框肯定”字样。把图像改成右下肺斑片且门控开，应看到框和斑片绑定，这条是对照，不是验收。改任何开关都会清掉揭晓状态，必须重新预测或至少重新运行，防止把上一轮的 $U$ 误记到新开关上。重置按钮回到门控开、空图、无预测。整次互动都标明教学模拟。若把这一页的肺炎两个字抄进真实模型卡，属于交付失败，与 CPU `checks` 是否为真无关。

### 8.4 可选 GPU 的最小数字协议

若只有 1×24GB，用小于 0.5B 的因果 LM。记录：

- 阶段 A：100 step 内投影范数离开初始化，视觉塔相对变化低于 $\varepsilon$（建议 $10^{-6}$）；
- 同一批假报告上，naive mask 复读 indication 的次数高于 $M_{\mathrm{med}}$；
- 20 张空图的 $U_{\mathrm{count}}$ 与 $U_{\mathrm{rate}}$。

卡时估计：上述规模在 24GB 上每个阶段数十分钟到两小时。超过半天还没跑完，先减分辨率，不要去解冻视觉塔指望它“更懂胸片”。没有 24GB 时，跳过 8.4，CPU 加浏览器即为完整主路径。

## 9. 评测与测量

六项必须分列。名称可以自定，定义不能含糊。

**聊天相对分。** LLaVA-Med 表 1：193 题，语言 GPT-4 当裁判，上下文是图注和 citance，不是像素。60K-IM 总体 50.2，LLaVA 36.1，Stage 1 23.3。分域：CXR 56.2、MRI 40.4、Histology 52.7、Gross 51.8、CT 50.1。对话 55.1、描述 36.4。只报总体 50.2 会把描述题的弱藏起来。

**封闭准确率。** 候选答案在提示里，生成后做精确匹配。表 4 从 LLaVA 初始化：VQA-RAD 84.19、SLAKE 85.34、PathVQA 91.21。

**开放 recall。** 真值 token 出现在生成里的比例。同表：VQA-RAD 61.52、SLAKE 83.08、PathVQA 37.95。不得把 91.21 和 37.95 平均成“PathVQA 64 分”。

**字段 mask 合规。** 抽样打印 `role` 与 label。indication / comparison 的有效损失 token 数必须为 0。CPU 实验把这条做成布尔。

**无框肯定 $U$。** 空图或“无发现”集合上 $U_{\mathrm{count}}$ 与 $U_{\mathrm{rate}}$。浏览器空图门控关时 $U=1$，门控开时 $U=0$。真实模型没有标准答案，必须自己造负例集并冻结 hash。

**多图一致性。** 若评 view matching 或时间变化，单独成行。CheXagent 在 MS-CXR-T 上 0.694（95%CI 0.565–0.790）。本课不要求复现该数；若你没做多图任务，写未做，不要用单图 VQA 顶替。

辅助测量：

- 可训练参数量与 optimizer 实际参数量必须相等；
- 第一阶段视觉塔和语言模型的参数差分；
- 反事实图：全黑、打乱胸片、或示意空图。若阳性词频率不掉，对齐是假的；
- 旧文本探针：医学指令之后，第 22 课那 20 条纯文本题是否还在。本课不把旧文本当主验收，但丢掉它会和第 22 课的失败臂重叠，需要在报告里点名。

不要把 ScienceQA 90.92%、VQA-RAD 84.19、浏览器 $U=1$ 写进同一张“我们的模型”表。前两个属于原论文设定，后一个属于教学查找表。

浏览器内置查找表（不得外传为读片分数）：

| 输入 | 门控 | 生成 | $U$ | 是否触发验收 |
|---|---|---|---|---|
| 空图 | 开 | 未见局灶实变 | 0 | 否 |
| 空图 | 关 | 无框“肺炎” | 1 | 是 |
| 有斑片 | 开 | 带框右下肺斑片 | 0 | 否（对照臂） |
| 有斑片 | 关 | 无框“肺炎” | 1 | 否（不是空图先验） |

验收指定第二行。预测必须先选“空图仍会无框报肺炎”。选错预测即使跑到第二行也不亮门。

把 LLaVA-Med 表抄进自己的报告时，按下表拆，不要把一列数字当成“医学能力”。

| 原文位置 | 数字 | 本课允许的用法 | 不允许的用法 |
|---|---|---|---|
| 表 1 总体 | 50.2 | 60K-IM 聊天相对分，裁判是语言 GPT-4 | 写成看图像素理解分数 |
| 表 1 Stage 1 | 23.3 | 只对齐会丢指令跟随 | 写成概念对齐失败 |
| 表 4 封闭 | 84.19 等 | 提示里有候选时的准确率 | 写成开放生成质量 |
| 表 4 开放 | 61.52 等 | 真值 token 的 recall | 写成没有幻觉 |
| 表 5 | 6.8h、8.0h | 八卡、batch 128 的卡时 | 写成任意硬件的常数 |
| 本课浏览器 | $U=1$ | 查找表触发了空图无框肯定 | 写成肺炎检出率 |

公开论文若只给聊天相对分和 VQA，没有 $U$，你的复现报告仍必须有 $U$。缺的那一列是本课新增协议，不是原作者的疏忽记录。你可以写“原文未测 $U$”，不能写“原文已经隐含没有幻觉”。

测量 $U$ 时把生成句按句号切开，再逐句跑阳性判定。一条报告里两句无框肺炎，$U_{\mathrm{count}}$ 加 2，不要按报告条数封顶成 1，除非你在卡上预注册“按报告计”。CPU 夹具按句计。浏览器查找表每轮只出一句，所以 $U$ 只能是 0 或 1。两种粒度不得混在同一张图的纵轴上。

封闭题若提示里列出了 yes/no，模型仍可能生成一段解释再落到答案上。LLaVA-Med 把候选写进提示，是为了让生成设定能覆盖封闭题。你的解析器必须声明：是取全文精确匹配，还是用正则抓最后一个 yes/no。本课 CPU 封闭准确率用逐项精确匹配，三条里对两条得 $2/3$。改解析器要改检查，不要在报告里用另一种解析去对齐 $2/3$。

## 10. 验收条件

机制验收（无 GPU 也可）：

- CPU 实验全部 `checks` 为 True；
- 浏览器实验先预测“空图仍会无框报肺炎”，再关掉门控、选空图，得到 $U=1$；
- 课文中的 7 / 8 / 14 与脚本 `natural_supervised_tokens`、`medical_supervised_tokens`、`naive_supervised_tokens` 一致。

三条必须同时成立。只有 CPU 没有互动预测，会漏掉“先押语言先验”这条教学契约。只有互动没有 CPU，会漏掉字段 mask 与开放 recall 的手算。数字 7 / 8 / 14 是夹具常量，改词表后必须同步改课文；只改脚本或只改课文，验收按失败处理。不要把 14 理解成“医学报告更长所以监督更多”：naive 更大是因为它错误地吞下了不该监督的字段，不是因为医学内容更丰富。医学配方的 8 个监督标记里，有一半来自阴性所见，这提醒你：正确 mask 仍然包含 `clear` 和 `no`，它们是 FINDINGS / IMPRESSION 的合法目标，只是不算无框肯定。

配方验收（若做了 GPU 微型实验）：

- 阶段 A：图注损失下降，视觉塔差分低于 $\varepsilon$；
- $M_{\mathrm{med}}$ 臂复读 indication 的次数低于 naive 臂；
- 空图集合 $U_{\mathrm{rate}}$ 有预注册阈值；未达阈值不得用开放 recall 宣称成功。

报告验收：

- 冻结表、数据身份、字段 mask、$U$、封闭/开放分列；
- 明确声明未比较三种 connector，未做临床验证；
- 未把浏览器分数写成影像诊断能力；
- 出现“肺炎”“病灶”时，上下文是协议词，不是医嘱。

## 11. 根据症状定位失败环节

| 症状 | 先查 | 不要做 |
|---|---|---|
| 图注 loss 下降，空图仍高置信写肺炎 | $U$、门控、负例集是否为空 | 立刻解冻视觉塔 |
| 报告 BLEU / ROUGE 很高，indication 被复读 | mask 是否变成 $M_{\mathrm{naive}}$ | 再加更多 MIMIC 报告 |
| 封闭准确率高、开放 recall 低 | 是否把分类设定和生成设定混报 | 把两列平均 |
| 开放 recall 高、$U$ 也高 | 生成里是否堆病灶同义词却不落框 | 用 recall 覆盖 $U$ |
| 第一阶段后不会回答问题 | 表 1 的 Stage 1=23.3，属预期 | 把聊天崩了写成代码事故 |
| 第二阶段后术语对、位置乱 | 有没有框监督；对照第 23 课 | 只加更长 caption |
| 侧位和正位描述互相矛盾 | 是否按单图拆样本 | 把矛盾写成“模型有主见” |
| 与第 22 课数字对不上 | 595K 和 600K 是否被写成同一个 stage | 用 ScienceQA 5.11 分解释 VQA-RAD |
| 视觉塔差分非 0 | optimizer 参数组 | 把非 0 当成“更懂医学图像” |
| 中文问题零样本尚可、报告字段全乱 | LLaVA-Med 表 6 只说明 Vicuna 多语先验，不说明字段 mask | 把中文对了写成医学配方成功 |
| 同一 checkpoint 两次 $U$ 差很大 | 词表、否定线索、框解析器 | 改阈值去凑 0 |

LLaVA-Med 结论自己写了：受幻觉和弱深度推理限制，这是许多大型多模态模型的通病。本课把这句话翻译成可执行探针，而不是翻译成“以后会好”。CheXagent 用 phrase grounding 和细粒度左右/上下/轻重推理补了一部分位置账；HuatuoGPT-Vision 用看得见图像的改写补了一部分数据噪声账。抄他们的分数无意义，抄“他们多测了哪一格”有意义。

再补一张“看起来像成功、其实协议失败”的对照，方便写周报。聊天相对分从 36.1 升到 50.2，只能说明领域指令让回答更像生物医学助手。开放 recall 升高，只能说明真值词更常出现在生成里。报告 ROUGE 升高，只能说明用词更像放射科句式。这三项都可以在 $U_{\mathrm{rate}}$ 同时升高时发生：模型更会写肺炎，也更不指向位置。周报若只列前三项，阅读者会以为系统变安全了。本课要求前三项和 $U$ 必须同页出现，升降方向不一致时，以 $U$ 和空图探针为否决项，不以均分挽救。

深度推理弱是另一项，本课不把它做成 CPU 检查。LLaVA-Med 表 2 的例子里，通用 LLaVA 把胸片看成“带电线的肋骨示意图”，领域模型会说出浸润和管路，语言 GPT-4 因为读了金标准图注还能点名气管插管。那是定性案例，不是可复现的推理分数。本课不把案例图写成基准。若你要测推理，另开题本：必须引用图像中可见的装置或左右位置，并且用框或编号作为可验证答案。没有可验证器的“看起来更专业”，本课不记分。

三项主指标在真实评测里都有噪声。教学建议空图探针至少 20 条，报告时同时给逐条生成，不要只给 $U_{\mathrm{rate}}$。20 条里差 1 条就是 5 个百分点。若只能做 20 条，把阈值写成条数，例如“无框肯定最多 1 条”。浏览器实验没有噪声，因为它是查找表；不要用它练习误差棒，只用它练习失败臂怎么触发。

交作业时把浏览器预测截图或文字记录放进同一目录：预测选项必须是“空图仍会无框报肺炎”，门控最终为关，图像为空图，$U$ 为 1。缺预测记录的，即使 CPU `checks` 全真，互动实验仍算未完成。课程把“先预测再揭晓”当成协议的一部分，因为它阻止用事后看到的 $U$ 去改口头因果：你必须在看见肺炎两个字之前，就押语言先验会穿过空图。

## 13. 前沿对照与改造方向

**公开方案。** LLaVA-Med 证明：从通用 LLaVA 出发，用 PMC 图注做概念对齐、用盲 GPT-4 对话做指令微调，可以在一天量级的 8×A100 预算里得到生物医学聊天助手，并在三条医学 VQA 上微调出可引用的封闭/开放分。BiomedCLIP / PMC-15M 把对比学习眼睛换成 1528 万对科学图注，文本编码器换成 PubMedBERT，用来解释“为什么通用 CLIP 会把胸片和积液细节对不上”。HuatuoGPT-Vision 认为盲 LLM 改写会看错组合图、留着与像素无关的句子，于是让 GPT-4V 同时看图和上下文，做成约 129 万 PubMedVision；他们在 LLaVA-v1.5-LLaMA3-8B 上显示，这份数据比把 LLaVA-Med 的对齐+VQA 直接混进去抬分更明显。CheXagent 不再追求“全生物医学插图助手”，而把胸片拆成 35 项任务、850 万三元组，单独评 view、疾病识别、时间变化、短语接地和 FINDINGS 生成；短语接地 mIoU 0.627。这些系统都没有授权本课去做临床决策。CheXagent 另有八名放射科医师的读者研究，报告住院医师编辑模型草稿相对从零写节约约 36% 时间；那是他们的工作流实验，不是本课验收，也不构成使用建议。

**差距。** 规模差距：PMC-15M 的 $10^7$ 对、PubMedVision 的 $10^6$ 条 VQA、CheXinstruct 的 $10^6$ 张图，钱可以买数据和卡时。买不来“你有没有把 indication 从损失里拿掉、有没有空图 $U$”。机制差距：本课能解决的是数据身份、字段 mask、无框计数和封闭/开放分列。本课不能解决的是原生动态分辨率（第 08 课）、自然物体 grounding 全套探针（第 23 课）、可验证奖励（第 17 课）。LLaVA-Med 的幻觉限制，本课只提供测量，不提供训练期保证。若要把 $U$ 变成奖励，那是改造清单第 4 条，不是主路径。

Qwen2.5-Omni 一类系统会把视觉配方和音频双工叠在同一套权重上。其技术报告若未公开医学字段 mask 和空图探针，对应格子写 `unknown`，不要用本课的胸片表去填。能确定的只有：眼睛若来自自然图像对比预训练，医学第一阶段仍应先改数据身份，再用该系统自己的消融推翻。

**动手改造（在缩小版上执行，写清失败判定）：**

1. **把 $M_{\mathrm{naive}}$ 改成 $M_{\mathrm{med}}$，其余冻结表不变。** 改 collator 的 `role` 分支。预算：CPU 上已有夹具；GPU 微型用同一 128 条假报告、相同 step。预期：indication 复读下降，FINDINGS 的 token 损失仍下降。失败判定：视觉塔差分被破坏，或 FINDINGS 有效 token 数变成 0（说明切字段时把正段也丢掉了）。
2. **在评测里加空图 / 无发现集合，计算 $U$。** 不改训练。预算：20 到 100 条负例，greedy 解码。预期：通用 LLaVA 或未加门控的医学指令模型 $U_{\mathrm{rate}}$ 明显高于带框监督的对照。失败判定：负例集里混进了含框阳性，导致 $U$ 分母被污染。必须先人工或规则审核负例。
3. **指令数据从盲改写换成“看得见图的改写”的缩小对照。** 教学可用人工写 50 条“根据图注但禁止引入图注未支持的器官”规则，模拟 unblinded 约束，不必真调用 GPT-4V。预算：与阶段 B 相同卡时的两个 run。预期：无中生有的器官名下降，$U$ 下降或持平。失败判定：正集开放 recall 明显下降且 $U$ 不降，说明约束过紧，应放宽规则而不是解冻视觉塔。
4. **把无框肯定做成可验证惩罚，接到第 17 课的 verifier。** 生成后解析病灶词和框；无框阳性则奖励为 0。预算：CPU 先实现解析器；GPU 只跑少量 RL 步。预期：$U_{\mathrm{rate}}$ 下降，封闭准确率不显著变差。失败判定：模型学会永远输出“未见异常”来把 $U$ 刷成 0，此时必须加“有框阳性漏报”的对称计数。该对称计数本课主路径不强制，但本条改造必须加，否则奖励被钻空。

改造实验的公共纪律：一次只改一个变量；失败判定写在训练开始前；卡时超过预算就降数据，不降探针。四条都做完也只说明缩小版上的方向，不能改写 LLaVA-Med 表 4 或 CheXagent 的 mIoU 0.627。

缩小版的预算要写具体到能拒绝临时加卡。改造 1 的 CPU 路径是改 `role` 分支并重跑 `lesson_58.py`，预期分钟级。若你有 1×24GB，128 条假报告、序列长度 256、两个 mask 臂各 200 step，通常在两小时内结束；超时先减到 64 条，不要把视觉塔解冻来“加快拟合”。改造 2 没有训练，只有解码：20 张空图 greedy 生成，解析 $U$，笔记本 CPU 也可做，有卡只为加快视觉前向。改造 3 的 50 条人工约束必须在训练前冻结文本 hash，训练中途改规则会使两臂不可比。改造 4 若接入第 17 课，先保证解析器在 CPU 上对夹具四句的 $U$ 与本课脚本一致，再跑 RL；解析器不一致时，奖励数字全部作废。四条改造都要在笔记里预注册对照臂名字，例如 `mask-med`、`mask-naive`、`u-probe-empty`、`unblind-50`、`rl-unboxed-penalty`，互不覆盖 checkpoint。

失败判定不能写“看起来更医学”。必须写可执行的不等式或计数。例如改造 1：naive 臂复读 `cough` 的次数高于医学臂，且医学臂 FINDINGS 有效 token 数大于 0。改造 2：空图 $U_{\mathrm{count}}\ge 1$ 至少在无门控臂上出现，有门控或有框臂不得用同一阈值。改造 4：永远输出“未见异常”把 $U$ 刷零时，记失败并启用漏报计数。写不出不等式的改造，本课视为未设计，不许开始训练。

### 13.1 十个常见记错

1. 把 LLaVA 的 595K 和 LLaVA-Med 的 600K 混成一个数。
2. 把表 1 的 50.2 写成 GPT-4 看图的分数。裁判是语言 GPT-4，上下文是金标准图注。
3. 把 Stage 1 的 23.3 写成“概念对齐失败”。它失败的是指令跟随。
4. 把开放 recall 写成准确率，或把封闭准确率写成生成质量。
5. 把 PathVQA 封闭 91.21 与开放 37.95 平均成单一 PathVQA 分。
6. 把表 5 的 6.8 小时写成任意 batch、任意卡数的通用常数。原文是八张 A100、batch 128。
7. 把 HuatuoGPT-Vision 的 129 万 VQA 和 LLaVA-Med 的 60K 指令横着减，却不写生成器是否看见图像。
8. 把 CheXagent 的 36% 时间节约写成你的复现结果，或写成临床建议。
9. 把 BiomedCLIP 的 15,282,336 对写成 LLaVA-Med 实际训练量。LLaVA-Med 第一阶段用了其中 600K。
10. 把本课浏览器 $U=1$ 写成可以和 phrase grounding mIoU 0.627 比的数。

这十行可以当报告互审清单。命中任意一行，把该段改掉再提交。

**顺手复现映射：**

- LLaVA-Med“只做 Stage 1 则聊天掉到 23.3”对应缩小版比较只训投影的描述模型与再加指令的对话模型。预期同方向：只对齐会堆术语、不会跟开放问题。
- “60K 优于 10K”对应指令条数扫描。预期同方向；26M 级上看不见则记效应小于噪声。
- “开放 recall 与封闭准确率必须分列”对应 CPU 里 recall=1 与准确率 $2/3$ 同时存在。预期能精确复核。
- HuatuoGPT-Vision“盲改写会引入与图无关的句子”对应本课 $M_{\mathrm{naive}}$ 吞下 indication。预期同方向：条件文本被当成生成目标。
- CheXagent“阳性短语可落地”对应本课 $U$。预期：加框监督后 $U$ 下降。规模不够时只比方向。

## 14. 论文与必读材料

每篇只带本课需要的问题。冻结公式能在第 22 课解决的，不在这里重读一遍。读的时候在纸上画四列：数据身份、冻结集合、字段或指令如何生成、幻觉/定位探针。缺一列就回去翻原文。

### [LLaVA-Med](https://arxiv.org/abs/2306.00890)

带着问题读：600K 与 60K 各自冻哪些参数；GPT-4 是否看见图像；表 1 为什么 Stage 1 会低于通用 LLaVA；表 4 开放列和封闭列的度量是否相同；表 5 的 6.8 小时和 8.0 小时对应几 epoch、多大 batch。把 193 题、50 张图、五种模态抄进笔记，并写明聊天裁判用的是图注不是像素。再问：过滤到单 plot 之后，真实多图检查还剩什么协议。答案：论文主路径几乎没剩，需要你自己加。

结论段关于幻觉和弱推理的限制要原句登记。本课的 $U$ 和空图探针就是对这句话的操作化。不要把“一天训完”理解成医学系统已经可部署。

### [LLaVA](https://arxiv.org/abs/2304.08485)

带着问题读：自然图像两阶段与 LLaVA-Med 的同构之处、数据不同构之处。595K / 158K、学习率 $2\times 10^{-3}$ 与 $2\times 10^{-5}$、ScienceQA 跳过预训练的 85.81% 对 90.92%，用来回答“骨架能借、样本不能借”。把公式里的 $W$ 和本课第一阶段只训投影对上。详细冻结表回第 22 课。

### [BiomedCLIP / PMC-15M](https://arxiv.org/abs/2303.00915)

带着问题读：15,282,336 对从 440 万篇 PMC 全文抽出；为何 caption 比 77 token 长、图像比 224 大；通用 CLIP 在 PMC 检索上差在细词。MIMIC-CXR 被他们记为 377,110 对，用来理解“两个数量级”这句话的分母。本课不实现 InfoNCE，对比损失回第 21 课。问：若第一阶段不换数据只换 BiomedCLIP 权重，还要不要 600K 图注对齐。LLaVA-Med 表 4 说换眼睛略好，但他们仍然做了 600K 对齐。不要把换眼睛理解成可以跳过领域图注。

### [HuatuoGPT-Vision](https://arxiv.org/abs/2406.19280)

带着问题读：盲改写与看得见图的改写差在哪；914,960 张图、1,294,062 条 VQA 怎么来的；表 1 把 LLaVA-Med VQA 记为 56,702 条，和 60K 指令如何同时理解（过滤与计数口径不同，抄的时候跟表走）。表 6 的 54.2 到 63.8 是他们的基座加 PubMedVision，不是在 LLaVA-Med 官方 7B 上微调。附录写了幻觉风险和仅限研究用途。本课同意该限制。

### [CheXagent](https://arxiv.org/abs/2401.12208)

带着问题读：35 项任务里哪些是感知、哪些是 FINDINGS 生成、哪些是纯文本汇总；短语接地 mIoU 0.627 怎样对应本课 $U$；view matching 与时间分类怎样对应多图协议。8,466,352 条三元组、1,077,494 张图用来建立胸片专项的规模坐标。读者研究的 36% 时间数字只许当作“他们做了工作流实验”的事实，不许写进本课验收，不许改写成使用建议。模型约 3.1B，说明医学专项不必从 34B 起步；本课缩小版更不必。

读完五篇，应能用一句话向没做过医学模型的同事说明：第 22 课的冻结顺序可以借用，自然图像的 caption 损失、单图假设和“写得像不像”的指标不能借用；空图上的无框肯定是必须单独抓住的失败臂。这句话里没有临床含义。若对方问“那胸片该怎么出诊断”，正确答复是：本课不回答诊断，只回答训练与评测协议有没有把语言先验当成图像证据。

读的时候建议按这个顺序，不要五篇并行扫摘要。先 LLaVA-Med 全文第 3–5 节和表 1、4、5，把两阶段、盲生成、开放/封闭三件事钉死。再回 LLaVA 只对冻结表和 595K/158K，确认骨架同构。然后 BiomedCLIP 的数据集段，弄清 1500 万对和 600K 的关系。HuatuoGPT-Vision 第 2 节和图 1 用来理解盲改写会引入什么噪声。CheXagent 只精读任务定义、短语接地和 FINDINGS/IMPRESSION 分任务，读者研究段落当“原文做了工作流实验”的事实登记，不展开成操作手册。五篇都读完仍应感到缺 $U$：那是本课要你补上的格子，不是你没读仔细。

若时间只够一篇，读 LLaVA-Med。若时间够两篇，加 CheXagent 的任务表，因为它把报告字段拆开了。HuatuoGPT-Vision 的 129 万数据很吸引人，但本课主路径不依赖调用 GPT-4V；把它当改造清单第 3 条的文献支持即可。BiomedCLIP 在已经懂第 21 课对比学习的人那里可以读得很快：你要的是 PMC-15M 的规模和“caption 更长、图更大”，不是再推一遍 InfoNCE。

纸上四列填完之后，用本课浏览器和 CPU 夹具各跑一遍。文献里的 50.2 和夹具里的 $U=1$ 必须出现在报告的不同小节。能把这两类数字分开写，这一课才算从自然图像配方里拆了出来。拆出来的标志是：你会在下一份医学训练计划里删掉一行，即把整份报告当 caption 算损失。光会背表并不够。删掉那一行之后，空图探针和无框计数必须还在。两件事同时成立，才说明自然图像配方没有跟着混进来。
