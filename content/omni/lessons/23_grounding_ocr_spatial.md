# 第 23 课：检验指代、OCR 与空间幻觉

> 内容：指代接地、OCR 定位、空间关系与物体幻觉探针<br>
> 建议周期：2-4 天读完并跑通 CPU 实验；若评开源 2B 级 VLM，另加 1-2 天<br>
> 硬件：无 GPU 可完成全文与 CPU 夹具；1×24GB 可跑开源小模型探针；Kosmos-2 / Grounding DINO 原训练为多卡作业，本课不要求复现<br>

## 1. 答对了不等于看见了位置

第七幕前两课把眼睛接到了语言模型上。第 21 课用对比学习把图和字拉进同一空间，第 22 课按冻视觉、训投影、再解冻语言模型的顺序把标准视觉语言模型（vision-language model, VLM：同时吃图像和文字、用 next-token 吐文字的模型）配方走通。到这一课，系统已经能对一张图写出选择题答案。这还不够。机械臂要伸向杯子，屏幕代理要点按钮，发票要读金额，这些任务问的是：模型有没有用对像素。

[第 08 课](08_dynamic_vision.md)已经处理过另一件相邻的事：固定 256×256 会糊掉小字，动态切片和多轴位置编码改变的是「眼睛被允许看多细、位置怎么编号」。那一课的负对照是打乱二维坐标后空间题下跌。本课不再改切片器，也不再讲 M-RoPE 的三个轴。本课假定视觉 token 已经进了语言模型，要检查的是：答案写对时，模型究竟看了哪一块。

一个最小反例就够说明两套账必须分开。桌上两只红色杯子，一左一右。问题是「左边那只杯子是什么颜色」。正确答案是「红色」。模型也可以输出「红色」，因为它在训练里见过无数「杯子、红色」共现，或者因为它把注意力放在了右边那只同样红色的杯子上。文字对了，被问的物体没被用上。把这种样例的 VQA 准确率（visual question answering accuracy：文字答案是否匹配标注）写进报告，再宣称模型会接地（grounding：把语言指称对应到图像里的区域、点或框），是在用错度量。

本课要造的是探针，不是新的骨干。指代表达（referring expression：用一句话唯一锁定图中某个物体，例如「戴蓝安全帽的人」）要求输出框或点，并用交并比判定命中。OCR（optical character recognition：读图中的字）要求预测区域盖住字形，而不是生成一段碰巧含这些字的配文。空间关系要拆成左/右、前/后、计数，每一项都有可以失败的对照。物体幻觉（object hallucination：描述或问答里出现图中没有的物体）用是否存在的是非题来量，而不是用一段自由描述里数名词。交互实验是 8×8 物体网格上的教学模拟：你先预测这一问会「都对」「答案对格子错」还是「物体不存在仍高置信答有」，再看玩具模型的答案和它实际使用的格子。CPU 实验用固定框和注意力表手算同一套公式，夹具里故意放进「答案对、命中失败」。

做完这课你手里会有：一张禁止把 VQA 均分当成 grounding 的报告模板；POPE 三档负采样的题本；OCR 按区域打分的协议；以及至少一例书面记录的「答对但看错地方」。第 24 课要把动作接进同一套 token，第 32 课要用 Set-of-Mark 在屏幕上点选。两课都默认你已经会把「文字对了」和「像素对了」分开记账。

和第 08 课的边界再写清楚一次，免得两课的 OCR 数字被加在一起。[第 08 课](08_dynamic_vision.md)问：同样的 Thinker、同样 64 个视觉 token，动态切片能不能让发票小字变得可读。本课问：可读之后，模型有没有把答案绑在金额栏上。08A 的 OCR 上涨，只说明 encoder 看见了更多字形像素；如果本课的区域列仍是空的，那上涨可能来自「语言模型更会猜发票格式」。两课的负对照也不同：08B 打乱 `query_xy`，本课涂黑物体或换同色干扰物。可以同一张发票两边都测，必须两个 run ID，禁止把「动态分辨率加接地」写成一个消融。也可以链回[第 01 课](01_baseline_reproduction.md)的 trace 纪律：本课每条探针输出都要能追到 image_id、解码配置和阈值，和当时追 logits 是同一类审计。第 17 课的可验证奖励则是后训练版的同一思想：能执行的判定比「看起来对」优先；POPE 的 Yes/No 和 IoU 阈值就是视觉侧的可验证器。需要时读[第 17 课](17_grpo_rlvr.md)的 verifier 段落，不要在本课重做 GRPO。

本课术语：

| 术语 | 简要解释 |
|---|---|
| 指代表达（referring expression） | 用短语或句子唯一指定图中一个物体，常伴随框或点 |
| 短语接地（phrase grounding） | 把字幕里多个名词短语分别对应到图中区域 |
| 位置 token（location token） | 把连续坐标离散成词表里的编号，和文字一起做 next-token |
| IoU | 预测框与真值框的交并比；本课默认阈值 0.5 |
| grounding 命中 | IoU 过线，或注意力质量分数落在物体 mask 上 |
| OCR 作为定位 | 先找到字形所在像素，再读出字符串；配文里出现该字符串不算 |
| POPE | 轮询式物体探针：把幻觉写成「图里有没有 X」的是非题 |
| CHAIR | 在生成的配文里统计提到但不在图中的物体比例 |
| Set-of-Mark（SoM） | 在区域上叠可读编号，让模型说编号而不是吐连续坐标 |
| 语言先验 / 共现 | 不看图也能从「餐桌旁边常有酒杯」这类统计写出答案 |

## 2. 本课解决的问题

当前系统（以及你按第 22 课训出的任何 VLM）默认验收是文字对不对。TextVQA、DocVQA、普通 VQA 都是这个口径。它解决不了四类失败，而且这四类会在报告里被均分盖住：

1. 指代失败：问题里的「左边那只」「戴帽子的人」被绑定到错误物体，答案词汇碰巧仍对。
2. OCR 失败：金额、牌照、界面文字被语言模型猜出来，对应字形区域没有被覆盖。
3. 空间失败：左右颠倒、前后不分、计数靠「常见是两个」而不是一个一个点。
4. 存在幻觉：物体不在图中，模型仍高置信说「有」。

本课的改造范围只包括评测协议、记录字段和一小段可手算的命中公式。不更换视觉编码器，不重做[第 02 课](02_multimodal_connector.md)的三种 connector，不重训第 08 课的切片器。若你要在真实模型上加位置 token 或点选头，那是第 13 节的改造实验，不是本课主路径的验收。

以下结果不能支持「模型会看位置」：

- 只报 VQA 或多项选择均分，没有框、点、编号或注意力质量分数；
- OCR 只报 BLEU / CIDEr 或「答案字符串出现在生成里」，没有区域；
- 幻觉只凭配文观感，没有固定题干的是非探针，也没有负例分母；
- 左右题没有声明参照系（观察者左还是物体左）；
- 把第 08 课动态分辨率带来的 OCR 上涨，直接写成 grounding 上涨。

执行顺序固定：先在 CPU 夹具上证明公式可复核，再在 8×8 教学网格上亲眼看到「答案对、格子错」，最后如果有 GPU，才把同一套探针接到开源权重上。没有 GPU 时，前两步已经构成完整交付。

## 3. 开始前需要准备什么

本课可以在没有 GPU 的机器上读完并跑通 CPU 实验。开始前在实验记录里分开写明上游事实和本课约定。

**上游事实：**

- 第 21 课给出图文共享空间，本课用它解释「为什么不看图也能写出物体名」：对比学习见过的共现，会变成问答时的语言先验。
- 第 22 课给出冻视觉、训投影、再解冻语言模型的顺序。指令微调若只用短答案 VQA，模型会学「写出像答案的词」，不一定学「指出答案在哪」。
- 第 08 课若已做过，保留动态分辨率前端；本课所有 OCR 探针必须在「encoder 实际看见的像素」上算，不要先把原图缩到糊掉再谈读字失败。
- 公开实现与论文以第 14 节为准，数字全部来自已打开的原文表或段落。

**课程约定：**

- 教学模拟的 8×8 网格和 CPU 夹具使用固定物体布局，不代表任何发布模型的成功率。
- IoU 阈值默认 $0.5$，与 Kosmos-2、Grounding DINO 在指代表达理解（referring expression comprehension, REC）里的常用判定一致。改阈值必须单列，不得和 $0.5$ 混报。
- 幻觉率的分母只包括「物体不在图中」的题。把「Yes 比例」当成幻觉率记为协议错误。
- 产出目录约定为 `artifacts/lesson23/`。CPU 实验在编排者注册后可用 `python3 run.py run 23` 写入该目录；注册前可直接调用 `lesson_23.run()` 复核。

只读本课、不训模型时，仍需交：公式手算、8×8 两则反例截图或文字记录、分项报告空表。这条支线标记为 `protocol-only`，不能写成「复现了 Kosmos-2」。

建议花在各节上的时间：第 1–4 节约 45 分钟建立口径；第 5 节机制约 3 小时，公式要手算一遍 IoU 和幻觉率，不要只看数字；第 6 节公开实现约 1 小时，打开仓库确认特殊符号；第 7–12 节边跑边写报告约半天；第 13–14 节读论文按「带着什么问题读」打勾，Kosmos-2 与 POPE 必读，Qwen2-VL 的 OCR/指称表必对原文，SoM 与 Molmo 可按你是否做第 32 课和第 24 课决定精读深度。没有 GPU 的人到第 12 节就可以停，第 13 节的改造实验标 `deferred`。

硬件分层写进记录，避免和论文卡时搅在一起。读课文和 CPU 实验：一台笔记本即可，本课夹具无网络、无 GPU、无文件副作用。教学网格在浏览器里跑，标了「教学模拟」。评 2B 级开源 VLM：1×24GB 通常够 greedy 解码加 120 条探针，不够微调 loc 头。Kosmos-2 原文 256 张 V100、约一天、6 万步、约 250 亿 token，那是他们的预训练，不是你的作业。Grounding DINO-T 原文在 16 张 V100、总 batch 32 上训；L 版 64 张 A100。本课若用官方权重当提议器，属于推理，写清 checkpoint 名即可，不要把 52.5 AP 抄成你训出来的。

## 4. 完成后应具备的能力

完成后，拿到任意「看起来答对了」的样例，你应能完成以下检查：

1. 写出预测框与真值框的 IoU，并按阈值判定命中；
2. 在与图像同尺寸的注意力图上，计算落在物体 mask 上的质量分数；
3. 构造或识别一例「VQA 对、对被问物体命中失败」；
4. 按随机 / 热门 / 对抗三种负采样各出若干「图里有没有 X」；
5. 只在负例上计算幻觉率，并解释它为什么不等于 Yes 比例；
6. 把 OCR 题拆成「区域」和「字符串」两列，字符串对但区域错记为失败；
7. 声明左右题的参照系，并准备左右翻转对照；
8. 说明 Set-of-Mark 把回归坐标改成分类编号之后，低分辨率下哪一项更稳；
9. 指出第 24 课的动作 token 和第 32 课的屏幕点击，分别复用本课哪一条探针。

第 24 课会把「抓住杯子」写成动作 token 或技能名。若本课列联表右上格很大，VLA 会在抓错杯子的同时得到「任务成功」的语言描述。第 32 课把屏幕控件编成 SoM 编号：本课 5.8 的编号碰撞、认错号、低分辨率回归变差，都会原样出现在按钮上。带着列联表和负例进那两课，比带着一个 VQA 均分进那两课便宜得多。

完成能力第 1 到 4 条可以在纸上验收：拿 CPU 实验打印出的 `known_iou` 应等于 $1/7$，幻觉率应等于 $3/4$，Yes 比例应等于 $5/6$。第 5 到 7 条在教学网格上验收：颜色题高先验必须答案对格子错，存在题高先验必须幽灵肯定。第 8 条口头能讲清 SoM 把回归改成分类即可。第 9 条写进报告最后一段，点名第 24 课用物体锁动作、第 32 课用编号锁点击。漏掉第 3 条（构造答案对命中失败）等于本课没上。

## 5. 原理:边造边讲

九个机制，每个按同一节奏：为什么需要、怎么运转、精确定义、在公开实现哪里、怎么证明做对了。

### 5.1 指代表达怎样变成位置 token

语言模型本来只会吐字。要让它指向「戴蓝安全帽的人」，一种办法是把框也变成字。Kosmos-2（[arXiv:2306.14824](https://arxiv.org/abs/2306.14824)）把指称写成 Markdown 超链接：短语写在方括号里，框写在随后的圆括号里，论文记作「text span 链到 bounding boxes」。连续坐标先离散成位置 token，再和文字共用下一词预测。

设图像宽 $W$、高 $H$，宽高各切成 $P$ 段，得到 $P\times P$ 个箱子。Kosmos-2 取 $P=32$，词表增加 $32\times 32=1024$ 个位置 token，图像分辨率 $224\times 224$、patch $14\times 14$，每个箱子对应 $7\times 7$ 像素。箱子中心代表该箱子内的坐标。一个框用左上角位置 token 和右下角位置 token 表示，外加边界符：

`<box><loc1><loc2></box>`

多个框用 `<delim>` 连接。短语本身用 `<p> ... </p>` 包起来，告诉模型这段文字和后面的框是一对。输入里还会放 `<grounding>`，提示「这次请把输出接到图上」。这套格式的代价是量化误差：物体中心若落在箱子边界附近，离散后会跳到邻箱。类比写门牌号：你把街道划成 32×32 的格子，只报格子编号，不报厘米级坐标。类比失效处：门牌对导航够用，对「杯耳朝向哪一边」这种细结构不够用，后面 5.8、5.9 会改用编号标记或连续点。

数据从哪来。Kosmos-2 构造 GrIT：从 LAION-2B 与 COYO-700M 的子集抽图文对，用 spaCy 切名词块，再用预训练接地模型（文中以 GLIP 为例）预测框，置信度低于 $0.65$ 的丢掉，再用依存树把名词块扩成指称。最终约 9100 万张图、1.15 亿文本跨度、1.37 亿框，平均指称长度 4.7 个词（原文 Table 1）。抽象名词如 “time”“love” 会被滤掉，因为图里没有对应区域。

训练仍是因果语言模型。Kosmos-2 在 Kosmos-1 语料上加入接地图文对，batch 约 41.9 万 token（文本 18.5 万，原图文对与接地图文对 21.5 万，交错数据 1.9 万），训练 6 万步、约 250 亿 token，256 张 V100、大约一天，学习率升到 $2\times 10^{-4}$ 后线性降到 0，可训练参数约 1.6B。指令微调另加 1 万步，学习率 $1\times 10^{-5}$，并构造「给定短语生成框 / 给定框生成短语」模板。这些数字来自原文 §3.3 与 Appendix Table 7–8，本课不要求复现这次训练。

评测时模型必须吐出能解码成框的位置串；解码失败（例如只有一个 loc）记为负例。Flickr30k Entities 上 Kosmos-2 零样本 val / test 的 R@1 为 77.8 / 78.7（原文 Table 2）。RefCOCO / RefCOCO+ / RefCOCOg 零样本 val 准确率为 52.32 / 45.48 / 60.57（原文 Table 3）。RefCOCO 与 RefCOCO+ 来自双人游戏、指称更短，RefCOCO+ 还故意去掉「在左边」这类空间词；RefCOCOg 更长、含空间关系。Kosmos-2 在 RefCOCOg 上相对更好，说明短游戏口令（“left bottom”）和带修饰的长指称不是同一分布。你自己的探针若只抽样短词，会漏掉长指称能力，也会高估「会说 left」就是会看左边。

验证：在 CPU 实验里不训 1.6B 模型，只检查「离散框到连续框再到 IoU」这条链可逆且边界清楚。真实模型侧，若位置串经常解不出两个 loc，先查特殊符号是否进了词表，再查 `<grounding>` 是否在推理时被丢掉。

把离散公式写进笔记，避免实现时用错 $P$。箱子沿宽的索引 $i\in\{0,\ldots,P-1\}$，中心像素 $x=(i+0.5)\,W/P$，高同理。Kosmos-2 原文：$W=H=224$，$P=32$，每箱 $7\times 7$。一个框需要两个箱子索引，顺序是左上、右下。若模型只吐一个 loc，无法还原矩形，按负例计。若吐出的左上在右下右边，也当解码失败，不要自动对调后算 IoU，否则你在帮模型改答案。多框时 `<delim>` 分隔，评测短语接地才需要多个框；REC 只用第一个框，这是 Kosmos-2 §4.1.2 的规则，你的 REC 桶照抄，短语桶才用 R@k。

GrIT 的流水线决定了噪声长什么样。名词块来自 spaCy，框来自 GLIP，阈值 0.65，再 NMS 去重叠。指称靠依存树把子节点拼回名词块，「a dog」扩成「a dog in a field of flowers」，框仍用狗的框，不用草地的框。于是数据里会有「短语比框更大」的系统性偏差：语言描述了场景，框只罩主体。你用合成数据时若短语和框严格同一物体，分布比 GrIT 更干净，Hit 会更好看，迁移到网络图片时会掉下来。报告里写清训练指称是「紧框」还是「带场景修饰」。指令微调阶段 Kosmos-2 还用模板让模型根据框生成短语、根据短语生成框，两种方向都要有，否则只会单向接地。

Flickr30k Entities 的评测输入带上文。短语「orange safety vest」的提示是「A man in a blue hard hat and \<p>orange safety vest\</p>」，上文用来消歧。你的最小探针如果把短语从句子里抠出来单独问，难度会高于该论文设定；若你想对照 Table 2，提示必须带上文。REC 则相反，整句指称单独作为 `<p> ... </p>`，没有额外 caption。两种任务不要共用同一条提示模板。

### 5.2 用 IoU 定义 grounding 命中

框对框，最常用的重合度量是交并比。预测框 $B_{\mathrm{pred}}$ 与真值框 $B_{\mathrm{gt}}$ 都写成 $(x_1,y_1,x_2,y_2)$，约定 $x_2>x_1$、$y_2>y_1$：

$$
\mathrm{IoU}(B_{\mathrm{pred}}, B_{\mathrm{gt}})
= \frac{|B_{\mathrm{pred}} \cap B_{\mathrm{gt}}|}{|B_{\mathrm{pred}} \cup B_{\mathrm{gt}}|}
$$

交集宽高若为负，面积记 0。并集是两框面积之和减去交集。Kosmos-2 与多数 REC 设定把一次预测算对，当且仅当 $\mathrm{IoU}\ge 0.5$。写成指示函数：

$$
\mathrm{Hit}_{0.5}
= \mathbf{1}\bigl[\mathrm{IoU}(B_{\mathrm{pred}}, B_{\mathrm{gt}}) \ge 0.5\bigr]
$$

若一次生成多个框，短语接地常用 R@k：前 $k$ 个框里只要有一个命中就算该短语召回。Kosmos-2 在 Flickr30k Entities 上 R@1 / R@5 / R@10 几乎一样（val 77.8 / 79.2 / 79.3），作者将其解释为模型没有靠大量冗余框刷召回。你若看到自己的 R@10 远高于 R@1，先查是不是把 10 个近乎重复的框都算上了。

IoU 有几条必须手算的边界，CPU 实验都覆盖了：

- 两框相同，IoU $=1$；
- 无重叠，IoU $=0$，边相贴面积仍为 0；
- 边长 2 的正方形与错开 1 的同尺寸正方形，交集面积 1、并集 7，IoU $=1/7$；
- 阈值是闭区间：恰好 $0.5$ 算命中，略低算未命中。

VQA 准确率是另一条轴：

$$
\mathrm{Acc}_{\mathrm{VQA}}
= \frac{1}{N}\sum_{i=1}^{N}
\mathbf{1}[\hat{y}_i = y_i]
$$

钉死协议：报告必须同时列出 $\mathrm{Acc}_{\mathrm{VQA}}$ 与 $\mathrm{Hit}_{0.5}$ 的列联表，禁止只交均分。四格是：

|  | 命中 | 未命中 |
|---|---|---|
| VQA 对 | 真看见 | 语言或同色捷径 |
| VQA 错 | 看对地方但说错词 | 双重失败 |

「答案对、格子错」落在右上格。没有这张表，均分会把右上格洗成成功。

验证：CPU 夹具里两只红杯子，问题「左边杯子什么颜色」，答案 `red` 与标签相同，预测框却在右边杯子上，对被问杯子 $\mathrm{IoU}=0$。`vqa_accuracy_is_not_grounding_accuracy` 必须为真。

手算一遍，避免把 IoU 写成「看着眼熟就对」。被问杯子框 $B_L=(8,8,24,28)$，宽 16、高 20、面积 320。模型框落在右杯 $B_R=(72,40,90,62)$，宽 18、高 22、面积 396。两框无交集，交集面积 0，并集 716，$\mathrm{IoU}=0$，未命中。若模型框与左杯完全重合，IoU 为 1。若模型框是 $(0,0,2,2)$、真值是 $(1,1,3,3)$，交集是边长 1 的正方形、面积 1，两框面积各 4，并集 7，$\mathrm{IoU}=1/7$。阈值 $0.5$ 是闭的：面积为 2 的两个框，沿 $x$ 错开 $2/3$，交集 $4/3$、并集 $8/3$，IoU 恰好 $0.5$，记命中；再错开一点掉到 $0.5$ 以下，记未命中。CPU 实验把这四条都写成 `checks`，改公式时必须一起改测试，禁止只改课文。

Grounding DINO 的框回归还用 GIoU。当两框不相交时 IoU 恒为 0，梯度消失，优化器无法知道「离得远」和「差一点点没碰上」的差别。GIoU 在最小外接矩形 $C$ 上补一项：

$$
\mathrm{GIoU}
= \mathrm{IoU}
- \frac{|C\setminus(B_{\mathrm{pred}}\cup B_{\mathrm{gt}})|}{|C|}
$$

不相交时 GIoU 为负，离得越远越负。本课验收仍用 IoU 阈值 0.5 判定命中，GIoU 只出现在训练损失里。你若复现 Grounding DINO 的匹配代价，原文把分类 / 框 L1 / GIoU 的匹配权重设为 2.0 / 5.0 / 2.0，最终损失权重为 1.0 / 5.0 / 2.0。不要把匹配权重和损失权重抄反，抄反后匈牙利分配会偏向分类分而放过框。

记录一条样本至少包含这些字段：`image_id`、`question`、`answer_pred`、`answer_gt`、`box_pred`、`box_gt`、`iou`、`hit`、`vqa_correct`、`cell_or_token_ids`。缺 `box_pred` 时允许改填 `point_pred` 或 `attn_mass`，但三者不能全空。全空的行在列联表里只能进「未测」，不能进「命中」。

### 5.3 Grounding DINO：检测器路线上的开集接地

VLM 把框塞进词表，是「语言生成路线」。另一条路线是检测器：输入图和文本，直接输出一批框和短语对齐分数。Grounding DINO（[arXiv:2303.05499](https://arxiv.org/abs/2303.05499)）把 DINO 检测器和接地预训练拼在一起，声称可按类别名或指称检测任意物体。

它把闭集检测器拆成三截，并在三截都做视觉-语言融合（原文 Figure 2 的 phase A/B/C）：

1. 特征增强器（neck）：图像 deformable 自注意力、文本自注意力，再加图到文、文到图交叉注意力；
2. 语言引导的 query 选择：用 $\mathbf{X}_I\mathbf{X}_T^{\top}$ 取每张图特征对文本的最大相似度，再取 top $N_q$ 个作为解码器 query，$N_q=900$，$d=256$；
3. 跨模态解码器（head）：每层在图像交叉注意力之外再加一层文本交叉注意力。

文本侧不用整句一个向量，也不让所有类别名互相看见。作者引入 sub-sentence 注意力掩码：类别名之间不互看，类别内部的词仍保留，避免把「cat dog car」当成一句语法通顺的话。损失与 DETR 同类：框回归用 L1 和 GIoU，分类用 query 与文本 token 的点积加 focal loss，匈牙利匹配后再算同样三项。辅助损失加在每层解码器和编码器输出上。

数字只引原文表。Grounding DINO-L（Swin-L，预训练 O365 + OpenImages + GoldG）在 COCO 上零样本 52.5 AP，即训练未使用 COCO 训练划分（原文摘要与 Table 2）。ODinW 零样本 mean AP 26.1（原文摘要与 Table 4）。指称理解上，Swin-T、O365+GoldG、未加 RefC 时 RefCOCO val 为 50.41；加入 RefC 后升到 73.98，再微调到 89.19（原文 Table 5）。作者明确写：现在的开集检测器若不看 REC 数据，细粒度指称零样本仍然弱。结论里也承认会在部分情况下产生假阳性，需要更多数据或技术压幻觉。

这条路线和 Kosmos-2 的差别，写进你的实验记录里：检测器输出的是框分数，VLM 输出的是词。检测器的「假阳性」对应 VLM 的「说出不存在的物体」。两边都要有负例。Grounding DINO 不能替代本课的 VQA 脱钩探针，因为它默认任务就已经是出框；它能替代的是「需要一个强开集提议器」时的外挂。第 5.8 节的 SoM 就会用这类分割/检测模型先画区域，再让 VLM 读编号。

验证：消融表（原文 Table 7）去掉编码器融合后，LVIS minival 零样本从 16.1 降到 13.1 AP。你若自己接 Grounding DINO 权重做提议器，至少记录 backbone、预训练数据组合、是否含 RefC/COCO，禁止把「52.5 AP」写到未使用 Swin-L 和对应数据的 run 上。

语言引导 query 选择写成矩阵更好记。图像特征 $\mathbf{X}_I\in\mathbb{R}^{N_I\times d}$，文本特征 $\mathbf{X}_T\in\mathbb{R}^{N_T\times d}$，$N_I$ 常超过一万，$N_T$ 小于 256。相似度矩阵 $\mathbf{X}_I\mathbf{X}_T^{\top}$ 对文本维取最大，再取 top $N_q=900$ 个图像位置当解码器 query。位置部分用编码器输出的动态锚框初始化，内容部分可学习。这一步已经在用文本挑「该看哪」，和 VLM 里答案 token 对视觉的注意力是亲戚：都在做语言条件的空间选择。差别是检测器强制输出 900 个框再匹配，VLM 只为当前生成步看一块。假阳性在检测器里表现为高分空框，在 VLM 里表现为说出不存在的名词。POPE 打的是后者；对前者要用未匹配的高分框计数，Grounding DINO 结论里承认这个问题仍然存在。

sub-sentence 掩码值得单独测一次。把类别名拼成「cat dog car」送进 BERT，若词与词之间互相看见，「dog」的向量会被「cat」污染。掩码让不同类别之间的注意力为 0，类别内部仍连通。Table 7 的 word-level 变体在 LVIS 上掉 0.5 AP。你若用 Grounding DINO 给 SoM 提区域，保持官方掩码；关掉它再报 ODinW 26.1 属于口径错误。ODinW 含 35 个以上数据集，作者同时报平均 AP 和中位数 AP：Grounding DINO-T 加 Cap4M 后平均 22.3、中位数 11.9，GLIPv2-T 平均同样 22.3、中位数 8.9。中位数低说明少数数据集拉高了平均。你的 20 张图连这张表的边都摸不到，不要把 ODinW 数字抄进 MiniMind 段落。

### 5.4 OCR 作为定位，而不是配文

OCR 在第 08 课是「分辨率够不够」的压力测试：固定缩放会糊小字，动态切片应该先在 OCR 桶上涨。本课换一个问题：即使分辨率够了，模型是在读那几个字形，还是在用语言模型补一个像金额的数字？

把 OCR 写成两个随机变量。区域 $R$ 是字形所在像素集合（框、多边形或 mask），字符串 $s$ 是要读出的文本。一次预测 $(\hat{R},\hat{s})$ 只有同时满足区域命中和字符串匹配才算对：

$$
\mathrm{Hit}_{\mathrm{OCR}}
= \mathbf{1}\bigl[\mathrm{IoU}(\hat{R}, R)\ge \tau\bigr]
\cdot \mathbf{1}[\mathrm{match}(\hat{s}, s)]
$$

$\mathrm{match}$ 可以是精确匹配，也可以是第 08 课用过的 ANLS（基于编辑距离的宽容分）。禁止的替代品：

- 只看 $\hat{s}$ 是否出现在整段生成里（配文里抄到了数字）；
- 只用 CIDEr / BLEU 打整句描述；
- 先把原图缩到 224，再抱怨 OCR 失败（那是第 08 课的分辨率问题，应单列）。

Qwen2-VL（[arXiv:2409.12191](https://arxiv.org/abs/2409.12191)）把 OCR 和文档理解当作独立能力来测，而不是当成 caption 的附属。原文 Table 2：DocVQA test 上 72B / 7B / 2B 为 96.5 / 94.5 / 90.1；OCRBench 为 877 / 866 / 809；TextVQA val 为 85.5 / 84.3 / 79.7；InfoVQA test 为 84.5 / 76.5 / 65.5。这些是文档/自然图文字理解分数，原文没有把它们拆成「区域 IoU × 字符串」两列。你引用时必须写任务名和模型尺寸，不能把 96.5 说成「Qwen2-VL 的 OCR 命中率」，更不能把它当成 MiniMind-O 的预期。

Qwen2-VL 如何表示框：坐标归一化到 $[0,1000)$，写成 `(x_tl, y_tl), (x_br, y_br)`，用 `<|box_start|>` / `<|box_end|>` 包起来，短语用 `<|object_ref_start|>` / `<|object_ref_end|>` 标记（原文 §2.2.1 Visual Grounding）。这和 Kosmos-2 的 32×32 位置 token 是两种离散法：一个是千分尺刻度，一个是 $P\times P$ 箱子。两者都把定位变成可训练的离散符号。

Qwen2.5-VL（[arXiv:2502.13923](https://arxiv.org/abs/2502.13923)）改了坐标协议：不再归一化，直接用输入图像的实际宽高写框和点，让模型学习尺度（原文 §2.1.2）。文档侧把版面、表格、公式等写成带框的 HTML（原文 Document Omni-Parsing）。Table 5：Qwen2.5-VL-72B 的 DocVQA test 96.4、InfoVQA 87.3、OCRBench 885。空间侧 Table 6：RefCOCO val 92.7；CountBench 上 72B 用「先检测再计数」式提示得到 93.6（Table 7）。这些数字说明：公开配方已经把「框/点/读字」当成一等公民。你的缩小版没有这些数据，就不要用均分假装有同样能力，要用探针把缺失暴露出来。

验证：同一张发票，问「总金额是多少」。记录三列：字符串、预测框、与金额栏真值框的 IoU。字符串对、IoU 低于阈值，记 OCR 定位失败。若你没有金额栏标注，至少用规则框出印刷数字再算重合；没有区域列的 OCR 表，本课验收视为缺项。

把发票拆成可重复的五步，和第 01 课的 trace 纪律同一精神：每一步都要能回放。

1. 保存原图像素哈希与宽高。后续所有框都在这张图的坐标系里，禁止中途 resize 却不改框。
2. 标出金额栏真值框。人工标一次，冻结成 json，禁止边看模型输出边改框。
3. 模型输出字符串 $\hat{s}$ 和框 $\hat{R}$（或点）。没有框就记 `box_missing`。
4. 计算 $\mathrm{match}(\hat{s}, s)$。精确匹配是默认；若用 ANLS，沿用第 08 课口径：按规范化编辑距离给部分分，并在报告里写「ANLS」，不要和 exact match 混在同一列。
5. 计算 $\mathrm{IoU}(\hat{R}, R)$。两列都过线才进 OCR 命中；任一列失败，案例进入诊断表的对应行。

一个典型假成功：图里金额是 128.00，旁边有「满 128 减 20」的促销文案。模型输出 128.00，字符串对了，框却盖在促销文案上。语言先验在这里的形状是「发票问答常见金额在右下」，促销条也在右下，于是答对了字、看错了栏。列联表右上格在 OCR 桶的名字就叫这个。

Qwen2-VL 原文把 DocVQA、InfoVQA、ChartQA、TextVQA、OCRBench、AI2D 分开报，正是因为「文档里的字」「信息图里的字」「自然场景里的字」「科学示意图里的字」会在不同分辨率和不同语言先验下分别塌掉。你的 20 张最小探针至少要跨出自然图和合成票据两档；全是 COCO 人像，OCR 桶等于没做。MTVQA 上 Qwen2-VL-72B 为 30.9、GPT-4o 为 27.8（原文 Table 2），内部多语 OCR 表（Table 3）里韩/日/法/德/意/俄/越多数高于 GPT-4o、阿拉伯语 70.7 低于 GPT-4o 的 75.9。本课不要求多语，但若你的用户界面是中文，探针必须含中文招牌和中文票据，不能用英文 TextVQA 分数代替。

### 5.5 空间关系：左/右、前/后、计数

「左边是什么」看起来像小学题，对 VLM 却叠了三层歧义。

第一层是参照系。观察者左边（图像坐标系 $x$ 较小）和物体自身的左边（物体朝向的左侧）不是一回事。镜子、车辆、人物侧面会把两套坐标撕开。协议必须写死：本课默认「左」= 图像坐标系 $x$ 较小的一侧，即观察者左。若题目用「他的左手边」，另开一桶，不要和观察者左混算准确率。

第二层是主语。问「香蕉左边是什么」，模型可能把「香蕉」当成答案而不是锚点，于是输出香蕉自己。交互实验里高先验时，玩具模型仍写出「苹」，使用的格子却是香蕉：答案词对了，锚点物体没换成左边那一格。这是 5.2 列联表右上格在空间题上的版本。

第三层是计数。计数可以靠语言先验（「桌上常见两只杯」），也可以靠一个一个点。Molmo（[arXiv:2409.17146](https://arxiv.org/abs/2409.17146)）把点选做成一等数据：PixMo-Points 含 230 万问-点对、来自 22.3 万张图，包含「目标不在图中」的负例，并让模型按从上到下、从左到右的顺序吐点，再用点数当计数（原文 PixMo-Points 与 §4 Fine-tuning）。点坐标写成 $0$ 到 $100$ 的纯文本。Table 1：Molmo-72B 的 CountBenchQA 为 91.2，自建 PixMo-Count test 为 85.2。消融写明：先点后数优于只出数字，乱序点不如固定空间顺序。Qwen2.5-VL-72B 在 CountBench 上用 detect-then-count 提示达到 93.6，原文同时给出 Gemini 1.5 Pro 85.5、GPT-4o 87.9、Claude 3.5 Sonnet 89.7、Molmo-72B 91.2（Table 7）。不要把这些数写进 MiniMind-O 的预期；要写进探针设计：计数题必须保存「点或框的集合」，只保存一个整数不算接地。

前后（occlusion / depth）比左右更脏，因为单张 RGB 没有深度。本课只要求：若你出「前面那只」，真值必须能从 2D 遮挡或明确图层得到；否则把该题移出主表，标成无深度的不可判定。不要用语言模型对「前后」的常识来代替像素证据。

Qwen2-VL 在 REC 上的通才数字（原文 Table 6）：72B 的 RefCOCO val / test-A / test-B 为 93.2 / 95.3 / 90.7，7B 为 91.7 / 93.6 / 87.3，2B 为 87.6 / 90.6 / 82.3。RefCOCO+ 去掉空间词，72B val 仍有 90.1，说明它不只靠「left/right」字面。你的缩小版若在「含左/右的题」上很高、在 RefCOCO+ 风格（纯外观、禁止空间词）上崩溃，应记为「会读空间词，不会绑外观」，不要写成「空间能力已具备」。

RefCOCO 的 testA / testB 也要分列。testA 偏人、testB 偏其他物体，不少论文两列差距到 5–10 个百分点。Kosmos-2 零样本 RefCOCO testA 57.42、testB 47.26；Grounding DINO-T 在 O365+GoldG 上零样本 testA 57.24、testB 43.21。你的 20 张图如果全是杯子，相当于只做了某一列。最小探针里左右题至少一半锚点不是杯子：人、车、文字牌都行。前后题若没有遮挡证据（谁挡住谁的像素），标 `unjudgeable`，不要用「餐桌上前面那只」这种自然语言常识当真值。

计数题的集合真值用格子集合或点列表。3 个红杯的真值是三个中心点，顺序按从上到下、从左到右，与 Molmo 的训练约定一致。模型若输出 3 但只点了两个，整数准确率为 1、集合召回为 $2/3$，报告两列。只报 3 会把「会说三个」写成「数过三个」。Qwen2.5-VL 的 detect-then-count 是先框后数，Molmo 是先点后数，你的日志里用 `count_mode: box|point|integer` 区分，三种模式的分母不同，不能平均成一个计数分。

验证：8×8 网格里苹果在香蕉左侧。问「香蕉左边是什么」。真值格子是苹果。若答案是「苹」但使用格子是香蕉，记空间命中失败。左右翻转图像后，答案应跟着翻；若答案不变，模型没在用 $x$ 坐标。

### 5.6 POPE：把幻觉写成是否存在

自由配文里数幻觉，会把「话多」和「看见不存在的物体」缠在一起。CHAIR（Caption Hallucination Assessment with Image Relevance）在配文里统计提到但不在图中的物体：

$$
\mathrm{CHAIR}_I
= \frac{|\{\text{被提到但不在图中的物体}\}|}{|\{\text{配文中提到的全部物体}\}|}
$$

$$
\mathrm{CHAIR}_S
= \frac{|\{\text{含幻觉物体的配文}\}|}{|\{\text{全部配文}\}|}
$$

POPE 论文（[arXiv:2305.10355](https://arxiv.org/abs/2305.10355)，EMNLP 2023）在 MSCOCO 上用 CHAIR 测了一批 LVLM，并指出两个问题：同一语义的指令会把 CHAIR 翻倍；CHAIR 还跟生成长度缠在一起。原文 Table 1，指令 $I_1$「Generate a short caption of the image」下 LLaVA 的 $\mathrm{CHAIR}_S=32.7$、平均长度 64.3；指令 $I_2$「Provide a brief description of the given image」下 $\mathrm{CHAIR}_S=62.7$、长度 90.7。InstructBLIP 两档指令下 $\mathrm{CHAIR}_I$ 为 2.6 和 2.5，长度约 8，幻觉少但配文也短。不能据此说 InstructBLIP「更诚实」而 LLaVA「更差」而不提长度。较小的 VLPM（OSCAR Base $\mathrm{CHAIR}_S=13.0$，VinVL Large $10.5$，OFA Large $8.9$，BLIP Large $8.8$，数字转引自该文 Table 1）在短配文设定下 CHAIR 更低，说明「更大、会聊天」并不自动减少物体幻觉。

POPE（Polling-based Object Probing Evaluation）把问题改成固定模板：「Is there a/an \<object> in the image?」答案只有 Yes / No。每张图出 $l$ 道题，正负例 1:1。负例三种采样：

- Random：从图中不存在的物体里均匀抽；
- Popular：抽全数据里最常见、但当前图没有的物体；
- Adversarial：抽与图中真值物体共现最多、但当前图没有的物体。

主指标用 Accuracy / Precision / Recall / F1，另报 Yes 比例。原文 Table 3，MSCOCO val、每图 6 题：InstructBLIP 随机档 F1 89.29、Yes 55.20%；热门档 F1 83.45、Yes 62.57%；对抗档 Accuracy 74.37、F1 78.45、Yes 68.97%。LLaVA 随机档 Accuracy 54.43、F1 68.65、Yes 95.37%；对抗档 Accuracy 50.77、Yes 99.10%。mPLUG-Owl 与 MultiModal-GPT 的 Yes 比例同样接近 100%。结论写在数字下面：这些模型几乎见题就说有，F1 被召回撑着，负例一变难就穿帮。从随机到热门到对抗，所有列出的模型都变差，和「常见物体、共现物体更容易被幻觉」的假说一致。

稳定性：原文 Table 4 换四种问法，LLaVA 的 POPE F1 平均 67.43±0.78；同一模型上 CHAIR$_I$ 换四种 caption 指令为 13.88±3.22。POPE 对措辞更稳，是因为它把输出锁成是否。可扩展性：没有人工框时可用 SEEM 等分割工具提物体再出题（原文 Table 5），排序仍是随机高于热门、热门高于对抗，但绝对 F1 会因分割更细而下降。一致性检查：InstructBLIP 对 1303 个答 No 的物体在配文里提到 0 次；MiniGPT-4 对 1445 个答 No 的物体在配文里提到 5 次。是非题和配文并非两套互不相干的人格。

SEEM 自动标注会带来标签集不一致。工具的类别表和 COCO 80 类对不齐时，POPE 的「不存在」可能是「工具没标到」而不是「图里真没有」。原文也承认这一点。本课最小探针坚持人工看一眼负例物体是否真的不在图里。20 张图做得到；500 张图才考虑自动分割，并且要抽检。抽检比例写进协议，建议至少 10%。自动标注的 POPE 与人工标注的 POPE 必须分列，Table 5 已经示范过两者 F1 有缺口，例如 MiniGPT-4 对抗档人工 71.37、SEEM 62.70。

幻觉率在本课的定义只使用负例：

$$
R_{\mathrm{hall}}
= \frac{|\{q: y=0,\ \hat{y}=1\}|}{|\{q: y=0\}|}
$$

Yes 比例是

$$
p_{\mathrm{yes}}
= \frac{|\{q: \hat{y}=1\}|}{|\{q\}|}
$$

CPU 夹具里 6 题、4 道负例、3 道假 Yes，则 $R_{\mathrm{hall}}=3/4$，$p_{\mathrm{yes}}=5/6$，两者不相等。检查项 `yes_ratio_is_not_hallucination_rate` 就是为这一行存在的。

POPE 原文 Table 6 还比较了幻觉探针和 VQA：InstructBLIP 在 A-OKVQA 上 VQA 59.68、随机档 POPE 87.20；MiniGPT-4 的 POPE F1 高于 LLaVA，VQA 却更低。作者的结论是：幻觉程度和 VQA 分数可以不一致，两套题都要测。这和本课 5.2 的列联表是同一纪律在「存在」轴上的版本。

不要把 Table 3 的 F1 写成「现代 VLM 的幻觉率」。那是 2023 年一组具体模型和 500 张 COCO val 图的结果。Qwen2-VL Table 2 报的是 HallusionBench 均分（72B 58.1，7B 50.6，2B 41.7），不是 POPE，不能换算。Qwen2-VL / Molmo 原文没有给出可对照的 POPE 表；没有表就不要编。

验证：交互实验里酒杯不在 8×8 网格中。先验 ≥ 0.55 时玩具模型对盘子给出高置信「有」。这是对抗负例的缩小版：负物体与真值物体（盘、叉、杯）共现。你必须先预测再揭晓，避免事后把「我早就看出来了」写进报告。

自己造 POPE 题本时，先做共现表再抽负例。对训练集或题本里每张图的物体集合 $O(x)$，统计

$$
c(u,v)
= |\{x: u\in O(x),\ v\in O(x)\}|
$$

对抗负例：取当前图的真值物体 $u$，选 $c(u,v)$ 最大且 $v\notin O(x)$ 的 $v$。热门负例：忽略当前图，取全局频次最高且不在图中的物体。随机负例：在词表里均匀抽不在图中的物体。三档必须用同一组正例，只换负例，否则 F1 差可能来自分母变化。正负 1:1 写进 jsonl 的 `label` 字段，禁止事后按模型输出重平衡。

把原文 Table 3 的 InstructBLIP 三档抄进笔记本当参照量级，不要当你的小模型指标。随机 F1 89.29、热门 83.45、对抗 Accuracy 74.37 / F1 78.45。LLaVA 随机档 Yes 95.37%，对抗档 Yes 99.10%，Accuracy 掉到 50.77，几乎等于全猜 Yes。你的 2B 开源权重如果 Yes 也超过 90%，报告第一句写「模型几乎拒绝答无」，第二句再写 F1。F1 被高召回抬起来的时候，Accuracy 和 Yes 比例比 F1 更诚实。

CHAIR 仍可作附录。配文「a cup, a plate, a wine glass, a fork」、图中物体 `{cup, plate, fork}` 时，$\mathrm{CHAIR}_I=1/4$。三条配文里只有第二条含 wine glass，则 $\mathrm{CHAIR}_S=1/3$。CPU 实验用这两条当公式夹具。主文不靠 CHAIR 做通过/失败判定，因为它对指令和长度敏感：同一 LLaVA，短 caption 指令 $\mathrm{CHAIR}_S=32.7$，长描述指令 $62.7$。

### 5.7 答案对、注意力在错物体上

框需要模型真的吐框。很多 VLM 只吐字。此时仍可定义一种不依赖框头的命中：看生成答案时，注意力质量有多少落在被问物体的 mask 上。

设图像被分成与注意力图同尺寸的格子，令 $a_i\ge 0$ 为格子 $i$ 的注意力权重（可来自跨模态层、某一头的平均、或 Grad-CAM 一类的归因；本课 CPU 实验直接给定 $a_i$），$\mathcal{M}$ 为物体 mask 上的格子：

$$
h_{\mathrm{att}}
= \frac{\sum_{i\in\mathcal{M}} a_i}{\sum_i a_i}
$$

$$
\mathrm{Hit}_{\mathrm{att}}
= \mathbf{1}[h_{\mathrm{att}} \ge \tau_a]
$$

默认 $\tau_a=0.5$。质量分数不是「最大响应在哪一格」：质量可以分散。双物体同色时，质量若大部分在干扰物上，$h_{\mathrm{att}}$ 对真值 mask 会低于阈值，而 VQA 仍然正确。

这套定义有三处必须写进局限，防止你把它当成脑成像：

1. 注意力不是因果。高 $h_{\mathrm{att}}$ 不证明模型「因为」这块像素才答对；低 $h_{\mathrm{att}}$ 在有些层也不证明没用视觉。本课只把它当作与 IoU 平行的可复核探针，负例（答案对、质量在错物体上）有诊断价值，正例不能单独当成功标准。
2. 层和头要固定。换一层数字会变。记录 `layer`、`head` 或「所有头平均」，禁止一次实验改三处还比大小。
3. resampler / Q-Former 会把空间分辨率打薄。第 02 课已经说明 query 压缩会先丢掉 OCR 和小物体。若你在 64 个 query 上算 mask 命中，必须先把 query 映射回原图像素；映射写不清，本探针作废。

CPU 夹具：8×8 权重在被问杯子 (0,1) 上只有 0.04，在另一只红杯 (4,2) 上 0.55，在盘子 (4,4) 上 0.31。被问 mask 的质量分数低于 0.5，干扰物 mask 最高。这就是「看见了红色，没看见被问的那一只」。

交互实验把同一现象做成格子高亮。颜色题在先验高时答案仍是「红」，使用格子却是杯 B。计数题答案可以仍是「2」，使用格子却是杯 B 加盘子：数字对了，集合错了。格子 IoU 定义为使用集合与真值集合的 Jaccard：

$$
\mathrm{IoU}_{\mathrm{cell}}
= \frac{|U \cap T|}{|U \cup T|}
$$

两边都空（是否存在题上正确答「无」）时记 1，避免 $0/0$。命中要求 $\mathrm{IoU}_{\mathrm{cell}}\ge 0.5$ 且不是幽灵肯定。

验证：验收必须找到这一例，不能只找到「完全答错」。完全答错太容易，教不会你读列联表。

### 5.8 Set-of-Mark：把坐标改成可读编号

连续坐标对语言模型不友好。GPT-4V 被要求直接吐框时，SoM 论文在一个 RefCOCO 子集上 ACC@0.5 只有 25.7；叠上编号后，同一套模型在 RefCOCOg REC 上到 86.4，RES mIoU 75.6（[arXiv:2310.11441](https://arxiv.org/abs/2310.11441) Table 2）。Flickr30K 短语接地上，编号+mask+框的 R@1 为 89.2。这些数字来自作者受 API 配额限制而子采样的验证集，原文 Table 1 写明每套约 100 张图，不能当成全量 SOTA。它仍然足够说明机制：给区域盖上模型「说得出」的标记，接地从回归变成分类。

做法分三步。用 SEEM / SAM / MaskDINO 等把图切成 $K$ 个区域；在每个区域上叠唯一编号（也可加框或半透明 mask）；把叠好的图送给 VLM，问句可以完全不提这些编号，模型仍可能自己引用。输出里的编号再映射回 mask，于是得到 $(r_k, m_k, \text{text}_k)$ 三元组。标记位置不能都放区域几何中心：重叠时要按面积从小到大分配，并用距离变换把编号挤到离边界最远的点。算术题、满屏数字的图不要再用数字当标记，改用字母，以免和画面内容撞车。

SoM 与 Kosmos-2 的位置 token、Qwen2-VL 的千分坐标，是三条把空间变成离散符号的路。SoM 的特殊之处是符号写在像素上，推理时由 OCR 式的读字能力去认，不要求训练时加 loc 词表。第 32 课会把它接到 GUI：可点控件先编号，再让模型输出要点哪一个。本课只要求你理解：低分辨率下回归 $(x,y)$ 的误差随格子变粗而变大，分类编号的误差是「认错号」，两种失败的曲线不同。交互实验的格子名「杯A」「杯B」就是 SoM 的缩影：模型若答「红」却高亮杯 B，等于认对了颜色、点错了编号。

局限也要写上。SoM 依赖外部分割好不好；漏区域则 GPT-4V 再强也选不中。原文用 GT mask 替换预测 mask 后，RefCOCOg mIoU 从 75.6 升到 90.1。本课教学网格没有分割误差，所以它不能证明你的真实分割链路。另外，开源 LMM 在原文定性里几乎认不出这些编号，作者认为规模和训练数据可能是原因，这不是本课能复现的结论，记下即可。

验证：同一 8×8，比较「输出格子坐标」和「输出物体名编号」。把网格从 8×8 改想像成 2×2 粗格子时，连续坐标会并掉左右物体，编号只要还印在物体上就可以分。第 13 节改造实验 3 会把这件事情做成可跑的小对照。

SoM 论文 Table 2 还给出了和专用模型的对照，读表时要看清哪些数字带星号。星号表示原论文在全量验证集上的数，本表其余行是作者因 GPT-4V 配额而子采样的约 100 张图。GPT-4V 加 SoM 在这份子集上：COCO 泛分割精度 75.7，ADE20K 开集分割 63.4，RefCOCOg REC 86.4 / RES mIoU 75.6，Flickr30K R@1 89.2，DAVIS2017 J&F 78.8。裸 GPT-4V 吐坐标的 REC 只有 25.7。LLaVA-1.5 在同一子集 REC 63.3。这些对照用来说明「会聊天的多模态模型」和「会接地」之间的缝，不能用来宣布 GPT-4V 已经超过 MaskDINO。教学网格没有分割模型，所以 Gate 只验收「答案列和格子列可以脱钩」，不验收 SAM 质量。

Qwen2-VL 的 Visual Agent 段把接地接到了手机 UI、ALFRED 和导航上（原文 Table 5）：AITZ 上 Type Match 89.6、Exact Match 72.1，高于表中 GPT-4o 的 70.0 / 35.3。那是第 32 课和机器人课的范围。本课只要记住：没有本课的框/点/编号列，那些 Exact Match 无从定义。UI 上的 Exact Match 就是接地命中换了个名字。

### 5.9 点选式接地：Molmo 与后训练里的绝对坐标

框是矩形，点是更便宜的监督。Molmo 的关键声明是：点选数据可以在不蒸馏闭源 VLM 的前提下采集。标注员指出物体、写描述、点完所有实例；另采「不在图中」；再把点当作解释传给纯语言模型改写答案。坐标归一到 $0$–$100$ 的纯文本，多点按空间顺序编号。计数变成链式：先点后数。AndroidControl 上 Molmo-72B 低层 / 高层准确率 88.7% / 69.0%，与该基准原文报告的 83.2% / 70.8% 同量级（Molmo 文 Evaluation 段）。本课只要这条机制：点比框便宜，负点（不在图中）直接服务 POPE 式负例。

Qwen2.5-VL 把框和点都做成绝对像素坐标，并构造含不存在类别、多实例和 PixMo 点选数据的 grounding 集（原文 Grounding Data with Absolute Position Coordinates）。Table 6 另报 ODinW 43.1、自建 PointGrounding 67.5（72B）。它和 Grounding DINO 的 55.0 ODinW（同表，检测器）仍有差距，说明通才 VLM 的开集检测还没取代专用检测器。你的报告若只有 VQA、没有点或框列，连进入这张表的资格都没有。

验证：CPU 实验不训练 Molmo。它只保证：当你有 mask 和注意力时，命中公式与「答案对」可以分开失败。真实点选评测留给有 GPU 的支线，使用公开权重，并写清提示是「先点后数」还是「只出数字」。

### 5.10 四条探针收成一张检查单

读到这里，机制已经够用来写检查单。检查单的用法是：每条模型输出先对号入座，再决定进哪一格，禁止「看起来挺对就过」。

| 探针 | 问什么 | 真值 | 成功 | 假成功 |
|---|---|---|---|---|
| 指代 / REC | 这句话指哪一块 | 框或点 | IoU 或点在 mask 内 | 说出正确类别但框在干扰物上 |
| OCR | 这块字是什么 | 区域 + 字符串 | 两列都过 | 字符串对、区域在促销栏或页眉 |
| 空间 | 左/右/计数 | 物体 id 或点集合 | 参照系正确且集合对 | 整数对、点空；或答案词对、锚点错 |
| 存在 / POPE | 有没有 X | Yes/No，负例三档 | 负例能拒、正例能认 | Yes 比例接近 100%，F1 虚高 |

检查单还有三条跨探针规则：

1. 同一张图可以同时进四条探针，但分数分列。一张餐饮图既问「左边杯子颜色」，又问「有没有酒杯」，又问「菜单第一行价格」。禁止把三个答案拼成一个「该图通过」。
2. 扰动一次只动一种。左右翻转只解释左右桶；遮挡被问物体只解释语言捷径；打乱 SoM 编号只解释编号有没有被读。把三种扰动同时加上去，失败了你不知道是哪一条。
3. 教学模拟、CPU 夹具、真实权重是三层证据。模拟证明你懂列联表；夹具证明公式可复核；真实权重证明协议能接到模型上。缺第三层时状态为 `protocol-only`，这是合法交付，只要不写成「已测开源 VLM」。

把检查单印在 `artifacts/lesson23/contingency.md` 的开头。后面的表只是这四行的展开。第 24 课的动作正确、视觉捷径，以及第 32 课的点击编号，都会再引用这张单子：动作或点击替换「答案」列，像素命中规则不变。

从检查单反推 MiniMind-O 现在缺什么，免得改造时盲目加模块。默认 MiniMind-O 的视觉路径是冻结 SigLIP2、固定 64 个 patch、MLP connector、文字 next-token，没有 loc 词表，没有点头，没有 POPE 题。所以主路径只能做三件事：用现成文字答案做 VQA 列；若你能取出注意力，做 $h_{\mathrm{att}}$；用外挂检测器或人工框做 IoU。前两件 CPU 和教学网格已经覆盖。第三件需要真实图。加 loc 词表属于第 13 节改造 1，不加就不准在报告里写「本系统会输出框」。外挂 Grounding DINO 权重当提议器是合法的，必须单列「外挂检测器」，不要写成 Thinker 自己吐的框。注意力若取不到（例如只部署了 API），本课允许只做框/点和 POPE，把 $\mathrm{Hit}_{\mathrm{att}}$ 标 `n/a`。四条探针不必同一天全绿，但缺哪条要写哪条，空白当成功是协议失败。

## 6. 在公开实现中定位这些机制

本课没有 MiniMind-O 里现成的 loc 词表或 POPE runner。对照放到公开仓库和本课夹具。读代码时带着「特殊符号有没有进词表、负例分母在哪」这两个问题。

Kosmos-2 发布页为 [https://aka.ms/kosmos-2](https://aka.ms/kosmos-2)。应对齐原文 §3.1 的符号：`<box>`、`</box>`、`<p>`、`</p>`、`<delim>`、`<grounding>`、`<loc*>`。推理路径必须能把 loc 序列还原成 $224\times 224$ 上的像素框；还原公式是箱子索引乘 $W/P$、$H/P$。若开源实现改了 $P$，IoU 表要重算，不能沿用论文数字。

Grounding DINO 代码在 [https://github.com/IDEA-Research/GroundingDINO](https://github.com/IDEA-Research/GroundingDINO)。应对齐三块模块名：feature enhancer、language-guided query selection、cross-modality decoder。Query 数 900、文本最大 token 256、BERT 文本塔、Swin 视觉塔。评测脚本若把检测任务的类别名直接空格拼接，应确认是否启用了 sub-sentence 掩码；关掉掩码就是原文 Table 7 的 word-level 变体。

POPE 代码与数据在 [https://github.com/RUCAIBox/POPE](https://github.com/RUCAIBox/POPE)。应对齐三种 jsonl：random / popular / adversarial，以及「Is there a/an … in the image?」模板。解析 Yes/No 的规则要固定：只匹配句首或独立词，不要在长句里搜到 “Yes” 就当肯定。Yes 比例必须和 F1 一起打日志。

Qwen2-VL 仓库 [https://github.com/QwenLM/Qwen2-VL](https://github.com/QwenLM/Qwen2-VL)。应对齐 `<|box_start|>` 与 `[0,1000)` 坐标。Qwen2.5-VL 技术报告改成绝对像素，两套权重不要混用同一后处理。文档 HTML 解析若启用，区域来自 HTML 属性，不要再跑一遍外接矩形当唯一真值而不加说明。

Molmo 说明与数据入口 [https://molmo.allenai.org/blog](https://molmo.allenai.org/blog)。应对齐点坐标 $0$–$100$ 和「先点后数」的提示模板。CountBenchQA 与 PixMo-Count 必须分列，后者更难、更偏自然图。

SoM [https://github.com/microsoft/SoM](https://github.com/microsoft/SoM)。应对齐：分割模型选择、编号绘制、编号到 mask 的反查表。没有反查表，模型说「9」你无法画回区域。

机制图 `lesson23Diagram` 把同一张图拆成文字答案、IoU 判定、POPE 三条边，汇到分项报告。读图时按步骤核对：输入是否同时流向视觉 token 和注意力；IoU 节点的说明是否写着阈值 0.5；POPE 节点是否强调负例；报告节点是否同时接收 Acc 与 Hit。若有人把 VQA 输出直接连到「成功」，那张图就画错了。本课事实栏四条都应对得上原文：IoU 0.5、列联表脱钩、POPE 负例分母、Kosmos-2 的 Markdown 超链接。

本课 CPU 夹具在 `experiments/src/learn_omni_experiments/lessons/lesson_23.py`：`iou`、`grounding_hit`、`attention_mass`、`hallucination_rate`、`chair_i`、`chair_s`。交互实验在 `web/components/labs/advanced/Lesson23GroundingLab.tsx`，先验阈值 $0.55$、幽灵置信度门槛 $0.8$ 写在模拟函数里，改了必须同步改课文。

读开源推理脚本时，按这个顺序打勾，漏一项就先别跑百分比：

1. 图像预处理是否与训练一致。Qwen2-VL 动态分辨率会改变 token 数；你若先把图压成 224 再送进声称「任意分辨率」的模型，OCR 桶的失败要记到预处理，不记到接地头。
2. 特殊符号是否在 tokenizer 里。loc、box_start、object_ref 若被切成普通子词，位置监督等于没加。打印一个编码后的 id 列表，确认它们是单 token。
3. 坐标还原函数的输入单位。Kosmos-2 是箱子索引，Qwen2-VL 是 $[0,1000)$，Qwen2.5-VL 是像素，Molmo 点是 $0$–$100$。三种数字长得像，混用一次 IoU 会系统性偏零。
4. 负例从哪来。POPE 仓库的三档 jsonl 已经分好；自己采样时必须保存随机种子和共现表版本。
5. Yes/No 解析器。模型可能输出「是的，图中有一个类似酒杯的器皿」。规则要预先写死：只认独立的 Yes/No/有/无，其余进 `unparsed` 桶，不进 Yes。把 `unparsed` 当 Yes 会人为抬高幻觉率。

第 02 课比较过 MLP / Resampler / Q-Former。本课不重做那组消融，但诊断时要记得：query 压缩会先丢掉小物体和字形。若你的 connector 是 16 个 query，注意力探针的空间分辨率只有 16 个槽，和 8×8 网格对不上。要么把 query 坐标映射回原图，要么改用框/点头，不要在 16 个槽上假装做了像素命中。

## 7. 数据与训练 recipe

主路径不训练大模型。若你要为探针造数据或做第 13 节的小改造，按下面配比记账。数据许可写进报告，不默认任何网页图片可训练。

**评测题本（必须）：**

| 桶 | 每图最少题 | 真值 | 负对照 |
|---|---|---|---|
| 指代 / 短语 | 1 条指称 + 框 | 框，IoU 0.5 | 同色干扰物、短口令 vs 长指称 |
| OCR 定位 | 1 个字符串 + 区域 | 区域 + 字符串 | 只对字符串不对区域 |
| 空间：左右 | 1 | 观察者左的物体 id | 左右翻转图 |
| 空间：计数 | 1 | 点集合或框集合 | 只对整数不对集合 |
| POPE 随机 | 正负 1:1 | Yes/No | Yes 比例 |
| POPE 热门 | 同上 | 同上 | 全数据频次表 |
| POPE 对抗 | 同上 | 同上 | 共现表 |

规模建议：CPU 教学用本课 8×8 即够。真实图像探针：每桶至少 50 图才能开始看方向，500 图才接近 POPE 原文抽样量（500 图 × 6 题）。少于 50 图只准写案例，不准写百分比。

**可选小训练（protocol-sft，非本课验收必需）：**

目标不在追论文数字。这一阶段只是让 MiniMind-O 或任意小 VLM 多一个 loc / 点头，便于你看见 Hit 从 0 变成非 0。

1. 投影层已按第 22 课对齐；本阶段只训「短语到框或点」的短序列，学习率低于指令微调主阶段。
2. 正例：短语与框；负例：图中不存在的短语，目标为「不存在」或空框，比例 1:1。没有负例，模型会学会见名词就画框。
3. OCR 正例必须带区域。合成票据可以自己渲染，许可标 CC BY 或内部自用。
4. 不要把 COCO 训练划分写进「零样本 COCO」报告。Grounding DINO 原文把含 COCO 的 60.7 AP 标了 $\ddagger$，你也必须这样标。

**禁止混进 recipe 的东西：**

- 用闭源 VLM 批量造 grounding 标注再写成「自研数据」，除非像 Molmo 那样明确走非 VLM 采集，并保存音频或操作日志；
- 把第 08 课 OCR 配比（文档倾斜）直接拿来当 grounding 配比：文档多只解决读字，不解决指代；
- 只训短答案 VQA，却在报告里写「已具备接地」。

合成数据的最低规格，避免你随手画两个色块就当 REC。画布 $256\times 256$；每张图 2 到 4 个互不重叠的矩形物体，边长 24 到 64 像素；同色双物体必须出现在不少于 30% 的图里；每张图写一条指称（含颜色或位置词）、一个 OCR 字符串（印在其中一个矩形上）、一条 POPE 负例（词表里有、图里无）。随机种子写入文件名。渲染脚本提交到 `artifacts/lesson23/synth/`，不提交 PNG 也可以，但 jsonl 必须能从种子重建。没有这一层，改造实验 1 的「Hit 从 0 变成非 0」无法复审。

正负例的比例写进配置而不是写进散文。REC 训练建议正:负 = 1:1，负例目标为 `<noobj>` 或空框，具体符号与词表一致即可，但必须在词表里占一个专用 id，不要复用 `none` 这种普通英文词。POPE 式 SFT 同样 1:1，对抗负例占比不少于负例的三分之一，否则模型只学会拒绝「斑马」这类和室内图无关的词，进不了酒杯这一档。OCR 负例用「邻栏文字」：金额栏旁边印促销数字，目标仍是金额栏。没有邻栏负例，字符串 CE 会鼓励模型看见 128 就输出 128，不管在哪一栏。

## 8. 按依赖顺序执行实验

实验 ID 前缀 `23`。一次只改一种探针或一种输入扰动。教学模拟和 CPU 夹具是必做；真实权重是可选。

### Step 0: 锁定公式与夹具

在 `experiments/` 目录运行本课 CPU 实验（编排者注册后）：

```bash
python3 run.py run 23
```

核对 `checks` 全为真。重点看：`vqa_correct_on_twin_cup_fixture`、`twin_cup_fixture_fails_queried_hit`、`hallucination_rate_is_three_quarters`、`yes_ratio_is_not_hallucination_rate`。把 `artifacts/lesson23/result.json` 的 metrics 抄进报告附录。这一步失败，后面所有百分比都没有单位。

### Step 1: 8×8 教学网格，先预测再揭晓

打开本课交互实验。默认先验 0.70、提问「颜色」。先选预测「答案对、格子错」，再揭晓。记录答案、使用格子、真值格子、置信度。再把提问换成「是否存在」，预测「物体不存在仍高置信答有」，揭晓。两条都勾上，验收才过。可选：点一个你认为模型会看的格子，对照揭晓后的使用集合。

把先验降到 0.40 以下，同一问应变成答案和格子一致。若低先验仍幽灵肯定，是模拟代码被改坏，不是发现了新现象。

### Step 2: 左右与计数桶（仍在网格上）

提问「左边是什么」，先验调高。预期：答案词可以是「苹」，使用格子是香蕉。提问「计数」，先验调高。预期：答案「2」，使用格子含盘子或不含杯 A。这两问不是 Gate 硬条件，但报告需要各一行，否则空间桶是空的。

### Step 3: 手造 20 张真实图的最小探针（无 GPU 可只标不跑模型）

选 20 张图，覆盖：双同色物体、菜单/发票各 4 张、明显左右关系、桌上缺酒杯的餐饮图。每张图写：指称、OCR 字符串与框、POPE 三问（一正两负，负例一个热门一个共现）。即使没有模型输出，题本本身是交付物。有 2B 级开源 VLM 时，用固定解码（greedy、温度 0）跑同一题本，填列联表。

### Step 4: 负对照，一次一个

对 Step 3 的题本做三种扰动，分别存 run ID：

1. 左右翻转，只看左右题；
2. 遮住被问物体（涂黑框内像素），看 VQA 是否还对：若仍对，语言捷径成立；
3. 打乱 SoM 编号（若你叠了编号），看答案是否跟着编号走。

第 08 课打乱的是 M-RoPE 坐标；本课打乱的是物体标记或像素内容。不要把两次打乱写成同一次消融。

### Step 5: 可选真实权重

若有 1×24GB，拉 Qwen2-VL-2B 或同等开源权重，只跑 Step 3 的题本和 POPE 三档。报 F1、Yes 比例、$R_{\mathrm{hall}}$、REC 的 $\mathrm{Hit}_{0.5}$。禁止把原文 72B 的 96.5 DocVQA 写进你的 2B 表格。HallusionBench 若跑，与 POPE 分列，不合并。

真实权重这条支线的最小日志如下，字段名固定，便于以后和第 24、32 课对照：

```json
{
  "image_id": "probe-014",
  "bucket": "pope-adversarial",
  "question": "图里有酒杯吗？",
  "label": "no",
  "pred": "有",
  "confidence": 0.91,
  "vqa_correct": false,
  "hit": false,
  "attn_mass_on_label_object": 0.0,
  "used_region_ids": ["plate"],
  "decoding": "greedy",
  "notes": "共现负例；模型看盘子"
}
```

`confidence` 若模型不吐概率，填 `null`，不要编一个 softmax。`used_region_ids` 来自框、点、SoM 编号或注意力 argmax，来源写进 `notes`。20 张图 × 每图约 6 题，日志大约 120 行，已经够看出 Yes 比例和右上格，不够写论文，够写本课报告。

Step 3 的 20 张图建议按这个配额抽，避免全是同一场景：同色双物体 4 张，左右关系 4 张，餐饮缺物（POPE 对抗）4 张，合成或真实票据 4 张，纯计数（3 到 8 个同类小物体）4 张。每张图冻结 `image_id` 和像素哈希。改图必须换 id，禁止在同一 id 下修标注。

若 Step 4 的遮挡对照里，涂黑被问杯子之后颜色题仍然答「红」，把该案例的 `notes` 写成 `language_prior_survives_occlusion`。这是[第 16 课](16_multimodal_preference_optimization.md)「必须看见媒体」在空间探针上的对应物：文字答案对遮挡不敏感，视觉就没有进决策。第 16 课用的是偏好对里裁掉媒体；本课用的是涂黑物体。两种扰动都在问同一件事，度量不同，不要把两次实验的数字横着减。

解码必须锁死，否则探针不可复现。默认 greedy、温度 0、不用 nucleus。POPE 是非题若用温度 0.8 采样，Yes 比例会随种子跳。REC 若做 beam search，R@k 才有多个框；greedy 时 R@1 与 R@5 应当接近，Kosmos-2 Table 2 就是这种形态。你若用采样又报 R@5，必须写 beam 或 sample 次数。OCR 字符串匹配前要做的规范化写进协议：空白、全角数字、货币符号。不定规范，exact match 会被「￥128.00」和「128.00」撕开，那是字符串规则问题，不是没看见字形。所有 run 在日志第一行写 `decoding=greedy, temperature=0, match=exact|anls`。

## 9. 评测与测量

所有数字带桶名、样本量、阈值和解码配置。

**必报表：**

1. 列联表：$N$、四格计数、$\mathrm{Acc}_{\mathrm{VQA}}$、$\mathrm{Hit}_{0.5}$ 或 $\mathrm{Hit}_{\mathrm{att}}$。
2. POPE 三档：Accuracy、Precision、Recall、F1、Yes 比例、$R_{\mathrm{hall}}$。
3. OCR：精确匹配或 ANLS，以及区域 IoU 中位数；两列都要。
4. 空间：左右准确率（含翻转对照）、计数准确率（整数）与集合 IoU。
5. 案例：至少 1 条答案对格子错，1 条幽灵肯定，附图像 id 与模型输出原文。

**口径：**

- REC：IoU 阈值 0.5，解码失败记负例，与 Kosmos-2 一致。
- 注意力命中：写清层、是否多头平均、$\tau_a$。
- 计数：整数对不算完，要点或框的集合 Jaccard。
- 幻觉：分母是 $y=0$。正例答 No 是漏检，进 Recall，不进 $R_{\mathrm{hall}}$。
- 小样本：50 图以下只准案例；若坚持写比例，必须同时写 Wilson 或正态近似区间。第 31 课会系统讲区间，本课先禁止把 $N=20$ 的 80% 写成能力证明。

**明确不报成成功的东西：**

- 训练 loss 下降；
- 配文更长、更流畅；
- 与原文 72B 表对比的「我们接近 SOTA」；
- 教学模拟里调低先验后「命中变高」（那是模拟设定）。

样本少时把区间算出来，避免 16/20=80% 看起来像结论。二项准确率的正态近似半宽约为 $1.96\sqrt{p(1-p)/N}$。$N=20$、$p=0.8$ 时半宽约 0.18，区间大约盖住 0.62 到 0.98。这个宽度意味着「看起来像能用」和「几乎随机」在同区间里。Wilson 区间在 $p$ 靠近 0 或 1 时更合适，POPE 对抗档 Acc 接近 0.5 时两种区间差别不大。本课不强制用哪一种，强制的是：N 小于 50 就写区间或改写案例，禁止只写点估计。第 31 课会把区间当成主题，这里只要你不被 20 张图的百分比说服自己。

注意力探针的测量还要固定归因算法。可选三种，一次实验只用一种：

1. 指定层、指定头的跨模态注意力，对答案 token 取平均，再按视觉 token 求和；
2. 所有头平均，其余同上；
3. 梯度类方法（Grad-CAM 等到视觉特征图）。

选定之后写进 `artifacts/lesson23/result.json` 旁的 `protocol.md`：层号、是否平均、是否在 resampler 之前。换层必须换 run ID。质量分数 $h_{\mathrm{att}}$ 的分母是全部视觉位置的注意力和，不要把文本位置算进去，否则分母被 prompt 长度带动，命中阈值会飘。

## 10. 验收条件

本课通过，当且仅当下列全部成立：

## 11. 根据症状定位失败环节

| 症状 | 先查 | 测量 | 处理 |
|---|---|---|---|
| VQA 高、IoU 全接近 0 | 是否在吐框、后处理是否把 loc 解错 | 解码失败率、框面积分布 | 先修解码，再谈能力 |
| VQA 高、IoU 中等、注意力在干扰物 | 同色/共现负对照是否存在 | 列联表右上格 | 加双物体题，不要加学习率 |
| 左右题高、翻转后不变 | 参照系、数据是否含镜像 | 翻转前后同一批题的差 | 镜像增强或把左右桶降权 |
| 计数整数对、点集合空 | 模型只学了数字语言先验 | 集合 Jaccard | 强制先点后数，否则该桶记失败 |
| OCR 字符串对、区域在图外或 IoU 0 | 是否用 caption 当 OCR | 区域列缺失率 | 改题本，禁止字符串-only |
| 小字全错、大标题对 | 回到第 08 课分辨率 | 原图是否被缩小 | 不要在本课解冻 ViT 来「补 OCR」 |
| POPE 随机档还可以、对抗档接近 50%、Yes≈100% | 模型见题就说有 | Yes 比例 | 加负例 SFT，或在解码加「必须看图」约束；先报现象 |
| CHAIR 随指令翻倍 | 用了配文幻觉指标 | 长度、指令原文 | 改 POPE，CHAIR 只作附录 |
| SoM 编号乱跳 | 编号重叠、与画面数字冲突 | 编号碰撞次数 | 换字母标记、重跑分配算法 |
| 2B 真实模型全桶接近随机 | 提示模板、图像预处理 | 空输出率 | 先修推理模板，再下结论说「小模型不会接地」 |
| 框全挤在图像中心 | 位置 token 是否崩到中间箱、坐标是否被归一化两次 | 框中心的均值和方差 | 打印若干 loc id，看是不是总在 $P/2$ 附近 |
| 点选顺序乱、计数却对 | 只学了整数语言先验 | 点序与从上到下的 Kendall 相关 | 打乱点序应让计数头变差，不变则没在用点 |
| HallusionBench 与 POPE 排序相反 | 两个基准问的不是同一件事 | 分列，不合并 | HallusionBench 含图文矛盾与幻觉，POPE 只问物体是否存在 |
| 中文招牌全错、英文 OCR 还行 | 多语 OCR 数据缺失 | 中英分桶 | 不要用 TextVQA 英文分代替中文界面 |
| 同色双物体只在颜色题失败、计数仍对 | 颜色题绑了错误实例，计数用了两只 | 分题记录 used_region | 这是预期分裂，写入列联表即可，不用改学习率 |

## 13. 前沿对照与改造方向

公开方案里，接地已经从「检测器的副产品」变成 VLM 的一等输出。Kosmos-2 用 Markdown 超链接把短语和 loc token 串起来，零样本短语接地 R@1 77.8（Flickr30k Entities val），但短游戏口令型 RefCOCO 只有 52.32。Grounding DINO 在三阶段都做融合，COCO 零样本 52.5 AP、ODinW 26.1，REC 零样本仍然明显弱于微调。Qwen2-VL 用 `[0,1000)` 框和专用分隔符，72B 的 DocVQA 96.5、OCRBench 877、RefCOCO val 93.2，HallusionBench 均分 58.1；它把 OCR、指称、幻觉相关基准拆开报，而不是只报一张 VQA 总表。Qwen2.5-VL 改成绝对坐标、框和点、文档 HTML，CountBench 93.6（detect-then-count），RefCOCO val 92.7。Molmo 用真人点选和「不在图中」负例，把计数写成点链，CountBenchQA 91.2。SoM 则在推理时给 GPT-4V 盖编号，不训练 loc 词表也能做区域级问答。这些系统共享一件本课能学会的事：输出里必须有可核对的空间对象（框、点、编号、mask），文字答案只是其中一列。

规模差距：GrIT 9100 万图、Qwen2-VL 预训练约 1.4 万亿 token、Qwen2.5-VL 约 4.1 万亿、Grounding DINO 的 O365+GoldG+Cap，都不是本课硬件能填的。钱能缩小的是数据和编码器分辨率。机制差距：列联表、POPE 三档、OCR 双列、计数用点集合、负例 1:1，这些不依赖百亿参数。缺它们，70B 模型的均分照样会把右上格藏起来。

动手改造（均另开实验 ID，不改本课主路径阈值）：

1. **位置 token 头。** 在第 22 课得到的小 VLM 上，按 Kosmos-2 格式加 $P=8$ 或 $P=16$ 的 loc 词表（词表增加 $P^2$ 个，不是 1024，除非你真用 $P=32$）。只在短语-框短序列上训投影+lm head。数据：自渲染 2 万合成图（单物体+双同色物体），1×24GB、约 3k–8k step。预期：合成 REC 的 $\mathrm{Hit}_{0.5}$ 从近 0 升到可测；双同色物体上列联表右上格下降。失败判定：位置串解码失败率 >20%，或 VQA 升而 IoU 仍近 0。
2. **POPE 负例 SFT。** 在同一小模型上加 1:1 是否存在题，对抗负例来自共现表。预算：5k 图、单卡数小时。预期：Yes 比例从接近 100% 降到 40%–60% 区间，对抗档 F1 上升。失败判定：随机档 F1 升、对抗档不动，说明只学会了拒答热门词。
3. **SoM vs 连续坐标。** 在 8×8 合成网格上训练两个头：分类 64 个格子编号，回归归一化 $(x,y)$。把测试网格从 8×8 改到等效 4×4 粗块（合并相邻格）。预算：纯合成、CPU 可完成。预期：粗块下回归误差上升大于编号分类误差。失败判定：两种头在粗块下误差相同，先查回归目标是否已被量化成格子中心，那等于偷偷分类。
4. **OCR 双列微调。** 自渲染发票 1 万张，loss = 字符串 CE + 框 L1。预算：1×24GB、与改造 1 同量级。预期：字符串准确率上升时区域 IoU 中位数同步上升。失败判定：字符串升、IoU 不动：模型在背金额模板。

顺手复现映射：

- Kosmos-2「短指称 RefCOCO 弱于长指称 RefCOCOg」：在你的题本里把「左边」短口令和「戴蓝帽穿橙背心的人」长指称分桶。预期同方向，幅度受数据量和 $P$ 限制。
- POPE「随机高于热门、热门高于对抗」：教学网格里酒杯（共现）应比「飞机」（网格中完全不相关）更容易诱出幽灵肯定。玩具模型已按此实现；真实 2B 模型预期同方向，若三档一样高且 Yes 接近 100%，先修拒答，再谈排序。
- Molmo「先点后数优于只出数字」：改造 3 的计数版，强制输出格子列表再写个数。预期集合 Jaccard 高于整数-only。复现不出先查点的顺序是否被打乱。

   - 读完检查：写出从箱子索引还原像素坐标的式子，并说明解码失败为何记负例。
2. [Grounding DINO](https://arxiv.org/abs/2303.05499)

4. [Qwen2-VL](https://arxiv.org/abs/2409.12191)

5. [Qwen2.5-VL](https://arxiv.org/abs/2502.13923)
   - 带着什么问题读：绝对坐标相对归一化坐标改了什么？文档 HTML 如何同时表示字和框？Table 6–7 的 REC、ODinW、CountBench 怎么和 Grounding DINO、Molmo 同表对比？

7. [Set-of-Mark](https://arxiv.org/abs/2310.11441)
   - 带着什么问题读：为什么直接吐坐标会差到 ACC@0.5 25.7？编号写在像素上之后，输出如何映射回 mask？GT mask 把 mIoU 从 75.6 抬到 90.1 说明瓶颈在哪？

复现清单（主路径）：公式手算通过；教学网格两个 Gate 条件勾上；列联表有颜色桶和存在桶；幻觉率分母是负例；引用数字能指回表号；未做 OCR 则写 `ocr-deferred`。缺任一项，本课记未完成。交互实验改先验或提问后必须重新预测再揭晓，禁止看着已经显示的格子补选预测。CPU 实验改公式后必须重新跑 `checks`，禁止手工改 json 里的布尔值。真实权重支线若做了，checkpoint 名、预处理和解码三行缺一不可。这三条审计和第 01 课冻结 hash 的目的相同：结果要能被人复跑，不能只存在于你当时的屏幕上。交作业时把 Gate 截图、`result.json` 和列联表放在同一目录，审阅者应能在不询问你的情况下复现两个假成功案例。若目录里只有均分，打回。假成功案例必须能让第三人按 image_id 或网格坐标找到同一格子，禁止用「大概在左边」这种不可复核的描述。网格案例写行列号，真实图案例写框的四个数字或点的两个数字，单位与预处理一致。数字抄自日志，不要事后目测重画一版框再报 IoU。目测框和模型框必须分列，混在一起会使命中不可审计。审计失败的作业按未完成处理，允许补交，不允许改口径过关。补交只许补日志和案例，不许把阈值从 0.5 改成 0.3 来提高命中，也不许把幻觉率分母改成全部题目。口径改了就不是同一课的验收。

交互实验和 CPU 夹具是同一套故事的两个缩放。网格上杯 A 在 $(0,1)$、杯 B 在 $(4,2)$、盘在 $(4,4)$、叉在 $(5,3)$、苹果在 $(6,1)$、香蕉在 $(6,2)$，没有酒杯。颜色题真值格子是杯 A；先验 $\ge 0.55$ 时玩具模型高亮杯 B，答案仍是「红」。计数题真值是杯 A 与杯 B；高先验时高亮杯 B 与盘，答案仍是「2」。左边题真值是苹果；高先验时高亮香蕉，答案仍是「苹」。是否存在题真值是「无」；高先验时看盘子答「有」，置信度 $0.78+0.18\times\mathrm{prior}$，默认先验 0.70 时约 0.91，超过 Gate 的 0.8。CPU 夹具把杯 A / 杯 B / 盘写成注意力 0.04 / 0.55 / 0.31，质量分数对杯 A 低于 0.5。你在报告里引用教学模拟时写「教学模拟，不是模型输出」；引用 CPU 数字时写公式名和夹具名。两者都证明机制，都不证明 Qwen2-VL-72B 的 93.2 RefCOCO。
